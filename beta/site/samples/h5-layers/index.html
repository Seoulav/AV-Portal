영상 배치 선택

그림을 좌우로 밀어 전체를 확인하세요 ↔

영상은 1개, 사용하는 카드 자원은 1 + 1개.경계에 걸친 부분이 양쪽 카드의 자원을 각각 사용합니다.

카드 A

1 / 16 사용

이 영상만 배치하면 15개 남음

카드 B

1 / 16 사용

이 영상만 배치하면 15개 남음

이 샘플을 읽는 기준

  • 화면의 영상 개수와 카드별 자원 사용량은 서로 다릅니다.
  • 같은 카드 안의 출력 포트 경계는 이 예시의 대상이 아닙니다. 단자 개수를 레이어 수로 계산하지 않습니다.
  • 16칸은 카드당 2K 기준입니다. 실제 사용량은 입력 커넥터 용량 설정, 장착 카드, 전환 방식 등에 따라 확인해야 합니다.
공식 자료와 예시의 근거 보기

공식 사양: 저장된 H5 사양서 V1.17.0의 PDF 4쪽에 카드당 2K 16 / DL 8 / 4K 4, 10쪽에 장치 최대 48이 기재되어 있습니다. 8쪽에는 입력 커넥터 용량 및 페이드 전환 제한이 있습니다.

운용 설명: 서로 다른 출력 카드 영역에 걸친 영상이 양쪽 자원을 소모한다는 예시는 사용자가 제공한 설명을 기준으로 만들었습니다. 공식 문서의 ‘cross-connector output’ 문구를 ‘서로 다른 카드에서도 추가 소모 없음’으로 확대 해석하지 않았습니다. 카드·펌웨어별 세부 적용 조건은 추가 확인 대상입니다.

설명용 화면: 실제 장비의 현재 설정, 출력 포트 배치, 영상 크기·해상도 비율을 재현한 화면이 아닙니다. 남은 자원 수는 다른 영상이 없는 이 예시에 한합니다.
