시리즈 선택

공개 목록의 Analog Way 제품을 시리즈별로 모았습니다.

02

모델 비교

수치는 각 제품의 현재 공개 JSON에서 읽습니다. 출력 커넥터와 실제 프로그램 출력을 구분합니다.

Aquilon의 화면당 레이어는 VPU 1개 예시이며 화면의 절대 상한이 아닙니다. C 시리즈는 주문형(BTO) 최대 구성입니다. Alta·Midra의 화면당 수는 최대 화면 구성 기준이고 한 화면 집중 시 값도 함께 표시합니다.

03

4K 패널 구성 조견표

겹침 없는 동일한 4K60 패널을 배치할 때 필요한 출력과 가능한 모델을 계산합니다.

작은 화면에서는 표를 좌우로 밀어 모델을 확인하세요. 모델 가능 여부는 아래 설계 가이드와 같은 평가 함수로 계산합니다. 출력 4개 이하 그룹의 자원 조견이며, 전체를 단일 화면으로 잇는 구성은 제조사 시뮬레이터에서 최종 확인해야 합니다. 출력 그룹당 믹싱 4개까지는 필요한 VPU 수가 같고, 5개부터 VPU가 추가됩니다(VPU당 소스 링크 8개 · Aquilon 사용설명서 66쪽 · 시뮬레이터 실측 2026-10-17). 4K60 출력 1개는 링크 2개를 사용합니다(사용설명서 61쪽). Midra의 2판 구성은 Eikos 4K 블렌딩만 가능하며, Zenith 100의 프로그램 출력은 최대 3개입니다. C 시리즈는 주문형 최대 구성입니다.
