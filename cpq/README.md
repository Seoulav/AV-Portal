# AV Portal 견적

CPQ는 Configure(구성), Price(가격 계산), Quote(견적 작성)의 약자입니다.

소스 기준은 hkkim0454/AV-CPQ의 7dcb7ab입니다. `UPSTREAM.json`은 선별 반입한 원본 파일별 해시입니다. 카탈로그·판매단가·품셈·노임 및 계산 모듈은 원본을 유지합니다. 연결에 필요한 입력과 배포 경로만 추가합니다.

## 실행 및 검사

- 이 폴더에서 `npm ci`, `npm run dev`를 실행합니다.
- `npm run verify`: 타입·단위/통합 시험·원가 경계 검사.
- `npm run test:e2e`: CPQ 개발 서버의 기존 브라우저 시험.
- 저장소 루트에서 `npm run build --prefix cpq`, `npm run build --prefix builder`, `node beta/build-builder-library.mjs --out beta/site/builder-library.json`을 실행합니다.
- 이 폴더에서 `npm run test:e2e:portal`로 실제 정적 빌드 `/AV-Portal/cpq/` 및 Builder 연계를 검사합니다.
- 루트에서 `node scripts/serve-portal.mjs`를 실행하면 `http://127.0.0.1:4188/AV-Portal/`에서 직접 검토할 수 있습니다.

## 사용

포털의 구성도에서 장비를 배치·연결합니다. 장비를 선택하면 시스템명과 견적 추가 옵션을 입력할 수 있습니다. 옵션은 포털 목록에서 고르며 호환성·단자를 자동 설정하지 않습니다. 적용 버튼으로 저장한 뒤 `견적 만들기`를 누릅니다.

CPQ는 새 견적을 만들며 변경 중인 기존 견적이 있으면 교체 전에 확인합니다. 구성도와 기존 견적을 자동 병합하지 않습니다. 케이블·커넥터는 현행 CPQ 규칙에 따라 첫 시스템에 표시합니다. 미확정 품목과 노무는 사람이 확인할 때까지 Excel 출력을 막습니다.

견적 메뉴 직접 접속, 품목 직접 선택, 구성도 JSON 열기, 작업 파일 저장/열기는 그대로 사용할 수 있습니다. 견적은 브라우저에 자동 저장하지 않으므로 새로고침 전에 작업 파일로 저장하세요. 팝업 차단 시 팝업을 허용하거나 구성도 JSON 내보내기/열기를 사용하세요.

## 원가·배포 경계

구성도만 허용 필드로 복사하여 같은 origin의 확인된 창에 메모리 메시지로 전달합니다. 원가·견적 문서를 메시지로 보내지 않고 URL에도 넣지 않습니다. 원가는 기존 CPQ 메모리 세션에서 처리하고 사용자가 확인한 영업팀용 Excel에만 포함할 수 있습니다. Portal/Builder의 자동 저장 코드를 CPQ에 불러오지 않습니다.

승인 자산만 빌드합니다. `.local`, 업로드, 고객 파일, 원가표, 로그 및 생성된 시험 Excel은 반입·배포 대상이 아닙니다. 템플릿 생성과 카탈로그 재생성은 원본 프로젝트 업무이므로 로컬 비공개 자료에 의존하는 명령은 이 패키지에 제공하지 않습니다.

이번 통합은 공개 배포 전 검토 상태입니다. main 병합은 Pages 배포를 촉발하므로 결과 보고 전에는 병합하지 않습니다.
