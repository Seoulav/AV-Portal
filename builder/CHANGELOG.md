# Changelog — AV System Builder (AV Portal)

## [v0.6.0] — 2026-10-07

[B-20261006-09](../Work/빌더/작업/B-20261006-09.md). P5의 4차로 구 Builder의 메모·영역 서식 편집과 테마를 옮겼다(seoul-visual-tech/av-system-builder `2fd568e`의 `EditAnnotationModal.tsx`, `AnnotationNode.tsx`, `ShapeNode.tsx`, `index.css`).

### Added
- 메모·영역 서식 패널: 메모나 영역을 하나만 고르면 오른쪽 패널이 서식 편집이 된다(결정 L-b). 항목·색 프리셋·빠른 서식 4종은 구 Builder와 같다(결정 L-c)
  - 메모: 글(여러 줄)·글자 크기와 색·바탕색과 투명도·테두리 색과 모양·모서리 둥글기·정렬. 영역: 이름·모양(사각형·둥근 사각형·원)·테두리 굵기
  - "적용"이 실행 취소 한 단위다. 바뀐 것이 없으면 기록하지 않는다. 1.1 서식 키만 쓰고 숫자는 범위 안으로 맞춘다
- 크기 바꾸기(React Flow `NodeResizer`): 메모 최소 60×30, 영역 최소 80×80. 바뀐 크기는 파일의 `style`에 남고 한 번 끌기가 실행 취소 한 단위다
- 고정(1.1 `data.locked`): 고정한 메모·영역은 끌거나 크기를 바꾸지 못한다
- 다크/라이트 테마: 상단 막대 "어두운 테마". 화면 색을 CSS 변수로 모으고 구 Builder 다크 값을 바탕으로 어두운 값을 뒀다. React Flow `colorMode`도 함께 바꾼다. 처음은 밝은 테마(결정 L-a), 고른 값은 브라우저에만 남는다
- vitest 10건(서식 적용·값 정리·빈 숫자 칸·손대지 않은 적용·내보내기 검증, 크기 바꾸기 실행 취소·누르기만 한 손잡이·측정은 기록 안 함, 두 번 누르기, 테마), Playwright 3건(메모 서식·되돌리기·초점, 영역 원·크기·최소 크기·고정, 테마 유지)

### Changed
- 메모·영역 모양을 구 Builder와 같게 그린다: 바탕과 테두리를 한 겹에 그려 투명도를 함께 준다. 테두리 "없음"을 지원한다. 영역 이름은 가운데 대문자다
- 메모·영역을 두 번 누르면 입력 창 대신 서식 패널의 글 칸으로 간다
- 전체 잠금(B-08) 중에는 메모·영역의 크기도 바꾸지 못한다(구 Builder는 잠금 중에도 크기를 바꿀 수 있었다)

### Fixed
- 원 모양 영역에서 모서리의 크기 손잡이가 잘려 잡히지 않던 문제(구 Builder에도 있던 `overflow: hidden`)를 고쳤다
- 어두운 테마에서 경고 알림 글자와 고른 연결의 테두리가 바탕에 묻히던 문제를 고쳤다

## [v0.5.0] — 2026-10-07

[B-20261006-08](../Work/빌더/작업/B-20261006-08.md). P5의 3차로 구 Builder 상단 막대의 편집 도구를 옮겼다(seoul-visual-tech/av-system-builder `2fd568e`의 `layout.ts`, `App.tsx`, `EquipmentNode.tsx` LOD).

### Added
- 오토 레이아웃(구 `getLayoutedElements`): Dagre로 신호 흐름 열을 정하고, 열마다 barycenter 교대 스윕 2회, 열 안 최소 간격 40px
  - 무작위 장면 300개(장비 1,672대)에서 구 Builder와 좌표가 모두 같다. 표본 4개를 회귀 시험으로 둔다
  - 노드·엣지를 id 순으로 맞춰 계산해, 다시 연 파일도 같은 배치가 나온다
  - `dagre@0.8.5`(구 Builder와 같은 판)를 버튼을 누를 때 불러온다. 첫 화면 번들에 넣지 않는다(결정 K-a)
- 복사·붙여넣기(Ctrl+C·V): 고른 장비·메모·영역과 그 사이 연결(라벨·케이블 포함). 연결은 엔진으로 다시 만든다. 붙일 때마다 40px씩 더 옮긴다(결정 K-b). 몇 칸 옮길지는 그 자리가 비었는지로 정해, 붙여넣기를 되돌리면 그 자리가 다시 빈다
- 잠금(장비 끌기 막기), 격자 맞춤 15px, 미니맵
- 선 종류 필터: 도면에 쓰인 선 종류 칩(결정 K-c). 숨긴 연결과 보이는 연결이 없는 장비를 숨긴다(결정 K-d). 간격은 모든 연결로, 교차 점프는 보이는 연결로 계산한다(B-07 리뷰 7번)
  - 숨긴 장비에는 선이 붙지 않고, 범위 선택에 그 단자가 들지 않으며, 골라진 채로 남지 않는다
  - 숨긴 종류는 연결을 다 지워도 칩이 남는다. 숨긴 종류의 연결을 새로 그으면 그 종류를 다시 보인다
  - 이슈에서 숨긴 대상을 누르면 필터를 푼다. 필터 때문에 새 장비나 붙인 장비가 숨으면 알린다
- LOD: 줌 0.55 미만에서 모델명 덮개, 0.3 미만에서는 모델명만. 줌마다 노드를 다시 그리지 않게 CSS 변수로 바꾼다
- vitest 18건(오토 레이아웃 9: 구 Builder 표본 4·신호 흐름·barycenter·최소 간격·순서 무관·실행 취소, 복사·필터 9), Playwright 7건(오토 레이아웃·복사·잠금과 격자·미니맵·필터·필터와 교차 점프·LOD)

### Changed
- 장비 노드에 LOD 덮개를 더했다(포인터를 받지 않아 단자 행과 근접 연결은 그대로다)
- 단축키 처리에서 contenteditable 안의 입력도 가로채지 않는다. Ctrl+C는 캔버스 밖에 골라 둔 글이 있을 때만 브라우저 복사로 둔다
- 상단 막대 버튼과 필터 칩은 눌러도 초점을 가져가지 않는다. 초점이 남으면 Space(화면 이동)를 놓을 때 그 버튼이 다시 눌렸다

## [v0.4.0] — 2026-10-07

[B-20261006-07](../Work/빌더/작업/B-20261006-07.md). P5의 2차로 구 Builder의 선 그리기를 옮겼다(seoul-visual-tech/av-system-builder `2fd568e`의 `edgeProcessing`·`edgeGeometry`·`CustomSmoothstepEdge`).

### Added
- 평행선 간격·채널 순서(Stage 0~4, `optimizeChannelOrder`)
  - 같은 쌍, 모이는 선, 퍼지는 선, 그 밖의 겹침, 전체 세로 통로 충돌을 구 Builder와 같은 규칙으로 띄운다
  - 무작위 장면 200개(엣지 1,949개)에서 구 Builder와 같은 값이 나오는 것을 확인했고, 표본 3개를 회귀 시험으로 둔다
  - 계산 전에 엣지를 id 순으로 맞춘다. 같은 조건끼리의 순서가 결과를 바꾸는데, 내보낸 파일은 엣지를 id 순으로 적으므로 다시 열어도 선이 같은 자리에 그려진다
- 직교 경로와 교차 점프: 앞으로 가는 선은 가로-세로-가로, 뒤로 가는 선은 아래 U자 우회. 교차하는 곳은 가로선이 반원으로 넘는다. 모서리는 둥글다
- 양방향끼리 이은 선은 장비 좌우 위치에 맞게 뒤집어 그린다(`normalizeBidiEdges`). 저장된 source·target은 그대로다
- 엣지 라벨은 줌아웃해도 읽히게 역으로 키운다(구 Builder와 같은 식)
- 케이블 보기(구 Builder BOM 모드): 연결 라벨에 케이블 요약을 보이고, 케이블이 없으면 "⚠ 미입력"과 흐린 선
- 엣지 선택·호버 표시: 무채색 테와 굵은 선(케이블 색과 겹치지 않게, 구 Builder 규칙). 선 굵기는 엣지에 직접 적힌 값보다 앞서도록 `!important`로 둔다
- vitest 11건(구 Builder 표본 대조 3, 엣지 순서와 무관, 모이는·퍼지는 선, 같은 쌍, 양방향 뒤집기, 경로·점프, 케이블 요약), Playwright 6건(세로 구간 겹침 없음, 교차 점프, 양방향 선 다시 그리기, 양방향 미리보기, 선택 굵기, 케이블 보기)

### Changed
- B-06의 간단한 평행 간격(`edgeSpacing.ts`)을 지우고 위 알고리즘으로 바꿨다(결정 J-a)
- 연결 미리보기(한 줄·묶음)도 이미 있는 연결과 함께 간격을 계산하고, 양방향끼리면 놓은 뒤와 같은 방향으로 그린다. 고리는 놓은 뒤 선이 닿을 점에 보인다
- 교차 점프는 엣지마다 다른 엣지 전체와 견주던 구 Builder 방식 대신, Canvas가 한 번에 구한다(세로 구간 색인)
  - 엣지 600개에서 교차 점프 계산만 한 프레임 142ms였던 것이 3ms가 됐다. 구성도 좌표를 쓰므로 React Flow 내부 좌표를 앱에서 읽지 않는다
- 장비를 끄는 동안에는 간격을 끌기 시작 때 값으로 두고, 놓을 때 다시 계산한다(결정 J-c). 끝점과 교차 점프는 매 순간 바뀐다
- 끌기 중에 바뀌지 않은 노드·엣지는 앞의 화면용 객체를 그대로 넘긴다. 이슈 목록은 이슈가 바뀔 때만 다시 그린다
  - 장비 50대·엣지 150개에서 끌기 한 프레임(중앙값)이 B-06의 66ms에서 33ms가 됐다. 같은 PC에서 Chrome으로 쟀다
  - 장비 150대·엣지 600개는 133ms에서 116ms로 줄었으나 아직 끊긴다. 앱의 계산(교차 점프 3ms, 끝점 0.4ms)은 작고, 나머지는 화면 그리기 쪽이다(따로 나눠 재지는 않았다). 명세의 이 완료 조건은 충족하지 못했다

## [v0.3.0] — 2026-10-07

[B-20261006-06](../Work/빌더/작업/B-20261006-06.md). P5의 1차로 평행선 한꺼번에 긋기를 만들었다(통합 기획 §7.3).

### Added
- 단자 고르기
  - 범위 선택이 점이 사각형 안에 들어온 단자를 함께 고른다
  - 단자 행을 누르면 그 단자만 고르고, Shift+누르면 더하거나 뺀다. Esc나 빈 곳 누르기로 모두 푼다
  - 고른 단자는 점에 2px 파란 테, 이름을 강조색으로 보인다
- 평행선 한꺼번에 긋기
  - 고른 단자 하나에서 끌면 같은 종류(출력·입력·양방향)의 고른 단자가 묶음이 된다(결정 I-a)
  - 놓은 단자부터 대상 장비의 같은 열 아래로 차례로 잇고, 이미 연결됐거나 막힌 단자는 건너뛴다. 다른 장비로는 넘어가지 않는다(결정 I-b)
  - 신호가 다른 단자가 묶음에 섞여도 그 단자만 빠지고(이유: 신호 불일치) 나머지는 잇는다
  - 대상 단자는 묶음을 대표하는 단자(아직 연결되지 않은 첫 단자)로 정한다. 끌고 있는 단자가 이미 연결돼 있어도 나머지는 잇는다
  - 끄는 동안 쌍마다 미리보기 선과 고리, 커서 옆에 "잇는 수/묶음 수" 배지를 보인다. 짝이 없는 단자는 붉은 점선이다
  - 모자라면 "N개 중 M개 연결"과 이유를 알린다(C1). 묶음 연결은 실행 취소 한 번에 모두 사라진다
- 평행 간격: 같은 두 장비 사이 엣지의 꺾이는 위치(`stepPosition`)를 띄워 겹치지 않게 그린다. 도착이 왼쪽인(뒤로 가는) 엣지는 `offset`을 띄운다. 미리보기도 기존 엣지와 함께 같은 간격으로 그린다. 화면에만 쓰고 파일에는 남지 않는다(결정 I-c)
- vitest 13건(묶음·짝짓기·신호 섞임·연결된 단자에서 끌기·입력 쪽 묶음·몸체에 놓기·평행 간격·한 번에 실행 취소·선택 색인), Playwright 4건(범위 선택 묶음, Shift+누르기·건너뛰기·모자람, 선택 풀기, Shift+누르기 미끄러짐·같은 행에서 끌기 취소)

### Changed
- 범위 선택으로 단자도 고르므로, 범위 선택 직후 고른 단자를 끌면 묶음 연결이 된다. 하나만 그으려면 Esc로 단자 선택을 푼다. 장비를 끌어 옮기기 시작하면 단자 선택은 풀린다
- 단자 핸들에 React Flow `nokey`를 붙였다. Shift(범위 선택 키)를 누른 채 단자를 눌러도 범위 선택이 시작되지 않는다

- 엔진 `geometry.portAnchors`(단자 끝점 좌표), `HANDLE_SIZE`·`HANDLE_OUTSET`
- 검증 오류 `bom-row-invalid`. 기성 수량은 1 이상 정수, 제작 길이는 0보다 큰 수, 제품명이 있어야 한다. 화면과 CLI가 같은 함수(`bomRowProblem`)를 쓴다
- Playwright 브라우저 시험 11건(`npm run e2e`, 합성 라이브러리). Builder CI에서 돈다

### Changed
- 장비는 헤더·사진으로만 옮긴다. 단자 행은 선 긋기 영역이다
- 선 긋기는 4px 넘게 움직여야 시작한다. 단자를 눌러서 연결하는 방식(click-to-connect)은 끈다
- 엣지 선택을 여러 개로 들고 있는다. 연결 편집 패널은 연결을 하나만 골랐을 때 열고, 닫기 버튼으로 이슈 목록으로 돌아간다
- 범위 선택 뒤 React Flow가 고른 장비들 위에 덮던 사각형을 없앴다. 그 위에서는 단자 행으로 선을 그을 수 없었다. 여러 장비는 고른 장비의 헤더를 끌어 함께 옮긴다
- 새 구성도의 `generator.version`은 `builder/package.json` 버전(0.2.0)이다. 연 파일의 값은 그대로 둔다(다시 내보내도 같은 파일)
