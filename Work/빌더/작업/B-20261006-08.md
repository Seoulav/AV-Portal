## 목표

**지금:** 장비 배치·연결·선 그리기는 구 Builder와 같은 수준이 됐다(B-04~07). 구 Builder 상단 막대의 편집 도구는 아직 없다.

- 장비가 많으면 손으로 배치해야 한다.
- 같은 묶음을 다시 만들려면 장비와 연결을 처음부터 다시 놓아야 한다.
- 배치를 마친 도면을 실수로 끌어 흐트러뜨릴 수 있다.
- 큰 도면에서 신호 한 종류만 보거나, 줌아웃해 장비를 알아보기 어렵다.

**이 작업이 끝나면:** 구 Builder(`seoul-visual-tech/av-system-builder` `2fd568e`)의 다음 편집 도구가 같은 동작으로 들어간다. 파일 형식은 바꾸지 않는다. 도구의 켜고 끈 상태는 파일에 남기지 않는다.

1. **오토 레이아웃.** Dagre로 신호 흐름을 왼쪽에서 오른쪽으로 놓고, 열마다 barycenter로 순서를 다듬는다(구 `src/utils/layout.ts`).
2. **복사·붙여넣기.** Ctrl+C·Ctrl+V로 고른 장비·메모·영역과 그 사이의 연결을 복제한다(구 `App.tsx:152-240`).
3. **잠금.** 장비를 끌어 옮기지 못하게 한다(구 `nodesDraggable`).
4. **격자 맞춤.** 장비를 15px 격자에 맞춰 놓는다(구 `snapGrid`).
5. **미니맵.** 오른쪽 아래에 전체 도면을 작게 보이고, 눌러 화면을 옮긴다(구 `MiniMap`).
6. **선 종류 필터.** 선 종류 칩을 눌러 그 종류의 연결을 숨긴다. 필터가 켜지면 보이는 연결이 없는 장비도 숨긴다(구 `hiddenLineTypeIds`, B-07 리뷰 7번).
7. **LOD.** 줌아웃(0.55 미만)하면 장비 위에 모델명을 크게 덮어 보인다. 0.3 미만에서는 모델명만 보인다(구 `EquipmentNode` LOD 오버레이).

## 범위

### 할 것

1. **오토 레이아웃** (`builder/src/layout.ts`)
   - 구 `getLayoutedElements`를 옮긴다. 노드 크기는 엔진 `geometry`(`NODE_WIDTH`·`nodeHeight`)를, 단자 높이는 `portAnchors`를 쓴다.
   - 그래프 설정은 구와 같다: `rankdir LR`, `nodesep 90`, `edgesep 30`, `ranksep 280`, 여백 50.
   - 신호선(`sdi`·`video`·`audio`·`usb`)은 가중치 3·`minlen 1`로 열을 정하고, 그 밖의 선은 가중치 1·`minlen 0`이다. 신호선이 없으면 모든 선을 가중치 1로 쓴다.
   - 열 묶기(열 너비 `NODE_WIDTH + 40`), barycenter 교대 스윕 2회, 열 안 최소 간격 40px까지 같다.
   - 장비만 옮긴다. 메모·영역은 그대로다. 실행 취소 한 번으로 되돌린다. 끝나면 화면을 도면에 맞춘다.
   - Dagre(`dagre@0.8.5`, 결정 K-a)는 버튼을 누를 때 불러온다(첫 화면 번들에 넣지 않는다).
2. **복사·붙여넣기**
   - 고른 장비·메모·영역과, 양 끝이 모두 고른 장비인 연결을 앱 안 클립보드에 담는다. 시스템 클립보드는 쓰지 않는다(구와 같다).
   - 붙여넣으면 새 id로 복제하고 40px 오른쪽 아래에 놓는다. 붙여넣은 것이 새 선택이 된다. 실행 취소 한 번으로 되돌린다.
   - 연결은 엔진 `connectPorts`로 다시 만든다. 라벨과 케이블(`bomRows`)도 복사한다.
   - 입력칸에서 누른 Ctrl+C·Ctrl+V는 가로채지 않는다.
3. **잠금·격자·미니맵** (상단 막대 버튼)
   - 잠금: 장비·메모·영역을 끌지 못한다. 연결 긋기·지우기·편집은 그대로다(구와 같다). 잠긴 동안 캔버스 테두리에 붉은 안쪽 그림자를 둔다.
   - 격자: React Flow `snapToGrid`, 15px.
   - 미니맵: 200×130, 오른쪽 아래, 확대·이동 가능. 장비·메모·영역 색을 구와 같게 둔다.
4. **선 종류 필터**
   - 상단 막대에 칩을 둔다. 칩은 선 종류 이름과 색 점이다. 누르면 숨기고 다시 누르면 보인다.
   - 숨긴 연결은 그리지 않는다. 파일·이슈·실행 취소에는 영향이 없다.
   - 평행선 간격은 모든 연결로 계산하고(숨겨도 다른 선이 움직이지 않는다), 교차 점프는 보이는 연결로만 계산한다(구와 같다).
   - 필터가 하나라도 켜지면 보이는 연결이 없는 장비를 숨긴다. 메모·영역은 그대로 보인다.
   - 숨긴 연결이 골라져 있으면 선택을 푼다.
5. **LOD** (`EquipmentNode`)
   - 줌 0.55 미만: 장비 위에 모델명(글자 `9/줌`, 13~44px)과 장비 이름(`6.5/줌`, 10~26px)을 덮는다. 0.3 미만에서는 장비 이름을 뺀다.
   - 덮개는 포인터를 받지 않는다. 단자 점과 근접 연결은 그대로 동작한다.
6. **시험**
   - vitest: 레이아웃(신호 흐름 순서, barycenter로 입력 순번대로 정렬, 최소 간격, 메모·영역 고정), 구 Builder `layout.ts`와 같은 입력에 같은 좌표(표본 대조), 복사·붙여넣기(새 id, 안쪽 연결만, 케이블 복사, 실행 취소 한 번, 검증기 통과), 필터(간격 불변, 점프는 보이는 선만).
   - Playwright: 오토 레이아웃 뒤 실행 취소, Ctrl+C·V, 잠금 중 끌기 무시, 격자 좌표, 미니맵 표시, 필터 칩으로 연결·장비 숨김, 줌아웃 LOD 덮개.
7. **문서**: `builder/README.md`, `builder/CHANGELOG.md` v0.5.0, 통합 기획 §8 이식 상태, 이 작업 파일, `Work/빌더/README.md`

  - 숨긴 장비는 React Flow에 `hidden`·고를 수 없음으로 넘긴다(화면용 객체에만). 그래서 Delete·범위 선택·미니맵에서 빠진다.
  - 근접 연결·묶음 놓기·미리보기·범위 선택 단자 고르기는 `visibleNodes`로 숨긴 장비를 뺀다(리뷰 1).
- **LOD**: 줌을 읽는 작은 컴포넌트(`LodLevel`)가 React Flow 바탕에 `data-lod`와 글자 크기 변수를 단다. 노드는 줌마다 다시 그려지지 않는다.
- **알려진 한계(구 Builder와 같다)**: 같은 두 장비를 신호선과 네트워크선이 함께 이으면 Dagre 그래프에는 장비 쌍마다 선 하나만 남는다. 나중에 넣는 네트워크선 설정(가중치 1, `minlen 0`)이 남아 두 장비가 가깝게 놓인다(리뷰 9, 예: 500px 대신 360px). 고치면 구 Builder와 좌표가 달라지므로 그대로 둔다.
- **명세와 다르게 한 것**
  - 숨긴 종류의 연결을 새로 그으면 그 종류를 다시 보인다. 그은 선이 바로 사라지면 연결이 안 된 것처럼 보인다.
  - 이슈에서 숨긴 대상을 누르면 필터를 푼다.
  - 숨겨 둔 종류는 연결이 없어도 칩을 남긴다(K-c 보완, 리뷰 2).
- **끌기 성능(같은 조건 비교)**: B-07 빌드와 이 작업 빌드를 같은 PC에서 연달아 쟀다(Chrome, 한 프레임 중앙값).

  | 장면 | B-07 빌드 | B-08 빌드 |
  |---|---|---|
  | 장비 50대·엣지 150개 | 16.7ms | 16.7ms |
  | 장비 150대·엣지 600개 | 49.9ms | 49.9ms |

  - 이 작업으로 느려지지 않았다. 150개는 화면 갱신 한계(60fps)에 붙어 있고, 600개는 아직 초당 20장 정도다.
  - B-07 기록의 값(33ms·116ms)보다 빠르게 나왔다. 같은 빌드가 측정 때마다 다르게 나온 것이라 PC 상태 차이로 본다.
