# B-20261016-02 — 빌더 전용 일반 장비: 소스 기기 PC·노트북

- 상태: 검토

- 작성일: 2026-10-16
- 사용자 요청: 2026-10-16 **"AV빌더에 PC/노트북 추가넣어줘 그래야 구성도에 소스기기로 사용할 수 있어"**
- 승인(2026-10-16, 선택지 응답):
  - 넣는 방식: **"빌더 전용 '일반 장비'로 추가"** (Portal 목록에는 나타나지 않고 빌더 장비 목록에만, 견적 장비 행 없음, 규칙 예외로 기록)
  - 단자: **"HDMI 또는 DP를 내가 직접 선택해서 불러오면 좋겠어"**

## 배경

[통합 기획](../../기획/시스템빌더통합기획-2026-10-06.md) §0 3차 결정은 "장비는 Portal 제품만 쓴다"였다.
PC·노트북은 특정 제조사 제품이 아니어서 Portal에 없고, 구성도에서 영상 소스를 그릴 수 없었다.
이번 결정으로 **PC·노트북 두 종류만** 예외로 둔다. 통합 기획 §0과 AGENTS.md에 예외를 기록했다.

## 한 일

| 항목 | 내용 |
|---|---|
| 장비 목록 | "소스 기기" 묶음에 PC·노트북. 각각 **HDMI 출력판·DP 출력판**을 골라 놓는다(+ 버튼·끌어 놓기) |
| 배치 단위 | `generic-pc:hdmi`·`generic-pc:dp`·`generic-laptop:hdmi`·`generic-laptop:dp`. 모델 표시는 `PC (HDMI)` 등 |
| 단자 | 고른 영상 출력 하나: `out-hdmi-1`(HDMI, 선 종류 HDMI) 또는 `out-dp-1`(DP, 선 종류 DP). 더 필요하면 장비 설정 창에서 더한다 |
| 구성도 JSON | 노드 `portal: { productId: "generic-pc", source: "builder", detailUrl: "" }`(HDMI·DP 구분은 노드 `id`·`model`). 단자 `verification: "GENERIC"`(빌더 표준 단자라 확인 배지·미확인 경고를 내지 않는다). 스키마 `portal.source` enum에 `builder` 추가(필드 값 추가만, 1.1 호환 유지) |
| Portal 반영 요청 | 만들지 않는다. 설정 창에서 내보내기 버튼을 숨기고, 엔진도 `generic-equipment`로 거절한다 |
| 견적 앱 | `portal.source === "builder"` 노드는 장비 행·미등록 경고·시스템을 만들지 않는다. 연결선 케이블은 그대로 산정 |
| 장비 목록 아래 집계 | "Portal 제품 N종"은 일반 장비를 빼고 센다 |

Portal 데이터(`beta/site/`)와 라이브러리 생성기는 바꾸지 않았다. 일반 장비는 빌더가 라이브러리를 읽을 때(`createLibraryIndex`) 붙인다.
