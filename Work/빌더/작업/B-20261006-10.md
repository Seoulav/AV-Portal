## 목표

**지금:** 구성도는 JSON 파일로만 내보낸다. 견적·시공 담당자에게 도면을 보여 주려면 화면을 캡처해야 한다.

구 Builder(`2fd568e`)는 "PDF"를 눌러 **화면을 PNG 한 장으로 찍어** PDF에 붙였다(`App.tsx:536-568`, `html-to-image` + `jsPDF`). 그래서 다음 문제가 있었다.

- 확대하면 흐려진다. 글자를 고르거나 찾을 수 없다
- 화면 크기·줌·테마에 따라 결과가 바뀐다
- 화면 밖 장비는 빠질 수 있다(찍기 전 화면 맞춤에 의존)

**이 작업이 끝나면:** 상단 막대의 "SVG"·"PDF"로 도면을 받는다.

1. **SVG**: 구성도 데이터(엔진 좌표)로 직접 그린 벡터 도면이다. 장비 상자·모델명·단자 이름·단자 점, 연결선(B-07과 같은 경로·간격·교차 점프), 연결 라벨, 메모·영역이 들어간다. 화면 상태(줌·선택·필터·테마)와 무관하게 늘 같은 결과다.
2. **PDF**: 같은 SVG를 벡터 그대로 PDF로 옮긴다. 글자를 고르고 찾을 수 있다.

## 범위

### 할 것

1. **SVG 그리기** (`builder/src/export/diagramSvg.ts`, 순수 함수)
   - 입력: 구성도(1.2)와 선 종류 색. 출력: SVG 문자열. 브라우저 화면(DOM)을 읽지 않는다.
   - 좌표는 엔진 `geometry`, 선은 `edges/edgeProcessing`·`edgeGeometry`를 그대로 쓴다. 화면과 같은 선 모양이 나온다.
   - 장비: 상자, 제조사·모델명·장비 이름, 단자 행(이름·점·색), 양방향 구획. 사진은 결정 M-c를 따른다.
   - 연결: 선 종류 색, 라벨(있으면), 케이블 요약은 넣지 않는다(화면의 "케이블 보기"와 같은 선택은 결정 M-d).
   - 메모·영역: 서식 그대로(B-09 그리기와 같은 규칙).
   - 도면 범위는 모든 노드를 감싸는 상자 + 여백이다.
2. **PDF** (`builder/src/export/diagramPdf.ts`)
   - SVG를 벡터로 옮긴다(결정 M-a). PDF 생성 라이브러리는 누를 때 불러온다(첫 화면 번들에 넣지 않는다, B-08의 Dagre와 같다).
   - 한글 글꼴을 넣는다(결정 M-e). 넣지 않으면 PDF에서 한글이 깨진다.
3. **상단 막대**: "SVG", "PDF" 버튼(또는 내보내기 메뉴). 파일 이름은 JSON 내보내기와 같은 규칙(`구성도-YYYYMMDD-HHmm`).
4. **시험**
   - vitest: SVG가 모든 장비·연결·메모를 담는다, 선 경로가 화면 경로와 같다, 결과가 결정적이다(같은 입력 → 같은 문자열), 필터·선택·테마와 무관하다, XML로 읽힌다(특수 문자 이스케이프 — `&`·`<`가 든 모델명·라벨).
   - Playwright: 버튼을 눌러 파일을 받는다, PDF 첫 쪽 크기·글자 추출(한글 포함).
5. **문서**: `builder/README.md`, `builder/CHANGELOG.md` v0.7.0, 통합 기획 §8 이식 상태, 이 작업 파일, `Work/빌더/README.md`

### 하지 않을 것

- PNG 내보내기(구 방식). 필요하면 SVG를 이미지로 바꾸는 별도 작업으로 한다
- 케이블 목록·BOM 표를 PDF에 붙이기(견적 범위, 통합 기획 §8 "보류")
- 여러 쪽 나누기·인쇄 축척 지정
- 구성도 파일 형식 변경

### 지킬 결정

- 1.1 호환 JSON. 이 작업은 파일을 바꾸지 않는다
- 공개 저장소 규칙: PDF·SVG 결과물과 실제 구성도는 커밋하지 않는다. 시험은 합성 픽스처로 한다

### 구현 메모

- **파일**
  - `builder/src/export/diagramSvg.ts`: 도면 SVG. 화면(DOM)을 읽지 않는 순수 함수다
  - `builder/src/export/diagramPdf.ts`: PDF. `jspdf` 4.2.1 + `svg2pdf.js` 2.8.1(둘 다 MIT). 누를 때 불러온다
  - `builder/public/fonts/`: Pretendard Regular 원본(SHA-256 `6d0af5258997aec7354a6e340fc2325ba321c410ca48b3af858c8c3d6e92a324`, v1.3.9 릴리스의 `public/static/alternative/Pretendard-Regular.ttf`)과 `OFL.txt`(Portal `beta/site/fonts/OFL.txt`와 같은 문서, 원저작 글꼴들의 저작권 표시 포함)
  - `builder/src/export/unusedPdfFeature.ts`·`vite.config.ts`: jsPDF의 선택 모듈(html2canvas·dompurify·canvg)을 빈 모듈로 바꿔 뺀다. 도면 내보내기는 그 기능을 쓰지 않는다
- **그리기**: 엔진 `geometry`(장비 치수·단자 높이), B-07 선 계산(`normalizeBidiEdges` → `edgeOffsets` → `edgeJumps` → `buildOrthogonalPath`), B-09 메모·영역 서식을 그대로 쓴다. 노드는 영역 → 선 → 라벨 → 장비 → 메모 순(화면과 같은 겹침), 각각 id 순이다.
- **결정성**: 노드·엣지를 id 순으로 그리고, 선 좌표는 0.1 단위, 그 밖의 수는 0.01 단위로 적는다. 화면 상태(선택·끌기·필터·테마)는 읽지 않는다.
- **글자 폭**: Pretendard Regular 실측(ASCII 95자 표, 한글 0.864em). 넘치는 이름은 가운데를 줄여 끝 번호를 남긴다.
- **PDF 글자 자리**: svg2pdf는 가운데·오른쪽 맞춤 글자의 폭을 브라우저에서 잰다. 같은 글꼴 바이트를 `BuilderPdfFont` 별칭으로 브라우저에 올려 잰 폭과 그린 폭을 맞춘다(화면 CSS의 Pretendard와 이름이 달라 화면 글꼴은 그대로다).
- **빠지는 글자**: jsPDF 글꼴의 문자표로 SVG의 모든 글자를 미리 확인해, 없는 글자를 알린다(예: 한자 `確認`).
- **크기**: 첫 화면 JS 503.05kB(gzip 161.58kB, B-09보다 약 11.7kB 늘어남 — SVG 그리기). PDF 묶음 486.98kB(gzip 154.91kB)와 글꼴 2.7MB는 누를 때만 받는다.
- **명세와 다르게 한 것**
  - M-e: 글자를 줄인 사본 대신 원본 전체판을 넣었다(위 결정 표 아래 설명).
  - 확인이 필요한 단자의 "확인" 배지를 넣었다(화면과 같다, 리뷰 9).
- **알려진 한계**
  - 글꼴에 없는 글자(한자·이모지·일부 기호)는 PDF에서 빠진다. 만든 뒤 알린다.
  - SVG를 다른 프로그램에서 열면 그 PC의 글꼴로 그려 글자 폭이 조금 다를 수 있다(PDF는 글꼴을 담아 같다).
  - svg2pdf는 `letter-spacing`을 쓰지 않아 PDF의 영역 이름 자간이 SVG보다 좁다.

| 2 | 중간 | svg2pdf가 가운데·오른쪽 맞춤 글자 폭을 사용자 PC 글꼴로 재서 PDF에서 자리가 어긋난다 | 같은 글꼴 바이트를 별칭으로 브라우저에 올려 잰다. PDF 그림으로 오른쪽 맞춤 단자 이름이 점 앞에서 맞는 것을 확인 |
| 3 | 중간 | XML이 허용하지 않는 제어 문자(붙여 넣은 세로 탭 등)가 SVG를 깨뜨리고, PDF는 일부만 그려질 수 있다 | 제어 문자를 뺀다. PDF는 SVG를 읽지 못하면 멈추고 알린다. vitest 1건 |
| 4 | 중간 | 글꼴에 없는 글자(한자·이모지)가 PDF에서 말없이 빠진다 | 미리 찾아 PDF를 만든 뒤 알린다. e2e(`確認`이 빠진다는 알림) |
| 5 | 중간~낮음 | 상자를 넘치는 메모 글이 잘리지 않고 도면 밖으로 나간다 | 메모마다 clipPath로 자른다(화면 `overflow: hidden`과 같다). vitest 1건 |
| 6 | 낮음 | 가져온 파일의 메모 서식 값 형식이 틀리면(`fontSize: null`, 숫자 라벨) SVG 만들기가 멈추고 아무 말이 없다 | 값마다 형식을 보고 기본값을 쓴다. SVG 버튼도 실패를 알린다. vitest 1건 |
| 7 | 낮음 | 승인된 M-e(줄인 글꼴)와 다르게 원본 전체판을 넣었다 | 결정 표 아래에 근거를 적었고 사용자에게 알린다 |
| 8 | 낮음 | 지연 불러오기 시험이 PDF 라이브러리를 보지 않는다. 테마·필터 단언은 실패할 수 없다. 경로 대조가 앞으로 가는 선 둘뿐이다 | PDF 묶음 요청을 확인한다. 실패할 수 없는 단언을 뺐다. U자 선 둘·뒤집힌 양방향 선을 더해 4개를 대조한다 |
| 9 | 낮음 | 확인 배지·양방향 행의 안쪽 점이 없다. 영문 메모가 낱말 중간에서 끊긴다. 아주 작은 도면에서 표기가 잘린다 | 모두 고쳤다(배지·점·낱말 줄 바꿈·폭 확보). vitest 3건. `letter-spacing`은 svg2pdf가 쓰지 않아 한계로 적었다 |

리뷰어가 확인한 것: 지연 불러오기(빌드 결과에서 jsPDF·svg2pdf는 PDF 묶음에만 있음), 순서 무관성, 특수 문자 이스케이프, 단자 행·헤더·점 위치가 엔진·CSS와 같음, 겹침 순서, U자 선이 도면 안에 들어옴, 굵게 글꼴 연결, 14,400pt 축소, 한글 PDF 제목 인코딩, 쓴 글자만 담는 글꼴 묶음, 글꼴 라이선스(원본 그대로·OFL 동봉·예약 이름 준수).
