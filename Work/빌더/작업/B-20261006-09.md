## 목표

**지금:** 메모·영역은 넣고 글만 바꿀 수 있다(두 번 눌러 입력 창). 서식 필드는 파일에 있고 그림도 그 값을 따르지만, 화면에서 바꿀 방법이 없다. 크기도 바꿀 수 없다. 화면은 밝은 테마 하나다.

**이 작업이 끝나면:** 구 Builder(`seoul-visual-tech/av-system-builder` `2fd568e`)의 다음 기능이 들어간다. 파일 형식은 바꾸지 않는다(서식 필드는 이미 1.1과 같다).

1. **메모·영역 서식 편집** (구 `EditAnnotationModal.tsx`)
   - 메모: 글(여러 줄), 글자 크기·색, 바탕색·투명도, 테두리 색·모양, 모서리 둥글기, 글 정렬, 빠른 서식 4종
   - 영역: 이름, 글자 크기·색, 바탕색·투명도, 테두리 색·모양·굵기, 모양(사각형·둥근 사각형·원)
   - 둘 다: 고정(`locked`), 지우기
2. **크기 바꾸기** (구 `NodeResizer`): 고른 메모·영역의 테두리를 끌어 크기를 바꾼다. 고정된 것은 바꾸지 못한다. 메모 최소 60×30, 영역 최소 80×80(구와 같다).
3. **고정** (구 `data.locked`): 고정한 메모·영역은 끌거나 크기를 바꾸지 못한다. 파일의 `data.locked`에 남는다(1.1 필드).
4. **다크/라이트 테마** (구 `index.css`의 `data-theme`): 상단 막대 버튼으로 바꾼다. 고른 테마는 브라우저에 남기고 파일에는 넣지 않는다.

## 범위

### 할 것

1. **서식 편집 패널** (`builder/src/components/NotePanel.tsx`)
   - 메모나 영역을 하나만 고르면 오른쪽 패널이 서식 편집으로 바뀐다(연결 하나를 고르면 연결 편집이 되는 것과 같은 자리, 결정 L-b).
   - 바꾼 값은 "적용"을 누를 때 한 번의 실행 취소 단위로 반영한다. 바뀐 것이 없으면 기록하지 않는다.
   - 색 프리셋·빠른 서식은 구 Builder 값을 그대로 쓴다(결정 L-c). 직접 색 고르기도 둔다.
   - 두 번 누르면 패널의 글 칸으로 초점을 옮긴다(지금의 입력 창을 바꾼다).
2. **크기 바꾸기·고정**
   - React Flow `NodeResizer`. 크기 변화는 파일의 `style.width·height`에 반영하고, 한 번 끌기가 실행 취소 한 단위다.
   - 왼쪽·위 테두리로 줄이면 위치도 바뀐다. 위치와 크기를 같은 단위로 기록한다.
   - 고정은 화면용 `draggable`에 반영한다(구 store와 같다). 전체 잠금(B-08)과 함께 쓴다.
3. **테마**
   - `builder/src/styles.css`의 색을 CSS 변수로 모으고 다크 값을 둔다(구 `index.css` 다크 값 참고). React Flow `colorMode`도 함께 바꾼다.
   - 기본은 밝은 테마(Portal과 같다, 결정 L-a). 고른 값은 `localStorage` `av-portal-builder:theme`에 둔다.
   - 선 종류 색·장비 사진은 테마와 무관하다.
4. **시험**
   - vitest: 서식 적용(한 단위 실행 취소, 바뀐 것 없으면 기록 안 함, 메모·영역 필드만), 크기 바꾸기(실행 취소 한 단위, 최소 크기), 고정, 내보낸 파일 검증 통과, 테마가 파일에 없음.
   - Playwright: 메모 서식 바꾸기·되돌리기, 영역 모양 원, 크기 끌기, 고정한 메모는 끌리지 않음, 테마 바꾸기와 다시 열었을 때 유지.
5. **문서**: `builder/README.md`, `builder/CHANGELOG.md` v0.6.0, 통합 기획 §8 이식 상태, 이 작업 파일, `Work/빌더/README.md`

### 구현 메모

- **원본**: `seoul-visual-tech/av-system-builder` `2fd568e`의 `src/EditAnnotationModal.tsx`(436줄), `src/AnnotationNode.tsx`, `src/ShapeNode.tsx`, `src/index.css`(테마 변수), `src/store.ts`(`data.locked` → `draggable`). GitHub API로 파일만 읽었다.
- **파일**
  - `builder/src/components/NotePanel.tsx`: 서식 패널. 프리셋·빠른 서식·숫자 범위는 구 창과 같다
  - `builder/src/components/NoteNodes.tsx`: 메모·영역을 구 Builder처럼 그린다. `NodeResizer`
  - `builder/src/state/theme.ts`: 테마 읽기·저장·`<html data-theme>`
  - 저장소: `updateNoteData`(1.1 서식 키만), `editNote`·`clearNoteFocus`, 크기 바꾸기 처리, `theme`·`toggleTheme`
- **서식 적용**: 패널은 기본값을 채운 값을 보이고, "적용"을 누르면 지금 값과 달라진 키만 보낸다. 손대지 않고 누르면 기록하지 않는다. 숫자 칸의 빈 값은 기본값, 범위 밖은 범위 안으로 맞춘다.
- **크기 바꾸기**: React Flow는 끄는 동안 `dimensions`(resizing true)와 왼쪽·위 손잡이면 `position`을 보내고, 끝에 resizing false를 보낸다.
  - 시작할 때 한 번 기록하고, 크기는 파일의 `style`에 둔다. React Flow가 노드에 붙인 `width`·`height`·`resizing`은 지운다.
  - 손잡이를 누르기만 하면 끝 신호만 오므로 크기를 바꾸지 않는다(리뷰 4).
  - 끄는 동안 엣지 간격을 고정한다(장비 끌기와 같다, 리뷰 8).
- **고정**: 화면용 노드에 `draggable: false`를 둔다. 크기 손잡이는 고정한 것과 전체 잠금 중에 숨긴다.
- **테마**: 화면 색을 CSS 변수로 모으고 `:root[data-theme='dark']`에 어두운 값을 둔다. React Flow `colorMode`와 바탕 변수도 함께 바꾼다. `index.html`의 작은 스크립트가 CSS보다 먼저 `data-theme`을 단다(깜빡임 방지, 리뷰 10).
- **명세와 다르게 한 것**
  - 전체 잠금 중에는 메모·영역 크기도 바꾸지 못한다. 구 Builder는 잠금 중에도 바꿀 수 있었다.
  - 원 모양 영역의 크기 손잡이가 잘리던 구 Builder의 `overflow: hidden`을 뺐다.
  - 영역을 처음 넣을 때 화면 밖에 놓이는 경우가 있다(B-04의 비켜 놓기 규칙). 이번 범위가 아니라 남은 일로 둔다.
