# B-20261012-04 — 견적 작업 화면 내용 폭 상한 확대 (1440 → 1760px)

- 상태: 완료
- 담당: Claude Code (Builder 작업 흐름)
- 작성일: 2026-10-12
- 사용자 요청: 2026-10-12 **"https://seoulav.github.io/AV-Portal/cpq/ 디자인 수정해 왼쪽 부분이 이상해"** (와이드 모니터 캡처 첨부)
- 사용자 결정: 선택지 3개(폭 확대 / 유지 / 화면 폭 추종) 중 **"내용 폭 상한을 넓힘"** 선택

## 조사

Work가 공개본을 2056px 폭으로 재현해 측정했다. 셸 좌우 여백이 각각 308px로
**대칭의 가운데 정렬이 맞았다** — 캡처가 오른쪽이 잘려 왼쪽만 비어 보인 것이다.
다만 상한 1440px이 넓은 모니터에서는 양옆을 많이 비워 두므로, 사용자 결정에
따라 상한만 올린다.

## 변경

- `cpq/src/styles/tokens.css` — `--q-max-w: 1440px` → `1760px`.
  토큰 파일은 RTCOM 원본값을 그대로 쓰는 원칙이라, 원본과 달라진 이유
  (사용자 결정)를 주석으로 남겼다. 다른 토큰은 건드리지 않았다.
- 좁은 화면(720px 이하 전면 폭)과 1440px 이하 화면은 기존과 동일하게 보인다.

## 검증

- `npm run build` · `npm run verify`(typecheck + vitest + audit:exports) 통과
- 2056px 재현: 셸 폭 1760px, 좌우 여백 각 148px 대칭 확인
- 390px 재현: 기존과 동일(전면 폭) 확인
