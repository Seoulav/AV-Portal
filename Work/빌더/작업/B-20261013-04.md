## 목표

슬롯 정보가 있는 프레임 노드의 설정 창에 **슬롯** 탭이 생기고, 슬롯 번호마다 카드를 고르면 카드 단자가 노드에 붙어 결선할 수 있다.

## 범위

- 할 것
  - 설정 창 **슬롯** 탭: `IN1…`·`OUT1…`(·`S1…`) 목록, 슬롯마다 호환 카드 선택(없음 포함). 입력 슬롯엔 입력 카드만 보인다.
  - 카드 단자 합성: 카드 `io`에서 만든 단자를 슬롯 순서대로 노드에 붙인다. 이름은 `IN2 HDMI In 3`처럼 슬롯 번호를 앞에 둔다.
  - 저장 형식(구 Builder 1.1과 호환, 필드 추가만)
    - `selectedOptionQuantities`: 키 `portal-option:<카드 productId>`, 값은 장착 장수. **견적 옵션과 같은 키**를 써서 카드가 곧 견적 품목이 된다(지금 견적 패널의 옵션 품목과 의미가 하나로 합쳐짐).
    - `optionPortIds`: 카드가 만든 단자 id 목록. id는 `opt-<카드 productId>-<슬롯번호>-<카드 단자 id>` — 구 Builder `opt-<옵션id>-<n>-<단자id>` 규칙을 따르되 `<n>`에 슬롯 번호를 넣어 카드 교체 시 다른 슬롯 연결이 유지된다.
    - 추가 필드 `slotAssignments: { "IN1": "<카드 productId>", … }`.
    - 최상위 `options[]`에 카드 품목을 등록(지금 견적 옵션과 같은 방식).
  - 카드를 빼거나 바꾸면 그 슬롯 단자에 걸린 연결을 B-01과 같은 확인 후 정리.
  - 이슈: 슬롯 정보가 있는데 빈 슬롯만 있으면 `slot-empty`(info). RTCOM 시리즈의 `series-config-pending`은 슬롯 정보가 생기면 이 흐름으로 바뀐다.
  - BLU-160 등 B-03에서 펼침이 꺼진 프레임: 예전 단자로 연결된 구성도를 열면 "카드 구성으로 옮기기" 안내(자동 변환은 D1).
  - 견적(CPQ) 쪽 확인: `selectedOptionQuantities`의 카드 키를 견적이 품목으로 읽는지 `cpq/` 테스트로 확인.
- 하지 않을 것
  - 슬롯 수·카드 데이터 보강(B-03·RTCOM 원본), 카드 단자 편집(카드는 Portal 값 그대로. 필요하면 B-01 단자 편집으로 노드에서 고친다).
- 지킬 결정: 1.1 호환(필드 추가만), 노드 1개 = 장비 1대(카드는 노드가 아니라 프레임의 구성).

### 구현 중 정한 것(사용자 확인 필요 항목은 ★)

- ★ **카드 ID는 카드 "배치 단위 ID"다.** 명세는 `<카드 productId>`라고 적었으나 RTCOM 카드는 제품 하나(`rtcom-xdm`)에 모델이 여럿이라 제품 ID로는 카드 종류·견적 수량을 나눌 수 없다. Portal 카드는 배치 단위 ID = 제품 ID라 명세와 같고, RTCOM 카드는 `rtcom-xdm:xdm-his100`이다. 단자 id `opt-rtcom-xdm:xdm-his100-IN1-in-hdmi-1`, 견적 키 `portal-option:rtcom-xdm:xdm-his100`. 견적 정의 `model`은 Portal 카드면 Portal 제품명(견적 옵션 탭과 같은 값), RTCOM 카드면 카드 모델명(`XDM-HIS100`)
- ★ **이슈 코드 `slot-legacy-ports`(안내)를 추가했다.** D1(자동 변환 안 함, 안내만)의 "구성도를 열면 안내"를 이슈 패널로 보이게 하려는 것이다. 슬롯 탭에도 같은 안내와 "카드 구성으로 옮기기" 버튼(프레임 단자만 남기는 되돌리기 초안. 적용해야 바뀐다)을 둔다
- **카드 단자는 단자 탭에서 고칠 수 있다**(명세 "필요하면 B-01 단자 편집으로 노드에서 고친다"). 비교 기준은 프레임 + 카드 값이라 고치면 `edited`·`portsEdited`가 붙는다. 다른 슬롯을 바꿔도 고친 카드 단자는 남는다
- **되돌리기**는 프레임 + 지금 장착한 카드 값으로 돌리고 카드 구성은 남긴다
- **견적 수량**: 장착 장수만큼 더하고 뺀다. 견적 옵션 탭에서 따로 넣은 예비 수량은 남기고, 장착 장수 밑으로는 내려가지 않는다. 카드 품목 정의는 지우지 않는다(견적 옵션과 같다)
- **단자 순서**: 슬롯을 바꾸면 목록마다 프레임 단자를 앞에, 카드 단자를 슬롯 순서로 뒤에 둔다(같은 슬롯 안 순서는 유지)
- **연결 확인**: 단자 탭과 슬롯 탭을 함께 바꿔도 걸리는 연결을 한 번에 세어 확인받는다
- **SPX-R6**: 라이브러리 `compatibleCards: []`(SPX-TX/RX 모듈은 `slots.note`에만 있다). 노트를 해석하거나 연결을 지어내지 않고 "장착 가능 모듈 정보 없음"으로 보인다. 이슈는 `slot-empty`(detail에 같은 문구)
- **슬롯 번호 문구**: IN1·OUT1·S1은 슬롯 종류별로 센 번호이며 후면 패널 순서와 같다는 보장이 없다는 안내를 슬롯 탭에 둔다
- **슬롯 번호 형식** `^[A-Z]+[1-9][0-9]*$`을 검증기·스키마에서 강제한다(카드 단자 id 접두어가 겹치지 않게)
