# B-20261018-01 — 견적 가져오기: 마이크 케이블 기본 커넥터를 XLR 3핀으로

- 상태: 검토
- 담당: Claude Code (Builder 작업 흐름)
- 작성일: 2026-10-18
- 배경: [B-20261016-01](B-20261016-01.md) 남은 일 — "A.AUDIO 마이크 케이블 구간에도 기본 RJ45 커넥터가 붙는 기존 동작은 이번 범위 밖이라 그대로 두었다. 마이크 케이블용 커넥터(XLR 등)를 정할지 사용자 확인이 필요하다."
- **사용자 결정(2026-10-18): XLR(3핀)으로 변경.**

## 목표

구성도 가져오기에서 기본 마이크 케이블(CBL-0106 · YJ56878) 구간의 커넥터를
기본 RJ45(CAT6 UTP용) 대신 **XLR 3핀**으로 센다.

## 구현 결정

| 결정 | 내용 | 근거 |
|---|---|---|
| 품목 | **CBL-0129(NC3FXX, F) + CBL-0130(NC3MXX, M) 한 쌍** | XLR는 RJ45와 달리 양끝이 암·수 한 쌍이다. 회의실 견적 샘플(VIP1-3·2-3·3-3)도 XLR 커넥터를 NC_FXX·NC_MXX 같은 수량으로 함께 올렸고, 뉴트릭 NC 시리즈를 썼다. 카탈로그의 다른 3핀 쌍(RC3F·RC3M)이 아닌 NC를 고른 것은 이 샘플 관행을 따른 것이다 — 바꾸려면 사용자 확인 |
| 수량 | 구간당 3개(사용 2 + 예비 1, 결정 D8 규칙 2)를 **두 SKU가 나눠** 갖고, SKU마다 10EA 묶음으로 올림. 예: 4구간 → 각 6개 → 각 1묶음 | 사용자가 준 구간당 개수 규칙의 총량을 지키면서 F·M을 같은 수량으로 두는 가장 단순한 방법 |
| 형식 | 구성도 JSON은 바꾸지 않는다. 견적 앱 가져오기 안에서만 처리한다 | 구 Builder 1.1 호환 유지 |
| 단자 어휘 | `beta/port-vocabulary.mjs`는 고치지 않는다 | 이 작업은 견적 커넥터 품목 계산이고 단자 변환 규칙과 무관하다 |
