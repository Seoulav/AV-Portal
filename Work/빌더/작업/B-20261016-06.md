## 참고한 LED 구성기 방식 (공개 코드 확인, 2026-10-16)

- 가격표는 저장소·공개 웹에 없다. 직원이 "가격표 불러오기"로 파일(`prices.local.js` 또는 JSON, `PRICES.panels` 등)을 고르면 브라우저 `localStorage`(`svtled_prices_v1`)에 저장하고, 다음 방문 때 자동 적용한다. 파일은 업로드되지 않는다.
- 가격표가 없으면 원가/견적 카드를 숨긴다. 단가가 빈 항목은 막지 않고 `incomplete`로 표시한다.

## 현재 견적 앱 상태

- 판매 단가 `cpq/data/approved/prices.json`(1,468품목)이 **공개 저장소에 커밋돼 있고 Pages로 배포된다.** 누구나·AI가 볼 수 있다.
- 원가는 "내 PC 원가 확인"(메모리 세션, CSV·XLSX 열 지정 읽기)으로만 다룬다. 매번 다시 골라야 한다.

## 사용자 추가 지시 (2026-10-16) — 표준품셈 원본을 그대로 가격표로

> **"표준품셈에 보면 G열이 원가인데 그게 다 채워서 갖고 있어 그 파일 올려서 사용 가능하니?"**

- 견적 단가표(`products.json`, `sourceSha256` `0cc2e8bd…`, 2026-10-03 생성)는 그 표준품셈 원본에서 뽑았다. SKU는 시트 접두어 + 원본 행 번호다(`options.sheet`·`options.sourceRow`). 추출 때 원가·매입처 열은 읽지 않았다(`rawTypes.ts` 주석, 결정 D1).
- 따라서 **1순위 가격표 = 사용자가 가진 표준품셈 원본 xlsx**다. 앱이 시트·행으로 SKU를 찾아 원가와 판매가(재료비 단가)를 읽는다.
  - 열은 머리글로 찾는다. 처음 한 번은 기존 XLSX 열 지정 화면처럼 사용자가 원가 열·판매가 열을 확인한다. **열 문자를 코드에 고정하지 않는다**(상·하반기 판의 열 위치가 다르다는 기존 기록).
  - **판이 다를 수 있다.** 행마다 그 행의 품명·규격이 `products.json`의 `quoteName`·`model`과 맞을 때만 가격을 붙인다. 맞지 않는 행은 "가격표 행 불일치, 확인 필요"로 표시하고 추측해서 붙이지 않는다. 불일치 건수를 불러오기 결과에 보여 준다.
  - 매입처·제조사·영업비고 열은 읽지 않는다.
- AI는 이 파일을 열지 않는다. 구현과 시험은 머리글 이름과 가짜 행으로만 한다.
- 아래 4시트 형식은 **2순위**(표준품셈 파일이 없거나 품목을 직접 관리할 때)로 둔다. 빈 서식 내려받기도 그 용도다.

## 할 일

1. **가격표 파일 형식**(2순위) — Excel 한 파일, 시트 4개(시트 이름으로 찾는다).
   | 시트 | 열 | 용도 |
   |---|---|---|
   | `품목 단가` | 품목코드 · 모델 · 품명 · 원가 · 판매가 · 비고 | 견적 행 금액. 품목코드 = 견적 단가표 SKU |
   | `기본값` | 선 종류 · 기본 케이블 코드 · 거리 미입력 기본 길이(m) · 커넥터 코드 | 지금 코드에 고정된 HDMI·LAN·A.AUDIO 기본값을 덮어쓴다(시트가 없거나 빈 칸이면 코드 기본값) |
   | `노무 확인` | 품셈 연결 코드 · 품셈 판 · 확인일 · 확인자 | B-20261016-05의 "확인한 연결 기억"을 파일로 옮기고 나누는 용도 |
   | `간접비` | 항목 · 요율 · 적용 여부 | 시트가 없으면 지금 가이드 기본값 |
   - 매크로·외부 링크·암호화·수식 가격 거부 등 기존 `private-cost` 읽기 규칙을 그대로 쓴다.
2. **불러오기·저장·지우기** — "가격표 불러오기"로 고르면 내용을 이 브라우저(IndexedDB 또는 localStorage)에 저장하고 다음 방문 때 자동 적용한다. "가격표 지우기"를 둔다. 파일 이름·내용을 네트워크로 보내지 않는다(기존 `audit:exports` 경계 유지, 전송 코드 없음을 시험).
3. **공개 판매 단가 제거** — `cpq/data/approved/prices.json`을 저장소·Pages 빌드에서 뺀다. 가격표가 없으면 금액 칸은 "단가 미등록"으로 비워 보이고(0으로 채우지 않음), B-05 결정대로 내려받기는 막지 않는다.
4. **빈 가격표 서식 만들기 도구** — 견적 앱에 "빈 가격표 서식 내려받기" 버튼(또는 `tools/` 스크립트)을 둔다. 공개 품목 목록(`products.json`)으로 `품목 단가` 시트의 품목코드·모델·품명을 채우고 가격 칸은 비운다. `기본값` 시트에는 현재 코드 기본값을 채운다.
5. **AI·저장소 차단**
   - `.gitignore`에 가격표 파일 이름 형식(예: `*가격표*.xlsx`, `*.prices.xlsx`, `prices.local.*`)을 넣는다.
   - `AGENTS.md`에 "가격표·원가 파일을 열거나 요청·커밋하지 않는다. 시험은 가짜 가격으로만 한다"를 넣는다.
   - 저장소에 실제 단가 형태의 파일이 다시 들어오지 않는지 검사(예: `cpq/data/approved/`에 `prices.json` 금지)를 시험으로 둔다.
6. 시험은 모두 가짜 가격으로 한다. 실제 단가를 쓰던 시험(`approvedData` 등)은 가짜 가격 고정 자료로 바꾼다.

## 하지 않을 것

- Git 이력 재작성(과거 커밋의 `prices.json`은 남는다. 사용자에게 알렸다)
- 가격표 공유 서버·비밀번호 공유(LED 구성기의 공유 업로드 기능)는 이번 범위 밖
- 실제 가격표 파일을 AI가 열거나 저장소에 넣는 일

## 결정이 필요한 사항

- 없음(사용자가 LED 방식과 "AI나 다른 사람 못 보게"를 정했다). 세부 UI 위치는 통상 구현 판단으로 한다.
