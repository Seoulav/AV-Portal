## 참고한 LED 구성기 방식 (공개 코드 확인, 2026-10-16)

- 가격표는 저장소·공개 웹에 없다. 직원이 "가격표 불러오기"로 파일(`prices.local.js` 또는 JSON, `PRICES.panels` 등)을 고르면 브라우저 `localStorage`(`svtled_prices_v1`)에 저장하고, 다음 방문 때 자동 적용한다. 파일은 업로드되지 않는다.
- 가격표가 없으면 원가/견적 카드를 숨긴다. 단가가 빈 항목은 막지 않고 `incomplete`로 표시한다.

## 현재 견적 앱 상태

- 판매 단가 `cpq/data/approved/prices.json`(1,468품목)이 **공개 저장소에 커밋돼 있고 Pages로 배포된다.** 누구나·AI가 볼 수 있다.
- 원가는 "내 PC 원가 확인"(메모리 세션, CSV·XLSX 열 지정 읽기)으로만 다룬다. 매번 다시 골라야 한다.

## 사용자 추가 지시 (2026-10-16) — 표준품셈 원본을 그대로 가격표로

> **"표준품셈에 보면 G열이 원가인데 그게 다 채워서 갖고 있어 그 파일 올려서 사용 가능하니?"**

- 견적 단가표(`products.json`, `sourceSha256` `0cc2e8bd…`, 2026-10-03 생성)는 그 표준품셈 원본에서 뽑았다. SKU는 시트 접두어 + 원본 행 번호다(`options.sheet`·`options.sourceRow`). 추출 때 원가·매입처 열은 읽지 않았다(`rawTypes.ts` 주석, 결정 D1).
- 따라서 **1순위 가격표 = 사용자가 가진 표준품셈 원본 xlsx**다. 앱이 시트·행으로 SKU를 찾아 원가와 판매가(재료비 단가)를 읽는다.
  - 열은 머리글로 찾는다. 처음 한 번은 기존 XLSX 열 지정 화면처럼 사용자가 원가 열·판매가 열을 확인한다. **열 문자를 코드에 고정하지 않는다**(상·하반기 판의 열 위치가 다르다는 기존 기록).
  - **판이 다를 수 있다.** 행마다 그 행의 품명·규격이 `products.json`의 `quoteName`·`model`과 맞을 때만 가격을 붙인다. 맞지 않는 행은 "가격표 행 불일치, 확인 필요"로 표시하고 추측해서 붙이지 않는다. 불일치 건수를 불러오기 결과에 보여 준다.
  - 매입처·제조사·영업비고 열은 읽지 않는다.
- AI는 이 파일을 열지 않는다. 구현과 시험은 머리글 이름과 가짜 행으로만 한다.
- 아래 4시트 형식은 **2순위**(표준품셈 파일이 없거나 품목을 직접 관리할 때)로 둔다. 빈 서식 내려받기도 그 용도다.

## 할 일

1. **가격표 파일 형식**(2순위) — Excel 한 파일, 시트 4개(시트 이름으로 찾는다).
   | 시트 | 열 | 용도 |
   |---|---|---|
   | `품목 단가` | 품목코드 · 모델 · 품명 · 원가 · 판매가 · 비고 | 견적 행 금액. 품목코드 = 견적 단가표 SKU |
   | `기본값` | 선 종류 · 기본 케이블 코드 · 거리 미입력 기본 길이(m) · 커넥터 코드 | 지금 코드에 고정된 HDMI·LAN·A.AUDIO 기본값을 덮어쓴다(시트가 없거나 빈 칸이면 코드 기본값) |
   | `노무 확인` | 품셈 연결 코드 · 품셈 판 · 확인일 · 확인자 | B-20261016-05의 "확인한 연결 기억"을 파일로 옮기고 나누는 용도 |
   | `간접비` | 항목 · 요율 · 적용 여부 | 시트가 없으면 지금 가이드 기본값 |
   - 매크로·외부 링크·암호화·수식 가격 거부 등 기존 `private-cost` 읽기 규칙을 그대로 쓴다.
2. **불러오기·저장·지우기** — "가격표 불러오기"로 고르면 내용을 이 브라우저(IndexedDB 또는 localStorage)에 저장하고 다음 방문 때 자동 적용한다. "가격표 지우기"를 둔다. 파일 이름·내용을 네트워크로 보내지 않는다(기존 `audit:exports` 경계 유지, 전송 코드 없음을 시험).
3. **공개 판매 단가 제거** — `cpq/data/approved/prices.json`을 저장소·Pages 빌드에서 뺀다. 가격표가 없으면 금액 칸은 "단가 미등록"으로 비워 보이고(0으로 채우지 않음), B-05 결정대로 내려받기는 막지 않는다.
4. **빈 가격표 서식 만들기 도구** — 견적 앱에 "빈 가격표 서식 내려받기" 버튼(또는 `tools/` 스크립트)을 둔다. 공개 품목 목록(`products.json`)으로 `품목 단가` 시트의 품목코드·모델·품명을 채우고 가격 칸은 비운다. `기본값` 시트에는 현재 코드 기본값을 채운다.
5. **AI·저장소 차단**
   - `.gitignore`에 가격표 파일 이름 형식(예: `*가격표*.xlsx`, `*.prices.xlsx`, `prices.local.*`)을 넣는다.
   - `AGENTS.md`에 "가격표·원가 파일을 열거나 요청·커밋하지 않는다. 시험은 가짜 가격으로만 한다"를 넣는다.
   - 저장소에 실제 단가 형태의 파일이 다시 들어오지 않는지 검사(예: `cpq/data/approved/`에 `prices.json` 금지)를 시험으로 둔다.
6. 시험은 모두 가짜 가격으로 한다. 실제 단가를 쓰던 시험(`approvedData` 등)은 가짜 가격 고정 자료로 바꾼다.

### 설계 판단

- **가격표 자리**: 판매가는 `catalog.prices`(견적 행 단가, 예전 `prices.json` 자리)로, 원가는 원가 세션(`services/private-cost/session.ts`)으로만 간다(`services/price-book/apply.ts`). 카탈로그·견적 문서·고객용·공유용 출력에는 원가가 실리지 않는다. 원가는 영업팀용(0) 출력과 "내 PC 원가 확인" 영역에서만 쓴다. 원가 파일을 따로 고르면 그 파일이 가격표 원가보다 우선한다.
- **1순위 표준품셈 원본**(`services/price-book/readPriceFile.ts`): 견적 단가표에 있는 시트만 본다. 시트마다 처음 40행 안에서 `품명`·`규격` 머리글 행을 찾고, 다음 행의 품명 칸이 비고 `단가`·`금액`이 있으면 2단 머리글로 본다. 위 칸이 비면 병합 범위의 시작 칸 글자를 쓴다. 열 이름은 `위 / 아래`(예: `원가 / 단 가`). **열 문자를 코드에 두지 않는다.** 첫 시트 기준으로 원가 열(`원가`+`단가`)·판매가 열(`재료비`+`단가`)을 미리 골라 보여 주고 사람이 확인한다. 다른 시트는 같은 열 이름으로 찾는다(열 위치가 달라도 된다). 이름이 없거나 둘 이상이면 그 시트는 사유와 함께 건너뛴다.
- **행 대응**: `products.json`의 `options.sheet` + `options.sourceRow`로 SKU를 찾고, 그 행의 품명·규격이 `quoteName`·`quoteSpec`과 공백·대소문자만 맞춘 비교로 같을 때만 붙인다. 다르면 "가격표 행 불일치"로 세고 붙이지 않는다. 결과에 붙은·불일치·빈 칸 건수와 수식·숫자 아님·파일에서 찾지 못한 품목 수, 불일치 행 표본(시트·행·SKU·사유, 최대 50건)을 보인다. 가격 값은 결과에 담지 않는다.
- **거부·제외**: 기존 `private-cost` 읽기 규칙(크기·ZIP·매크로·외부 링크·암호화·시간 제한)을 그대로 쓴다(`readXlsxWorkbook` 추가). 가격 칸이 수식이면 그 칸만 읽지 않는다. 빈 칸·음수·숫자 아님은 미등록이다(0 아님). 매입처·제조사·구매처·비고·영업·메모 열은 고를 수 없고 읽지 않는다. 파생 단가 품목(`배관 기타자재`)은 판매가를 붙이지 않는다.
- **2순위 4시트 가격표**: `품목 단가` 시트가 있으면 이 형식이다. 품목코드=SKU이고, 모델·품명 중 **하나 이상이 적혀 있고 맞아야** 붙인다(둘 다 비면 대조할 수 없어 붙이지 않는다). 목록에 없는 코드는 세고, 중복 코드는 **모든 줄을** 빼고 센다. `$`·`¥`·`€`·`£`가 붙은 칸과 참/거짓 칸은 숫자가 아닌 칸으로 센다.
- **저장**(`services/price-book/store.ts`): IndexedDB 데이터베이스 `av-cpq.price-book.v1`, 저장소 `price-book`, 열쇠 `current` 하나에 `{가격표, 표준품셈 열 선택}`을 둔다. 쓰기·지우기는 한 줄로 세워 순서대로 처리하고, 저장 중에는 단추를 막는다. 파일 이름은 저장하지 않는다. 앱은 저장된 가격표를 읽은 뒤 화면을 연다(5초 안에 응답이 없으면 가격표 없이 연다). 견적 단가표 지문이 다르면 적용하지 않고 다시 불러오라고 알린다. 저장이 실패하면 이번 방문에서만 쓰고 그 사실을 알린다. 「가격표 지우기」는 열 선택까지 지운다.
- **열린 견적**: 가격표를 바꿔도 열린 견적의 단가는 조용히 바뀌지 않는다. 「열린 견적에 가격표 단가 적용」을 누르면 같은 판 문서의 품목 단가만 다시 붙인다(실행 취소 가능, `domain/quote/repriceFromCatalog.ts`).
- **차단 규칙**: `tools/audit-exports.mjs` 7번 규칙에 IndexedDB 허용 파일 하나를 더했다. 상수 세 개는 정해진 값으로 **한 번만** 선언해야 하고, 저장소 호출은 정해진 모양만 받는다(`open(DB, …)`, `transaction(STORE, 'readonly'|'readwrite')`, `objectStore(STORE)`, 옵션 없는 `createObjectStore(STORE)`, `get(KEY)`·`delete(KEY)`, `put(값, KEY)` — 같은 줄에서 닫혀야 한다). `getAll`·`getKey`·커서·`clear`·`add`·`count`·`index`·`createIndex`·`deleteObjectStore`·`deleteDatabase`·`databases`와 `localStorage` 등 다른 저장소는 막는다. `services/price-book`은 원가 모듈로 보아 고객용·도메인·직렬화 경로가 가져오지 못하고(1번 — import 문자열을 실제 경로로 풀어 상대 경로 우회도 잡는다), 네트워크에 닿지 못한다(3번). 가격표 모듈은 `services/price-book`·`features/price-book`·`app/App.tsx`에서만 가져올 수 있다(1-1번). 위반 7종(상대 경로 import, `src/data`에서 가져오기, 자동 열쇠 저장소, 열쇠 없는 `put`, 줄을 넘긴 `put`, 상수 가리기, `deleteObjectStore`)을 넣어 각각 잡히고 되돌려 통과하는 것을 수동 확인했다.
- **공개 판매 단가 제거**: `cpq/data/approved/prices.json` 삭제, `UPSTREAM.json`의 `localChanges`에 제거 기록(`removed: true`). `tools/vite-approved-data.ts`는 `prices.json`을 금지 파일로 두어 dev 서버는 404, build는 원본 폴더에 있으면 멈춘다. `tools/build-approved.ts`는 더 이상 `prices.json`을 만들지 않는다(네 파일). 앱(`loadCatalog`)은 `prices.json`을 요청하지 않는다.
