## 1) 유일 후보 자동 연결 (`model-contained`)

4단계 모델명 검색은 지금까지 후보만 올리고 연결하지 않았다(계획 2026-10-06 §6).
사용자 지시로 다음 조건을 **모두** 만족할 때만 자동 연결한다.

| 조건 | 이유 |
|---|---|
| 후보가 정확히 **1건** | 둘 이상이면 어느 쪽인지 사람이 정해야 한다 |
| **model 또는 quoteSpec 칸**에서 맞음 | 품명·설명 칸에서만 맞은 후보는 부속품·일반 명칭일 수 있다 — 기존대로 제시만 한다 |

- `matchedBy: 'model-contained'`를 신설하고 제품·단가를 붙인다.
- 자동 연결 사실은 숨기지 않는다: 비차단 경고 `device-model-contained`(장비·옵션 공통)와
  견적 비고 `자동 연결. 확인 권장`에 맞은 글자를 남긴다.
- BLU-101 사례: 카탈로그 규격 `BLU-101, AEC/Bluelink지원` → 이제 자동 연결.

## 2) A.AUDIO 기본 마이크 케이블 자동 지정

구성도 연결선에 케이블 품목이 없으면 지금까지 "품목 미정" 행을 세웠다.
`DEFAULT_BULK_CABLE_SKU_BY_LINE_TYPE`(cables.ts)에 등록된 선 종류는 기본
품목을 자동 지정한다. 현재 등록: **A.AUDIO → CBL-0106 (YJ56878, 10M 벌크,
품셈 묶음 '1CH MIC CABLE')**.

- **거리는 역산하지 않는다.** 경로 입력이 있는 구간만 길이를 합산하고,
  한 구간이라도 거리가 없으면 키 전체의 수량을 비우고 차단 경고를 세운다
  (모자란 합계가 조용히 나가는 것을 막는다).
- 교체 선택지로 같은 품셈 묶음의 케이블(YJ56878·9451)을 경고에 싣는다.
- 등록되지 않은 선 종류는 기존 동작 그대로다.
