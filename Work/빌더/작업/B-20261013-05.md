## 배경

지금 연결 규칙([기반명세](../기반명세.md) §7.1)은 **신호가 같으면 허용하고 커넥터가 다르면 `connector-adapter` 경고**를 낸다. 영상(HDMI→DVI)에는 맞지만 오디오에는 맞지 않는다. 마이크 XLR 출력 → DSP 유로블록 입력은 현장에서 **XLR(F)–피닉스 3P 케이블 하나로 끝나는 정상 결선**인데 "어댑터 필요" 경고가 뜬다.

또 노드에는 단자 이름만 보여 오디오 단자가 XLR인지 유로블록인지, 마이크 레벨인지 라인 레벨인지 알 수 없다.

## 아이디어

오디오 결선은 **커넥터 모양이 아니라 신호의 성격**으로 판단한다. 커넥터는 케이블 양 끝 처리 문제다.

| 판단 | 규칙 | 결과 |
|---|---|---|
| 신호 영역 | 아날로그(MIC·LINE) / 디지털(AES3·S/PDIF·Dante…) / 스피커 레벨이 다르면 | **차단**(지금과 같음 — `signal-mismatch`) |
| 레벨 | 마이크 → 라인 입력 | 경고 `signal-level`: "프리앰프 필요" |
|  | 라인 → 마이크 입력 | 경고 `signal-level`: "감쇠(패드) 필요" |
| 커넥터(아날로그 오디오·AES3) | XLR·TRS·유로블록·RCA·3.5mm·D-Sub 등 **선을 물리는 단자끼리** | 경고 대신 안내 `audio-cable`: 추천 케이블(예: "XLR(F)–유로블록 3P 평형") |
| 커넥터(스피커) | 스피콘·바인딩 포스트·유로블록·TS 끼리 | 안내 `audio-cable`: "스피콘–유로블록 스피커 케이블" |
| 커넥터(AES3 ↔ BNC) | 임피던스가 달라 발룬 필요 | 경고 `connector-adapter` 유지 |
| 평형 | 평형(XLR·TRS·유로블록) ↔ 불평형(RCA·3.5mm) | 안내 `audio-unbalanced`: "불평형 구간 — 거리·잡음 주의" |

화면:
- 노드의 오디오·스피커 단자 행에 **커넥터 약칭**(XLR·TRS·EB·RCA·3.5·SPK·BP)과 **레벨**(MIC·LINE·M/L)을 작게 붙인다.
- 연결 패널에 "추천 케이블"과 **[케이블로 추가]** 버튼(제작 케이블 행으로 추가, 길이는 사용자가 입력).
