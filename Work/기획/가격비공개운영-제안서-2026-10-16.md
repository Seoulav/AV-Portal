## 한 줄 요약

견적 앱의 판매 단가가 **지금 인터넷에 공개돼 있다.** 가격을 저장소와 웹사이트에서 빼고, 직원이 가격표 파일을 **자기 PC 브라우저에서만** 불러와 쓰게 바꾸자. 비용은 0원이고 포털·Builder 공개는 그대로 유지된다.

## 1. 현재 상황

| 항목 | 사실 (2026-10-16 확인) |
|---|---|
| 판매 단가 파일 | `cpq/data/approved/prices.json` — 1,468품목의 판매 단가 |
| 공개 여부 | `https://seoulav.github.io/AV-Portal/cpq/data/approved/prices.json` 이 누구에게나 열린다(HTTP 200) |
| 저장소 | `Seoulav/AV-Portal`은 **공개 저장소**. 2026-10-12 커밋 `3de8448b`부터 이력에 있다. 포크 0건 |
| 원가 | 저장소에 없다. "내 PC 원가 확인"에서 매번 파일을 골라 그 화면에서만 쓴다 |
| GitHub 요금제 | Seoulav 조직은 **Free** |

## 2. 위험 요소

1. **누구나 우리 판매 단가를 받아 갈 수 있다.** 주소만 알면 경쟁사·고객도 1,468품목 단가 전체를 내려받는다.
2. **지워도 과거 기록에서 다시 나온다.** 공개 저장소의 Git 이력은 영구 보관된다. 지금 지워도 2026-10-12 이후 커밋에서 꺼낼 수 있다.
3. **AI 에이전트가 가격을 읽는다.** 이 저장소에서 일하는 Claude·Codex·Gemini가 파일을 열면 가격이 대화 기록과 외부 서비스 로그에 남는다.
4. **원가를 쓰기 불편하다.** 원가는 매번 파일을 다시 골라야 해서, 결국 누군가 원가를 저장소에 올리고 싶어질 수 있다. 그러면 1~3번 위험이 원가로 번진다.

## 3. 원인

- 견적 앱은 **GitHub Pages 정적 사이트**다. 서버도 로그인도 없어서, 앱이 읽는 파일은 모두 공개 주소가 된다. "앱에 넣는다"가 곧 "인터넷에 공개한다"이다.
- 처음 설계에서 단가를 품목 목록(`products.json`)과 **분리해 두었지만**(결정 D3, 나중에 뺄 수 있게), 아직 빼지 않았다.
- 저장소를 비공개로 바꿔도 해결되지 않는다.
  - Free 요금제에서는 비공개 저장소의 **Pages가 꺼진다** → 포털·Builder·견적 앱이 모두 닫힌다.
  - 유료(Team, 1인 월 $4)로 올려도 **사이트 자체는 공개**다. 로그인을 걸려면 Enterprise Cloud(1인 월 약 $21)가 필요하다.
  - 비공개여도 저장소에서 일하는 AI는 가격을 그대로 읽는다.

## 4. 해결 방안 (A안)

**가격은 저장소에 두지 않는다. 직원 PC의 브라우저 안에만 둔다.**

```
[직원이 가진 가격표 파일]  →  견적 앱 "가격표 불러오기"  →  이 PC 브라우저에 저장
     (표준품셈 원본 xlsx)          (파일은 어디로도 전송 안 됨)      (다음 방문 때 자동 적용)
```

하는 일:
1. `prices.json`을 저장소와 웹사이트에서 **뺀다.**
2. 견적 앱에 **가격표 불러오기 / 지우기** 단추를 둔다. 1순위 가격표는 회사가 이미 가진 **표준품셈 원본 xlsx**(원가 열·판매가 열 포함)다. 원본이 없으면 앱이 주는 빈 서식(4시트)에 채워 쓴다.
3. 가격표가 없으면 금액 칸은 **"단가 미등록"**으로 비운다(0으로 채우지 않는다). 품목·수량·노무비 계산은 그대로 된다.
4. 품명·규격이 우리 품목과 다른 행은 가격을 붙이지 않고 **"확인 필요"**로 표시한다(판이 다른 파일을 잘못 맞추지 않게).
5. 가격표 파일이 다시 저장소에 들어오지 못하게 `.gitignore`·자동 검사·AI 작업 규칙(`AGENTS.md`)을 둔다. 시험은 가짜 가격으로만 한다.

직원이 쓰는 법:
- **처음 한 번**: 견적 앱 → 가격표 불러오기 → 파일 선택 → (처음만) 원가 열·판매가 열 확인
- **그다음부터**: 그냥 견적 앱을 열면 가격이 붙어 있다
- **가격이 바뀌면**: 새 파일을 다시 불러온다
- **공용 PC를 쓰면**: 끝나고 "가격표 지우기"

## 6. 한계 (숨기지 않고 알린다)

- **이미 공개된 과거 단가(2026-10-12 이후 커밋)는 되돌리지 않는다.** 이력을 다시 쓰려면 강제 push가 필요하고, 남이 받아 간 사본까지 지울 수는 없다. 2026-10-04 영업자료 사건 때와 같은 결정이다(AGENTS.md 「비공개 자료는 올리기 전에 암호화한다」).
- 가격표는 PC·브라우저마다 따로 있다. 브라우저 데이터를 지우면 다시 불러와야 한다.
- 가격표를 나눠 주는 일(메일·사내 공유폴더)은 앱 밖에서 한다. 공유 서버는 이번 범위가 아니다.
