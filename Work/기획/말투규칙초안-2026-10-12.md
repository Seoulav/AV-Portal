## Work가 세 말투를 나란히 놓고 읽었다

사용자가 가리킨 본보기 둘과, 고칠 대상의 현재 문장이다.

| 출처 | 실제 문장 |
|---|---|
| **알티컴** `qms-44ux` | `HDMI 소스 4대 연결` · `외부 제어` · `TCP/IP 제어` · `전원 어댑터 12V 5A` |
| **BSS** `blu-101` | `Phoenix/Combicon · Mic/Line 입력 4채널` · `라인 출력 4채널` |
| **현재 삼성 등** | `USB 장치를 연결할 때 사용합니다. 허용 전류는 최대 1.0A입니다.` |

**차이는 하나다.** 본보기 둘은 **명사로 끝나는 압축형**이고, 고칠 대상은 **「~합니다」 설명문**이다.

## 규칙 — 간단하다

### 1. 번호 지도 설명(`desc`)은 명사형으로 끝낸다

| | |
|---|---|
| 어미 | **「~합니다」·「~입니다」를 쓰지 않는다.** 명사로 끝낸다 |
| 길이 | 한 호흡. 보조 정보는 **` · `(가운뎃점)**으로 잇는다 |
| 값 | **바꾸지 않는다.** 수치·조건·단서는 전부 보존한다 |

### 2. 전환 예 — 실제 대상 문장으로

| 지금 | **바꾼 뒤** |
|---|---|
| `USB 장치를 연결할 때 사용합니다. 허용 전류는 최대 1.0A입니다.` | `USB 장치 연결 · 허용 전류 최대 1.0A` |
| `음향 케이블을 이용하여 소리를 내보낼 때 사용합니다.` | `음향 케이블로 소리 출력` |
| `RS232C 어댑터를 이용하여 MDC를 연결할 때 사용합니다.` | `RS-232C 어댑터로 MDC 연결` |
| `다음 디스플레이로 RS-232C 제어 명령을 전달하는 루프아웃입니다.` | `다음 디스플레이로 제어 명령 전달 · 루프아웃` |
| `RJ-45 · 네트워크 제어 및 PoE+ 전원을 연결합니다.` | `네트워크 제어 · PoE+ 전원` |

### 3. 지키는 것

- **사실·수치·단서를 지우지 않는다.** 「실물 촬영으로 확인, 매뉴얼 대조 전」 같은 검증 단서는 그대로 남긴다 — 알티컴도 남긴다
- **단자 이름(`label`)·번호·좌표는 건드리지 않는다.** 바꾸는 것은 `desc` 문장뿐이다
- `io`의 `availability`·`condition`, `specifications` 값은 **이번 범위가 아니다.** 설명문 어미가 있는 곳만 뒤에 따로 묶는다
