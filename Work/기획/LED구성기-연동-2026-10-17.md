# LED 구성기 → Analog Way 설계 가이드 연동

W-20261017-009 · 2026-10-17. LED 구성기가 계산한 **완성 벽 해상도(픽셀)**를 AV Portal 설계 가이드로 전달하는 링크 규약이다. 외부 `svt-led-calculator` 저장소는 이 작업에서 수정하지 않는다.

## 링크 형식

```text
https://seoulav.github.io/AV-Portal/analogway/?ledw=<가로 픽셀>&ledh=<세로 픽셀>
https://seoulav.github.io/AV-Portal/analogway/?ledw=<가로 픽셀>&ledh=<세로 픽셀>&layers=<출력 그룹당 4K60 믹싱 수>
```

예: `?ledw=6144&ledh=3456&layers=2`. 단추 문구 예시는 **「이 해상도로 가능한 프로세서 보기 → AV Portal」**이다. 유효한 링크를 열면 「LED 벽 해상도(픽셀)」 입력 방식이 선택되고 설계 가이드까지 이동해 가능한 모델과 모델별 최대 레이어 수가 표시된다. `layers`를 생략하면 0으로 시작한다. URL의 `layers`는 **출력 그룹당** 수이며, 화면의 PIP 창 수는 **벽 전체** 수다. 예를 들어 4×2판은 출력 그룹 2개이므로 `layers=3`이 PIP 6개로 표시된다.

## 환산과 범위

가로 타일 수 `ceil(ledw / 3840)`, 세로 타일 수 `ceil(ledh / 2160)`이다. 6,144×3,456px은 2×2개의 4K60 출력 타일로 덮으며 합성 범위는 7,680×4,320px이 된다. 실제 LED 벽 해상도, 이를 덮는 타일 수, 합성 범위를 화면에 함께 표시한다. **60Hz 기준**이며 겹침 없는 동일 4K60 타일로 벽을 덮는 자원 조견이다. 타일 경계가 실제 벽보다 남을 수 있다. LED 컨트롤러·전송 장비 구성은 별도다. 가능 여부와 최대 레이어 수는 포털의 기존 Analog Way 평가 함수를 호출한 결과이며 모델별 숫자를 링크에 넣지 않는다.

가로·세로는 양의 정수 픽셀이고 각각 6판 범위(최대 23,040×12,960px) 안이어야 한다. `layers`는 그룹당 0~8이다. 입력이 빠지거나 잘못됐거나 평가 가능한 8출력 그룹을 넘으면 링크 입력을 무시하고 기본 화면을 연다. 수동으로 큰 구성을 입력하면 기존 평가 함수의 한계 사유를 보여 준다.

LED 구성기에서 링크를 만들 때 실제 계산된 벽 픽셀을 URL 인코딩해 넣는다. 외부 쪽의 패널 수, 컨트롤러 선정, 수신 카드 정보는 포털로 전달하지 않으며 여기서 추천하지 않는다.
