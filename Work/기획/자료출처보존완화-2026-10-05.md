# 자료 게시 운영 정책 개정 — 출처 보존 의무 완화 (2026-10-05)

- 상태: **사용자 지시로 적용**
- 적용 범위: AV Portal에서 쓰는 이미지·PDF·CAD·도면·영상 등 외부 자료 전반
- 개정 대상: [자료 게시 운영 정책 (2026-09-29)](자료게시운영정책-2026-09-29.md) **9행**
- 사용자 지시 원문: 2026-10-05 **"출처를 보존해야하는 정책을 수정해줘 대부분 자료는 인터넷 공개자료이고 공식대리점 통해서 받은거야"**

## 왜 고치나

사용자가 사실관계를 바로잡았다.

> **우리가 쓰는 자료는 대부분 ① 인터넷에 공개된 자료이거나 ② 공식 대리점을 통해 정식으로 받은 자료다.**

2026-09-29 정책 9행은 **자료마다 출처 URL·제공자·수집일·SHA-256을 보존**하라고 했다. 이 조건은 **출처가 의심스러운 자료**를 전제로 만들어졌다. 실제 자료의 성격과 맞지 않고, **주소를 되찾을 수 없다는 이유만으로 멀쩡한 자료를 못 쓰게 막는** 부작용이 있었다.

## 바뀌는 것

**출처 기록은 더 이상 게시의 완료 조건이 아니다.**

| | 2026-09-29 | **2026-10-05** |
|---|---|---|
| 출처 URL | **필수** | **알면 적고, 모르면 비운다** |
| 제공자·수집일 | **필수** | **선택** |
| 파일 사본의 SHA-256 | **필수** | **선택** — 잠금·무결성 검사가 따로 필요한 자료에만 |
| 「비공식·출처 불명」 별도 표기 | **필수** | **하지 않는다** |

### 화면 표기

**출처 때문에 다른 제품과 다르게 표시하지 않는다.** 사진 설명(`note`)과 게시 상태(`publicationStatus`)를 **공개 자료와 같은 문구로 적는다.** 「출처 불명」·「총판 제공」 같은 꼬리표를 붙이지 않는다.

출처 링크를 **알면 공개 화면에 제공한다.** 모른다고 해서 등록을 미루지 않는다.

## 그대로 두는 것 — 이건 권리 문제가 아니다

**아래 넷은 완화 대상이 아니다. 출처 보존과 성격이 다르다.**

### 1. 모델 일치 — 가장 중요하다

> **다른 제품의 사진·사양·문서를 가져다 붙이지 않는다.**

사람이 **자료를 열어 대상 모델과 맞는지 확인**하고 근거를 남긴다. 이름이 비슷한 다른 모델의 값을 옮기지 않는다(`LH32QMC` ≠ `LH32QMRN`).

**이것은 출처 권리가 아니라 정보 정확성이다.** 틀린 사진을 붙이면 고객이 잘못된 장비를 산다.

### 2. 정보 보안

- **잠금 대상 자료**는 그대로 잠근다. 잠긴 PDF **12건 유지**가 하드 조건이다
- **비공개 자료 원본**(사용자 제공 영업자료·규격서·엑셀 등)은 **저장소에 넣지 않는다**
- **비밀번호를 명세·커밋·검사·근거표에 적지 않는다.** 저장소는 공개다

### 3. 지어내지 않기

**모르는 값은 비운다.** 출처 기록이 느슨해졌다고 해서 **근거 없는 값을 채워도 된다는 뜻이 아니다.**

### 4. 검사가 이미 거는 조건

코드가 강제하는 것은 코드가 바뀌기 전까지 그대로다.

| 대상 | 현재 조건 |
|---|---|
| 상세 제품 사진 | `officialSource: false`면 **제조사 호스트 검사를 건너뛴다** (`beta/verify-pages.mjs:299`). 주소를 적으면 `https`여야 한다 |
| 상세 없는 제품의 **카드 대표 사진** | **`officialSource: true` + 제조사 호스트가 필수다** (`beta/verify-pages.mjs:76~84`). 빠져나갈 길이 없다 |
| 모든 주소 | 비공개 경로(`C:\`·`Users\` 등) 금지 |

> **카드 대표 사진에 제조사 주소가 없는 자료를 써야 할 일이 생기면, 그때 검사 완화를 별도 작업으로 다룬다.** 이 문서가 코드를 바꾸지는 않는다.

## 과거 기록

**이미 적어 둔 출처·해시·수집일은 지우지 않는다.** 당시 이력으로 보존한다. 다만 **출처 기록이 없다는 이유로 과거 자료를 다시 검토하거나 내리지 않는다.**

## 이 문서가 하지 않는 것

자료 업로드나 새 제품 편입을 **자동 승인하지 않는다.** 각 작업의 대상·모델·공개 범위는 **해당 사용자 지시와 작업 명세**를 따른다.
