# W-20261004-002 — 01 폴백·버전 배지 검증 근거

기준: `origin/main` `e1f57018a243da5336c9ae4b920d6e96e29a79de`. 공개 AV 상세 JSON 242종은 변경하지 않았다. 그중 작성된 `keyFacts` 76종, 자동 폴백 166종을 분리했다. RTCOM 상세 32종은 이 배치의 166종에 포함되지 않으므로 기존 폴백 선택과 표시를 유지했다.

## 길이 기준과 화면 판정

명세의 24자 우선·48자 상한을 먼저 구현해 166종을 Chromium 390px에서 확인했다. 9종의 12개 값이 2줄 셀에서 잘렸다. `mxc420-c`의 한글 23자 값도 잘려, 글자 수만 48자로 제한하는 방식으로는 해결되지 않았다. 확인한 9종은 `avhub`, `cm20`, `h-output-card-hdmi20-4k`, `h-preview-card-2xrj45-1xhdmi13`, `hyperdeck-studio-hd-plus`, `mxc420-c`, `strong-usb-cable`, `ultripower-ps`, `ulxd8`이다. 따라서 **16자 이하 우선, 부족하면 20자 이하**로 조정했다. `[value, unit].filter(Boolean).join(' ')`을 기준으로 센다. 후보 순서는 기존의 그룹별 앞 두 행을 따르고 검증 상태가 `REVIEW REQUIRED`·`CONFLICTED`·`MISSING`인 행은 제외한다.

숨긴 제품은 **`cm20`, `ultripower-ps`**다. 01의 설명·카테고리는 남고 사양 격자만 숨는다. [166종 화면 검사](W-20261004-002-screens/fallback-audit.json)에는 제품별 최종 값·잘림·가로 넘침·JS 오류를 남겼고, [변경 전후 선택 결과](W-20261004-002-screens/fallback-analysis.json)에는 242종 전체의 후보·선택·제외 행을 남겼다. `vs10`의 실제 게시 `지원 포맷` 표시값은 명세의 95자가 아닌 **67자**였지만, 상한 초과와 카드 혼잡은 같았다. `gs728tppv3`의 `모델 설명`·`주문 코드`도 01 카드에서 빠졌다. 사양 원본 행은 그대로 남았다.

변경 전 네 칸에서 자주 밀려난 사양 이름은 `광원 수명` 15, `전원` 11, `카드 치수(W x D x H)` 10, `밝기` 9, `모델 설명` 8, `구성` 7, `지원 해상도`·`지향 패턴`·`비디오 처리` 각 5회다. 짧은 값 우선이라는 임시 규칙 때문에 중요한 `밝기`도 밀릴 수 있다. 다음 직접 작성 `keyFacts`에서 제품군 축을 골라야 하는 근거다. 폴백의 17~20자 값에만 2줄 제한을 적용하고, 작성된 `keyFacts`의 공통 `long-key-value` 스타일은 원래대로 보존했다.

## 버전 배지와 화면

기존 “배포 메타데이터는 내부용” 결정을 사용자의 2026-10-03 “프로그램에서 버전 표기가 우측 상단에 있게해줘” 지시로 뒤집었다. 공개 홈·정적 카탈로그·상세에 배지를 붙였고, 시안 페이지에는 붙이지 않았다. 홈·상세의 `sticky` 헤더가 우상단을 차지하므로 처음의 `top:12px`/모바일 `8px`은 실제 헤더와 겹쳤다. 최종 위치는 홈·상세 기본 **112px**, 721~1000px 홈 **155px**, 720px 이하 홈 **185px**·상세 **120px**이다. 카탈로그는 별도 정적 헤더의 우상단 빈 공간인 **12px**(460px 이하 **8px**)이다. 카탈로그의 넓은 `header` 영역 직사각형과 배지 직사각형은 교차하지만 제목·설명·링크 등 실제 콘텐츠와는 겹치지 않는다.

[수정 전 18화면](W-20261004-002-screens/before/)과 [수정 후 18화면](W-20261004-002-screens/after/)은 `vs10`·`gs728tppv3`·`ua845uwb`·`eikos-4k`, 작성 카드 3종(`lh43qhcebgcxkr`·`dci-4-600da`·`varia-80`), 홈·카탈로그를 각각 1280px·390px에서 나란히 비교할 수 있다. [721px·1024px 추가 화면](W-20261004-002-screens/intermediate-final/)과 [950px 화면](W-20261004-002-screens/width950/)도 보존했다. 홈·상세 배지와 헤더 조작 요소의 겹침, 페이지 가로 넘침, 값 잘림, JS 오류는 **0건**이었다. 작성 카드 3종 × 2폭의 카드 값 목록은 수정 전후 정확히 같다. 로컬 배지의 `build local · unreleased`는 정상이며 Pages 배포에서 갱신된다.

정적 `catalog.html`은 배지 스크립트 하나를 읽지만 제품 281건의 본문과 링크는 생성된 HTML에 이미 들어 있어 JavaScript 없이도 읽힌다. 기존 정적 카탈로그 검사에서는 모든 `<script>`를 막고 있었으므로 버전 스크립트 **하나만** 허용하도록 좁혔다. 상세는 원본 시안에서 생성되는 파일이므로 `beta/detail-asset-transforms.mjs`에 공개 배지 삽입을 반영했다.

## 회귀·리뷰

- 전용 검사 처음: **3 fail / 0 pass**. 구현 후 **4 pass / 0 fail**. 작성 카드 스타일 분리와 RTCOM 기존 선택 보존은 각각 회귀를 먼저 재현해 수정했다.
- 독립 리뷰: Critical 0, Important 3. (1) 작성 카드의 `long-key-value`에도 새 2줄 제한이 걸릴 수 있음 → AV 폴백 전용 선택자로 격리. (2) RTCOM 32종에도 필터가 적용되어 `rtcom-umc`가 4칸에서 1칸이 됨 → RTCOM은 기존 선택·표시를 유지하고 32종 검사 추가. (3) 홈 901~1000px에서 헤더 두 줄과 배지가 겹침 → 홈 721~1000px의 `top` 155px, 950px 재확인. 남은 Critical/Important 0.
- 제품 JSON 242종은 `git diff origin/main -- beta/site/detail/data` **0건**. 02 PORT MAP 및 원본 자산도 변경하지 않았다.
