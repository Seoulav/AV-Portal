## 구현 결과

네 제품의 해설 데이터 모델을 같은 필드 구조로 맞췄다. 화면 수 최대일 때 화면당 레이어와 한 화면만 쓸 때 최대 레이어를 분리하고, 화면 수 최대 구성의 Aux 수를 별도 표시한다. Zenith의 화면별 자원 배분 예와 2×2 비교도 추가했다. 배경·전경 레이어, Aux의 고정 레이어/자원 사용, 믹싱과 분할을 쉬운 말로 설명한다. Eikos Hard/Soft Edge의 두 출력 블렌딩 화면은 MM 42쪽을 근거로 표시한다.

Work 독립 검토 후 동시 최대값을 분리하고, 화면 최대 구성 때 Zenith 100/200의 Aux를 각각 1/2개로 정정했다. 화면별 배분 예를 AM 43쪽에 맞췄다. 배경은 라이브 입력 또는 정지 이미지이며 라이브 화면마다 별도 배경·전경 레이어가 있다고 정정했다. Midra 1080p Aux는 크기 조절 불가 레이어 1개, Alta Aux는 레이어 자원을 쓰지 않는다고 표시했다. XDM 원문은 접고 쉬운 요약을 먼저 보이며, 공개 화면의 “작업 PR 본문” 안내를 제거했다.

Zenith 100·200은 Alta 4K라는 공식 계열명을 사용한다. 모델별 데이터시트와 공용 매뉴얼의 레이어 규칙을 `Work/기록/W-20261016-011-근거표.md`에 기록했다. 영어 원문과 인쇄 쪽수는 이 파일과 PR 본문에 함께 적는다.
