## 무엇을 고치는가

DM7 Port Map 번호가 **63개**이고 그중 48개가 설명까지 같다.

| 묶을 대상 | 현재 | 설명(전부 동일) |
|---|---:|---|
| 아날로그 입력 | 32개 | `밸런스 XLR · 마이크 또는 라인 레벨 소스를 연결합니다.` |
| OMNI OUT | 16개 | `밸런스 XLR · 아날로그 오디오를 출력합니다.` |

나머지 15개(AES/EBU 입출력, 타임코드, 워드 클록 입출력, Dante PRIMARY/SECONDARY, NETWORK, USB TO HOST, GPI, PY 카드 슬롯, AC 전원 A/B)는 **각각 고유하므로 그대로 둔다.**

**63 → 17개**가 목표다.

### 묶는 방식

```text
이전:  { n:1, label:"아날로그 입력 1", desc:"밸런스 XLR · 마이크 또는 라인 레벨 소스를 연결합니다.", x1:…, x2:… } × 32
이후:  { n:1, label:"아날로그 입력 1–32", desc:"밸런스 XLR 32개 · 마이크 또는 라인 레벨 소스를 연결합니다.",
         x1:<첫 단자 왼쪽 끝>, x2:<마지막 단자 오른쪽 끝>, y:…, side:… }
```

`portMap.items`가 이미 `x1`~`x2` 가로 범위를 지원하므로 **렌더러·스타일 코드를 고치지 않는다.** 데이터 변경만으로 된다.

주의할 점:

1. **블록이 떨어져 있으면 블록마다 따로 묶는다.** 한 번호가 사진의 빈 구간을 가로지르면 안 된다. DM7 뒷면은 XLR 블록이 여러 덩어리로 나뉘어 있으니 실제 사진을 보고 판단한다.
2. **수량을 사진에서 세지 않는다.** 기존 PDF 쪽 근거 또는 기존 `io` 수량으로 확인된 값만 `desc`에 적는다. 확인 안 되면 범위·수량 표기 없이 묶기만 한다.
3. 번호를 **1부터 다시 연속**으로 매긴다. 순서는 기존대로 입력 → 출력 → 네트워크/제어 → 전원.
4. `dm7.json`의 `portMap` 외 값은 건드리지 않는다.
