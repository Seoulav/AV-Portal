# W-20261004-031 제조사 링크·돋보기 검증

## 제조사 링크

- 기존 목록은 `?brand=…&sort=brand`를 읽고 브랜드를 **대소문자까지 정확히** 비교한다. `catalog.json`에는 250종·28개 제조사가 있고 상세 JSON 243종 중 Sony 5종의 표시명만 `SONY`, 목록 값은 `Sony`다. 상세의 표시 문자열을 그대로 링크에 넣으면 이 5종은 빈 목록이다.
- 링크의 **표시 글자**는 상세의 `manufacturer`를 유지한다. **필터 값**은 카탈로그의 해당 `slug`가 가진 `brand`를 사용한다. 상세 데이터나 목록 필터를 고치지 않았다.
- 링크를 브레드크럼, 제목 밑의 제조사 부분, MANUFACTURER 카드에 둔다. 제목 밑 시리즈·분류 문구까지 링크로 묶지 않았고, 바닥글·확대 대화상자의 제품 이름은 그대로다. 세 링크는 밑줄·강조색·키보드 초점 윤곽을 갖는다.
- 시안은 공개 상세와 상대 경로가 달라 `../../beta/site/`로 이동한다. 독립 리뷰 Important 1건으로 발견해 수정하고 URL 해석 검사에 고정했다. 공개 상세는 `../`로 이동한다.
- 전용 검사는 카탈로그의 상세 243종과 28개 제조사에 대해 정확한 필터 값과 비어 있지 않은 목록을 확인했다. 실제 Chromium에서 Samsung **18종**, Sony **5종**, BSS Audio **9종**으로 브레드크럼 이동을 확인했다(1280px·390px). 카탈로그 요청 실패 시 표시 제조사로 링크를 구성하는 폴백은 남는다. 이 경우 `SONY`는 필터에 맞지 않을 수 있으나, 정상 게시 상태에서는 같은 사이트의 카탈로그가 제품 상세와 함께 제공된다.

## 돋보기

- 기존 확대 보기와 사진 Port Map이 같은 `attachLoupe`·`LOUPE_SIZE`를 사용한다. **둘 다 180→216px**로 바꾸고 3배 대화상자 배율·Port Map 1.2배는 유지했다. 따로 분기하면 동일 부품이 갈라지므로 공유했다. JS·CSS 지름 일치와 `Diagram` 비활성은 전용 검사에 고정했다.
- Chromium에서 BLU-101 확대 대화상자의 실측 원 지름이 1280px·390px 모두 **180→216px**, Sony SRG-X40UH 사진 Port Map도 **180→216px**이었다. Port Map 390px 사진 표시 영역은 약 **501×284px**이고 원은 그 안에서 유지되며 바깥 번호표는 가리지 않는다. 원은 포인터를 올릴 때만 사진 일부를 덮고 떠나면 사라진다. 두 폭 모두 가로 넘침 0, 콘솔 오류 0.
- 납작한 BLU-101 사진의 확대 대화상자에서는 사진 래퍼 높이 때문에 원 일부만 보이는 기존 특성이 있다. 이번 변경은 해당 래퍼와 이미지 배율을 고치지 않았다. 세로 사진 SRG-X40UH의 Port Map에서는 216px 원이 온전히 보인다.
