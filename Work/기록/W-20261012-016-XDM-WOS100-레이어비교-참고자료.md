## XDM-WOS100 Wall Overlay 출력 카드 구성도

Analog Way Aquilon 데이터시트의 응용 구성도 방식으로 그렸다. XDM 메인프레임의 입력 슬롯에서 들어온 소스가 WOS100 카드 1장(HDMI 4포트)을 거쳐 비디오월 하나를 채우고, 그 위에 커맨드로 다른 소스를 중첩하는 흐름이다.

XDM-WOS100 카드 전면: HDMI 출력 4포트와 WOS100 인쇄 표기

| 항목 | 값 |
|---|---|
| 슬롯 명칭 | XDM-WOS100 – HDMI (Wall Overlay) Output Slot |
| 포트 | HDMI 출력 4포트 (Female HDMI, HDMI v2.0) |
| 최대 해상도 | 4096×2160@60Hz 4:4:4 · 3840×2160@60Hz 4:4:4 |
| 동작 모드 | Switching mode 또는 Video Wall 기능 · 심리스 전환 |
| 중첩(Overlay) | 커맨드로 Video 중첩 기능 사용 · 상세는 별도 커맨드 매뉴얼 |
| 장착 메인프레임 | XDM-12 / 20 / 36 / 72 / 144 / 216 (4포트 슬롯 공용) |

### 응용 구성도 — WOS100 1장으로 2×2 비디오월 + 중첩

WOS100 카드 1장은 HDMI 4포트로 2×2 비디오월 한 면을 채우고, 매트릭스의 어느 입력 슬롯 소스든 배경으로 보낼 수 있다. 중첩 윈도우(파란 상자)는 커맨드로만 켜며, 공개 카탈로그에는 중첩 개수·해상도·레이어 수가 적혀 있지 않아 그림의 2개는 예시다.

- **Aquilon의 "4K 레이어 / 2K 레이어"**는 같은 자원을 두 방식으로 쓰는 값이다. 4K 레이어 하나가 2K(DL) 레이어 둘과 같고, 분할(split) 레이어로 쓰면 다시 2배가 된다.
- **NovaStar H**의 값은 출력 카드 1매 기준이며 전역 합산이 아니다. 섀시 상한(H2 32 · H5 48)과 카드당 자원 중 작은 쪽이 실제 한도다.
- **Colorlight X100 Pro** 사양서는 레이어를 해상도로 나누지 않으므로 4K와 2K 칸을 합쳐 표기했다.
- **XDM-WOS100**은 레이어 수를 공개 자료에서 확인할 수 없다. 알티컴 커맨드 매뉴얼을 받으면 채울 수 있다.
