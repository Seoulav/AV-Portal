## XDM-WOS100 Wall Overlay 출력 카드 구성도

Analog Way Aquilon 데이터시트의 응용 구성도 방식으로 그렸다. XDM 메인프레임의 입력 슬롯에서 들어온 소스가 WOS100 카드 1장(HDMI 4포트)을 거쳐 비디오월 하나를 채우고, 그 위에 커맨드로 다른 소스를 중첩하는 흐름이다.

XDM-WOS100 카드 전면: HDMI 출력 4포트와 WOS100 인쇄 표기

| 항목 | 값 |
|---|---|
| 슬롯 명칭 | XDM-WOS100 – HDMI (Wall Overlay) Output Slot |
| 포트 | HDMI 출력 4포트 (Female HDMI, HDMI v2.0) |
| 최대 해상도 | 4096×2160@60Hz 4:4:4 · 3840×2160@60Hz 4:4:4 |
| 동작 모드 | Switching mode 또는 Video Wall 기능 · 심리스 전환 |
| 중첩(Overlay) | 커맨드로 Video 중첩 기능 사용 · 상세는 별도 커맨드 매뉴얼 |
| 장착 메인프레임 | XDM-12 / 20 / 36 / 72 / 144 / 216 (4포트 슬롯 공용) |

### 응용 구성도 — WOS100 1장으로 2×2 비디오월 + 중첩

WOS100 카드 1장은 HDMI 4포트로 2×2 비디오월 한 면을 채우고, 매트릭스의 어느 입력 슬롯 소스든 배경으로 보낼 수 있다. 중첩 윈도우(파란 상자)는 커맨드로만 켜며, 공개 카탈로그에는 중첩 개수·해상도·레이어 수가 적혀 있지 않아 그림의 2개는 예시다.

- **Aquilon의 "4K 레이어 / 2K 레이어"**는 같은 자원을 두 방식으로 쓰는 값이다. 4K 레이어 하나가 2K(DL) 레이어 둘과 같고, 분할(split) 레이어로 쓰면 다시 2배가 된다.
- **NovaStar H**의 값은 출력 카드 1매 기준이며 전역 합산이 아니다. 섀시 상한(H2 32 · H5 48)과 카드당 자원 중 작은 쪽이 실제 한도다.
- **Colorlight X100 Pro** 사양서는 레이어를 해상도로 나누지 않으므로 4K와 2K 칸을 합쳐 표기했다.
- **XDM-WOS100**의 출력 1개당 4개의 4K/60 소스 중첩은 사용자 확인(2026-10-12)에 따라 `FOUND`로 기록한다. 구성기의 「XDM-WOS100 레이어 구성도·비교표 보기」에도 같은 수치가 표시된다. 커맨드 가이드 44~55쪽은 OW 명령과 `P1234`의 네 우선순위 요소를 보여 주지만, **출력당 최대 레이어 수를 문장으로 명시하지 않는다.** 따라서 가이드를 4레이어 상한의 독립 근거로 인용하지 않는다.

### XDM Command Guide 1013 후속 대조 (2026-10-14)

- 사용자 제공 원본 `RTcom_XDM Command Guide_1013.pdf`: 73쪽, SHA-256 `986bb5e5727dc86449e4ad72572e7125ff24f192f32250dee7d3849952f651ec`, 열람 암호 없음. 포털 XDM 상세에 「XDM 커맨드 가이드(1013 · 사용자 제공)」로 게시한다.
- 가이드 **인쇄 44~55쪽**: XDM-WOS100 Wall Overlay `OW` 명령. 인쇄 45쪽의 `Pxxxx`는 출력 포트 우선순위이며 `P1234`와 `P4321` 예시가 있다. `X`·`Y`는 위치, `W`·`H`는 중첩 창의 크기이고 `W0`/`H0`은 레이어 해제다. 출력당 최대 레이어 수나 중첩 창 너비·높이의 실제 상한은 명시되지 않는다. 명령 예시를 근거로 이 제한을 새로 계산하지 않는다.
- 가이드 **인쇄 44쪽**의 Video Wall 타이밍 목록은 `W03`~`W14`를 지원 대상으로 적고 `W14`를 `3840×2160p@60`으로 적는다. 이는 명령의 타이밍 조건이며 모든 중첩 창이 그 해상도까지 독립적으로 지원된다는 뜻으로 확대하지 않는다.
- HOS100 참고: 가이드 **인쇄 25~28쪽**의 `OQ` Quadview 명령은 `L00`~`L13` 레이아웃 코드를 정의한다. 구성기의 「XDM-HOS100 멀티뷰 레이아웃 보기」에 표시된 14개 레이아웃 코드와 일치한다. HOS 수치를 WOS의 레이어 수 근거로 사용하지 않는다.
