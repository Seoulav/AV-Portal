## 불일치·제외 및 후속 자료

- Rio1608-D3: 공통 매뉴얼에 모델 적용은 확인되나 Rio1608 **자체 후면 그림 또는 단자 표**가 필요하다. 독립 리뷰에서 G2 누락을 발견해 최초 잠정 통과를 철회했다. Rio3224 전용 9쪽을 두 모델의 증거로 재사용하지 않는다. 기존 JSON은 바꾸지 않는다.
- Rally Mic Pod Hub: 공식 모델 전용으로 **3개 단자의 위치·기능을 각각 식별할 수 있는** 고해상도 후면 도면 또는 매뉴얼이 필요하다. 현재 PDF의 `1 to 3` 연결 가능이라는 제품 설명과 기존 I/O 수량만으로 세 번째 좌표를 추정하지 않는다. 기존 JSON은 바꾸지 않는다.
- H2: PDF 파일명의 PSU 표기는 실제 본문과 다르다. 정확 모델 H2 자료임을 1·7쪽에서 직접 확인했다. **독립 리뷰 Important 지적**으로 사진의 `I-4` 실크와 10쪽 최대 입력 카드 4개를 재대조했다. 예시 사진만으로 `I-1`~`I-4`와 `O-x`의 슬롯 경계·번호를 정확히 좌표화할 수 없어 입력·출력 선택 카드 슬롯 5개 잠정 마커를 제거했다. 고정 제어·전원 8개만 확정하며 슬롯 도면은 후속 자료로 남긴다.
- Rio: 9쪽 그림은 Rio3224-D3 전용이다. Rio1608-D3의 후면 공통 기능이 사진상 비슷해도 G2의 모델 전용 그림/표 요건을 충족하지 않는다.
- ULTRITOUCH-2-HR: PDF 23쪽은 HDMI·USB·ENET2 미구현이라고 밝힌다. 보이는 슬롯의 라벨이 있어도 동작 포트로 번호를 붙이지 않는다.
- GS728TPPv3: 고객 사용 금지 콘솔에는 번호를 붙이지 않는다. 전면 24 RJ45·4 SFP는 이 Rear 사진의 단자가 아니다.
- VS10: PDF 5쪽의 LAN은 사용자 기능 없음. RJ45가 보이더라도 지도에서 네트워크 제어로 확정하지 않는다.
