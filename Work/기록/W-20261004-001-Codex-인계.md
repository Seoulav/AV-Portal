## ★★ 가장 큰 위험 — `crop` 25종

알티컴에는 **`crop` 개념이 없습니다. 베낄 코드가 없는 유일한 부분입니다.**

지금은 CSS 음수 여백으로 잘라냅니다.

```js
featured.style.marginTop    = -map.crop.top    * cropScale + 'px';
featured.style.marginBottom = -map.crop.bottom * cropScale + 'px';
```

SVG에는 음수 여백이 없습니다. **`<image>`의 `y`와 `viewBox` 높이로** 같은 결과를 내야 합니다.
