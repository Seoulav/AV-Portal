## 완료 범위

사용자 제공 PDF **8개**를 `beta/site/manuals/`에 원본 바이트 그대로 복사했고 `beta/site/docs/manifest.json`의 `uploads`에 **17건**을 추가했다. 8개 제품의 자료 목록은 등록표에 제품별로 정리했다. 삼성전자 자료 5개와 윈스타비투비 자료 3개는 `title`에서 발행처·문서 번호 또는 원본 규격서 번호로 구분된다. 기존 `uploads` 5건·`mirrors` 111건과 모든 제품 JSON은 변경하지 않았다. 렌더러·스타일 코드도 변경하지 않았다.

QMC 규격서 2쪽은 `LH32QMRNBGCXKR`, 9쪽은 `LH98QMTBPGCXKR`로 직접 확인했다. 우리 `lh32qmcebgcxkr`·`lh98qmcebgcxkr`와 달라 규격서를 붙이지 않았다. `lh98qmcebgcxkr`에는 적용 목록에 있는 삼성 매뉴얼만 붙였다. 비디오월 매뉴얼의 실제 원본 파일명은 인계 표와 달리 끝에 `-1`이 붙는다. 문서 번호와 14쪽 내용은 일치한다.

`verify-pages`가 기존 3개 물리 파일만 허용하고 과거 두 Port Map 검사가 manifest 전체 SHA를 잠갔기 때문에, **검증 코드만 좁게 갱신**했다. 새 전용 검사가 기존 미러 111건·업로드 5건을 고정하고 새 PDF의 SHA·제품 연결을 검사한다. `verify-pages`는 manifest에 연결된 물리 PDF를 폴더와 대조하고 22개 업로드 행의 제품·경로·종류·제목을 검사한다.
