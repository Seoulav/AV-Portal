## 확인된 문서·콘텐츠 후보

1. **RS1 문서 유형**: `Aquilon RS1 Quick Start Guide`가 `User Manual` 유형으로 노출됩니다. 제조사에서 제공하는 QSG와 User Manual은 별도 항목입니다.
2. **RS 계열 매뉴얼 연결**: RS alpha·RS2·RS3·RS5 일부 공식 제품 페이지는 `LivePremier unit - User Manual`로, 다른 페이지는 `Aquilon unit - User Manual`로 표시됩니다. 포털에 공통 `Aquilon_User_Manual_v6.2.pdf`를 연결한 RS alpha/RS2/RS3/RS5에 대해 실제 PDF 적용 모델 목록과 현재 제품 페이지 링크를 확인해야 합니다. RS1·RS4·RS6는 공식 페이지에서 Aquilon manual/QSG 구성이 확인됩니다.
3. **브로슈어 링크 누락**: Aquilon RS alpha·RS2·RS3·RS4·RS5·RS6의 문서 제목은 있으나 포털 URL이 비어 있습니다. 공식 제품 페이지에는 Aquilon brochure가 연결돼 있습니다.
4. **QSG 누락**: RS2·RS4·RS5·RS6 및 RS alpha에 모델 전용 공식 QSG가 있는데 문서 항목이 없습니다. RS1에는 QSG가 있으나 유형을 바로잡아야 합니다.
5. **빈 문서 자리표시자**: 16종 전부 `Independent Specification` 항목이 URL 없이 `미확인`으로 남아 있습니다. Eikos 4K·Pulse 4K·Zenith 100/200·RC400T에는 `Technical Document` 빈 자리표시자도 있습니다.
6. **Pulse 4K 스트리밍 값**: 개요의 720p30과 기능/현재 공식 제품 페이지의 1080p30이 상충합니다. 후속에서 최신 공식 자료 대조 후 정리해야 합니다.
7. **Eikos 4K 모드 명칭**: 포털 `Mixer`와 공식 제품 페이지 `Switcher` 용어 차이.
8. **별도 시그널 플로우 부재**: C·Cmini·C+·Cmax·RS1만 `signalFlow` 데이터가 있습니다. RS alpha·RS2–RS6·Pulse 4K·Eikos 4K·Zenith 100/200·RC400T에는 별도 signalFlow 데이터가 없습니다. 1단계에서는 생성하지 않았습니다.
9. **RC400T 보강 가능 자료**: 공식 2D 도면·QSG·릴리스 노트·펌웨어가 제품 페이지에서 제공됩니다. 후면 지도/신호 관계 작성 가능 여부는 원본 도면·가이드의 실제 내용을 검토해야 합니다. User Manual은 현재 공식 페이지 문서 목록에서 확인하지 못했습니다.

## Port Map 및 레이어 계획

Port Map 15종은 이번 점검에서 좌표를 수정하지 않았습니다. `layerPlan`·`videoLayerPlan` 수치도 기존 값 그대로 유지했습니다. 해당 값들은 완료된 별도 검증 작업을 기준으로 보존했으며, 본 점검에서 새 수치 불일치를 발견해 기록한 항목은 없습니다. 제품 이미지·지도 좌표의 재측정은 수행하지 않았습니다.
