## 실제 완료·검증

DM7의 동일한 XLR 설명 48개를 오른쪽 입력 1–16, 가운데 입력 17–32, 왼쪽 OMNI OUT 1–16의 세 물리 블록으로 묶었다. 기존 고유 항목 15개를 보존해 총 **18개**다. 두 입력 블록 사이의 빈 구간 때문에 17개로 무리하게 줄이지 않았다. `워드 클록 입력`을 입력 구간으로 옮겨 번호는 1부터 연속이고 입력 → 출력 → 네트워크/제어 → 전원 순서다. `dm7.json`의 `portMap` 밖 원본 값과 이미지·PDF SHA-256은 불변이다. 다른 제품과 렌더러·스타일은 수정하지 않았다.

`node --test tests/remaining-port-maps.test.mjs`는 변경 전 3 pass / 1 fail (`63 !== 18`)에서 변경 후 4 pass / 0 fail로 바뀌었다. Chromium 로컬 1280px·390px 전후 4화면과 수정 후 1024px·721px 2화면에서 번호 겹침·잘림·페이지 가로 넘침·깨진 이미지·JS 오류·실패 응답이 모두 0이었다. 수정 후 설명 문장 중복은 0개다. 비교 이미지와 전체 목록 캡처는 근거표에서 직접 볼 수 있다. 전체 `npm test`와 Pages/검색 인덱스의 최종 결과는 커밋 후 진행 기록에 채운다.
