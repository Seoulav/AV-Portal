## 결과와 근거

타일 선택기의 현재 레이어 입력은 종전처럼 가능/불가 판정에만 사용한다. 가능한 Aquilon 카드의 최대치는 같은 벽·입력·보조 출력 조건에서 출력 그룹당 믹싱 0~8개를 기존 `calculateRecommendations`에 각각 넣고, 통과한 결과의 벽 전체 `used.layers` 최댓값을 읽는다. 모델별 최대 수치를 코드에 적지 않았다. 배경 1장은 처리 자원을 쓰지 않는 별도 층이다.

| 벽 | 모델 | 믹싱 N | 분할 표시 2N | 표시 판정 |
|---|---|---:|---:|---|
| 4×2 | RS2 | 8 | 16 | 그룹당 믹싱 5에서 불가 전환 확인 → 실제 최대 |
| 4×2 | RS4 | 12 | 24 | 그룹당 믹싱 7에서 불가 전환 확인 → 실제 최대, 분할은 환산 |
| 4×2 | RS6 | 16 | 32 | 그룹당 믹싱 8의 평가 상한 도달 → 여기까지 확인, 분할은 환산 |
| 2×2 | RS alpha | 4 | 8 | 그룹당 믹싱 5에서 불가 전환 확인 → 실제 최대 |
| 2×2 | RS4 | 8 | 16 | 그룹당 믹싱 8의 평가 상한 도달 → 여기까지 확인, 분할은 환산 |
| 4×4 | Cmax | 16 | 32 | 그룹당 믹싱 8의 평가 상한 도달 → 여기까지 확인 |

분할 수는 Work의 2026-10-17 답변대로 `믹싱 1개 = 분할 2개`로 표시했다. 근거는 Aquilon 매뉴얼 66쪽 pairs 규칙과 2026-10-17 시뮬레이터 실측이다. 그룹당 8개를 넘는 분할 수는 직접 평가한 값이 아니라 환산임을 카드에 밝힌다. Work 독립 검증 후에는 믹싱 평가가 그룹당 입력 상한 8개에 닿은 카드의 문구를 `최대`에서 `N개까지 확인(평가 입력 상한) · 실제 한도는 이보다 클 수 있음`으로 바꿨다. 상한 아래에서 다음 입력이 불가한 카드는 `최대`를 유지한다.

4×2 결과 요약에는 [공개 RS2 데이터시트](https://dwn01.analogway.com/Site+Internet/Series/Aquilon/Products/Aquilon+RS2/Technical+Datasheet/Aquilon-RS2-datasheet-en-20260703.pdf) 8쪽 응용 구성도(8K 월 2개 + 4K60 PIP 믹싱 8개 + AUX 4개)를 제조사 예로 링크했다. 사용자 제공 캡처 이미지는 저장소에 넣지 않았다. XDM·Alta·Midra 계산과 제품 JSON은 변경하지 않았다.
