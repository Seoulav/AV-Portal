## 구현 범위

영상·기타 제조사 확인 필요 행을 재조사했다. VARIA-80 공식 Quick Start Guide로 USB-C OTG 1개를 보강하고, Ki Pro GO2의 공유 타임코드 입력을 새 단자 중복 없이 처리했다. Roland 4종의 모델별 RS-232 핀아웃을 근거로 DB-9 양방향 포트를 생성했다. TR535에서는 공식 후면 사진과 브로슈어에 맞춰 HDMI·SDI·RS-232·RS-422 잭을 반영하고 기존의 허위 Ethernet 제어 단자 4개를 제거했다.

빌더 report는 확인 필요 **119→112행**, 단자 **2,836→2,842개**, I/O 있으나 단자 0 제품 **4→4**다. 변동과 남은 제조사별 사유는 [근거표](W-20261012-013-C3-근거표.md)에 있다. 세션 A 소유 오디오 제품과 TR315·TR335·`pt-*`는 수정하지 않았다.
