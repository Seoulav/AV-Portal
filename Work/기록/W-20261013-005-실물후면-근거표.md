## 사진 판독과 I/O

| 사진에 인쇄된 위치·명칭 | 제품 데이터 처리 |
|---|---|
| 오른쪽 CH.1부터 왼쪽 CH.8, 구별 MAX.2500W, 전체 MAX.9900W | 순차 출력 8구 지도 범위. 기존 전력 원문 충돌은 유지 |
| CH.8 옆 `TX RX V+ GND / SERIAL` | SERIAL 4핀 단자대 한 행 · 설명서의 RJ-45와 형상 차이 명시 |
| CH.4와 CH.3 사이 `24V / 1.5A DC OUTPUT` | 실물 인쇄 1.5A를 대표 표시, 리플렛 500mA·설명서 3쪽 800mA와 함께 `CONFLICTED` 유지. 모든 판본의 공통 정격으로 단정하지 않음 |
| `LINK OUT`·`SPRC LED`·`LINK IN`·`REMOTE SWITCH` | 사진상 서로 다른 Mini-DIN/RCA 단자를 각 행으로 기록. SPRC LED와 구판 REMOTE LED의 동일 기능 여부 미확인 |
| 오른쪽 `L/N/G`, `WHITE: LIVE / BLACK: NEUTRAL / GREEN: GROUND` | AC 입력 단자대. 설명서의 L/N/E 표기와 차이를 condition에 보존 |
| 비연동 AC 아울렛·별도 모니터 단자 | 리플렛의 기존 행은 지우지 않되 실물 후면에서 별도 식별되지 않는다고 표시. 사진 지도에는 없음 |

현재 I/O 10행(기존 8행). 사진상 단자 이외의 구판 RJ-45를 최신 Rear 지도에 그리지 않았다. 소개 문구도 RJ-45 및 비연동 아울렛을 현재 실물에서 확인한 것처럼 읽히지 않도록 판본 근거를 구분했다. 01 카드는 실물 DC 24 V / 1.5A와 세 출처의 전류 불일치를 나란히 보인다. 설정 가이드의 RJ-45 핀 그림은 원문 사실이므로 유지하고, 실물 사진 판본에 그대로 적용하지 말라는 문구를 추가했다.

Builder 생성 보고의 전체 수치는 현재 I/O 1575행·생성 단자 2884개·확인 필요 87행이며, 착수 기준은 I/O 1573행·생성 단자 2886개·확인 필요 83행이다. DS-8S 구판 RJ-45·REMOTE SWITCH 기반 생성 단자는 사진 기준의 단자로 교체하면서 빠졌고, 새 SERIAL/LINK/RCA는 신호 규격을 사진만으로 확정할 수 없어 확인 필요로 남는다. 실제 사진에 없는 구판 단자를 Builder에 유지하거나 프로토콜을 추정하는 override는 만들지 않았다. 다른 제품 데이터·Builder 변환 규칙은 변경하지 않는다.
