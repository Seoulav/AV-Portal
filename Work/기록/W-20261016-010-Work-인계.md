# W-20261016-010 Work 인계 — Aquilon 레이어 구성 해설·브로슈어 버튼

## 완료한 수정

- 2×2 4K60 화면은 4개 출력, 출력 용량 2씩 총 8개 출력 링크로 설명합니다. VPU 1개의 소스 링크 8개 중 용량 2 믹싱 레이어가 2개씩 사용하므로 화면 전체 최대 4개, 분할 레이어 8개입니다(매뉴얼 66·79쪽).
- 모델별 화면 수는 매뉴얼 71쪽의 4K60 PGM 출력 수÷4입니다. 화면당 레이어는 전 모델 4(분할 8)이며, 장비 전체 레이어는 모델별로 4(8)/4(8)/8(16)/8(16)/12(24)/12(24)/16(32)입니다. 출력 커넥터 수는 브로슈어 7쪽으로 별도 표기합니다.
- 화면 전체 레이어와 출력 안 PiP는 동일 자원을 사용해 PiP가 링크를 절약하지 않는다고 표시합니다(67–68쪽). Region Captive PiP 용어는 RS1 데이터시트 3쪽, Screen region 자원 최적화는 매뉴얼 83쪽 근거로 구분하고 절감 산식은 미확인으로 둡니다.
- 매뉴얼 101쪽의 배경 콘텐츠·출력 용량 일치 및 배경 비확대·축소를 반영했습니다. RS2 이상에서 링크 8개 이하 화면을 VPU 2개에 나눌 수 있는지, 용량 1 HD PiP 혼합 비용은 미확인으로 명시했습니다.
- XDM-WOS100 비교는 RTCOM 원본의 HDMI 4포트와 “커맨드 중첩(레이어를 쓰면 4포트 모두 같은 화면)”만 사용하며, 원본에 없는 레이어 수를 추가하지 않습니다.
- 390px 표의 좌우 스크롤 안내, 7종 `layerPlan` 검증, 롤백 해시, 제품 상세·프로토타입 렌더를 반영했습니다. 브로슈어 데이터 기반 빠른 문서 버튼은 유지했습니다.
