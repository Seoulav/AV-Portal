## 구현 범위

- 종합 페이지의 4K 패널 조견표: 1·2·3·4·6·8·9·12·16판 구성별 한 줄에 레이어 0개와 출력 그룹당 믹싱 2개를 합쳐 표시한다. 합성 해상도, 출력·링크·출력 링크 기준 Aquilon VPU, 시리즈별 가능한 모델을 보여 준다. 두 레이어 조건의 가능 모델이 같음을 평가 함수 결과로 확인한 뒤 한 줄로 합친다. 12판의 3×4·4×3 회전 구성도 같은 판정임을 검사한다.
- 기존 설계 가이드의 `4K 패널 가로×세로` 입력 방식: 가로·세로 1~4, 출력 그룹당 믹싱 레이어 0~8, 1×1·2×1·2×2·3×2·4×2·4×4 단추, 격자 그림과 즉시 갱신되는 모델 목록. 입력·결과·복사 텍스트에 `출력 그룹당`을 명시한다. 기존 해상도 입력·출력 구성과 평가 함수를 보존한다.
- 판이 4개를 넘으면 출력 4개 이하인 인접 그룹으로 나눠 기존 평가 함수에 전달한다. 이것은 출력·레이어 **자원 조견**이다. 여러 그룹을 하나의 끊김 없는 화면으로 잇는 기능까지 확정하지 않으며 제조사 시뮬레이터 확인을 안내한다. 계산 수치의 근거는 기존 [레이어 연출 기준](../기획/AnalogWay-레이어연출기준.md)과 [시뮬레이터 실측](W-20261017-003-시뮬레이터실측.md)이다.
- 제품 JSON·기존 Alta/Midra 평가식·RTCOM 원본·잠긴 PDF·Builder/CPQ는 변경하지 않았다.
