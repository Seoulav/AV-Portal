RTCOM raw 32개는 수정하지 않았다. 어댑터에서 원본 지도 36개를 개별 이미지와 묶어 전달하고, QMS-88UX의 비디오 모드와 오디오 출력 경로, 공식 링크를 보조 섹션/문서에 연결한다. XDM·SPX·VDM의 `lineup`은 원본 구성기에서 메인프레임·카드 목록으로 보이지만 포털에서 빠져 있었으므로 표로 전달한다. `catalogPages`는 제품의 사용자 기능이 아니라 카탈로그 참고 쪽수이며 기존 `documents`와 `sources`의 카탈로그 근거에 반영돼 있으므로 별도 화면 필드로 중복하지 않았다.

원본 `portMap`의 좌표와 번호는 유지했다. 원본에서 `side`를 생략하면 위쪽인 규칙만 포털의 아래쪽 기본값과 맞추기 위해 명시적으로 변환했다. 원본이 같은 면의 사진 여러 장에 지도를 각각 붙인 경우도 정확한 파일명으로 구분한다. 원본 링크의 HTTP 예외는 `rtcomav.com/kor/bbs/board.php`의 필수 쿼리가 있는 공식 링크에만 허용한다.

원본 구성기의 XDM 신호 구성 그래픽을 포털의 SIGNAL FLOW로 복제하지 않았다. 원본 `io` 행 근거가 없는 연결선을 그리면 사실을 만드는 것이기 때문이다. 대신 원본 메인프레임·카드 라인업을 표로 보존하고 기존 제품정보·슬롯 구성기 링크를 유지한다. XDM의 **내용 전달과 시각 배치는 구별**해야 한다.
