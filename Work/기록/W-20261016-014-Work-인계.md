# W-20261016-014 Work 인계

## 완료한 수정

- Aquilon RSalpha·RS1~RS6 카드형 지도를 카드 종류별 외곽 범위 괄호로 재배치했다. 입력 카드 종류는 왼쪽, HDMI 출력 카드 열은 오른쪽에 한 번호 원으로 표시하며 장착 카드 수를 설명에 넣었다. 번호와 단자 이름은 유지했다.
- Pulse 4K·Eikos 4K·Zenith 100·Zenith 200의 줄 간 지시선을 가장자리 짧은 괄호로 이동했다. 같은 높이의 괄호는 좌우 가장자리로 나눴다.
- RS 제어 단자의 하단 via 경로를 PSU·GPO 블록 사이 빈 세로 통로에 배치했다. 제품 사진과 Port Map 데이터 외의 제조사 사양·I/O는 변경하지 않았다.
- Port Map 번호 집계와 비대상 제품 번호 목록 불변을 회귀 테스트로 추가했다. 이전 Aquilon 라벨 테스트는 새 카드 종류별 단일 괄호 규칙을 확인하도록 갱신했다.
