이번 사용자 승인 범위는 BRC-AM7 로컬 시안의 **재사용성 정리**다. Draft PR #34에서 공통 화면 렌더러와 제품별 데이터 객체의 경계를 만들었다. `product-detail-model.mjs`가 Quick Documents 네 슬롯·Additional 자료·가변 사양/I/O 그룹·Rear 이미지 위치를 준비한다. `app.js`와 `index.html`의 SONY/BRC 고정 값은 제거하고 BRC 콘텐츠의 `presentation`에 기존 표시 문구, I/O 신호 매핑, PoE++ 안내를 넣었다. 콘텐츠의 Features 8·사양 27·I/O 14, 문서 8건, 출처·상태와 이미지 네 역할은 유지한다. 이는 화면 전용 임시 구조이며 최종 Schema/DB/Storage/API 결정이 아니다.
