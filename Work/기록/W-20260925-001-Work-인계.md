# W-20260925-001 Work 인계 — Group 1 상세 요약 UI 로컬 검토

2026-09-25 사용자 지시로 공개 상세 5개의 공통 화면을 제품 중심 요약형으로 바꿨다. 이 작업의 구현 PR에는 코드·진행 기록·이 인계서만 포함한다. main 병합과 GitHub Pages 배포는 사용자 화면 검토 전까지 하지 않는다.

- DM7 로컬 미리보기: `http://127.0.0.1:4225/detail/?product=dm7`
- 회사 PC의 Git 무시 캡처: `outputs/product-detail-preview/dm7-desktop-1440.png`, `dm7-mobile-390.png`

## 자료와 제한

- 공식 출처: [Sony BRC-AM7](https://pro.sony/ko_KR/products/ptz-network-cameras/brc-am7), [Yamaha DM7](https://kr.yamaha.com/ko/business/audio/products/mixers/dm7/), [AJA Ki Pro GO2](https://www.aja.com/products/ki-pro-go2), [Panasonic PT-MZ17KL](https://eu.connect.panasonic.com/be/en/projectors/pt-mz20-series/pt-mz17kl), [Logitech Rally Bar](https://www.logitech.com/ko-kr/products/video-conferencing/room-solutions/rallybar.html).
- 사진의 화면 표시와 공개 재게시 권한은 별개다. 기존 이미지 검증 상태는 변경하지 않았다. 사진 파일은 `outputs/`에만 있으며 Git에서 무시된다. 공개 JSON·Library·원본 조사 데이터는 수정하지 않았다.
- Work에서 다음 기획 시 공개 사진 권리 증빙 또는 사용자가 직접 보유한 사진을 제품별로 연결하는 조건을 정리하면 된다. 사용자의 별도 승인 없이 이 PR을 병합하거나 Pages를 배포하지 않는다.

## 후속 화면 검토 — 연결 단자

- 연결 단자는 공통 renderer에서 `그룹 수량 요약 → 압축 행 → 상세 보기`로 변경했다. 사용자 화면에는 I/O 대신 연결 단자라고 표시한다.
- DM7 표시 요약: 오디오 4, 네트워크·제어 3, USB 2, 동기 3, 확장 1, 전원 2. 원본 그룹·15개 항목·각 필드·출처·검증 상태는 삭제하지 않았다.
- BRC-AM7과 DM7의 공식 Rear 이미지는 로컬 미리보기에서 단자 목록 왼쪽에 표시한다. 나머지 3개는 Rear가 없어 이미지 열을 만들지 않는다. 단자 위치 번호는 근거가 없어 생략했다.
- 검토 캡처는 기존 두 PNG를 갱신했다. DM7 페이지 높이는 1440px 폭에서 3698px, 390px 폭에서 4196px이며 가로 넘침은 두 화면 모두 0이다.
- 자동 검증은 1440·768·390px에서 5개 제품의 단자 14/15/11/4/9, 그룹 요약과 상세 펼침, Specs 27/16/16/13/16, 문서 4칸, Rear 유무와 가로 넘침 0을 확인했다. 합친 그룹의 원본 그룹명과 미확인 Fixed/Optional 값은 단자 상세에 남긴다. `node beta/verify-pages.mjs`와 `npm test`(49 pass·1 skip·0 fail)가 통과했다.
