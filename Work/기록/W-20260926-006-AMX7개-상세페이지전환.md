# W-20260926-006 — AMX 7개 제품 상세페이지 전환 기록

## 대상

NX-3200, NX-2200, NX-1200, VARIA-100, VARIA-80, VARIA-SL80, VARIA-SL50 (모두 AMX, HARMAN Professional Group 소속).

## 조사 과정

### NetLinx NX 통합 컨트롤러(NX-1200/2200/3200)

각 제품의 amx.com 제품 페이지에서 Data Sheet PDF 링크(`/en-US/product_documents/nx-<모델>-datasheet-pdf`)를 확인했다. 이 링크는 302 리다이렉트를 거쳐 `adn.harmanpro.com/product_documents/documents/<id>_<timestamp>/<Model>.DataSheet_original.pdf` 형태의 실제 PDF를 서빙한다. 세 모델의 데이터시트를 모두 PDF로 확보해 텍스트를 추출했다.

- NX-1200(FG2106-01): 1RU x 1/3 랙 공간, AxLink 1개, LAN 1개, 디지털 I/O 4개, RS-232/422/485 1개, RS-232 전용 1개, IR/Serial 2개, IR 수신 1개. 크기 42.16×147.32×130.81mm, 무게 0.726kg.
- NX-2200(FG2106-02): 1RU, Dual NIC(LAN+ICSLan), 디지털 I/O 4개, RS-232 전용 3개, IR/Serial 4개, 릴레이 4개. 크기 45.15×431.80×231.64mm, 무게 2.758kg.
- NX-3200(FG2106-03): NX-2200과 동일 크기/무게이나 포트를 8/8/8/8(Serial/Relay/IR/Digital I/O)로 확장(NX-2200의 4/4/4/4 대비 2배). AxLink 2개, RS-232/422/485 2개, RS-232 전용 6개.

세 모델 모두 1600 MIPS 프로세서, 512MB DDRAM, 1MB NVRAM을 공유하며 SD 메모리 카드 용량만 차이(NX-1200: 4GB, NX-2200/3200: 8GB).

이 세션 후반 재확인 시점에 동일 amx.com product_documents 링크가 403 Forbidden을 반환했다(레이트 리밋 또는 일시적 차단으로 추정). 이미 확보한 PDF 텍스트로 작업을 진행했으며, sources에는 원래 확인했던 amx.com product_documents URL을 그대로 기록했다.

### Varia 터치 패널(VARIA-100/80/SL80/SL50)

NX 컨트롤러와 달리 4개 Varia 제품 페이지에는 별도의 다운로드 가능한 Data Sheet PDF 링크가 HTML에 없었다(datasheet/DataSheet/documents 패턴 grep 결과 0건). 대신 각 제품 페이지 자체에 "Specifications" 제목의 표가 직접 임베드되어 있어, 이 표를 1차 출처로 사용했다.

- VARIA-100: 10.1" 1920×1200, 스피커 2×2W, 카메라 5MP, NFC 지원, 173.9×242.88×20.5mm, 567g.
- VARIA-80: 8" 1280×800, 스피커 2×2W, 카메라 5MP, NFC 지원, 148.9×201.2×21.7mm, 532g.
- VARIA-SL80: 8" 1280×800(SL=Slim Line, 싱글갱 전기박스 매립형), 스피커 2×1W, 카메라 5MP, 127.64×213.22×26.65mm, 482g.
- VARIA-SL50: 5.5" 720×1280(portrait), 스피커 1×1W, 카메라/NFC 미지원(N/A), 143.4×80.8×24.3mm, 173g — Varia 시리즈 중 최소형.

각 페이지 Downloads 섹션에는 별도 Data Sheet PDF 항목(예: "Data Sheet – VARIA-100" 버전 B)이 표시되어 있었으나, 실제 PDF 파일 URL을 확보하지 못했다(다운로드 링크가 JS 기반 동적 생성으로 추정). 이에 따라 4개 제품 모두 issues에 "Data Sheet PDF 접근 불가"를 REVIEW REQUIRED로 기록하고, 페이지 내 Specifications 표를 근거로 명시했다.

4개 Varia 제품은 공용 "Configuration & Programming Manual – Varia Touch Panels"를 사용하며, 이는 seriesNote에 기록했다.

## 이미지 확보

7개 제품 모두 각 amx.com 제품 페이지의 히어로 이미지(`productattachment/<id>/product_attachment/vert_medium_2x-<hash>.webp`)를 다운로드해 확보했다. NX 컨트롤러 이미지는 전면·측면에 모델명이 인쇄돼 있어 시각적으로 식별 가능하나(다만 육안 검증까지는 VERIFIED로 격상하지 않고 FOUND로 유지, RC400T처럼 모델명이 큼직하게 보이는 경우만 VERIFIED 사용), Varia 패널은 화면 자체에 브랜딩이 없어 FOUND로 유지했다.

다운로드한 파일 크기: nx1200(900×298), nx2200(900×177), nx3200(894×178), varia100(1500×1124), varia80(1500×1124), variasl80(1500×1125), variasl50(1136×1600, 세로형).

## 코드 변경

- `beta/manufacturer-hosts.mjs`: AMX 항목에 `amx.com`, `harmanpro.com` 추가(`techdata-ps.com`는 유지). 기존 카탈로그의 official_links가 이미 amx.com이었고, 이미지·데이터시트 출처가 techdata-ps.com에는 없어 필요했다.
- `beta/group1-images.mjs`: 7개 슬러그 신규 항목(group1Images, cardImages) 추가.
- `beta/site/catalog.json`: 7개 AMX 항목에 slug·card_image 필드 추가(Python 스크립트로 brand='AMX' AND product 매칭).
- `beta/site/detail/data/*.json`: 7개 신규 파일(빌드 스크립트: `/tmp/.../scratchpad/build_batch6_details.py`, 기존 배치 스크립트와 동일한 헬퍼 함수 패턴 재사용).

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 이미지 파일명 중복 없음을 포함해 통과했고(7개 신규 파일 모두 고유 파일명 사용, 시리즈 공용 이미지 없음), npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다.

## 남은 일

- Varia 4개 제품의 공식 Data Sheet PDF는 접근 경로를 찾지 못했다. Work가 별도로 다운로드 URL을 확인하거나, 사용자가 PDF를 직접 제공할 경우 반영이 필요하다.
- NX 컨트롤러 3개의 amx.com product_documents 링크는 세션 후반 403을 반환했다. 재현 가능한 차단인지, 일시적 레이트리밋인지 후속 확인이 필요하다.
- 다음 최소 브랜드로 계속 진행 예정(NETGEAR/Roland/Yealink 각 8개 등).
