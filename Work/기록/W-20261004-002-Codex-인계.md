### 고치는 곳

`selectKeySpecifications()` — `beta/site/detail/product-detail-model.mjs:123`

```js
export function selectKeySpecifications(specificationGroups = [], limit = 10) {
  const selected = [];
  for (const group of specificationGroups) {
    for (const item of group.entries.slice(0, 2)) {
      if (selected.length >= limit) return selected;
      if (!['REVIEW REQUIRED','CONFLICTED','MISSING'].includes(item.verification)) selected.push(item);
    }
  }
  return selected;
}
```

규칙:

1. 표시값 = `[value, unit].filter(Boolean).join(' ')`
2. **24자 이하 먼저** 채운다
3. 모자라면 **48자 이하**로 채운다
4. **48자 초과는 쓰지 않는다**
5. **2개 미만이면 격자를 숨긴다**

5번은 새 규칙이 아닙니다. 작성된 `keyFacts`는 이미 `length >= 2`를 지킵니다(`detail-enhancements.mjs:100`). **폴백만 예외였습니다.**

안전망으로 `.long-key-value`에 `-webkit-line-clamp:2`.

**24·48은 제가 정한 출발점입니다. 실측해서 안 맞으면 근거와 함께 바꾸고 보고하세요.**
