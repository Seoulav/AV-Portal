# W-20260924-008 · Product Detail I/O 바로 보기 인계

2026-09-24 사용자의 공개 사이트 피드백에 따라 Group 1 상세 다섯 제품의 I/O를 첫 진입부터 바로 읽을 수 있게 바꿨다. 기존 I/O 그룹명과 각 제품의 항목 수를 유지하고, 그룹별 누르기 동작만 없앴다. 커넥터 행은 이름·방향·신호·수량·규격·고정/옵션을 먼저 표시하고 조건·공식 출처·검증 상태를 같은 행에 둔다.

공통 renderer인 `prototype/brc-am7/app.js`·`styles.css`와 이 파일에서 생성하는 `beta/site/detail/`의 두 파일만 바꾼다. 제품별 JSON, 공개 Library 27개, Quick Documents, 사양 및 검증 데이터는 변경하지 않는다. 공개 이미지·PDF나 비공개 원본을 추가하지 않는다.

`node beta/verify-pages.mjs` 통과, `npm test` 42 통과·1 로컬 비공개 입력 미설정 건너뜀·실패 0. 로컬 공개 아티팩트 1440px·390px에서 다섯 상세의 I/O 14/15/11/4/9개가 모두 클릭 없이 보이며 가로 넘침이 없다. 배포 후에는 실제 공개 URL에서 동일한 상태와 Library 보존을 확인한다.

사진·PDF 권한 및 기존 REVIEW REQUIRED 검토는 이 표시 변경으로 해결되지 않는다. Work는 이를 기존 조사 과제로 이어가며 I/O 값이나 검증 상태를 화면 변경만으로 확정하지 않는다.

PR #42는 main에 병합되고 Pages 배포가 성공했으나, 공개 브라우저에서 캐시된 이전 JS가 계속 사용되는 사례를 확인했다. 후속 캐시 수정에서 상세 HTML의 CSS·JS 주소에 이번 배포 버전을 붙였다. 공개 최종 확인은 그 후속 PR 병합 뒤 수행한다.

후속 [PR #43](https://github.com/Seoulav/AV-Portal/pull/43)은 `e1ff17f`로 병합됐고 [최종 Pages 실행 #35960141486](https://github.com/Seoulav/AV-Portal/actions/runs/35960141486)이 성공했다. 실제 공개 BRC-AM7 기본 링크에서 커넥터가 클릭 없이 보이는 것을 확인했다. 다섯 상세의 1440px·390px I/O 전체 수량·가로 넘침 없음·Quick Documents 4칸, 공개 Library 27개도 확인했다. 추가 제품·자료·검증 상태 변경은 없다.
