# W-20260926-016 — Crown 26개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-015(Powersoft) 완료 후 다음 최소 브랜드인 Crown(HARMAN Professional Solutions 소속, 26개)을 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다.

AMX·BSS Audio·JBL 배치에서 확인된 패턴대로 techdata-ps.com을 먼저 확인했으나, 이번에는 그마저도 아니었다 — Crown 제품 상세 페이지가 자바스크립트 렌더링 방식이라 정적 요청으로는 사양·이미지를 전혀 추출할 수 없었다(검색 결과로 매뉴얼 PDF 1건과 케이스스터디 게시물 제목만 확인). 규칙에 따라 제조사 공식 사이트(crownaudio.com)로 완전히 대체해 사양·이미지 전부를 확보했다.

## 모델 접미사 정정

작업 지시에 포함됐던 접미사 의미 추정이 실제와 달랐음을 조사 과정에서 발견하고 정정했다(모든 해당 제품의 issues에 명시):

- **"BL" 접미사**: 전력/전압 변형이 아니라 HARMAN 독자 규격 BLU link(256채널 디지털 오디오 버스) 지원 모델을 의미한다. BL 모델과 비BL 모델의 출력 사양(W)은 동일하다(예: CDi 2/300과 CDi 2/300BL은 W 수치가 같음).
- **"N" 접미사**: Dante가 아니라 BLU link 기반 "Network 시리즈"를 의미한다. 실제 Dante/AES67 지원은 "DA" 접미사 모델(DCi 4/300DA, DCi 4/600DA)에만 있다. 이는 제조사 자체 제품 영상 설명("Install DA Series is a Dante/AES67 solution, Install Network Series features BLU link")으로 확인했다.

## 데이터 완성도

- **CDi DriveCore 12개(2/300, 2/300BL, 2/600, 2/600BL, 2/1200, 2/1200BL, 4/300, 4/300BL, 4/600, 4/600BL, 4/1200, 4/1200BL)**: 부하별(2/4/8/16Ω, 70V/100V) 정격 출력표, 브릿지 모노 출력표, THD/주파수응답/SNR/댐핑팩터/크로스토크/입력감도, 물리 사양, 전원까지 전부 확인. 동작 온도·인증 세부는 페이지 텍스트에 없어 정보 없음 유지.
- **DCi Install 10개(2/300, 2/300N, 2/600, 2/600N, 4/300, 4/300N, 4/600, 4/600N, 4/300DA, 4/600DA)**: 위와 동일 수준으로 확인. DA 2개 모델은 Dante/AES67 이중화 포트, 48/96kHz, Dante Domain Manager 지원까지 반영. SNR/크로스토크는 DCi 페이지에 없어 정보 없음.
- **I-Tech 4X3500HD**: THD/SNR(≥108dB)/IMD/댐핑팩터(>5000) 등 오디오 성능, 물리·전원 사양, 전면+후면(Speakon 백패널) 이미지 확보. 부하별(2/8/16Ω, 70V/100V, 브릿지) 세부 출력표는 페이지 텍스트에서 확인되지 않아 이슈로 남김.
- **ComTech D 2125/4125/8125**: 채널 수, 파워쉐어링 출력, Dante+DSP+HControl 기능 목록, 전면 이미지만 확보(공식 페이지에 후면 이미지 자체가 없음). THD/주파수응답/SNR/임피던스/정확한 치수·무게/동작온도/인증 수치는 페이지 텍스트에 전혀 없어 이 배치에서 커버리지가 가장 낮은 제품군이다 — 데이터시트/매뉴얼 PDF 원문 대조가 필요하며, URL은 기록했으나 이번 배치에서는 PDF를 직접 열람하지 않았다.

## 이미지

adn.harmanpro.com에서 각 제품의 `x_large_2x`(최고 해상도) 변형을 확보했다(원본 4096px 폭). 다른 배치(JBL)의 1500~2100px 이미지보다 훨씬 커서(파일당 최대 500KB) 웹 서빙에 과도하다고 판단, 폭 2000px로 리사이즈 후 cwebp -q 85로 재압축해 파일당 100~250KB 수준으로 낮췄다(원본 해상도는 originalSize 필드에 그대로 보존).

- **CDi/DCi/I-Tech 23개 모델**: 전면+후면 모두 확보.
- **ComTech D 3개 모델**: 공식 사이트에 후면 이미지가 게시되어 있지 않아 전면만 반영(대체 이미지 강제 삽입 없음).
- DCi 2채널/4채널 시리즈의 후면 이미지는 모델별 개별 촬영이 아니라 시리즈 공용 대표컷(예: "DCi 2 CH 후면 공용 이미지")을 재사용하고 있음을 그대로 반영했다(alt 텍스트에 "공용 이미지"로 명시).

## 검증
