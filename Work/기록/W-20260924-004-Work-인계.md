# W-20260924-004 → Work: 공식·한국 수입원 웹사이트 연결

2026-09-24 사용자는 **모든 제품**에 제조사 공식 웹사이트를 연결하고, 한국어 제조사 공식 사이트를 우선하며, 한국어 제조사 사이트가 없는 경우 확인된 한국 공식 수입원 홈페이지를 연결하도록 지시했다. 이는 링크 조사·연결의 목표이며 모든 제품의 URL이나 수입원 자격이 현재 확인됐다는 뜻은 아니다. 기존 공급처/업체 비공개 값은 공식 수입원 공개 증빙과 구분한다.

## 실제 확인한 현황

- GitHub Pages 공개 베타: 장비 25개, 제조사 모델 페이지 링크 25개, 수입원 유형 링크 0개. 보류 313개는 계속 비공개다.
- Git 제외 로컬 제품 목록: 338개 중 246개에 하나 이상의 `official_sources`, 92개에 없음. 브랜드 미식별 4개. 공식 출처 항목 490개 중 `language: ko` 명시 60개다. 60개는 문서도 포함하므로 한국어 제품 홈페이지 60개라는 의미가 아니다.
- 내부 탐색 화면은 명시적 한국어 제조사 출처를 먼저 표시하도록 코드 변경·테스트했다. 새 URL, 수입원 링크, 원본 목록은 아직 연결하지 않았다. 현재 `ko` 출처가 있는 50개 제품은 이미 그 출처가 앞에 있어 화면에서 즉시 바뀐 순서는 0개다.
- 제조사 직접 확인한 한국어 제품 페이지 후보: [BSS Audio EC-4BV](https://bssaudio.com/ko/products/ec-4bv/description), [NETGEAR GSM4248PX](https://www.netgear.com/kr/business/wired/switches/fully-managed/gsm4248px/), [NETGEAR XSM4216F](https://www.netgear.com/kr/business/wired/switches/fully-managed/xsm4216f/). 현재 제품 목록/공개 베타에는 이 URL들이 없다. 공식 페이지와 모델명을 열람했지만 기존 로컬 목록·공개 JSON은 이번 부분 작업에서 수정하지 않았다.
- [Powersoft 공식 유통사 찾기](https://www.powersoft.com/en/contacts/commercial-enquiries)에는 한국 파트너가 표시되지만, 연결할 한국 홈페이지 URL과 제품별 적용은 아직 미확인이다. 공식 파트너 명칭만으로 웹사이트를 추정하지 않는다.

## Work가 준비할 다음 조사 묶음

1. 30개 식별 브랜드의 한국어 제조사 사이트 존재 여부와 실제 제품/시리즈/일반 홈페이지의 종류를 기록한다. 제품 전용 페이지와 홈페이지를 같은 명칭으로 표시하지 않는다.
2. 한국어 제조사 사이트가 없을 때만 제조사의 현재 공식 파트너/수입원 목록 등 **공개 근거**로 한국 수입원 지위를 확인한다. 해당 회사의 실제 HTTPS 홈페이지와 대상 제품/브랜드의 적용 관계도 별도로 확인한다. 판매점, 과거 대리점, 비공개 공급처 칸은 공식 수입원으로 자동 승격하지 않는다.
3. 각 제품에 제조사 한국어 → 확인된 한국 수입원 → 제조사 글로벌의 표시 순서를 적용한다. 제조사 글로벌 링크는 버리지 않는다. 수입원 링크는 `official_links`에 섞지 말고 출처 유형을 분리한다. 근거가 없으면 `미확인`으로 남긴다.
4. 92개 공식 링크 미기록과 브랜드 미식별 4개는 우선 조사/식별이 필요하다. 새 옵션 19행과 보류 제품 313개의 **공개 편입**은 이 링크 작업으로 승인되지 않는다.
5. Work의 Sony Product Detail 조사 PR #35와 중복하지 말고, 링크 조사 전용 묶음/인계서를 별도로 준비한다. 실제 공개 데이터 필드·Pages 배포 방식 변경에는 별도 검증이 필요하다.

원본 Excel, 로컬 제품 JSON, 내부 공급처, 비공개 자료·경로, 사진/PDF는 GitHub에 넣지 않는다. 현재 코드 변경은 한국어 표시 우선순위뿐이며 전체 338개 링크 완성을 주장하지 않는다.
