# W-20261012-016 XDM 커맨드 가이드 후속 인계

- 범위: XDM-WOS100 레이어 수의 근거를 분리해 [W-016 참고자료](W-20261012-016-XDM-WOS100-레이어비교-참고자료.md)에 반영하고, 사용자 제공 XDM Command Guide 1013을 `rtcom-xdm` 상세의 문서 카드로 게시한다. RTCOM raw 및 구성기 저장소는 무변경.
- 원본: 사용자 제공 `RTcom_XDM Command Guide_1013.pdf`, 73쪽, 1,025,992바이트, SHA-256 `986bb5e5727dc86449e4ad72572e7125ff24f192f32250dee7d3849952f651ec`. 열람 암호가 없으며 원본 바이트를 `beta/site/manuals/rtcom-xdm-command-guide-1013.pdf`에 그대로 보존한다.
- 수치 근거: **출력 1개당 4개의 4K/60 소스 중첩**은 사용자 확인(2026-10-12)과 구성기 공개 「XDM-WOS100 레이어 구성도·비교표 보기」 표기가 일치한다. 검증등급은 `FOUND`. 커맨드 가이드 인쇄 44~55쪽은 `OW` 중첩 명령과 인쇄 45쪽 `P1234`의 네 출력 우선순위 요소를 설명하지만, **출력당 최대 레이어 수를 문장으로 명시하지 않는다.** 가이드를 4레이어 상한의 독립 근거로 쓰지 않는다.
- 제한: 같은 쪽의 `X`·`Y`는 창 위치, `W`·`H`는 창 크기이며 `W0`·`H0`은 레이어 해제다. 창의 실제 최대 너비·높이 수치는 가이드에 없다. 인쇄 44쪽 `W14=3840×2160p@60`은 Video Wall 타이밍이고 개별 창 해상도 상한이라고 단정하지 않는다. HOS100은 별도 `OQ` 명령(인쇄 25~28쪽)으로 `L00`~`L13`의 14개 레이아웃 코드가 구성기 코드표와 일치한다.
- 게시 경로: `docs/manifest.json`의 uploads 한 행으로 XDM에만 연결한다. AV 카탈로그에 없는 RTCOM 동적 상세이므로 `verify-pages`가 검증된 RTCOM index의 slug도 소유 제품으로 허용하도록 최소 변경했다. 임의 slug나 제외 제품은 통과시키지 않는다.
- 역사 검사: 새 PDF 파일과 uploads 한 행만 선택적으로 제외하고 과거 PDF·manifest 해시의 기대값은 그대로 유지한다. 메타데이터가 바뀌거나 잠금 표기가 붙으면 되감기 함수가 실패한다. 잠긴 PDF 12건은 그대로 유지한다.
- 로컬 화면: XDM 상세 1280px·390px에서 문서 카드가 보이고, 보기에서 73쪽 PDF 첫 쪽이 렌더되며 내려받기 파일명이 정확함을 확인했다. 캡처는 로컬 `tmp/rtcom-cmd/xdm-viewer-1280.png`, `xdm-viewer-390.png`에 있다.
- 검증: 전체 순차 검사 653건 중 652 pass·0 fail·기존 skip 1, `node beta/verify-pages.mjs` 276장비·273상세·480 WebP·135 uploads, `node beta/sync-rtcom.mjs --check` 32/32, 검색 인덱스 `--check` 통과. 기존 잠금 PDF 12건 유지. 원본 `rtcom/raw/`은 무변경.
