# W-20261013-007 세션 C — WMF Port Map 근거·점검표

원본은 삼성전자 한글 사용설명서 `beta/site/manuals/samsung-flip-pro-wmfx-manual-ko.pdf`(BN81-28453F-02, SHA-256 `2352fb9ead673818c08138552fb83aac18c57b4576ea343a6ed3171985c7a35a`)다. 1쪽 적용 목록에 WM55FX·WM65FX·WM75FX·WM85FX가 있고, 13쪽은 WM55FX/WM65FX, 14쪽은 WM75FX/WM85FX의 후면과 단자표를 **별도 그림**으로 제시한다. 국내 제품 페이지와 제품 JSON은 각각 LH55WMFWBGCXKR·LH75WMFWLGCXKR을 WM55FX·WM75FX로 연결한다. 두 모델은 같은 7개 단자 범례지만 후면 본체 그림이 달라 이미지를 공유하지 않았다.

| 모델 | 도면 | I/O 대조 | 지도 |
|---|---|---|---|
| LH55WMFWBGCXKR | 한글 매뉴얼 13쪽 WM55FX/WM65FX 도면 | 후면 HDMI 출력·LAN·SERVICE·HDMI 입력·오디오 출력·USB(1A)·TOUCH 7개 일치 | 개별 Diagram 7개 표식 |
| LH75WMFWLGCXKR | 한글 매뉴얼 14쪽 WM75FX/WM85FX 도면 | 같은 7개, 후면 배치 그림은 55형과 다름 | 개별 Diagram 7개 표식 |

기존 9개 I/O 행 중 USB-C 허브와 RS-232C 입력은 13·14쪽 후면 그림에 없으며 기존 자료 상태도 `REVIEW REQUIRED`다. 두 항목은 좌표를 만들지 않았다. 전원 표시 또한 I/O 행이 아니므로 지도에서 제외했다. 사용설명서 15쪽의 옵션 트레이 그림을 후면 단자 위치로 해석하지 않았다.

| 번호 | 대상 단자 | 55형 판정 | 75형 판정 |
|---|---|---|---|
| 1 | HDMI 출력 | OK — 화살표가 바깥으로 향하는 HDMI 한 개 | OK |
| 2 | RJ45(LAN) | OK — LAN 한 개 | OK |
| 3 | SERVICE | OK — SERVICE 원형 한 개 | OK |
| 4 | HDMI 입력 | OK — 화살표가 안쪽으로 향하는 HDMI 한 개 | OK |
| 5 | 오디오 출력 | OK — 스피커 표기 옆 원형 단자 한 개 | OK |
| 6 | USB(후면) | OK — USB(1A) 한 개 | OK |
| 7 | TOUCH | OK — TOUCH 한 개 | OK |

각 구간은 패널 인쇄와 커넥터 그림을 포함하고 인접 단자 그림을 침범하지 않는다. [55형 점검 이미지](W-20261013-007-C-WMF-audit-lh55wmfwbgcxkr.png)와 [75형 점검 이미지](W-20261013-007-C-WMF-audit-lh75wmfwlgcxkr.png)를 원본 픽셀로 열어 눈으로 확인했다. 로컬 대표 [1280px](W-20261013-007-C-WMF-local-1280.png)·[390px](W-20261013-007-C-WMF-local-390.png) 캡처에서 7개 번호와 설명 카드가 나타나고 브라우저 오류·문서 가로 넘침이 없다. 모바일 지도 자체는 사용자가 수평 스크롤할 수 있다.
