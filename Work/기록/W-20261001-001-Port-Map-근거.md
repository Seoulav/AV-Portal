# 시범 후면 지도 근거·실측

W-20261001-001 / 사용자 승인 후면 지도 보완. 원본 사진과 PDF는 변경하지 않았다. 좌표는 **게시 파일 실제 픽셀**이며 원본 다운로드 이미지의 크기로 환산하지 않는다. `measuredImage`가 파일·픽셀을 고정한다. `y`는 RTCOM과 동일하게 괄호를 붙일 사진 속 높이이며 다단 후면의 위치 혼동을 줄인다. 수량은 사진으로 계산하지 않았다.

번호: 입력→출력→네트워크/제어→전원. A/B가 떨어져 있으면 별도 번호. 일반 설정 스위치는 제어 뒤, 전원은 마지막이다. H5 입력/출력/MVR 장착 카드는 사진 구성 예시로만 설명한다.

## 자료 부족 / 기존 불일치 보존

- **novastar-h5 / io[7].quantity**: MVR 슬롯 수가 PDF 텍스트에 명시되지 않음. 사진 수량 계산 금지.
- **ulxd4d / io[1].quantity**: 기존1은 매뉴얼9/43쪽의 RF cascade2와 다름. 기존 비어 있지 않은 값이므로 보존, 후속 승인 필요.
- **aquilon-rs1 / portMap**: Rear 사진 없음. 기존 데이터 전체 유지.
- **eb-pq2220b / settings / PDF-dependent values**: 정확 모델 PDF 사본 없음. 기존 근거의 단자 위치만 연결, 새 수량과 설정은 비움.
