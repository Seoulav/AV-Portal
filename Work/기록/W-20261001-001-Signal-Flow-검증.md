## QMS 비교 근거

[실제 RTCOM QMS-88UX](https://seoulav.github.io/rtcom-configurator/#products/qms-88ux)의 03 카드를 1280/390에서 직접 캡처했다. 지정한 src/products.js의 ioFlowDiagram 및 XDM-PSU/SPX-R6 구조를 읽되 제품별 예외 코드는 복사하지 않았다.

QMS fixture는 기존 `beta/site/rtcom/raw/products/qms-88ux.json`의 io[0] HDMI 입력 8, io[1] 매트릭스 출력1–8/멀티뷰9·10, io[2] QD1/QD2 추출, specifications의 해상도/HDMI/HDCP, overview의 4:4:4 및 기존 기능·매뉴얼 기록을 사용한다. 이번 fixture는 사용자 지정 비교 화면의 재현이며 RTCOM 원본/어댑터/실제 제품으로 연결하지 않는다. 기술적 의미를 인증하는 작업은 이후 실제 데이터 PR의 PDF 페이지 대조로 수행한다.

각 유형 fixture는 제품 등록용 데이터가 아닌 **설명용 합성 데이터**다. 테스트의 VERIFIED 값 역시 validator 경로를 검증하기 위한 값이며 실제 제조사 검증 판정이 아니다.

## 독립 검토와 수정

독립 검토: Critical 0 / Important 3 / Minor 0. 중요한 3개 모두 실패를 먼저 재현한 뒤 수정했고 전체 테스트를 다시 통과했다.

- matrix는 단일 블록만 지원한다. 복합 matrix 체인/다른 처리 블록과 섞인 matrix는 연결 단자로 fallback한다. 일반 멀티스테이지에는 이 제한이 없다. 향후 실제 필요가 확인되면 별도 배치 규칙이 필요하다.
- 경로 label은 그림 아래에서 읽는다. 그림 안의 입력/출력/처리 이름과 대역은 유지하며 길고 겹치는 문구를 피하는 대신 일부 설명은 아래로 시선을 옮겨야 한다.
