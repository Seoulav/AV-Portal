## 충돌·조건 출처 이동

호스피탈리티 TV 3종은 국내 페이지의 제품 소개가 영상 처리 엔진을 “크리스탈 프로세서 4K”로 소개하지만, 같은 국내 페이지의 상세 스펙은 “Quantum Processor Lite”로 표기한다. 두 행의 값을 그대로 두고 각각 `CONFLICTED`로 표시했다. 전원·RF 지역 차이는 국내 스펙으로 해결했다. HDMI 단자 수처럼 한국 페이지에도 없는 미확정 항목은 기존 이슈를 유지했다.

반복된 “영국/캐나다/카리브/뉴질랜드 판매 모델 기준”, “지역 코드만 상이”, 교차 검증 언급은 행의 측정 조건이 아니다. 관련 모델·지역·남은 해외 사용 범위는 `sources[]`의 이름·`scope`에 한 번 표시하고, 각 행의 예전 문구 전체는 근거 JSON `conditionChanges[].before`에 남겼다. 제품 소개의 적용·운영 설명은 국내 출처 `scope`로 모았으며 현행 여부를 별도 확인해야 하는 이전 메모임을 표시했다. 실제 측정 한정인 “유리 미장착”, “자사 실험치”는 짧게 남겼다. 한국 스펙 탭으로 확인되어 더는 사실이 아닌 과거의 “정확한 해상도 수치 미기재” 같은 문구는 화면과 출처 `scope`에 재게시하지 않고 근거 JSON의 변경 전 이력으로만 보존했다.
