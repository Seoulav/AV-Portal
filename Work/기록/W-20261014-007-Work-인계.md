# W-20261014-007 Work 인계 — HDF-CCF USB 3.2 Gen2 분류

- 완료 범위: HDF-CCF 1개 제품을 제조사 HDCVT로 등록하고 제품 탐색 분류 `USB 3.2 Gen2 10Gbps`를 categories 4단 값으로 추가. 사용자 승인에 따라 이 정확한 제품만 4단을 허용하고 전체 검증기로 나머지 제품의 3단을 유지.
- 데이터: 길이 옵션 5m·10m·15m 한 모델. PD 값 5m 90W / 10m·15m 85W 및 본문 100W 표기 충돌을 `CONFLICTED`로 보존. 4-lane / 2-lane 모드, SOURCE→DISPLAY 방향, 최대 15m를 자료 근거로 반영.
- 문서: V1.1 사용자 제공 매뉴얼 업로드. SHA-256 `c96e33cce303073b0c0106c3e61eb90d6f33a712e1f8c2a5e7bd41ee3229518f`, 7쪽, 잠금 없음. 상세 문서 카드와 PDF 접근은 자동 검사에 포함.
- 보류: Beluga Highwave Pro C-to-C 8K 5M은 공식 사이트에서 정확한 모델의 USB 3.2 Gen2 / 10Gbps 사양을 확인하지 못해 미등록. AJA Ki Pro GO2 및 INOGENI U-BRIDGE 3는 기존 등록 사양이 USB 3.2 Gen1이므로 후보 보고만 했으며 재분류하지 않음.
- 변경 검증: 직렬 전체 테스트 705건 중 704 통과, 기존 skip 1, 실패 0. `verify-pages` 284 제품·281 상세·502 검토 이미지·143 업로드 PDF 통과. 검색 인덱스 `--check`, feature wording, diff check 통과. 잠긴 PDF 참조 12건 유지.
- 출처: HDCVT 공식 모델 페이지 `https://cn.hdcvt.com/product_169/567.html`; 세부 제품 사양은 해당 모델 공식 페이지 및 업로드 매뉴얼을 확인. Beluga 판매 페이지는 USB 규격을 입증하지 않으므로 등록 근거로 사용하지 않음.
- 공개 검증: 배포 후 상세 JSON·카탈로그·검색 결과·문서 링크/PDF HTTP 상태와 SHA 확인. 브라우저 UI 사용 불가 시 비시각 확인으로 보고.
- 완료: PR #511 병합 SHA `b881074592a5cf72c52ead02168238507c88993b`; Builder CI run `38595234366` 성공. Pages 배포 run `38595836941` 성공.
