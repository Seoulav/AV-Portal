# W-20260923-011 — 영상 옵션 12행 공식 자료 조사 결과

2026-09-23 승인된 새 Excel `영상` 51–54행을 먼저, 59–66행을 다음으로 **내부 읽기 전용** 평가했다. 기존 44–50행은 재조사하지 않았다. 한국어 제조사 공식 사양서를 먼저 검색했지만 이번 조사에서 본문을 확보하지 못해 제조사 글로벌 공식 문서를 사용했다. 검색에서 찾지 못한 것을 자료 부재의 증명으로 해석하지 않는다. 원본 Excel·제품 목록·앱·자료대장·제조사 원본 파일은 수정하지 않았다.

제조사 원문은 NovaStar [H2 사양서 V1.15.0](https://oss.novastar.tech/uploads/2025/06/H2-Video-Wall-Splicer-Specifications-V1.15.0.pdf), [H5 사양서 V1.15.0](https://oss.novastar.tech/uploads/2025/06/H5-Video-Wall-Splicer-Specifications-V1.15.0.pdf) 및 Colorlight [X100 Pro-2U 사양서 V1.0](https://support.colorlightinside.com/uploads/X100Pro-2USpecificationV1.0_1754904146.pdf)이다. 표의 페이지는 PDF 뷰어 번호가 아니라 **문서 인쇄 페이지**다. Colorlight [제조사 다운로드 페이지](https://en.colorlightinside.com/product/download/111)에는 2U·4U·7U V2.0이 등재되지만 이번 접근에서 세 PDF 본문이 열리지 않았다. 아래 Colorlight 카드 사실은 **열람한 2U V1.0**에만 적용한다. 최신 V2.0이나 4U·7U의 카드 대응을 확인한 것으로 확대하지 않는다.

12행 중 **제조사 문서에서 대응하는 카드 표기 10행(51–53, 59–65)**을 찾았다. 이는 각 원본 행의 정확 발주품을 확인했다는 뜻이 아니다. 54·66행 전원 부품 모델은 문서에서 확인하지 못했다. **별도 발주 품번 0/12, 판매 단위 0/12**로 평가했다. NovaStar 카드 항목은 H2/H5 각 문서에 실려 있고, Colorlight의 카드 항목은 2U 구판에만 확인됐다. 모든 설치 조합의 슬롯·HW/FW 조건과 4U/7U 적용은 미확인이다. W-008의 **52행 편입 후보 1건·보류 11건**은 그대로 유지하며, 19행 전체의 후보 8/보류 11 결정도 변경하지 않는다.

공식 URL을 찾은 것과 포털 게시·사진 이용·PDF 재배포 허가는 별개다. 12행 모두 포털의 URL 표시·사진·PDF 권한은 확인되지 않았다. 특히 Colorlight 2U V1.0 p.23에는 문서 복제·재배포에 사전 서면 허가가 필요하다는 권리 고지가 있으므로 파일을 올리지 않았다. 이 권리 상태는 내부 문서 검토를 막지 않는다.

W-006/[열린 Draft PR #10](https://github.com/Seoulav/AV-Portal/pull/10)에 연결할 질문은 실제 주문 품번과 판매 단위, 51행 `3`/`3G` 표기, 52행 dual link·53행 복사 포트 의미, 54행 `H_800W` 식별·H2/H5 적용, 59행 두 HDMI 입력 카드 중 실제 발주품, 60–65행 원본과 공식 코드의 대응, 66행 전원 부품명, 2U/4U/7U별 카드·전원·슬롯/HW/FW 조건, URL/사진/PDF별 권한이다. **질문만 기록했고 업체에 발송하지 않았다.**

2026-09-23 사용자 정정에 따라 [AGENTS.md](../../AGENTS.md)에 RTCOM은 직접 제공 제조사 자료를 우선하고 공식 홈페이지의 제품 소개·특징 기본 정보도 조사 가능하다고 명시했다. 제공 자료와 홈페이지의 출처를 구분하며, 홈페이지 내용만으로 미확인 사양·호환성·재게시 권한을 확정하지 않는다. 이번 12행 작업에서 RTCOM 개별 웹 조사는 하지 않았고 과거의 웹 조사 금지 기록은 그대로 두었다.
