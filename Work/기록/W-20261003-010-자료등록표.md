# W-20261003-010 JBL 자료등록표

## 적용 게이트와 중복

사용자 제공 `_harman/JBL/`·`JBL2/`를 1순위, JBL Pro 수집 `JBL_web/`을 2순위로 대조했다. 대상 16종에는 고유 PDF **19개**를 한 번씩 게시하고 `uploads` **28건**을 추가했다(75→103). 게시 파일 SHA-256 중복은 **0건**이다. `control-426ct`의 제공 매뉴얼과 Enhanced 공용 매뉴얼은 SHA-256 `427e76dad5f0…`로 완전히 같아서 하나만 올렸다. Control 23-1·25-1·28-1의 세 로컬 사본도 `e412eb09a6a1…` 한 파일이다.

**AC18 모델 게이트:** `AC18.pdf`는 텍스트층이 없는 1쪽 도면이므로 PDF 화면을 직접 열었다. 제목 칸에는 **“CUSTOMER DRAWING: AC18/95, AC18/26”**이 인쇄돼 있다. 따라서 두 제품에만 붙인다. 같은 폴더의 AC15·AC16·AC25·AC26·AC28 도면은 다른 캐비닛이며 게시하지 않았다. [화면 증거](W-20261003-010-screens/ac18-model-gate.png)를 남긴다.

Control 400 매뉴얼은 표지의 적용 모델을 확인했다. Standard에는 412/414/416/418C/T, Enhanced에는 419CS/T·424C/T·424LP·426C/T·426LP, Premium에는 440CS/T가 포함된다. 제공 416C/T 19쪽 파일은 Standard 시리즈의 한글 설명서이고, 제공 447C/T 19쪽 파일은 Premium 시리즈의 447C/T 포함 설명서다. 파일명만으로 문서의 단독 적용 범위를 판단하지 않고 제목에 실제 시리즈를 표기했다. Control Contractor 3종의 1쪽 PDF는 **스피커 본체 매뉴얼이 아닌 MTC-23UB-1/25UB-1/28UB-1 브래킷 설치 지침**이므로 참고자료로 게시했다.
