가이드 슬라이드 2는 이 제품군을 The Wall로 소개한다. 슬라이드 7·10은 8K 콘텐츠 재생을 S-Box와 연결하고 모델별 지원 차이를 주의시킨다. 따라서 세 상세 설명은 **완성 디스플레이가 아닌 LED 캐비닛(모듈)**임을 밝히고 색온도 설정과 8K 재생의 S-Box 전제를 명시했다.

가이드에는 대상 모델의 제품 사진과 연결 단자 구성이 없다. 세 상세의 `images`와 `io`는 빈 배열이고 이미지 상태에는 `MISSING` 사유를 기록했다. `io`를 추측으로 채우지 않았다. 가이드 1쪽의 재배포 금지 문구에 따라 원본을 공개 사이트에 복사하지 않았고 `documents`에도 연결하지 않았다. 출처 `S1`에 파일명·발행처·슬라이드·SHA만 기록했다.

삼성 한국 [LED 사이니지 목록](https://www.samsung.com/sec/business/led-signage/)에서 MPF 개별 모델 페이지를 확인하지 못했다. 공식 링크는 이 국내 목록으로 두고 `scope`에 **시리즈 목록 페이지 · 개별 모델 페이지 미확인**을 표시했다. 목록은 제품 사양의 근거로 사용하지 않았다. 해외 지역 페이지도 사용하지 않았다.

로컬 [화면 캡처](W-20261002-012-screens/)는 3종 상세의 1280px·390px와 LED Signage 목록의 두 폭을 포함한다. 세 상세는 HTTP 200, JS 오류·깨진 이미지·가로 넘침 0이며 사진·단자 섹션이 빈 상태 규칙에 따라 숨겨진다. 목록은 제품 사진 없음 자리 표시 3개를 보여 주며 LED Signage 필터 결과가 정확히 MPF 3종이다. `MP008F` 검색 1건, `MPF` 3건, `LED` 검색에서 세 모델이 모두 확인됐다. 상세 사양 표에 두 메타데이터 행과 가이드 사양 20행이 표시된다.
