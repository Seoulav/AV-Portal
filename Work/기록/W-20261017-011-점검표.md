# W-20261017-011 1단계 Port Map 눈 점검

검토 대상은 Aquilon RS2와 C+의 기존 Rear 사진이다. 사진 파일은 수정하지 않았다. 슬롯은 사진의 카드 장착 칸을 위에서 아래로, 각 줄은 왼쪽에서 오른쪽으로 번호를 붙였다. 장착된 카드는 해당 사진의 예시이며 주문 구성과 구분했다.

| 모델 | 슬롯 번호와 사진 대조 | 고정부 번호와 사진 대조 | 결과 |
|---|---|---|---|
| RS2 | ①·② HDMI 입력, ③ HDMI 출력 / ④ DP 입력, ⑤ SDI 입력, ⑥ HDMI 출력 / ⑦ HDMI 출력, ⑧ 덮개가 있는 최하단 옵션 칸 | ⑨ USB, ⑩ SYNC IN/OUT, ⑪ AC 전원 공급 장치 2개와 가운데 덮개, ⑫ LOCK, ⑬ LAN, ⑭ ON/OFF·GPI·GPO, ⑮ MULTIVIEWERS, ⑯ Dante | 16개 번호의 괄호·지시선이 해당 영역에 닿음 |
| C+ | ①·② HDMI 입력, ③ HDMI 출력 / ④ HDMI 입력, ⑤ SDI 입력, ⑥ HDMI 출력 / ⑦·⑧ DP 입력, ⑨ HDMI 출력 / ⑩ HDMI 출력, ⑪ 덮개가 있는 최하단 옵션 칸 | ⑫ USB, ⑬ SYNC IN/OUT, ⑭ AC 전원 공급 장치 3개, ⑮ LOCK, ⑯ LAN, ⑰ ON/OFF·GPI·GPO, ⑱ MULTIVIEWERS, ⑲ Dante | 19개 번호의 괄호·지시선이 해당 영역에 닿음 |

슬롯 사진의 종류와 배열은 각 모델의 Rear 사진을 직접 확대해서 확인했다. 최하단 덮개 칸은 [RS2 제품 페이지](https://www.analogway.com/products/aquilon-rs2)와 [C+ 제품 페이지](https://www.analogway.com/products/aquilon-cplus)의 Expandability Option 설명을 대조했다. 그 설명은 최하단 슬롯에 링크 카드와 QSFP+ 인터페이스 카드를 장착하거나 출력 카드로 교체할 수 있음을 밝힌다. 덮개가 보이는 사진 자체에 QSFP+ 단자가 있다고 표시하지 않았다.

번호 원은 사진 바깥 여백에 있다. 가장자리 카드 줄은 사진 바깥 괄호로 묶었고, 가운데 카드에는 짧은 직각 지시선을 썼다. `portMapSegments`로 검사한 사진 안 최장 수평 지시선은 RS2 사진 폭의 **0.239**, C+의 **0.190**이다(허용 상한 0.25). 다른 번호의 지시선과 6px 이내로 나란히 지나는 구간은 **0건**이다. 실측 최소 평행 간격은 RS2 **7.94px**, C+ **7.57px**이다. 760px와 390px의 양쪽 끝 확대 캡처에서 번호의 연결 대상도 눈으로 확인했다.

`python scripts/portmap-audit.py aquilon-rs2 aquilon-cplus`는 RS2 1건, C+ 6건의 `OVERLAP`·`STACKED` 신호를 냈다. ②·⑤·⑧처럼 서로 다른 높이의 카드 괄호, ⑯~⑲처럼 아래쪽에서 서로 다른 x 좌표로 내려오는 선을 사각 영역으로 묶어 판정한 신호다. 실제 SVG 선분의 6px 검사와 760px·390px 캡처를 대조했을 때 해당 선끼리 겹치거나 다른 슬롯을 관통하지 않았다. 이 도구 신호를 무시하지 않고 시안 비교 이미지에 함께 남긴다.

390px 브라우저 측정: RS2·C+ 모두 문서 `scrollWidth=390`. Port Map 사진 영역은 너비 298px의 상자 안에서 560px 콘텐츠를 좌우로 이동한다. 사진 양쪽 끝 캡처를 [시안 비교](W-20261017-011-시안검토.md)에 실었다.
