## 예정 범위·검증

PDF 응답 문서만 `beta/site/docs/`에 사본으로 두고 대응표(`url → file, sha256, bytes, fetchedAt`)로 연결한다. 상세 JSON·`catalog.json`은 고치지 않는다. 50MB 초과 파일은 원본 링크로 남긴다. 다시 실행 시 SHA 동일 파일 유지, 실패 시 이전 사본 유지. PDF.js는 RTCOM과 같은 판을 저장소에 넣고, RTCOM 0.124~0.126과 같은 팝업(보이는 쪽만 그림, 폭 조절, 넓게, 휴대폰 전체 화면, 내려받기, 원문 링크)을 만든다. 사본 없는 문서는 기존처럼 새 탭. `beta/verify-pages.mjs` 허용 목록과 사본 검사를 보완한다.

대표 4종 1280px·390px 캡처, 사본 전수 열림 검사, 내려받기 SHA 일치, 사본 수·총용량·제외 목록, `beta/site` 전체 용량, 콘솔 오류 0, 키보드 초점, 데이터 무변경을 보고한다.

## 미결 사항과 인계

사본 약 460MB는 2026-09-29 당시 추산이며 실제 수집·검증 뒤 수량과 용량을 다시 보고한다. 1GB에 가까워지면 LFS·저장소 분리를 사용자에게 제안한다. 구현 승인은 문서 PR 병합이 아니라 위 사용자 지시에 따른다.
