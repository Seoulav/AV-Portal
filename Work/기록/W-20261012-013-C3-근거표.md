# W-20261012-013 세션 C 3차 — 영상·기타 확인 필요 행 재검토

기준 `origin/main` `12c1e607ddd6d9c9d176f1b7ff0d884686c7366e`. 기존 [A2 조사](W-20261012-013-A2-근거표.md)와 [B2 인계](W-20261012-013-B2-Work-인계.md)의 보류 사유를 먼저 읽고, 정확 모델의 추가 공식 자료에서 물리 수량과 방향이 확인된 행만 처리했다. 삼성 해외 지역 자료는 국내 제품의 근거로 사용하지 않았다.

| 제조사·제품 / 행 | 처리와 공식 근거 |
|---|---|
| AMX VARIA-80 `io[1]` | [정확 모델 Quick Start Guide](https://www.amx.com/en-US/site_elements/quick-start-guide-varia-80) 1쪽 Fig. 1 후면에는 USB 단자 하나만 그려져 있다. 기존 D1 Data Sheet 2쪽의 USB Type C OTG 형상과 대조해 수량 공백을 `1`로 채웠다. 새 Q1 출처를 제품에 추가했다. |
| AJA Ki Pro GO2 `io[9]` | [AJA 공식 제품 사양](https://www.aja.com/products/ki-pro-go2)의 Timecode 절은 RP-188이 기존 SDI 입력 BNC를, LTC가 기존 오른쪽 아날로그 오디오 XLR 입력을 사용한다고 명시한다. 이 행은 새 물리 소켓이 아니므로 `already-represented`로 분류했다. 기존 SDI 4개·XLR 2개는 그대로다. |
| Roland V-160HD·V-1HD+·V-80HD·VR-6HD의 RS-232 행 | 모델별 [V-160HD 제어 문서](https://static.roland.com/assets/media/pdf/V-160HD_Control_jpn03_W.pdf), [V-1HD+ Reference Manual](https://static.roland.com/assets/media/pdf/V-1HD_plus_reference_eng02_W.pdf), [V-80HD 제어 문서](https://static.roland.com/assets/media/pdf/V-80HD_Control_eng01_W.pdf), [VR-6HD 제어 문서](https://static.roland.com/assets/media/pdf/VR-6HD_Control_eng02_W.pdf)의 DB-9 핀 2 RXD·핀 3 TXD와 전이중 통신을 대조했다. 제품 I/O의 `N/A` 방향 원문은 유지하고, 정확 행 override로 모델마다 DSUB-9 양방향 1개를 생성했다. |
| AVer TR535 `io[0]`·`io[2]` | [국내 정확 모델 브로슈어](https://kr.presentation.aver.com/DownloadFile.ashx?n=3259&t=ModelBrochure)와 [공식 후면 사진](https://kr.presentation.aver.com/model/tr535)을 대조했다. 실제 영상 출력은 HDMI 2개·3G-SDI 1개다. 제어는 RS-232 DIN8 1개·RS-422 RJ45 1개다. IP/PoE RJ45·USB 3.0은 이미 별도 I/O 행에 있으므로 복합 행에서 다시 만들지 않았다. 특히 기존 생성기가 제어 행을 Ethernet 4개로 펼치던 오류를 교정했다. 포털 I/O 원문은 바꾸지 않았다. |

## Builder 집계

| 항목 | 전 | 후 |
|---|---:|---:|
| 제품 / I/O 행 | 305 / 1,573 | 305 / 1,573 |
| 생성 단자 | 2,836 | 2,842 |
| 단자 생성 행 | 1,326 | 1,333 |
| 확인 필요 행 | **119** | **112** |
| I/O 있으나 단자 0 제품 | 4 | 4 |

단자 0인 `x100pro-2u/4u/7u`는 선택형 카드 프레임이고, `rally-mic-pod-extension-cable`의 12-pin 형상은 기존부터 추정이다. 근거 없이 본체 고정 단자를 추가하지 않았다.
