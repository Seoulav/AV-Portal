# W-20260926-009 — Televic 9개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-008 완료 후 다음 최소 브랜드인 Televic(카탈로그상 10개)을 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다.

## 핵심 발견: 지식베이스 페이지 vs 데이터시트 PDF

Televic의 conference.televic.digital 지식베이스 페이지 자체는 실질적인 사양 정보가 거의 없는 색인/링크 페이지였다. 실제 모델별 세부 사양은 각 페이지에서 링크된 documents.televic.digital(Nextcloud 공유 인스턴스)의 제조사 공식 데이터시트 PDF에 담겨 있었다. 에이전트는 페이지 텍스트가 아니라 각 모델 고유의 데이터시트 PDF를 다운로드해 pdftotext로 사양을 추출하고, 제품 사진도 페이지가 아니라 PDF 내부에서 pdfimages 방식으로 추출했다(페이지 자체에는 Televic 로고 배너만 있고 실물 사진이 없었음).

## 제품별 조사 결과와 중요한 정정

10개 중 여러 개가 하나의 공유 지식베이스 페이지(D-Cerno, Plixus, Microphones)에 여러 SKU가 함께 실려 있어, 카탈로그 항목과 실제 제품의 대응 관계를 신중하게 확인해야 했다.

- **D-Cerno CU, D-Cerno D SL**: 제조사가 "Legacy/Discontinued"로 분류한 구형 제품. 각각 고유 데이터시트(71.98.0320, 71.98.0306)로 사양을 확인했다.
- **D-Cerno AE**: 현재 활성 제품, 가장 상세한 데이터시트(71.98.0322)로 확인.
- **D-Cerno Advanced — 중요한 정정**: 조사 전 가정과 달리 이것은 실물 디스커션 유닛이 아니라 **소프트웨어 라이선스**(SKU 71.98.0360)였다. D-Cerno AE 중앙 엔진에 8x8 멀티채널 USB, 8x8 AES-67, DSP 모드, 사용자 역할, 커스텀 라우팅 등의 기능을 해제하는 라이선스로, 데이터시트 자체가 노트북/소프트웨어 UI 사진만 담고 있었다. 실물 이미지를 만들어내지 않고, 이번 배치에서 제외했다(GS728TPP와 동일한 성격의 보류) — Work가 이 카탈로그 항목을 "제품"이 아닌 "라이선스/옵션"으로 재분류할지 검토할 필요가 있다.
- **D-Mic 50 SL / D-Mic 40 SL**: 각각 고유 데이터시트로 확인한 결과, 구스넥 길이(505mm vs 405mm)와 무게 외에는 전기적 사양이 완전히 동일했다 — 이는 복사 오류가 아니라 제조사가 실제로 명시한 사실이다.
- **Plixus AE-R Dante**: 랙형 오디오 엔진, Dante 64x64 카드 탑재. 고유 데이터시트(71.98.2904)로 확인.
- **Plixus AE-R PS — 중요한 정정**: 조사 전 가정(Dante 없는 오디오 엔진 변형)과 달리, 이것은 Plixus AE-R용 **외장 전원 공급 장치**(액세서리)였다(데이터시트 71.98.2931, 지식베이스의 "Power Management" 섹션에서도 확인). "40개 이상의 델리게이트 유닛을 사용하는 설치 환경에 필요"하다고 명시되어 있다. 오디오/네트워크 사양을 지어내지 않고 전원 장치 고유 사양(입출력 전압, 보호회로 등)만 기록했다.
- **Confidea FLEX**: 터치스크린 일체형 디스커션/의장 유닛. 고유 데이터시트(71.98.0131)로 확인.
- **Plixus NEXT — 중요한 정정**: 조사 전 가정(디스커션 유닛 또는 통역 데스크)과 달리, 이것은 **네트워크 익스텐더**(배선/포트 수 확장 장비)였다(데이터시트 71.98.2911, 지식베이스에서 "Network Extender"로 분류). 디스커션 유닛 관련 필드(마이크·버튼·디스플레이)는 해당 없음으로 처리하고 네트워크/전원 사양만 기록했다. 데이터시트에 포장 크기/무게가 "TBD"로 명시되어 있어 임의로 추정하지 않고 제외했다.

## 검증한 스키마 정합성

에이전트 산출물은 `issues`/`features`/`specifications`/`io` 필드가 전부 올바른 딕셔너리 스키마로 작성되어 있어 별도 정규화가 필요하지 않았다. D-Cerno Advanced를 제외한 9개 전 제품에 이미지가 포함되어 있어 `verify-pages.mjs`의 요구조건을 만족했다.

## 코드 변경

- `beta/group1-images.mjs`: 9개 슬러그 신규 항목(group1Images, cardImages) 추가.
- `beta/site/catalog.json`: 9개 항목에 slug·card_image 필드 추가.
- `beta/site/detail/data/*.json`: 9개 신규 파일.
- `beta/manufacturer-hosts.mjs`: 변경 없음(기존 `televic.digital` 허용 규칙이 서브도메인을 모두 커버).

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 105 details, 123 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다.
