## 자료를 어떻게 찾았나

사용자가 준 전자칠판 매뉴얼은 **구형 Flip(`WM**B`)**이었고 우리 제품은 **신형 Flip Pro(`WM**FX`)**라 쓸 수 없었습니다.

Work가 삼성 사이트 내부 API로 정확한 매뉴얼을 찾았습니다.

```
POST https://www.samsung.com/sec/business/xhr/goods/goodsManual
     mdlCode=LH55WMFWBGCXKR & goodsId=G000184098 & manualLang=KO
```

**이 방법은 다른 삼성 제품에도 재사용할 수 있습니다.** `goodsId`는 제품 페이지 HTML의 `StPrdtOptItemVO`에 있습니다.

| 파일 | `BN81-28453F-02_WUG_WMFX_KR_KOR_260806.1.pdf` (70쪽, 11,589 KB) |
|---|---|
| SHA-256 앞 16자 | `2352fb9ead673818` |
| 표지 적용 모델 | **`WM55FX WM65FX WM75FX WM85FX`** |

`LH55WMFWBGCXKR` → WM55FX, `LH75WMFWLGCXKR` → WM75FX. 위치: `_samsung-pdf/`

```
pdftoppm.exe -png -r 70 -f 13 -l 14 "<pdf>" out   # 단자
```

## ★ 가장 중요한 것 — "후면 단자표에 없음" ≠ "제품에 없음"

**매뉴얼 14쪽 표 제목이 「후면 단자」입니다.** 전면·옵션 트레이 단자는 이 표에 **없습니다.**

우리 데이터의 **`USB-C 허브`와 `RS-232C 입력`이 이 표에 없습니다.** 하지만 **지우면 안 됩니다.** 전면이나 옵션 트레이에 있을 수 있습니다.

→ 두 행 모두 **유지**하고 `REVIEW REQUIRED` + `availability`에 **"매뉴얼 후면 단자표에 없음 · 전면/옵션 트레이 여부 미확인"**을 적으세요.

**행을 삭제하지 마세요.** 삭제는 사용자 결정 사항입니다.

## 매뉴얼 13·14쪽 후면 단자 (2종 동일)

| 단자 | 개수 | 설명 |
|---|---:|---|
| HDMI 출력 | 1 | 외부 기기로 화면을 출력할 때 |
| LAN | 1 | **10/100 Mbps** · **CAT 7(STP) 권장** |
| SERVICE | 1 | **서비스 전용.** 별도 기능 없으니 연결 주의 |
| HDMI 입력 | 1 | 외부기기 연결 |
| 오디오 출력 | 1 | 소리를 내보낼 때 |
| USB (1A) | 1 | USB 메모리. 최대 **1.0 A** |
| **TOUCH** | 1 | **HDMI·DP로 입력되는 PC 화면을 터치 컨트롤.** USB 케이블로 PC와 연결 |

**`TOUCH`는 전자칠판의 핵심 단자인데 지금 데이터에 없습니다.** 터치를 PC로 전달하는 경로가 통째로 빠져 있었습니다.
