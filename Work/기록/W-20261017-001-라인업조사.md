**사용자 결정(2026-10-17): 두 모델 모두 등록하지 않는다. 사용자가 단종으로 확인했다("둘 다 등록 안 함, 단종 맞아").** 공식 사이트 표기와 무관하게 이 결정이 기준이며, 이후 라인업 대조에서 이 두 모델을 다시 등록 후보로 올리지 않는다.

두 모델 모두 [Midra 4K 시리즈 페이지][src10]와 [Midra 4K FAQ][src11]에 올라 있습니다. 공식 단종 목록에서 해당 두 이름은 확인되지 않았습니다. **이 사실을 판매 지속·국내 취급 확정으로 해석하지 않습니다.** Work가 이 두 행으로 사용자에게 등록 여부를 먼저 묻습니다.

- 두 모델의 데이터시트 1쪽에서 각각 `Ref. QMX-4K`, `Ref. QVU-4K`를 확인했습니다.
- 공식 후면 사진을 열어 각각 `MODEL: QMX-4K`, `MODEL: QVU-4K` 인쇄를 직접 확인했습니다. 자료 링크만 있는 후보와 구분했습니다.
- 이름이 비슷한 QuickMatriX(QMX150), QuickMatriX-H(QMX150-H), QuickVu(QVU150), QuickVu-3G(QVU150-3G)는 다른 모델입니다(3절).

### 표 읽는 법

- **DS**: 데이터시트, **UM**: 사용설명서, **QSG**: 빠른 시작 안내. 공식 제품 페이지가 연결한 자료를 기록했습니다. 공용 UM의 세부 적용 모델·사양 검증은 이번 등록 전 조사의 범위를 넘으며, 실제 등록 작업에서 적용 목록을 다시 확인해야 합니다. QSG를 UM으로 취급하지 않았습니다.
- **미확인**은 확인한 페이지·목록에서 찾지 못했다는 뜻입니다. 자료 없음·미지원·단종 아님을 뜻하지 않습니다.
- **후면 표기 링크**는 공식 갤러리의 Back/Rear 표기를 확인했다는 뜻입니다. 두 신규 Midra 4K 후보 외 사진의 모델 인쇄까지 시각 검증한 것은 아닙니다. **사진 있음·후면 미분류**는 갤러리는 있으나 후면 여부를 확정하지 않은 상태입니다.
- **공식 단종 표기**에는 공식 [단종 목록][src14]의 제목 원문과 URL만 기록합니다. 그 목록에 있어도 이번 후보에서 삭제하거나 등록 여부를 대신 판단하지 않았습니다.
- **지역 한정**: 확인한 제품 페이지에서 판매 지역 제한의 명시적 문구는 찾지 못했습니다. TAA 로고는 판매 지역 제한으로 해석하지 않았습니다. 국내 취급·재고는 확인하지 않았습니다.

## 5. 자료 표기 차이와 후속 확인

1. **Aquilon RS alpha**: 공식 제품 주소는 `aquilon-rs-alpha`, 포털 slug는 `aquilon-rsalpha`입니다. 코드 `AQL-RS-ALPHA`가 같아 신규 누락 모델로 세지 않았습니다.
2. **RC400T**: 공식명 RC400T Event Controller와 포털명 RC400T는 같은 코드입니다.
3. **Aquilon DP 카드**: 공식 페이지 제목은 DisplayPort 1.2 / 1.4 input/output card이나 첨부 DS 링크 제목에는 Four DisplayPort 1.2가 남아 있습니다. 표에는 공식 페이지 제목과 코드를 보존했습니다. 이 조사에서 DP 1.4 지원을 확정하지 않았습니다.
