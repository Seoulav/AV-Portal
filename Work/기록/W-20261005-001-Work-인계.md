## 화면과 묶음

`?brand=Samsung&sort=brand`는 제품 카드 대신 **전체 보기 + 7개 시리즈 칸**을 먼저 보여 준다. `series=qmc`는 QMC 카드만, `series=all`은 삼성 전체 카드를 보여 준다. 제조사 칩과 상세의 제조사 링크는 기존 주소를 유지한다.

| 칸 | 제품 수 |
|---|---:|
| 단독형 UHD H 시리즈 (QHC; 기존 QHF 포함) | 5 |
| 단독형 UHD M 시리즈 (QMC) | 6 |
| 비디오월 | 2 |
| 호텔 TV HU8000F 시리즈 | 3 |
| 비즈니스TV | 1 |
| 전자칠판 | 2 |
| LED 사이니지 | 3 |
| **합계** | **22** |

칸 순서는 기존 `brandSort.order`의 최소값으로 구했고, 칸 안의 모델 순서는 기존 `sort=brand` 결과를 보존한다. `QHF` 값을 `QHC`로 바꾸지 않았으므로 115인치는 승인된 맨 앞 순서 그대로다. 묶음이 없는 BSS Audio에서는 시리즈 칸 없이 기존 9종 카드가 바로 나온다.

## 동작 검증

- **유지 4가지:** 결과 내 검색, 세부 분류, 자료 필터, 정렬을 조작한 뒤에도 `series=qmc`가 URL에 남았다.
- **해제 6가지:** 제조사 칩, 제조사 선택, 상단 검색, 상위 분류, 필터/탐색 초기화, 빈 결과 초기화에서 `series`를 지웠다. 검색 제안의 제조사·카테고리·제품 갈래도 전용 상태 검사에서 지움으로 고정했다.
- **정규화:** 삼성의 빈 값·`all`·유효 id는 유지하고, 브랜드 없는 `all`, 삼성 외 브랜드의 `all`, 모르는 id는 제거한다. 최종 `brand`가 사라진 뒤 고아 `series`가 남지 않도록 `setFacets` 이후 처리했다.
- **이력:** 시리즈 선택은 새 이력으로 기록한다. 같은 칸을 다시 누를 때 이력 길이는 그대로였다. 뒤로가기는 칸 선택 단계, 앞으로가기는 모델 카드로 돌아왔다. `series=all` 새로고침 후에도 삼성 전체 카드를 유지했다.
- **상세 복귀:** QMC 카드에서 상세에 들어갔다 돌아와 `series=qmc`, 6개 카드, 마지막 검사에서 스크롤 825→825를 확인했다. Chromium에서 `pageshow.persisted === true`를 실제로 관측했다. 복원 리스너 추가는 필요하지 않았다.
- **화면:** [1280px·390px 선택 단계 및 QMC 카드 캡처](W-20261005-001-screens/). 8개 선택 버튼(전체 보기 포함), 가로 넘침·JS 오류 0. 1280px에서 키보드 Enter로 QMC를 선택했다.
- **독립 리뷰:** Critical·Important 0건. 복원 여부만 출력하던 검사에 이벤트 시점의 URL·선택·카드·스크롤 단언을 추가했다. 수정 후 Chromium에서 bfcache 복원을 실제 관측했고 네 값이 모두 일치했다.
