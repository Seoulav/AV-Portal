## 제안 순서

1. 시범 사용자 확인 뒤 모델 경계가 분명한 Crown DA·Shure 수신기부터 제조사별 5–10종 데이터 PR.
2. NovaStar·Analog Way·Lightware 등 레이어/카드 자원이 있는 군은 모델별 카드·화면 한도 먼저 대조.
3. 디스플레이 37종은 Signal Flow를 추가하지 않고 기존 연결 단자 유지, 사진 좌표·설정만 확인.
4. PDF 부족·원본/게시 크기 불일치·액세서리 흐름 없음 후보는 빈 항목과 필요한 자료를 명시. 별도 승인 없이 제외하거나 추측하지 않는다.
5. 각 PR마다 기존 값 불변 검사, PDF 페이지·이미지 측정표, 1280/390 캡처와 검색 인덱스 검사 후 병합. RTCOM 제품 변환(3단계)은 별도 승인.
