알티컴의 최종 `--rt-muted`는 `#687386`이고, 최종 `.rt-meta b`는 `#376cd0`이다. `#376cd0`은 AV Portal의 기존 토큰과 다르지만 **알티컴에 실제로 있는 색**이므로 그대로 사용했다. W-20261004-001에서 제거한 `#2459b0`은 알티컴에 없는 색이었으므로 판단이 모순되지 않는다. 세 공개 페이지의 버전 표기에는 같은 Pretendard Variable 파일을 사용한다. 정적 카탈로그는 원래 이 글꼴을 선언하지 않아 버전 부품 CSS에 자체 `@font-face`를 선언했다.

알티컴 로컬의 두 줄은 `AV 시스템 설계 도구` / `CATALOG BASED · 0.195`, Portal은 사용자가 정한 `AV 장비 자료실` / `DOCUMENT BASED · v0.1.0 · local`이다. **문구 길이 때문에 너비와 헤더 내 절대 x 좌표는 다르지만**, 패딩·글꼴·색·줄높이·배경·모서리·흐름 배치는 일치한다. 실제 배포의 둘째 줄은 `version.json` 빌드 번호를 표시한다. SHA와 배포 시각은 둘째 줄에서 빼고 `title`에 둔다. 로컬은 배포 시각이 비어 있어 `커밋 unreleased`만 표시한다.

## 서로 다른 헤더에 맞춘 처리

- 홈은 `.site-header`의 기존 브랜드·메뉴 다음에 배지를 둔다. 390px에서 메뉴가 두 열로 표시된 아래에 배지가 전폭으로 나온다.
- 상세는 브랜드·검색/제품 탐색 동작 다음에 둔다. 390px에서 동작 줄 아래 전폭으로 나온다. 기존 헤더의 sticky 동작을 유지하며 배지와 헤더의 상대 위치가 스크롤 전후 동일하다.
- 정적 카탈로그는 `build-readable-catalog.mjs`가 HTML을 생성한다. 생성기와 산출물을 함께 변경하고 헤더 내부의 본문 묶음과 배지를 flex로 배치했다. 390px에서는 본문·다운로드 링크 아래 전폭으로 쌓인다.

세 페이지 모두 1280px·390px에서 문서 가로 넘침 0, JS 예외 0, 화면에 보이는 요소 겹침 0이다. 배지의 `position`은 모두 `static`이고 헤더 안에 있다. [나란히 캡처](W-20261004-008-screens/comparison-rtcom-qms-44ux-vs-blu-101.png)와 [실측 JSON](W-20261004-008-screens/measurements.json)을 보존했다. `version.json` 요청을 막은 [실패 화면](W-20261004-008-screens/metadata-fallback-390.png)도 `AV 장비 자료실` / `DOCUMENT BASED · 확인 필요` 두 줄로 나온다.

## 제거한 떠 있는 배지 규칙

1. `.pg-page .system-version{top:112px}`
2. `721px~1000px`의 홈 `top:155px`
3. `720px 이하`의 공통 `top:120px`와 홈 `top:185px`
4. `460px 이하`의 `right:8px;top:8px` 및 축소 패딩·9px 글자

기본 `position:fixed;right:14px;top:12px`, `pointer-events:none`, 흰 반투명 배경·blur·테두리·그림자도 제거했다. 작은 화면에는 알티컴과 동일하게 전폭 배지와 11px 글자를 적용했다.
