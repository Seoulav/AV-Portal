## 회귀 검사 결함과 수정

`tests/w032-history-fs.mjs`는 24개 과거 검사에서 `node:fs`를 대신하여 카메라 JSON 전체를 과거 fixture로 읽었다. 그 결과 현재 `brc-am7.io=[]`, `model=INVALID`, `srg-x40uh.portMap` 좌표 변이도 과거 해시에서 보이지 않았다. 이 shim을 삭제하고 각 테스트가 `node:fs`로 실제 파일을 읽게 했다. 과거 전체 해시를 계산하는 **그 지점에만** `beforeW032Raw` 또는 `beforeW032Product`를 적용한다. 이 함수는 현재 객체를 복제하고, W-032에서 달라진 `documents`의 개별 필드·추가 행과 두 제품의 새 `signalFlow`만 원상 복원한다. 바뀐 문서 필드와 플로우가 이번 승인 결과와 정확히 일치하는지도 검사한다. 나머지 `io`, `model`, `specifications`, `keyFacts`, `images`, `portMap`은 현재 입력 그대로 과거 해시로 전달된다. 과거 해시 기대값은 수정하지 않았다.

`tests/w032-invariants.test.mjs`는 현재 변경 대상 카메라 5종의 기술 필드를 착수 전 fixture와 직접 비교하고, 나머지 카메라 3종의 JSON SHA-256을 고정한다. 메모리에서 BRC I/O와 모델명을 바꾸고 SRG-X40UH Port Map 좌표를 바꾸면 역변환 뒤에도 변이가 남아 기존 해시와 달라짐을 검사한다. `port-map-merge`의 현재 렌더 동작은 실제 JSON 250종으로 검사하며, 과거 플로우 9종 기대값은 별도 역변환 지점에서만 확인한다.
