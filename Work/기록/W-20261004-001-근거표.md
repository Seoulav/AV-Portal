## 화면·검증 결과

- 47종 × 1280px·390px **94/94 화면**에서 Port Map과 설명 카드가 나타났다. 카드 4열/2열, 번호·카드 수 일치, 사진 위 번호 0, 번호끼리 겹침 0, 페이지 가로 넘침 0, 깨진 이미지 0, JS 오류 0. 모바일은 RTCOM과 같이 **SVG 내부만 가로 스크롤**하며 스크롤 안내가 보인다.
- 실행 중 사진 DOM의 `getBoundingClientRect()` 측정과 30px씩 번호를 이동시키던 반복문, `paddingTop/Bottom` 보정은 제거했다. SVG의 원본 이미지 치수와 기존 Port Map 픽셀 좌표로만 배치한다. 레이아웃 변화·이미지 전환 시 SVG가 컨테이너 폭에 맞춰 비례한다.
- `displayWidth` 사용 제품은 **0종**이다. 합성 단위 검사에서는 분기를 확인했으나 실제 제품 화면 검증은 불가능하다.
- RTCOM의 `left/right` 세로 괄호 분기를 렌더러에 유지했다. **현재 `validMarker`는 `top/bottom`만 허용하므로 실제 제품에서 `left/right` 지도는 표시될 수 없다.** `ez-umd-plus` 측면 사진 활용과 검증기 확장은 별도 작업이다.
- RTCOM의 높이 2U 이상 조건부 정면/후면 버튼은 이번 범위 밖이다. AV Portal은 기존 방향 선택 버튼을 유지한다.
- 독립 리뷰에서 지도 표시 시 숨겨진 원본 사진의 자세한 `alt`가 접근성 트리에서 사라지는 문제(Important 1건)를 발견했다. SVG `<desc>`와 `aria-describedby`로 원본 문장을 옮겼고, 브라우저 접근성 트리에서 이름 `SRG-X40UH 단자 지도`와 사진 설명이 함께 복구됨을 확인했다. 최종 Critical/Important **0건**이다.
