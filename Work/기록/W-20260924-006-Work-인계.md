# W-20260924-006 · Group 1 공개 Beta 인계

2026-09-24 사용자 승인으로 기존 25개 Library와 Group 1 다섯 제품 상세를 GitHub Pages 공개 Beta에 연결한다. 선행 Draft PR #33 → #34 → #37 순서와 수행 PR을 main에 반영한 뒤 기존 Pages Actions로 배포한다.

## 공개 결과와 선택 이유

- Library는 기존 25개를 유지하고 AJA Ki Pro GO2, Panasonic PT-MZ17K만 더해 장비 27개다. 기존 BRC-AM7, DM7, Rally Bar는 카드 하나씩만 유지한다.
- 상세는 공통 renderer와 제품별 정적 JSON 5개를 사용한다. 로컬 Work Markdown이나 개인 PC의 원본 파일 없이 실행된다. 이는 UI용 임시 구조이며 최종 Schema·DB·Storage 결정을 뜻하지 않는다.
- 공개 화면에는 제품 정보·사양·I/O·공식 출처·검토 상태를 표시한다. 개인 경로, 원본 행, 업체·공급처 정보, 단가, 내부 메모, Work 입력 원문과 사진·PDF 바이너리는 배포 아티팩트에서 제외한다. 사진은 역할별 상태와 공식 제품 페이지 링크만 제공한다.
- PT-MZ17K의 지역·L 접미어 적용이 검토 중이므로 Library의 공식 링크는 비워두고 상세에서 검토 상태와 함께 제조사 페이지를 안내한다. 다른 빈 자료는 MISSING으로 표시하고 가짜 링크를 만들지 않는다.
- 공개용 `packageStatus`는 다섯 제품 모두 REVIEW REQUIRED다. Work의 READY FOR CODEX/READY WITH REVIEW FLAGS는 개발 전달 준비 상태이며 공개 사실 검증과 다른 의미다. 개별 VERIFIED·FOUND·MISSING·REVIEW REQUIRED·CONFLICTED 값은 유지한다.
- Pages 검증은 허용 파일 목록과 공개 JSON 고정 해시를 확인한다. SHA 입력은 CRLF를 LF로 정규화해 Windows 체크아웃과 Git의 LF blob을 동일하게 판정한다.
