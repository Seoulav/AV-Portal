## 01 카드·검증

작성 규칙의 밝기→해상도→화면 크기→명암비/설치 방향 축을 재검토했다. 115QHF는 국내 `밝기(최대) 1000 nit`를 첫 축으로 추가해 **2→3개**(최대 밝기·화면 크기·설치 방향)가 됐다. 해상도와 명암비는 국내 검증 근거가 없어 카드에 쓰지 않았다. LH55WMF는 국내 자료가 없으므로 기존 2개(화면 크기·설치 방향)를 유지했다.

전용 검사는 데이터 변경 전 해외 URL 잔존으로 **RED 1/4 fail**, 변경 후 **GREEN 6/6 pass**. `npm.cmd --silent test`는 첫 실행에서 Windows 임시파일 관련 RTCOM 동기화 검사 3개가 실패했으나 해당 파일 단독 재실행 **5/5**, 전체 재실행 **207 tests / 206 pass / 0 fail / 기존 skip 1**이다. `node beta/verify-pages.mjs` **249·242·370**, 검색 인덱스 `--check` 통과. [로컬 캡처](W-20261002-014-screens/) 14종 × 390px에서 상세 HTTP 200, JS 오류·깨진 이미지·가로 넘침·상세 로드 실패 모두 0건이다. 기존 값/행, 국내 근거, 출처 참조 및 범위 밖 삼성 제품 바이트 불변은 [근거 JSON](W-20261002-014-evidence.json)과 전용 검사에서 고정했다.

현재 제품 JSON의 해외 지역 URL 0건이다. 전자칠판 LH55WMF는 국내 상세 자료가 없어 기존 값 25개 사양과 단자 4행이 여전히 `REVIEW REQUIRED`이며, 국내 `P`가 병기된 밝기 행은 `P`만 남겼다. 국내 자료 확보와 다수 확인 필요 행의 표시 방식은 후속 기획 입력이다.
