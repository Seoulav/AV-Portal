## BLU-50 적용 모델 게이트

`매뉴얼_BLU-50.pdf`의 [표지 화면](W-20261003-011-screens/blu50-model-gate.png)은 **“Soundweb London BLU-50 Installation Guide 5040341-C”**다. 20쪽의 텍스트층 전체에서 `v2`, `Version 2`, `revision`을 검색한 결과 **0건**이다. 텍스트가 없는 2·19쪽은 Chrome PDF 뷰어에서 직접 열어 **빈 쪽**임을 확인했다. 본문은 BLU-50이라고만 적고 `BLU-50v2`를 명시하지 않는다. 따라서 **`blu-50v2`에는 게시·연결하지 않았다.** 기존 영문 데이터시트 미러와 15개 마커 Port Map은 유지된다.

`blu-aec-in`·`blucard-in`·`blucard-out`에 해당하는 사용자 제공 PDF도 없어 **업로드 0건 유지**다. 세 제품의 기존 미러는 유지한다.
