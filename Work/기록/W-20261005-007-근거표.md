## 설명서·도면·번호 대응

기존 게시본 `manuals/samsung-qbc-qhc-qmc-shc-manual-ko.pdf`는 BN81-24537G-14이다. `pdftotext -f 20 -l 20`으로 20쪽 제목과 적용 모델 목록을 확인하고 그 쪽을 직접 열었다. **QM50C·QM75C가 모두 20쪽 「단자 설명」 적용 모델 목록에 있다.** 사용자에게서 온 더 낮은 `-02` 개정본은 게시하지 않았다. `Diagram` WebP는 기존 20쪽 게시 도면과 바이트가 같고, 게시 픽셀에서 추출한 물리 단자 구간과 11개 괄호의 중심을 대조하는 검사가 통과했다. 기존 5종과 지도 항목·좌표도 같다.

원본은 각각 공식 **정확 모델 페이지**의 갤러리 URL에 연결되지만 두 원본의 내용은 같다. 개별 인치의 실물 전용 사진이라고 주장하지 않고 `note`에 **제품군 공통 이미지**로 표기했다. 도면도 제품별 파일로 복제하여 자산 참조와 파일의 1:1 관계를 유지한다. 제품 JSON `images[].sourceUrl`에 원본 전체 URL이 있다.

새 두 WebP의 SHA는 서로 같고 기존 QMC 32·43·55·65·85·98 여섯 제품의 Main WebP SHA와는 모두 다르다. 따라서 이번 두 공식 갤러리가 같은 이미지를 돌려 쓰는 것은 확인되지만, 기존 여섯 제품과 같은 바이트라고 쓰지 않는다.

공식 QMC 기존 **32·43·55·65·85·98** 페이지와 신규 **50·75** 페이지에는 모두 `판매중지된 상품` 문구가 있다. 이는 기존 제품에도 나타나므로 이번 작업에서 단종 필드나 화면 표기를 새로 만들지 않았다. Chromium 첫 DOM 캡처에는 판매 문구가 잡히지 않았으나 공식 페이지 본문 재확인에서 여덟 모델 모두 확인했다.

## 회귀 검사 범위 대조

기존 테스트 여러 개가 **당시 제품 디렉터리 전체**를 오래된 SHA-256 값과 비교한다. 두 신규 JSON을 기존 집합 해시에 넣으면 현재 기존 제품이 하나도 바뀌지 않아도 실패한다. 이에 `w007-history.mjs`의 정확한 두 슬러그만 과거 집합에서 제외하고, 새 두 제품은 전용 검사·현재 목록 수치·Port Map 픽셀 검사로 직접 고정했다. 과거 SHA-256 기대값, 기존 `assert`와 skip/todo는 삭제하지 않았다. 과거 검사에서 읽는 **기존 제품 JSON은 모두 현재 파일 그대로** 통과한다. 기존 제품 JSON·PDF·manifest·렌더러 변경은 `git diff --name-only`에서 0건이다. 현재 수치를 검사하는 곳에서만 265→267, 삼성 33→35, 상세 258→260, 지도 69→71, 작성 카드 121→123, `미지원` 단자 15→17로 실제 새 두 제품만큼 갱신했다.
