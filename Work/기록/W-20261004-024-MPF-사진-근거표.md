세 원본은 각각 **1920×1280**이다. 깨끗한 배경에 캐비닛 정면 전체가 보이고 홍보 글자가 겹치지 않아 갤러리의 첫 정면 사진을 선택했다. 원본 PNG는 저장소 밖의 무시된 임시 산출물에서만 보관하고 Edge canvas로 WebP 품질 0.9로 변환했다. `mp012f`와 `mp016f`의 서로 다른 SKU 갤러리가 **바이트까지 같은 원본**을 제공한다. 게시 WebP 두 장도 동일 해시이며 색·크기·내용을 인위적으로 바꾸지 않았다. 제품별 파일명은 Pages의 이미지 참조 1:1 계약 때문에 다르게 두었고, `alt`·`note`·출처에 **제품군 공통 이미지**라고 명시했다. 두 개를 서로 다른 모델 전용 실물 사진이라고 소개하지 않는다.

착수 기준은 **257 장비·250 상세·391 WebP·107 PDF**, 무사진 상세 6종이었다. 명세의 “242종 중 MPF만 무사진”은 W-030 등록 전 수치다. 이번에 MPF 3종만 채워 **257·250·394·107**, 무사진 상세는 `ie015a-e`·`ie020a-e`·`if015r-m` 3종으로 남겨야 한다. 신규 LED 3종의 사진을 다른 계열에서 추정해 붙이지 않았다.

전용 검사 `node --test tests/mpf-images.test.mjs`는 사진 등록 전 `mp008f` 사진 0장으로 **RED(1 fail)**, 등록 후 **GREEN(1 pass)**이었다. 기존 `tests/samsung-led-mpf.test.mjs`의 등록 당시 사양 20항목과 원본 이미지 부재 기록은 역사 fixture로 대조하고, 현재 사진 3건은 전용 검사로 잠갔다. 전체 순차 검사 340건 중 339 pass·0 fail·1 기존 skip, `verify-pages` 257·250·394·107, 검색 인덱스 `--check` OK. 기본 병렬 `npm.cmd test`는 기존 Windows `rtcom-sync` 임시 폴더 `rename EPERM` 1건이 재현됐다. 이력 검사의 기존 해시·수량은 바꾸지 않았다.
