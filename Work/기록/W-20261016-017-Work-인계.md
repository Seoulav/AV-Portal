## 기능과 작성 방법

- 같은 쪽 번호가 가로·세로 모두 22px 미만이면 뒤 번호를 24px 단위로 내린다. 괄호 높이는 고정. 내려간 번호가 사진 높이를 벗어나면 아래 여백을 늘린다. 같은 높이여도 x가 다른 DM7·KI PRO GO2는 유지.
- 항목의 via는 원본 사진 좌표 1~3개 쌍이다. 예: `"via": [[203,744],[0,744]]`. 유한수·원본 경계·crop 가시 범위 검사. 점과 점 사이를 수평/수직으로 연결하며 시작은 괄호에, 끝은 번호 원 가장자리에 붙인다.
- left/right + via: x는 실제 괄호 위치, 번호는 사진 바깥 고정 여백. via 없는 기존 x·번호 위치는 보존.
- 기존 원 반지름10·흰 숫자11px/700·파랑 #007AFF·선1.5 유지. 렌더러·검증기 공개 복사본은 기존 build-detail-assets 생성 절차로 맞춤.
