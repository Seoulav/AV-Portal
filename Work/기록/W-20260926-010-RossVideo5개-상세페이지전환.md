# W-20260926-010 — Ross Video 5개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-009 완료 후 다음 최소 브랜드인 Ross Video(카탈로그상 11개, 전부 Ultrix 모듈형 라우팅/스위칭 플랫폼)를 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다. 사용자가 취침 전 "모든 제품 진행하되 고해상도 이미지를 최대한 찾아줘"라고 명시적으로 지시해, 에이전트가 이미지를 확보하지 못한 항목에 대해 이 세션에서 추가로 공식 Cutsheet/Quick Start Guide PDF를 뒤져 실물 사진을 더 찾는 작업을 직접 수행했다.

## 핵심 발견: 소프트웨어 라이선스 vs 실물 하드웨어

Televic 배치에서 얻은 교훈(카탈로그 이름이 물리 모듈처럼 보여도 실제로는 라이선스인 경우가 있음)을 적용해, 에이전트에게 11개 항목 각각이 실물 하드웨어인지 소프트웨어 라이선스인지 명시적으로 검증하도록 지시했다.

- **ULTRISCAPE**: 카탈로그 카테고리에 이미 "License"로 표기되어 있었고, 조사 결과 실제로 Ultrix I/O 카드(HDX-IO/MODX-IO/IPX-IO) 위에서 동작하는 멀티뷰어 헤드 라이선스로 확인됨.
- **ULTRIMIX-MXR**: 카탈로그 URL 자체가 "ultrix-licenses"(라이선스) 페이지를 가리켰고, 애플리케이션 노트에도 "the newest software licensable feature"로 명시되어 있어 라이선스로 확인.
- **ULTRISYNC-18**: 같은 라이선스 페이지에서 "Ultrisync"/"Ultrisync-UHD" 프레임 동기화 라이선스를 확인했으나, "-18" 접미사가 정확히 무엇을 의미하는지는 공식 자료 어디에서도 문자열 그대로 등장하지 않아 확인하지 못함(이슈로 기록).
- **ULTRIMIX-DANTE**: 새 카드가 아니라 이미 설치된 ULTRIX-HDX-IO/MODX-IO 카드의 AUX C/D SFP+ 포트를 Dante 오디오로 전환하는 라이선스로 확인.

이 4개는 물리적 치수·무게가 존재하지 않고 제품 사진도 없어(UI/기능 스크린샷만 존재), 실물 이미지를 만들어내지 않고 이번 배치에서 제외했다.

## 실물 하드웨어 3종 (에이전트가 이미지까지 확보)

- **ULTRIX-NS-FR2**: 2RU 프레임. 공식 제품 페이지(2026-07 업로드 이미지, 768×440)로 사양·이미지 모두 확보.
- **ULTRIX-HDX-IO**: SDI I/O 카드. 공식 I/O Cards 페이지 이미지(2048×521, 상당히 고해상도)로 확보.
- **ULTRITOUCH-2-HR**: 컨트롤 패널. 공식 제품 페이지에서 전면(1600×800)과 후면(1600×800, 2RU/4RU 공용 가능성 있음을 명시) 이미지를 모두 확보해 front+back 요건을 충족.

## 실물 하드웨어인데 이미지가 없었던 2종 — 이 세션에서 추가 확보

에이전트는 ULTRIPOWER(1RU 랙마운트 PSU 섀시)와 ULTRIPOWER-PS(개별 전원 모듈)를 물리 제품으로 정확히 식별했으나, 공식 제품 페이지에서 실제 사진을 찾지 못해 이미지 없이 보고했다. 사용자의 "고해상도 이미지 최대한 확보" 지시에 따라 이 세션에서 추가 조사를 진행했다.

1. `documentation.rossvideo.com/files/Brochures/Infrastructure/Ultripower%20Cutsheet.pdf`(제조사 공식 Cutsheet)를 확보해 `pdfimages`로 내부 이미지를 추출.
2. 추출된 이미지 중 하나는 **Ultripower 후면 패널**(이더넷 포트, OUT 1-4 전원 커넥터, IEC 인렛 A/B) 사진이었고, 다른 하나는 **Ultripower 전면 패널** 사진으로 중앙에 "Ultripower" 라벨, 좌우 슬롯(SLOT 1/SLOT 2)에 "Ultripower-PS"라고 선명하게 표기된 개별 전원 모듈 2개가 장착된 모습이었다.
3. 이 전면 사진 한 장으로 (a) ULTRIPOWER(섀시)와 (b) ULTRIPOWER-PS(개별 모듈)를 모두 시각적으로 확인할 수 있어, 두 이미지를 각각의 상세페이지에 반영했다. ULTRIPOWER는 추가로 후면 사진도 반영해 front+back을 충족했다.
4. `documentation.rossvideo.com/files/Manuals/Routers/Ultripower/Ultripower%20Quick%20Start%20Guide%20(2101DR-302).pdf`(1페이지, 3.4MB)도 확인했으나, 내부 이미지는 배경 워터마크와 라벨이 달린 벡터 다이어그램(사양표 포함: Inputs 100-240VAC, Positive Output 15VDC @ 300W, Max Total Output 1200W)이라 실제 촬영 사진보다 품질이 낮아 채택하지 않았다. Cutsheet PDF에서 추출한 사진(1225×200~1229×200)이 낮은 해상도이긴 하지만, 라벨 없는 순수 실물 촬영 사진이라는 점에서 우선 채택했다.

## 끝까지 이미지를 찾지 못한 2종

- **ULTRITOUCH-PS**: Ultritouch 컨트롤 패널의 외장 전원 어댑터. Ultritouch 공식 Brochure PDF에서 패널 후면의 PWR1/PWR2 커넥터 사진(고해상도)은 확보했으나, 어댑터(브릭) 자체의 단독 사진은 발견하지 못했다.
- **SFP-MADI-COAX**: MADI 동축 트랜시버 SFP 모듈. `Ultrix SFP Modules Guide`에 블록 다이어그램만 있고 사진이 없었으며, I/O Cards 제품군 페이지의 `ultrix_SFP_topFront` 고해상도 이미지(2048×1845)를 확인했으나 이는 다른 제품인 "ULTRIX-MOD-SFP"(4슬롯 SFP 캐리어 서브모듈) 사진으로, SFP-MADI-COAX 자체를 보여주지 않아 사용하지 않았다.

이 2개는 실물이 존재하는 제품이지만 이번 배치에서 이미지 없이 상세페이지를 만들 수 없어(프로젝트 규칙상 상세 슬러그가 있는 모든 제품은 이미지 최소 1장 필요) 제외했다.
