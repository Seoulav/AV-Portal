# W-20261012-005 Port Map 읽기 명확성 전수 점검표

기준: `origin/main` `1cb8117`, 2026-10-12. `scripts/portmap-audit.py --all`의 84종 overview를 각 제품별로 직접 확인했다. lint는 좌표의 일부 중첩만 알리므로 사진과 지시선의 의미를 육안으로 판정했다. 수정 뒤 84종을 다시 렌더했다.

- 총계: **84종, 706→696개 표식**. 수정 13종, 변경 없이 정상 70종, 단자 경계 추가 확인 1종.
- 유형별 수정 제품 수: A 두 줄 배열 2종(`ki-pro-go2`, `dm7`), B 대상 불명 1종(`ki-pro-go2`), C 다른 단자 관통 10종(DCi 8종·`dm3`·`novastar-h2`), D 과다 표식 1종(`vs10`). 한 제품이 두 유형에 속해 유형 합계는 수정 종수와 다르다.
- `dm7`은 18→18개. 세 XLR 뱅크를 세로 괄호로 두 줄 모두 표시했다. 서로 다른 AES/EBU·워드 클록·Dante·전원 기능이므로 더 합치지 않았다. **정확한 줄 표시가 15개 목표보다 우선**이라는 사용자 판단을 적용했다.
- `ki-pro-go2`: 11→14개. HDMI 윗줄 1·2는 오디오 XLR을 피하려고 각각 표시하고 아랫줄 3–4를 묶었다. SDI 출력은 윗줄 1–2/아랫줄 3–4로 나눴다. 번호 재배치에도 SDI 입력 1–4, 오디오 L/R·LTC, REF LOOP, 모니터 출력, USB, LAN, DC 2계통은 그대로다.
- `vs10`: 26→13개. 아래 대응표에서 구 번호 모두를 정확히 한 번씩 다룬다. 입력 1–6과 7–8은 서로 다른 줄이어서 별개 번호이고, PGM HDMI와 Multiview HDMI도 역할이 달라 분리했다.
- `ultritouch-2-hr`은 최초 점검 때 소켓이 가려져 보류했다. 후속에서 [제조사 도면·각도 사진 대조](W-20261012-005-ultritouch-후속근거.md)로 ENET1·PWR1·PWR2 소켓을 확정하고 사진·좌표를 교체했다. 최초 84종 판정과 13종 수정 수치는 당시 결과로 보존한다.
- 사진·`io`·사양·렌더러·`validMarker`는 변경하지 않았다. `portMap` 외 현재 제품 필드는 이전 SHA-256으로 전수 고정하며, 선택적 되감기가 승인된 `portMap`만 되돌린다.
