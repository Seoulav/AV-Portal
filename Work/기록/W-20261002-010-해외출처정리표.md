# W-20261002-010 삼성 사이니지 해외 출처 정리표

## 기준과 판정

착수 main `bc7633d6866489b5d939ed18a62e1528c54ad942`의 삼성 14종 사양·I/O 688행을 다시 조사했다. 해외 **단독** 출처 63행(LH115QHF 35, LH55WMF 28)에 국내·해외 **혼합** 출처 2행(LH32QMC 색재현율, LH55WMF 밝기)이 더해져, 해외 페이지를 조금이라도 참조하는 행은 **65행**이다. Work가 전달한 63행은 혼합 2행을 빠뜨린 수치다.

사용자가 직접 제공한 삼성전자 `[사이니지] 스마트 LCD 사이니지_115QHF.pdf`(SHA-256 `4be5f424f5d7bce2c716f4375b1dfc31f126e71f3e7db739b389289331486962`)와 `제품가이드.pptx`(SHA-256 `347a5d9a3a657c89d648da0aa82d3c3dcd9c27a367efa192ce34dc08167674f4`)를 확인했다. PDF 1~2쪽과 가이드 슬라이드 4는 정확 모델 `LH115QHFEBGXKR`를 적는다. 표는 화면 크기·사용 시간·사운드·USB·소비전력(On)·크기·무게·인증을 제공하지만, 이들은 이미 국내 `P` 또는 기존 국내 문서 `S3/S4` 행이다. 해외 `S2`만 근거인 35행의 패널·연결성 세부 사양은 없다. PDF 1쪽의 **최대 1000nit**는 기존 **밝기(Typ) 1000nit**와 측정 조건이 달라 대체하지 않았다. 사용자 원본은 공개 자산에 복사하지 않았다.

LH32QMC의 한국 공식 스펙은 색재현성 `72 %`만 표기한다([W-005 근거 JSON](W-20261002-005-samsung-sources-evidence.json)). 기존 `72% (NTSC)`의 NTSC 한정은 캐나다 페이지에만 있으므로 값에서 한정을 제거하고 출처를 국내 `P`로 바꿨다. 나머지 해외 참조 64행은 **값과 수량을 보존**하면서 `REVIEW REQUIRED`로 낮췄다. 해외 페이지는 `sources`에 “국내 자료 미확보 · 해외 지역 페이지 기록”으로 남겨 과거 값의 출처만 설명한다. 현재 `FOUND`/`VERIFIED`인 해외 출처 기반 행은 **0**이다.

## 화면·잔여 사항

[390px 화면 기록](W-20261002-010-screens/local.json)은 삼성 14종 전부 HTTP 200·JS 오류 0·실제 이미지 로드 실패 0, 01 핵심 카드 넘침 0을 확인했다. 두 제품의 자료 출처 절에 “국내 자료 미확보”가 표시된다. 전체 페이지의 가로 넘침은 변경 전후 같은 9종에서 관찰됐고, 03 전체 표의 기존 가로 스크롤에서 발생한다. 이번 배치의 렌더러·스타일 변경은 0건이다.

WMF 29행과 115QHF 35행의 국내 세부 사양 자료는 아직 없다. 사용자 제공 국내 문서가 확보되면 해당 행을 개별 대조해 승격해야 한다. W-20261002-012 LED 등록은 이 배치에서 수행하지 않았다.
