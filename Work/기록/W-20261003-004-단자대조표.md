## 적용 모델 판정과 Work 명세 정정

13쪽의 ①~⑫ 목록은 12쪽 **두 도면의 공통 범례**다. U800F 도면에는 ①~⑨만 있고, ⑩ HP-ID·⑪ HEADPHONE JACK·⑫ SERVICE는 U700F 도면에만 있다. Work 명세가 공통 목록을 U800F 전용으로 읽어 **7행 추가**라고 한 것은 오류다. 사용자 확인에 따라 U800F 3종에는 **4행만 추가**하며 U700F 전용 세 단자를 만들지 않는다. 이 적용 모델 게이트는 추후 U700F 제품 등록 때도 필요하다.

## RJ12 전체 매뉴얼 검색

PDF 32쪽의 추출 가능한 텍스트 전체에서 `RJ12`를 검색했다. 11쪽에 **`데이터 케이블(RJ12)의 동작 사양: RS232`**가 한 번 나온다. 같은 쪽 도면은 **TV의 DATA 단자에서 STB의 ETH MODEM 단자로 가는 케이블**을 보여준다. 12쪽 U800F 도면 및 13쪽 단자 목록은 `DATA`만 표시한다. 따라서 RJ12를 별도 TV 포트라고 확정할 수 없고 DATA와 동일 물리 단자일 가능성이 있다. 기존 `RJ12` 행은 삭제하지 않고 `REVIEW REQUIRED`로 낮춰 이 관계가 미확인임을 명시했다. `DATA`는 매뉴얼에 직접 표시돼 별도 행으로 추가했다. 중복 여부는 실물이나 별도 단자 사양 자료로 판단해야 한다.

세 제품의 `io`는 기존 9행에서 **13행**으로 같아졌다. `HDMI-COUNT` 과거 이슈는 수량 확인 사실로 갱신했으며 HDMI 버전 미확인 사실은 남겼다. `specifications`·01 카드·사진·그 밖의 상세 필드는 변경하지 않았다. 대상 외 상세 JSON 전체는 정규화한 Git LF 바이트 SHA-256 집계로 고정했다. 세 제품의 보호 필드와 기존 사양은 [근거 JSON](W-20261003-004-evidence.json)의 SHA-256으로 고정했다.
