# W-20261004-020 — 삼성 LFD Port Map 좌표·도면 근거

기준은 `origin/main` `ae358d1be890240f2baeaf546ea184bf011921ea`이다. 공개 배포본의 수정 전 화면과 로컬 수정 후 화면은 [화면 캡처](W-20261004-020-screens/)에 같은 1280px·390px 크기로 보관한다. 좌표의 구조화된 전후 값과 원본 SHA-256은 [근거 JSON](W-20261004-020-evidence.json)에 기록했다.

## 판정과 측정

QMC·QHC 5종의 제품별 WebP 5개는 서로 SHA-256 `43a0ce418f6779a153b1d43f565a37272b24f8ca4f3f1843615f33e2ef811a56`로 같다. 기존 파일은 교체하지 않았다. Chromium 캔버스에서 **게시 WebP 자체**를 회색조로 읽고 `x=35..114`, 밝기 140 미만인 픽셀의 연속 y 구간을 추출했다. 4px 미만의 독립된 잡점 구간과 위·아래 바깥 테두리의 짧은 구간만 제거했다. A와 C는 단자 11구간, B는 10구간이며 도면의 실제 단자 수와 일치한다. `tests/port-map-coordinates.test.mjs`는 이 과정을 고정하고 좌표 양끝이 실측값과 각각 ±8px 이내인지 검사한다. 변경 전 전용 검사 **3 fail**, 변경 후 **5 pass**를 직접 확인했다.

아래 표의 `실측`은 게시 WebP 픽셀, `전`은 W-020 이전 공개 JSON, `후`는 이번 JSON의 `y1–y2`다. A의 4~11번은 위로 약 25~39px 밀려 있었고, B의 9·10번은 아래끝이 각각 19·13px 길었다. Work가 준 A 수치와 독립 측정값은 일치했다. B의 1~8번은 Work가 ±5px 범위로만 보고했으며 이 표에는 직접 측정한 정확한 구간을 남긴다.

## C — LH115QHFEBGXKR

저장소의 삼성 한글 사용설명서 `samsung-qpdx5k-qhfx-manual-ko.pdf` **15쪽 `QH115FX`** 패널을 직접 열었다. 14쪽은 다른 모델 `QP105DX-5K`이므로 사용하지 않았다. 15쪽을 PDF.js에서 **4.5배 렌더링**하고, 렌더 캔버스의 **x=166, y=495, 폭=318, 높이=1375** 영역을 잘라 WebP 품질 0.95로 게시했다. 위쪽 USB 2부터 아래쪽 IR과 닫힌 외곽 테두리까지 모두 들어간다. 처음 확인한 로컬 크롭은 아래 테두리가 열려 있어 게시하지 않았다. 새 도면은 `318×1375`, SHA-256은 근거 JSON에 있다. `measuredImage`와 게시 해상도를 일치시켰으며 02 렌더 높이는 **900px**이다.

115인치 도면은 **HDMI 3·2·1 다음 DisplayPort**이고 QMC·QHC는 **DisplayPort 다음 HDMI 3·2·1**이다. 따라서 공통 도면을 복사하지 않았다. 11개 `label`·`desc`는 기존 제품 값과 매뉴얼 15쪽 설명표가 이미 일치하며 바꾸지 않았다. 7종 전체의 번호·라벨·설명·방향 SHA-256은 변경 전후 `6efdeff673bef36f69c6859ea400b7f02eb77d06f6fd00ebdccfd28f4068b6cd`로 같다. 특히 115인치 HDMI 설명은 매뉴얼의 `HDMI 케이블`이고 QMC·QHC의 `HDMI 또는 HDMI-DVI 케이블`로 덮어쓰지 않았다.

## 화면과 돋보기

7종 × 1280px·390px의 전후 **28화면**, 390px 전후 비교 2장과 115인치/QM43C 나란히 보기 1장을 남겼다. 모든 수정 후 화면에서 도면 로드, 번호·카드 수 일치, 가로 넘침 0, JS 오류 0이다. 390px에서 115인치와 QM43C의 흰 도면 단자 이름은 돋보기 없이 읽힌다. 115인치는 QMC·QHC와 같은 형식으로 보이고 번호 11개가 단자 아이콘과 맞는다.

돋보기는 제품명이 아니라 **현재 이미지 역할 `Diagram`**으로 제한했다. 7종의 02 도면에서 돋보기는 안 뜬다. 사진 Port Map `srg-x40uh`의 02에서는 뜬다. 115인치 `Diagram` 확대 대화상자에서는 안 뜨고, **기존 `Rear` 사진을 선택해 확대한 대화상자에서는 아직 뜬다.** 사진 자료와 일반 사진 돋보기 기능을 유지하는 현재 규칙의 결과다. 사진 팝업까지 끌지는 사용자가 별도로 정할 일이다. 51종 사진 Port Map의 데이터와 렌더 계산식은 바꾸지 않았다.

## 범위와 회귀

제품 JSON은 위 7종만 수정했다. 다른 235종은 기존 바이트 그대로다. 7종에서도 `portMap` 좌표와 115인치 `Diagram` 이미지 등록 외 기존 값은 바꾸지 않았다. 기존 `Rear` 사진은 보존했다. 115인치 도면 추가로 WebP는 **381→382**이며 제품 참조와 파일 수는 1:1이다. 과거 검사들은 새 변경만 역변환해 당시의 고정 SHA와 비교하며 과거 `Work/기록/`은 수정하지 않았다.
