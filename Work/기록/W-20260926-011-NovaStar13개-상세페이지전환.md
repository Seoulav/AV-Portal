# W-20260926-011 — NovaStar H Series 13개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-010 완료 후 다음 최소 브랜드인 NovaStar(H Series, 카탈로그 13개)를 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다.

세션 초반 사용자가 자신의 개인 LED Calculator(`hkkim0454.github.io/svt-led-calculator`)의 "05 프로세서" 섹션을 참고 자료로 안내했고, 그 앱의 소스 코드(`processor-data.js`)에서 H2/H5의 슬롯·레이어 사양(이사가 2026-09-13/15에 공식 자료로 재확인한 값)과, 앱의 이미지 매니페스트(`app.js`의 `PROC_IMG_IDS`)에서 사용자가 직접 제공한 실물 전/후면 사진(`ns-h2-front.jpg`, `ns-h2-back.jpg`, `ns-h5-front.jpg`, `ns-h5-back.jpg`)을 이미 확보해 둔 상태였다. 이번 배치에서 이 사전 확보 자료를 에이전트에게 "확인된 참고 데이터"로 제공해 중복 조사를 피하고, 에이전트에게는 이 수치와 모순되지 않는 범위에서 물리 사양(치수·무게·전원 등)과 11개 개별 카드/전원 모듈의 사양·이미지를 새로 조사하도록 지시했다.

## H2 / H5 챠시

- 사전 확인 자료(슬롯 4/2·10/3, 레이어 32/48, 카드당 16×2K/8×DL/4×4K)와 에이전트가 새로 찾은 공식 Specifications PDF(V1.17.0)의 수치가 정확히 일치함을 확인했다.
- 다만 사전 자료가 인용한 "NOVASTAR_H Series(ver.2)" V1.12.0과 이번에 찾은 V1.17.0(2026-05-30 변경 이력 포함) 사이에 버전 차이가 있어, 완전한 원본 대조 없이 "동일 문서 계열의 개정판으로 판단"이라고 이슈에 명시했다 — 임의로 동일 문서라고 단정하지 않았다.
- 새로 확보한 물리 사양: 랙 유닛, 치수, 무게(순중량/총중량), 전원 입력/소비전력, 동작/보관 온습도, 소음, 전면 LCD(H2는 일반 LCD, H5는 터치스크린), 후면 컨트롤 카드 I/O(이더넷 1, RS-232 RJ45/568A 1, USB 2.0 2, Genlock IN/LOOP BNC), PSU 이중화(H2 없음/H5 옵션).
- 냉각/팬 정량 사양(팬 개수·풍량)은 공식 자료 어디에도 명시되어 있지 않아 "정보 없음"으로 유지하고 이슈로 기록했다.
- 이미지는 사용자가 직접 제공한 전/후면 실물 사진(H2: 2400×532/2400×534, H5: 2400×1176/2400×1175)을 그대로 사용했다. sourceUrl은 제조사 공식 제품 페이지 URL로 설정해(이 프로젝트에서 이미지가 사용자 경로로 확보됐어도 출처 확인 근거는 제조사 공식 페이지를 인용하는 기존 관례—Magnimage LED-780H 사례—를 따름), 스키마 일관성을 유지했다.

## 11개 카드/전원 모듈

에이전트가 H2 Specifications PDF(V1.17.0)에서 `pdfimages`로 카드면 사진을 전부 추출해, 11개 전 항목에 이미지를 확보했다(공백 0건). 전원 모듈(H_800W)은 실물 촬영 사진(제조사 OEM 파워서플라이, "800W"/"94%" 효율 라벨 육안 확인 가능)까지 찾아 VERIFIED로 처리했다.

- **H_4xHDMI input card**: 카탈로그 설명은 "4-channel HDMI"이나, 실제 카드면 사진과 데이터시트 확인 결과 HDMI 1.3 2개 + HDMI 1.4 2개(상호 배타적 사용)로 구성되어 있음을 발견했다. 카탈로그 표기를 임의로 고치지 않고 이슈로 기록했다.
- **H_800W**: 무게와 명시적인 "핫스왑" 인증 문구가 개별적으로 기재되어 있지 않음(H 시리즈 공통 "핫스왑 가능한 입출력 카드"라는 일반 서술만 존재)을 확인, 이슈로 기록했다.

## 발견한 문제와 수정: 슬러그-HTML 태그 충돌

에이전트가 제안한 슬러그 `h2`/`h5`를 그대로 사용해 `verify-pages.mjs`는 통과했으나, `npm test`의 `tests/catalog-scaling.test.mjs`("제품 추가는 코드가 아닌 데이터 변경으로 끝난다") 테스트가 실패했다. 이 테스트는 `beta/site/index.html`/`app.js`에 제품 슬러그 문자열이 하드코딩되지 않았는지 `source.includes(slug)`로 검사하는데, `index.html`에 있는 일반적인 `<h2>` HTML 제목 태그가 문자열 "h2"를 포함하고 있어 우연히 매치되었다. 슬러그를 `novastar-h2`/`novastar-h5`로 변경해 해결했다(상세 JSON 파일명, group1-images.mjs의 두 매니페스트 키, catalog.json의 slug 값 모두 일괄 변경).

## 코드 변경

- `beta/manufacturer-hosts.mjs`: NovaStar 항목에 `en-website001.oss-us-east-1.aliyuncs.com` 추가. 이 호스트가 novastar.tech 공식 제품 페이지에 직접 임베드되어 있음을 `curl`로 확인한 뒤(제조사 자체 CDN, 제3자 미러 아님) 허용 목록에 반영했다.
- `beta/group1-images.mjs`: 13개 슬러그 신규 항목(group1Images, cardImages) 추가.
- `beta/site/catalog.json`: 13개 항목에 slug·card_image 필드 추가.
- `beta/site/detail/data/*.json`: 13개 신규 파일(novastar-h2.json/novastar-h5.json 포함).

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 123 details, 145 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다(슬러그 충돌 수정 후).

## 남은 일

- H_800W 무게·핫스왑 인증 여부 후속 확인.
