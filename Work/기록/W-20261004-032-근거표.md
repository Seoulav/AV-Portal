# W-20261004-032 — 카메라 흐름·문서 근거

기준 `origin/main` `db61ddb9bd8bc70bbef7ff88ee105ed07ddbcaa2`. 명세 작성 당시의 “8종 자료 0건”은 **포털에 올라온 파일 0건**이라는 뜻이었다. 착수 시점에는 AVer 3종과 Sony RM-IP10의 공식 PDF가 이미 `docs/`·`manifest.mirrors`에 있었다. 기존 링크와 미러를 재사용해 중복 파일을 만들지 않았다.

## SIGNAL FLOW

| 제품 | 입력·출력 근거와 판정 |
|---|---|
| BRC-AM7 | 기존 `io`의 GENLOCK IN·TC IN 및 SDI OUT1(12G/6G/3G/HD)과 OUT2(3G Level A/HD)를 구분. OPTICAL은 옵션 SFP+와 OUT1 동일 신호를 명시. HDMI/SDI 무조건 동시 출력은 공식 근거가 없어 쓰지 않음 |
| SRG-A40 | 기존 `io`의 HDMI 최대 4K, SDI 3G/HD 및 4K 미지원 구분. HDMI·SDI 동시 출력 조건은 텍스트로 표시. GENLOCK·TC는 `Not available`이라 그리지 않음 |

두 제품만 `signalFlow`를 추가했다. 나머지 카메라 6종, 기존 `srg-x40uh` Port Map, 모든 카메라 `io`·사양·keyFacts·사진은 그대로다. [BRC 화면](W-20261004-032-screens/brc-am7-flow-1280.png) · [SRG-A40 화면](W-20261004-032-screens/srg-a40-flow-390.png).

시안 `prototype/brc-am7/content.json`도 명세대로 같은 BRC 흐름과 PDF 판정을 반영했다. 시안의 오래된 `io`는 검증 등급 필드가 없어서 흐름 검증이 거부됐으므로, **흐름이 참조하는 단자 행만** 공개 상세의 `VERIFIED` 등급을 옮겼다. 단자 이름·값·방향은 그대로다. 시안의 PDF 미러 상대 경로는 실제 공개 `beta/site/docs/`를 가리키도록 한 줄 수정하고, 공개 상세 빌드에서는 기존 `../docs/`로 변환되게 했다. [시안 1280px](W-20261004-032-screens/prototype-brc-flow-1280.png) · [390px](W-20261004-032-screens/prototype-brc-flow-390.png)에서 흐름과 PDF 563쪽 로딩을 확인했다.

## 문서 연결

| 제품 | 게시 PDF 판정 |
|---|---|
| BRC-AM7 | 기존 HelpGuide 링크·`print.pdf` 행을 유지하고 해당 URL을 새 미러에 연결. 563쪽 |
| SRG-A40 | 제조사 한국어 공용 설명서 `SRG-A40/SRG-A12` 연결. 기존 영어 문서는 별도 행 보존. 114쪽 |
| SRG-X40UH | 제조사 한국어 공용 설명서 `SRG-X40UH/SRG-H40UH` 연결. 기존 영어 문서는 별도 행 보존. 58쪽 |
| RM-IP500 | 제조사 한국어 설명서 연결. 기존 영어 문서는 별도 행 보존. 87쪽 |
| RM-IP10 | 기존 공식 영어 설명서 미러 재사용. 한국어본 확인되지 않아 영어임을 명시. 84쪽 |
| CL01 | 기존 AVer 공식 설명서 미러 재사용 |
| TR315·TR335 | 같은 공식 AVer 공용 설명서 URL과 기존 미러 **1개**를 공유 |

새 미러 4건의 전체 URL·SHA-256·바이트·취득 시각은 [`manifest.json`](../../beta/site/docs/manifest.json)에 있다. Sony 3건의 전체 URL은 제조사 지원 페이지에서 확인했으며, 명세에 축약된 `...`를 추측해 채우지 않았다. 매뉴얼 표지·본문에서 적용 모델과 언어를 확인했다. 기존 Sony 영어 자료의 유효한 링크는 보존하고 한국어판 미확인 메모만 정리했다.

`manifest.mirrors` **111→115**, `uploads` **107 그대로**. `verify-pages`의 PDF 107은 업로드 항목 수이지 새 미러 파일 수가 아니다. 카메라 8종의 PDF 버튼에서 실제 팝업을 열고 내려받은 바이트를 미러 SHA와 대조했다. 8종 × 1280px·390px 화면과 PDF 보기 캡처는 [화면 기록](W-20261004-032-screens/)에 있다.

PDF 본문 결함·지원 자료의 출처·변경 범위는 [PDF 뷰어 범위 보완](W-20261004-032-PDF-뷰어-범위보완.md)에 별도로 기록했다.
