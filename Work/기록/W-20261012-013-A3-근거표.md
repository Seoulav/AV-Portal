# W-20261012-013 세션 A 3차 — 오디오 계열 보류 행 근거

기준 `origin/main` `12c1e607`. 대상은 오디오 제조사만이다. 영상·기타 제조사와 세션 C의 제품은 바꾸지 않았다. `node beta/build-builder-library.mjs --report`의 착수 수치는 305제품·I/O 1573행·단자 2836개·확인 필요 119행이며, 오디오 계열은 Powersoft 29·Crown 1·Shure 1이다. BSS·Yamaha 확인 필요 행은 0개다.

| 제품 | I/O 행 | 공식 근거 | 확정한 물리 수량 |
|---|---|---|---|
| Duecanali 804/1604 DSP·DSP+D 4종 | 각 GPI/REMOTE와 ALARM 2행 | [Powersoft Duecanali + Quattrocanali User Guide](https://www.powersoft.com/wp-content/uploads/user_guide/PS_duecanaliquattrocanali_UG.pdf) 6–7쪽 후면 명칭·커넥터 표. 두 기능은 별도 Phoenix 단자대다. | 각 행 `1` |
| Quattrocanali 1204/2404/4804 DSP·DSP+D 6종 | 각 GPI/REMOTE와 ALARM 2행 | 같은 공식 가이드 6–7쪽. GPI/REMOTE와 GPO/Alarm의 별도 후면 블록을 확인했다. 블록 안의 접점 수가 아니라 Builder에서 연결할 **물리 블록 수**를 적었다. | 각 행 `1` |

총 **28행**의 `quantity`만 바꿨다. 그 밖의 I/O 방향·커넥터·신호·사양·Port Map·사진은 유지했다. Mezzo 322 AD의 `io[7]`에는 기존 `2채널` 표기가 있고, Builder의 `io[0]` 전용 변환이 이미 밸런스 단자대와 스테레오 미니잭 **각 1개**를 생성한다. `io[7]`까지 수량 `1`로 바꾸면 실물 미니잭이 두 개로 중복된다. 그래서 원문을 유지하고 `mezzo-322-ad#7`에 `already-represented` 어휘 규칙을 넣었다. 전용 검사는 미니잭이 정확히 한 개만 생성됨을 확인한다.

Powersoft의 남은 1행은 위 중복 미니잭을 `already-represented`로 표시해 해결했다. 단자 수는 중복 생성하지 않았다. 남은 전체 90행은 다른 제조사 88행과 Crown·Shure 각 1행이다.

DS-8S 실물 Rear 사진은 [VS ENT 공식 DS-8S 제품 페이지](http://www.vsent.co.kr/bbs/board.php?bo_table=c4&wr_id=14)와 공식 호스트 검색을 다시 확인했지만 찾지 못했다. 기존 근거표에서 제품 페이지의 280×280 사진은 Front로 판정됐다. 사용자에게 실물 Rear 파일이 아직 전달되지 않았으므로 기존 매뉴얼 `Diagram`을 그대로 둔다. 사진에 인쇄됐다는 DC 24V/1.5A를 새 사실로 입력하지 않았다.
