## 화면 구성

RTCOM 상세에서 `#products/<id>` 원본 화면을 동일 출처 iframe으로 삽입한다. 원본 배너·탐색만 iframe 문서에서 숨기고 원본 제품 제목과 01~06 본문, 다이어그램, 메인프레임, 카드 상세 동작을 유지한다. 원본 렌더가 비동기로 끝난 후 제품 본문 높이를 관찰한다. iframe 접근 불가·제품 화면 부재 시 iframe을 제거하고 기존 포털 카드만 표시한다. 구성기 저장소는 변경하지 않았다.

포털 고유 사진 Port Map, 관련 제품, 문서, 자료 출처·검증 기록은 계속 노출한다. 포털의 중복 01·03·04·05와 보조 데이터 카드는 **「포털 데이터 표 펼치기」**에 접어 두되 제거하지 않는다. 기존 원본 제품정보 링크도 유지한다. 이 방식은 원본 화면을 우선 보여 주면서, 원본에 없는 포털 I/O 세부 표와 보조 데이터의 접근을 보존한다.
