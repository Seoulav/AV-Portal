# W-20260926-012 — Epson 15개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-011 완료 후 다음 최소 브랜드인 Epson(15개 프로젝터)을 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다. AGENTS.md의 링크 우선순위 규칙에 따라 제조사 공식 한글 사이트(epson.co.kr)를 1순위로 사용했다(15개 전부 이미 이 사이트).

## 카탈로그 링크 불일치 발견

15개 중 6개(EB-L690U, EB-PQ2216B, EB-PQ2213B, EB-PU2216B, EB-PU2213B, EB-PU1008B)의 카탈로그 official_links가 실제로는 사양표가 없는 지원/다운로드 페이지(`/s/SPT_...`)이거나 완전히 404였다(EB-PU1008B는 카탈로그 링크와 `/EB-PU1008B` 단축 URL 둘 다 실패). 에이전트가 사이트 검색으로 실제 사양이 있는 제품 페이지(`/p/V11H.../`)를 찾아 대체 사용했고, 각 제품의 issues에 어떤 URL로 대체했는지 기록했다.

## 모델명 표기 차이

카탈로그의 "EB-PU2010W/B"는 공식 페이지·사양서 어디에서도 그 표기 그대로 등장하지 않았고, 일관되게 "EB-PU2010B"로만 표기되어 있었다(색상 변형 표기로 추정). 카탈로그 표기를 임의로 고치지 않고, 확인된 공식 모델명(EB-PU2010B)으로 사양을 수집한 뒤 이슈로 차이를 기록했다.

## 이미지 재사용 확인

같은 물리적 섀시를 쓰는 형제 모델들의 공식 이미지가 동일했다(PQ2220B/2216B/2213B 3개가 690×460 동일 사진, PU2216B/2213B 2개가 동일 사진, L790SU/L690U/L790U 3개가 960×640 동일 사진, L895E/L895U 2개가 동일 사진, PU2010B/PU1008B 2개가 동일 사진). 에이전트가 각 사진을 시각적으로 대조해 실제로 같은 챠시임을 확인한 정상적인 제조사 자산 재사용으로 판단했다. 각 슬러그에는 고유 파일명을 부여해(동일 바이트 내용, 다른 파일명) `verify-pages.mjs`의 파일명 전역 유일성 요구를 만족시켰다.

## 코드 변경

- `beta/group1-images.mjs`: 15개 슬러그 신규 항목(group1Images, cardImages) 추가.
- `beta/site/catalog.json`: 15개 항목에 slug·card_image 필드 추가.
- `beta/site/detail/data/*.json`: 15개 신규 파일.
- `beta/manufacturer-hosts.mjs`: 변경 없음(기존 `epson.co.kr`, `goepson.com` 허용 규칙이 `mediaserver.goepson.com`을 포함해 커버).

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 138 details, 160 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다.
