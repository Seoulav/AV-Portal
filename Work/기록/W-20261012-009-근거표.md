## 단자 ↔ I/O 대응

TR315·TR335는 [각 모델 데이터시트](https://www.averusa.com/pro-av/downloads/datasheet-brochure/tr315-datasheet.pdf)와 [TR335 데이터시트](https://www.averusa.com/pro-av/downloads/datasheet-brochure/tr335-datasheet.pdf)의 후면 도면·인터페이스 표를 사진과 대조했다. 기존 `io[0]`의 네 영상 매체와 `io[2]`의 제어 단자를 물리 소켓별로 보여 준다. 사진에 보이지만 I/O에 없었던 `AUDIO IN`과 `DC 12V`만 각 모델 `io[4]`·`io[5]`로 보강했다. 기존 영상·제어 행과 Signal Flow의 evidence 인덱스는 그대로다.

| 번호 | TR315·TR335 (공통 사진, 새 사진 픽셀 기준) | I/O 근거 |
|---:|---|---|
| 1 | LAN/PoE+ | `io[0]` IP 출력 · `io[2]` 네트워크 제어 · `io[3]` PoE+ |
| 2 | RS-232 | `io[2]` |
| 3 | RS-422 | `io[2]` |
| 4 | USB 3.0 출력 | `io[0]` USB · `io[1]` UVC |
| 5 | 오디오 입력 | 새 `io[4]`, 데이터시트 MIC/LINE 입력 |
| 6 | HDMI 출력 | `io[0]` |
| 7 | 3G-SDI 출력 | `io[0]` |
| 8 | DC 12V 입력 | 새 `io[5]`, 데이터시트 전원 입력 |

CL01은 기존 `cl01-rear.webp`를 그대로 썼다. [공식 데이터시트](https://www.averusa.com/pro-av/downloads/datasheet-brochure/cl01-datasheet.pdf)의 후면 그림과 실사진에 Micro USB, RS-422, RS-232, LAN, DC 12V가 왼쪽부터 보인다. 번호 1~5를 그 순서대로 배치했다. 기존 `io[0]`은 RS-485만 적혀 있었지만 사진에는 `RS422`가 인쇄돼 있고 데이터시트는 RS-485/RS-422를 함께 명시한다. 그래서 이 한 행의 connector·condition만 출처 `D` 범위에서 보강했다. 다른 CL01 I/O는 변경하지 않았다.

## 위치·화면 판정

`portmap-audit` 3종 렌더를 직접 봤다. TR315/TR335의 `SHARED_WITH`는 제조사가 양쪽 모델에 동일한 사진을 제공하고 좌표를 각각 같은 픽셀에서 잰 결과다. 나머지 lint 신호 0건. TR 8개와 CL01 5개의 괄호가 실제 단자 테두리를 덮고, 이웃 단자나 지시선을 관통하지 않는다. 1280px·390px 실화면에서 지도 수 8/8/5, JS 오류 0, 문서 전체 가로 넘침 0. 모바일은 사진 영역의 기존 좌우 스크롤로 나머지 단자를 볼 수 있다.
