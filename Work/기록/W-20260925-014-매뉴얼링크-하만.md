## 배경

`AGENTS.md` 우선순위: 하만 계열은 1순위 테크데이타피에스(techdata-ps.com, 국내 공식 총판), 2순위 제조사.

## 접근 가능 여부 확인

- **테크데이타피에스**: 최초 `curl`은 JS 쿠키 챌린지(CUPID) 때문에 안 열렸으나, Playwright로 실제 브라우저 렌더링하니 정상 로드됨(캡차 아님, 자동 통과되는 봇 방지 스크립트).
- **제조사 직접 사이트**(crownaudio.com, jblpro.com, bssaudio.com, amx.com): 실제 브라우저로 열어도 전부 403 Forbidden. 이 세션 네트워크에서 차단된 것으로 판단, 우회하지 않음.
- 사용자가 직접 모바일에서 techdata-ps.com의 개별 제품 페이지(예: BSS BLU-101)를 열어 "메뉴얼/시방서/도면/브로슈어/사양서/기술문서" 탭 구조를 스크린샷으로 보여줘서, 이 세션이 처음에 확인 못 했던 실제 매뉴얼 다운로드 구조(개별 제품 페이지의 "메뉴얼" 탭)를 찾을 수 있었다.

## 방식

1. techdata-ps.com의 브랜드별 카테고리(Crown/JBL/BSS/AMX)를 순회하며 각 카탈로그 제품의 techdata 내부 idx를 찾음.
2. 각 제품 페이지에서 "메뉴얼" 탭을 클릭하면 `board/download.php?...file_name=...&o_file_name=...` 형태의 실제 다운로드 URL로 이동/다운로드가 시작됨 — 이 URL을 `manual_link`로 채택.
3. 브라우저의 `download` 이벤트로 실제 URL을 캡처(페이지 이동이 파일 다운로드로 처리되어 `page.url()`만으로는 불안정한 경우가 있어 보강).
4. URL 끝의 `&ckattempt=N`(이 세션이 반복 접근하며 생긴 봇 방지 챌린지 시도 횟수, 세션마다 달라짐)은 제거하고 저장 — 실제 콘텐츠 식별에는 `file_name`·`o_file_name`만 쓰인다.
5. `manufacturer-hosts.mjs`에 AMX·BSS Audio·Crown·JBL을 모두 `techdata-ps.com`으로 추가.
