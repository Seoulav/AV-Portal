## 지도 실측과 자료 경계

Duecanali·Quattrocanali 지도는 제품별 2060×210 공식 도면 또는 967×95·968×96 공식 후면 파일을 기준으로 쟀다. Mezzo는 해당 모델의 약 490×95 후면 파일을 각각 기준으로 쟀다. 18종 모두 번호는 1부터 연속이다. 4채널 Mezzo의 아날로그 입력 단자대는 실제 사진의 두 블록에 맞춰 `3–4`와 `1–2`로 나눴다. Mezzo 네트워크 번호가 아래 GPIO 단자대를 가리키던 초기 렌더 오류는 RJ45 블록으로 바로잡고, GPIO 번호는 아래 단자대에 배치했다.

렌더 점검은 `portmap-audit`의 시각 판정 기준을 적용했다. 이 Windows 환경에 Python/Pillow 실행기가 없어 `scripts/portmap-audit.py`는 실행하지 못했다. 동일한 상세 렌더러를 로컬 Chromium에서 열어 18종 1280px 지도를 생성했고, 단자 배열별 대표 화면을 눈으로 비교했다. 대표 화면은 [Duecanali 일반 DSP 1280](W-20261013-001-캡처/duecanali-804-dsp-1280.png)·[390](W-20261013-001-캡처/duecanali-804-dsp-390.png), [Quattrocanali DSP+D 1280](W-20261013-001-캡처/quattrocanali-2404-dspd-1280.png)·[390](W-20261013-001-캡처/quattrocanali-2404-dspd-390.png), [Mezzo AD 1280](W-20261013-001-캡처/mezzo-604-ad-1280.png)·[390](W-20261013-001-캡처/mezzo-604-ad-390.png)에 보존했다. 390px 사진은 가로 스크롤로 전체 번호를 확인하며, 번호·단자 이름 카드가 보인다.

## I/O·Builder 결과와 보류

기존 B2 수량 보강 행은 유지했다. 공식 매뉴얼로 확인한 Due/Quattro의 제어 Ethernet·GPI/REMOTE·ALARM·보조 아날로그 입력과 Mezzo의 GPIO를 보강했다. 322 AD에는 원본 자료에 있는 비밸런스 입력·라인 출력을 추가했다. B2 전후 검사와 이번 18종 선택적 되감기 검사에서 승인 필드 외 모델명·사양 등의 변이가 노출되는지 확인했다.

`node beta/build-builder-library.mjs --report` 결과는 착수 기준 **303제품·I/O 1462행·단자 2632개·확인 필요 88행**에서 **303제품·I/O 1512행·단자 2676개·확인 필요 117행**으로 바뀌었다. 새 확인 필요 29행은 Powersoft의 GPI/ALARM/GPIO 등 수량 미기재 행이다. 도면의 단자대 외형으로 제어 접점 수나 Builder 결선 수를 단정하지 않아 수량을 비워 두었다. 이는 Builder 전환의 남은 근거 확인 사항이다.

명세 현황표의 Mezzo 322 AD `Rear 있음` 전제는 실제 기준 main에서 **Rear 없음**이었다. 해당 모델의 공식 제품 페이지 후면을 확보해 추가했으며, 명세 정정 자체는 Work가 맡는다.
