- 원본: `beta/site/manuals/samsung-hoteltv-hu8000f-hu7000f-manual-ko.pdf` (SHA-256 `B61EA1BE4F423FB59C7912B79C2C9076FD8B9FD9D9CE188BB1525DB056BEC1EE`). 12쪽에서 U800F와 U700F를 별도로 그리며, U800F 그림에는 HP-ID·HEADPHONE·SERVICE가 없다.
- 6종 Diagram 파일은 같은 도면 이미지이며 각각 SHA-256 `AF8C14CBB0C14BF888C135D153CF9FAC500BC2FDCD9ECA45740527BE7C4F014B`. 매뉴얼 1쪽의 여섯 크기 모델에 공통 적용되는 U800F 도면을 크기 변형 전체에 사용했다. 실제 각 패널의 고유 후면 사진이라고 주장하지 않는다.
- 표식은 USB 1–2, HDMI 입력 1–3, LAN 입력, LAN 출력, 안테나 입력 1–2, DATA, EX-LINK, 옵티컬 출력, VOL-CTRL, VARIABLE AUDIO OUT 순이다. 기존 I/O의 무선 연결 2행은 물리 단자가 아니어서 표시하지 않았다. 기존 RJ12 행도 도면의 어느 단자인지 확정할 수 없어 새 표식을 만들지 않았다.
- 묶음 라벨은 범위 마커와 en dash를 썼다. 번호·지시선은 단자 몸체를 가리키고 사진의 단자와 겹치지 않음을 [좌표 점검 이미지](W-20261013-007-C-captures/u800f-audit.png)에서 눈으로 확인했다. 대표 HG55의 [1280px](W-20261013-007-C-captures/u800f-map-1280.png)·[390px](W-20261013-007-C-captures/u800f-map-390-left.png) 캡처에서 지도 10개와 화면 넘침이 없음을 확인했다.

## BEHHL 6종 — Port Map 보류

| 모델 | 보류 사유 |
|---|---|
| LH43BEHHLBFXKR | 설치가이드 단순 그림은 HDMI 2개, 국내 스펙은 HDMI 3개. 정확 모델의 후면 도면·사진을 확보하지 못함 |
| LH50BEHHLBFXKR | 동일 |
| LH55BEHHLBFXKR | 동일 |
| LH65BEHHLBFXKR | 동일 |
| LH75BEHHLBFXKR | 동일 |
| LH85BEHHLBFXKR | 동일 |

- 설치가이드: `beta/site/manuals/samsung-behx-h-installation-guide-ko.pdf` 1쪽. 그림은 USB 1·HDMI 2·LAN 1·안테나 1개만 나타낸 간략도다. 한국 삼성 비즈니스 제품 사양의 HDMI 3개와 충돌한다. 이 그림을 6종의 물리 좌표 근거로 사용할 수 없다.
- 글로벌 공식 추가 조사: [삼성 홍콩 BEHX-H](https://www.samsung.com/hk_en/business/smart-signage/uhd-4k-signage/behx-h-lh43behhvgjxxk/)와 [삼성 독일 BEHX-H](https://www.samsung.com/de/business/smart-signage/uhd-4k-signage/behx-h-lh65behhlguxen/) 페이지는 HDMI 3개 사양을 표시한다. 그러나 모델 접미사가 국내 `BFXKR`와 다르고 정확 모델의 후면 도면·사진이 없어서 국내 후면 좌표를 확인하지 못했다. 글로벌 페이지의 값으로 국내 제품 JSON을 변경하지 않았다.
- 후속 입력: `BFXKR` 실물의 뒷면을 모델명·단자가 판독되는 파일 사진으로 받거나, 삼성 공식 정확 모델 후면 자료를 확보한 뒤 다시 대조한다. 여섯 제품 JSON은 이번 PR에서 그대로 둔다.
