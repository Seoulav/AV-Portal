# W-20261004-032 — Work 인계

## 완료 범위

- BRC-AM7·SRG-A40 두 종에만 03 SIGNAL FLOW를 게시. BRC는 SDI OUT1(12G/6G/3G/HD)과 OUT2(3G/HD)를 나누고 GENLOCK IN·TC IN·옵션 OPTICAL을 근거에 맞춰 표현. SRG-A40에는 없는 Genlock·TC를 그리지 않고 SDI 4K 미지원 및 HDMI·SDI 동시 출력 조건을 글로 표시했다.
- 카메라 8종의 공식 PDF `보기`·`내려받기` 연결. Sony 한국어 PDF 신규 미러 4건을 `beta/site/docs/`와 `manifest.mirrors`에 등록하고 기존 RM-IP10·AVer 미러는 재사용했다. AVer TR315/TR335는 같은 URL·파일을 공유한다. 기존 영문 문서 행과 BRC 웹 HelpGuide 링크는 보존했다.
- 명세가 지목한 BRC 시안 파일도 공개 상세와 맞췄다. 시안의 미러 상대 경로를 게시 위치로 고쳤으며, 기존 단자 **값은 바꾸지 않았다**.
- Sony 3종의 PDF 팝업에서 한글 본문이 누락되던 기존 결함을 해결했다. 사용자 직접 응답 “이번에 최소 수정 포함”과 임시 기획·리뷰 담당자의 제한된 판단에 따라 PDF.js 4.10.38 공식 CMap·표준 글꼴 자산과 로딩 옵션만 추가했다. 상세 카드 렌더러·PDF 원본·비밀번호 정책은 그대로다. 판단과 변경 파일은 [범위 보완](W-20261004-032-PDF-뷰어-범위보완.md)에 분리 기록했다.

- 최종 `npm.cmd test` **346 tests / 345 pass / 0 fail / 기존 skip 1**. 앞선 두 번에는 기존 RTCOM 임시 디렉터리 `rename EPERM`이 재현됐으나 마지막 전체 재실행에서는 통과했다. 실패를 감추려고 기대값이나 skip을 바꾸지 않았고 `TEMP`를 작업 폴더로 지정해도 EPERM이 간헐 재현될 수 있음을 확인했다.
- 기존 작업 테스트는 당시 제품·미러 전체 해시를 보존한다. W032 시작점의 카메라 5개 JSON 바이트를 `tests/fixtures/w032-before/`에 고정하고, 과거 테스트에서만 이를 재생한다. 이번 변경 검사는 현재 JSON을 그대로 읽는다.
- PR 파일 수가 큰 이유는 PDF.js 4.10.38의 CMap·표준 글꼴 **185개 개별 자산**, 공식 PDF **4개**, 요청된 전후 화면 **52개**, 과거 기준을 보존하는 테스트 파일 **24개와 기준 JSON 5개** 때문이다. 역사 검사에서는 기대 해시·skip을 고치지 않았고, W032 전용 검사는 현재 데이터를 직접 검증한다. Git 제외 조사 사본·비밀번호·영업 원본은 포함하지 않는다.

## 다음 기획 입력·제한

- Sony `RM-IP10`은 공식 영어 설명서만 확인됐다. AVer CL01·TR315·TR335는 기존 공식 미러가 이미 있었으므로 새 파일을 만들지 않았다. 명세의 예상 “신규 7건”은 실제 신규 **4건**으로 정정해 해석해야 한다.
- 사용자 지시에 따라 나머지 카메라 6종의 SIGNAL FLOW는 그리지 않았다. 필요한지 여부는 화면 결과를 본 사용자가 따로 판단한다.
- PDF 본문 누락은 기존 모든 한글 자료의 공통 장애가 아니었다. 이번에 확인한 기존 삼성 한글 2건은 수정 전에도 표시됐다. 같은 PDF.js 자산은 모든 문서에서 사용할 수 있으므로 이후 자산 버전 변경 시 본문·잠금 회귀가 필요하다.
- Sony 원본 PDF는 제조사 공개 주소에서 받아 무결성을 검증했다. 로컬 조사 사본과 npm tarball은 Git 제외 `outputs/coordination/`에만 있고 게시 파일·지원 자산 외에는 커밋하지 않는다.
