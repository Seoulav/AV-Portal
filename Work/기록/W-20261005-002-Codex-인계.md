## ★ 핵심은 한 군데입니다

삼성은 묶음 이름을 **코드에 박아** 뒀습니다. **알티컴은 그러면 안 됩니다.**

이름이 `rtcom/raw/index.json`에 있고 그 파일은 **매일 자동 동기화**됩니다. 베껴 넣으면 원본이 이름을 바꿨을 때 우리만 옛 이름을 들고 있게 됩니다.

> **지켜야 할 것은 하나입니다 — 「이름을 코드에 박지 않는다」.**

`seriesGroupsFor(brand, items)`가 **이미 `items`를 받으니**, `adaptRtcomCatalog`가 **지금 버리는 `group`을 항목에 실어 주면** 됩니다.

## ★ 제가 권하는 방법과, 아닐 수도 있는 이유

`seriesIdFor`가 이미 `item.brandSort?.group`을 봅니다. 같은 모양으로 실으면 고칠 곳이 줄어듭니다.

```js
brandSort: { group: product.group, order: <1~5>, size: <index.products 안 자리> }
```

기존 정렬이 **묶음 순서 → `size` 오름차순**으로 풀려 **원본 순서가 그대로** 나옵니다.

**다만 솔직히 적습니다.** 삼성에서 `size`는 **인치**인데 여기서는 **원본 자리**입니다. 숫자 비교에만 쓰여 동작은 맞지만 **이름이 어긋납니다.**
