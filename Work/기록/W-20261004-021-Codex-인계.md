## 문제는 두 줄입니다

`pdf-viewer.mjs:224` — 창이 열리는 순간 `download.href = file`이 걸립니다. `task.onPassword`는 **그 뒤**(`:243`)입니다.

`app.js:152` — 상세 카드의 `↓ 내려받기`는 **창을 열지도 않고** 파일로 바로 갑니다.

## 어떻게 — 비밀번호를 저장소에 안 적고

**PDF.js가 이미 판정기입니다.** `onPassword`가 맞는지 틀린지 알려 줍니다. **우리가 비밀번호를 알 필요가 없습니다.**

```
보기 → 비밀번호 → 열림 → 그제야 내려받기가 살아남
```

1. 창이 열릴 때 **내려받기를 꺼 둡니다**
2. `task.promise`가 **풀린 뒤에만** `download.href`를 겁니다
3. 상세 카드의 `↓`는 **잠긴 자료면 창을 엽니다**

**비밀번호 문자열은 어디에도 안 적습니다.** 저장소는 공개입니다.

**12건.** `uploads` **103건은 그대로**입니다.
