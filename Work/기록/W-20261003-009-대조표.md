# W-20261003-009 Crown 자료·조건 대조

## PDF 적용 모델과 게시

사용자 제공 로컬 PDF 11사본을 SHA-256으로 묶으면 고유 5개다. 같은 파일을 제품별로 복제하지 않고 `beta/site/manuals/`에 한 번씩 게시했다. `manifest.json`에는 11개 제품 연결을 추가했다. 각 파일의 전체 SHA·바이트 수·연결 제품은 [근거 JSON](W-20261003-009-evidence.json)에 있다.

| 게시 파일 | 앞 12자 | 적용 모델 확인 | 연결 |
|---|---|---|---:|
| `crown-dci-network-series-manual-ko.pdf` | `7795eb2db600` | 표지 1쪽 DCi N 대상 4종 명시 | 4 |
| `crown-comtech-d-series-operation-manual.pdf` | `ed862bcd6c65` | 표지 1쪽 CTD-2125·4125·8125 | 3 |
| `crown-comtech-d-2125-data-sheet.pdf` | `755ed5fd5fc4` | 2쪽 CTD-2125 모델 열 | 1 |

두 ComTech 사양서는 **서로 다른 SHA-256**이지만 2쪽 텍스트 표는 같고 두 파일 모두 2125·4125·8125를 명시한다. “2125 전용”과 “4125·8125 전용”이라는 Work 표현은 문서 내용 기준으로 엄밀하지 않다. 제공 폴더별 파일 구분과 요청된 연결 대상은 유지했다. PDF.js `보기`의 캔버스 렌더링과 `↓ 내려받기`를 5개 파일 모두 실제 클릭해 확인했다([결과](W-20261003-009-screens/document-check.json)). 사진·기존 PDF의 바이트는 변경하지 않았다.

## 기존 `io`·사양 대조와 `condition`

DCi N 매뉴얼 6~8·52~53쪽을 기존 4종 `io`·사양과 대조했다. BLU link는 Dante가 아니며 Ethernet/HiQnet은 제어·모니터링용이다. 입력은 밸런스 6핀, 출력은 10 AWG까지 허용하며, 15A IEC 전원은 해당 2·4채널 모델에 적용된다. 출력 W 사양 값은 일치했지만 독립 리뷰에서 I/O 불일치가 발견됐다. 네 제품 모두 아날로그 입력이 누락돼 있었고, BLU link·Ethernet의 커넥터가 “규격 정보 없음”이었다. 두 300N 제품은 GPIO와 AUX를 RJ-11 한 행으로 합쳤고, 두 600N 제품은 두 행 자체가 없었다. 매뉴얼 6쪽과 각 Rear 사진에 맞춰 아날로그 입력·별도 GPIO(RJ-11)·AUX(3핀), BLU link IN/OUT용 RJ45 두 개, Ethernet RJ45를 4종에 정리했다. 새 `M1` 출처는 게시한 한글 매뉴얼의 파일명·SHA·쪽수를 기록한다. 출력·전원 기존 행은 그대로다. `dci-2-300n` 디지털 오디오 I/O 조건에 섞인 “요청서상 N=Dante 가정” 메모와 다른 3종의 “이슈 참고” 메모는 제거하고 기존 `issues`가 판단과 정정 이력을 보존하는지 확인했다.

Crown **사양** `condition`은 214→127행이다. `정격출력, 20Hz-20kHz`, `8Ω, 20Hz-20kHz`, `20Hz-100Hz` 같은 측정 조건은 유지했다. 인치·파운드 병기와 전원 주파수·허용 오차는 원문 수치가 사라지지 않도록 공개 `value`의 괄호로 이동했다. `공식 후면 사진 판독`은 출처 메모여서 `condition`에서 제거했고 기존 행의 `source`와 [변경 전 근거](W-20261003-009-evidence.json)를 보존했다. 사양 행 수·이름·그룹·출처·검증 등급은 불변이며, 변경 가능한 값 이동을 전용 검사로 대조한다.

명세는 Crown 26종 `keyFacts` 0개라고 했으나 착수 시점 main의 `dci-4-600da`에는 **4개가 이미 있었다**. 기존 공개 데이터이므로 수정하지 않았다. 나머지 25종은 0개 그대로다. 기존 Port Map 22종도 변경하지 않았다. 새 지도 4종으로 Crown은 26/26이다.

사진 공유에 따른 후속 점검: 600N이 300N과 같은 Rear WebP를 사용하므로 사진에 인쇄된 AC 소비전력도 2채널 375W·4채널 650W로 같다. 이번 배치는 기존 사진을 그대로 쓰도록 지정돼 있어 바꾸지 않았다. 이 표기가 600N의 실제 표기와 맞는지는 모델별 사진 확보 때 별도 확인이 필요하다. 지도 설명에는 그 인쇄 소비전력 값을 사용하지 않았다.
