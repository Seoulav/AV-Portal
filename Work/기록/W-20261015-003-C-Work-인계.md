# W-20261015-003 · HDF-CCF 허브 USB-PD 입력 정정

## 사용자 지시와 변경

사용자 원문: “USB-C허브는 USB-PD전원 공급받아서 입력 노트북을 충전하는거 이 부분을 그렇게 해석해서 수정해”.

시나리오 2의 허브 위에 외부 USB-PD 전원과 허브로 내려가는 주황색 화살표를 추가했다. 전원 경로는 **외부 USB-PD 전원 → 허브 → HDF-CCF → 노트북 충전**으로 표시했다. 영상·USB의 SOURCE → DISPLAY 방향, PD의 DISPLAY → SOURCE 방향, 직결 시나리오와 기존 PD 출력 수치 충돌 표기는 유지했다. 허브·전원 공급기는 제품 포함품으로 표기하지 않았다.

- 로컬 화면 1280px·390px: 허브 입력 화살표·텍스트 눈 확인, 브라우저 오류·문서 가로 넘침 없음.
- 전체 직렬 검사 712건(711 pass, 0 fail, 기존 skip 1). 검색 인덱스 검사 및 Pages 검증 통과.

- 후속: PR CI, 최신 main 통합, 병합과 Pages 공개 확인. 병합 결과는 PR 상태가 기준.
