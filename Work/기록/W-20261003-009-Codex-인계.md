| 조건 | 내용 |
|---|---|

## 조건 정리 — AMX와 다르게 하세요 ★

Crown의 `condition` 214행은 **대부분 진짜 측정 조건**입니다. AMX처럼 20행까지 줄이면 **안 됩니다.**

| 유지 ✅ | 제거 ❌ |
|---|---|
| `정격출력, 20Hz-20kHz` (23) | `공식 후면 사진 판독` (12) → 출처 메모 |
| `8Ω, 20Hz-20kHz` (22) | `19" x 3.5" x 14.25"` (10) → 인치 환산 |
| `20Hz-100Hz` (22) | `20.1 lbs` (8) → 파운드 환산 |
| `정격출력 이하, 20Hz-1kHz` (12) | `3.5" 높이` (6) |
| `8Ω 정격출력 기준` (11) | `19" x 3.5" x 12.25"` (6) |

**앰프에서 `8Ω, 20Hz-20kHz`를 지우면 THD·주파수 응답 수치가 무의미해집니다.** 삼성 디스플레이와 성격이 다릅니다.

**목표: 214 → 150 이하.**

추가로 `dci-2-300n`의 `디지털 오디오 전송` 행 조건이 `요청서상 'N=Dante' 가정과 다름, 이슈 참고`입니다. **`issues`로 옮기세요.** `condition`은 이슈 기록 칸이 아닙니다.
