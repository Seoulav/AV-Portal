# W-20261012-013 세션 A 단자 대조

기준은 `origin/main` `53c7e74`의 Builder 보고서다. 세션 A 소유 30종의 확인 필요 행은 40개였고, 이번 변경으로 25개가 남는다. 전체 보고서는 303제품·I/O 1,459행·단자 생성 행 1,111→1,126·확인 필요 225→210이다. 전체 단자 수는 2,302→2,329개다. 단자 0 제품은 전후 5종이며 이 범위의 제품이 아니다.

## 근거가 확인되어 생성한 행

| 제품·I/O 행 | 처리 | 적용 근거 |
|---|---|---|
| EB-PU2010W-B #4·#5 | BNC SDI 입력·출력 각각 1 | [Epson EB-PU2010 시리즈 공식 인터페이스 사양](https://files.support.epson.com/pdf/specs/specifications_ebpu2010series_en_r102.pdf): 모델 적용 목록과 SDI In/Out |
| EB-PU2213B·EB-PU2216B #4·#5 | 각 모델 BNC SDI 입력·출력 각각 1 | [Epson EB-PU2220 시리즈 공식 인터페이스 사양](https://files.support.epson.com/pdf/specs/specifications_ebpu2220series_en_r100.pdf): 두 모델 적용 목록과 SDI In/Out |
| MX392/C #1·#2 | 스크류 터미널 LED IN 1, SWITCH OUT 1을 GPIO 입·출력으로 분리 | [Shure MX39x 사용자 안내](https://www.shure.com/en-US/docs/guide/MX39x), Logic Connections. 공통 접지는 독립 세 번째 포트로 만들지 않음 |
| PT-MZ882 #6 | AUDIO IN 1·OUT 1, M3 스테레오 미니잭 | Panasonic 한국어 사용설명서 DPQP1564ZA/X1 27쪽, 적용 모델 PT-MZ882/MZ782/MZ682 |
| PT-VMZ51·61·71 #2 | AUDIO IN 2·VARIABLE AUDIO OUT 1, M3 스테레오 미니잭 | Panasonic 한국어 사용설명서 DPQP1388ZD/X1 25쪽, 세 모델 적용 |
| ULXD4Q #0·#2·#3 | BNC 안테나 2, XLR 4채널 출력 4, Dante Primary/Secondary RJ45 2 | [Shure ULX-D Dual and Quad 사용자 안내](https://www.shure.com/en-US/docs/guide/ULXD-DQ)의 Quad Receiver 후면 패널. `quantity`와 출처 조건만 보강 |

Epson·MX392·Panasonic은 공개 I/O 문구가 사실에 맞으므로 제품 JSON을 바꾸지 않고 `IO_OVERRIDES`에서 원문 `connector`·`signal`을 정확히 대조한다. 원문이나 행 순서가 바뀌면 override가 적용되지 않는 기존 stale 검사에 맡긴다. ULXD4Q는 기존 `sources.M`이 가리키는 공식 사용 안내에서 실물 수량을 확인해 공개 I/O의 공백을 채웠다. 그 밖의 사양·사진·지도는 바꾸지 않았다.

## 남은 25행과 보류 이유

| 제품 | 수 | 이유 |
|---|---:|---|
| DS-8S | 5 | 리플렛에는 연동 AC 8·비연동 AC 1의 기능과 수량이 있으나 게시 리플렛 그림은 전면뿐이라 아울렛의 물리 규격을 특정할 수 없다. RS-485 링크·REMOTE·모니터 단자의 물리 수량 또는 형상도 미기재. 전원 연결에 임의 범용 단자를 만들지 않음 |
| MX392/C·MX418D/C | 2 | 팬텀 전원은 마이크 오디오 케이블을 통해 공급되므로 별도 전원 소켓을 만들면 한 물리 단자가 중복됨 |
| PT-MZ11K·PT-MZ14K | 각 4 | 한국어 매뉴얼의 SERIAL/MULTI SYNC·REMOTE 1/2·DC OUT/USB 복합 기능을 Builder의 단일 신호/물리 단자에 근거 없이 단순화할 수 없음 |
| PT-MZ17K | 5 | SERIAL/MULTI SYNC·REMOTE 1/2의 신호/복합 방향 미확정 4행과 원래 `MISSING`인 AC 전원 1행 |
| PT-MZ882 | 3 | SERIAL/MULTI SYNC·REMOTE 1/2 신호 의미 미확정 |
| TR315·TR335 | 각 1 | 영상 4매체 복합 행이 별도 USB·LAN 행과 물리 단자를 공유함. 행을 그대로 쪼개면 동일 소켓 중복 가능 |

`eb-*`의 나머지 행, 다른 `pt-*`, CL01은 이번 보고서에서 확인 필요 0행이다. 위 25행은 근거 없는 포트를 추가해 숫자만 낮추지 않았다. 세션 B 소유 모델은 여기서 수정하지 않았다.

## Builder 화면 표본

로컬 Pages 미리보기에서 실제 생성 라이브러리로 MX392/C의 GPIO In·GPIO Out·마이크 오디오 출력, ULXD4Q의 RF 입력 2·아날로그 출력 4·Dante I/O 2를 확인했다. MX392의 기존 팬텀 전원은 별도 포트가 아니어서 확인 표시로 남고, ULXD4Q의 전원 및 Dante 호환성 확인 표시 역시 이번 범위에서 제거하지 않았다. [MX392/C 화면](W-20261012-013-A-MX392-Builder-local.png) · [ULXD4Q 화면](W-20261012-013-A-ULXD4Q-Builder-local.png). 이 캡처는 배포 전 로컬 화면이며 공개 화면은 병합·배포 후 따로 확인한다.

## 검증 원칙

전용 검사는 생성된 포트의 커넥터·신호·방향·수량을 실제 Builder 라이브러리에서 확인한다. ULXD4Q 역사 역변환은 세 I/O 행의 변경된 `quantity`·`condition`·`source`만 이전 값으로 복원하며, 나머지 현행 필드의 변이는 기존 해시 검사에 그대로 전달한다. 잠긴 PDF 파일은 변경 대상이 아니다.
