# W-20261014-009 Carbonite Ultra 후면 단자 설명 근거

기준: `origin/main` `781ec120`의 `carbonite-ultra.json`과 게시된 **Ultra User Manual v9.2** (`carbonite-ultra-user-manual-v9-2.pdf`, 277쪽, SHA-256 `0527e3d4d02e60e634321ab7072505110510a35d7cc62f97ee1504340e319848`). 쪽 번호는 PDF 본문 인쇄 쪽 번호와 대조했다. 후면 실물 사진은 `carbonite-ultra-rear.png`(1600×800)이다. 제품의 `io`, 사양, 사진, 충돌 상태, Port Map의 번호·라벨·좌표는 변경하지 않는다.

출력 수의 충돌은 기존 `io[1]`·사양의 `CONFLICTED`를 그대로 유지했다. 사진은 MV OUTPUT IO-1·IO-2·1·2와 OUTPUT 3–12를 표시하고, 매뉴얼 175·170쪽은 MV OUT 1–4와 OUT 5–14(전체 14)를 표시하지만 제조사 사양표는 SD/HD 12·UHD 11이다. 단자별 할당과 사진의 하드웨어 판본은 확정하지 않으며, 두 설명의 끝에 이 상충을 짧게 표시했다.

범위 밖에서 발견한 사실: 현재 `io[5]` LTC와 `io[2]` AES의 커넥터는 `HD-BNC`로 기록돼 있지만, 매뉴얼 177–178쪽 도면과 게시 사진에는 3핀 소켓이 보인다. 이번 설명은 해당 커넥터 형상을 단정하지 않았으며 I/O 데이터 정정은 별도 근거 검토가 필요하다. 매뉴얼 167쪽은 DashBoard 또는 프레임 USB를 통한 소프트웨어 업그레이드를 설명하지만 후면 `UPGD` 단자와 동일하다고 명시하지 않는다. `SD` 라벨도 카드 슬롯 용도를 이 도면에서 설명하지 않으므로 추정하지 않았다.
