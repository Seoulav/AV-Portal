# W-20260926-015 — Powersoft 17개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-014(JBL) 완료 후 다음 최소 브랜드인 Powersoft(카탈로그상 18개 중 이미 상세페이지가 있는 Mezzo 322 AD 1개를 제외한 17개)를 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다.

AGENTS.md의 Powersoft/EAW 전용 규칙("시방서·사양서는 다산SR 1순위, 없으면 기존 제조사 자료 사용")에 따라 에이전트에게 다산SR(dasansr.com)을 먼저 확인하도록 지시했다. 에이전트는 다산SR의 모든 경로(robots.txt, sitemap.xml 포함)가 "CUPID" 쿠키 챌린지 기반 봇 차단(캡차)에 걸려 자동 접근이 전혀 불가능함을 확인했다. 에이전트는 이 차단을 우회하려는 시도를 하지 않았고(정책상 올바른 판단), 규칙의 대체 조항에 따라 Powersoft 공식 사이트(powersoft.com)를 1차 출처로 사용했다. 이 접근 제한은 모든 제품의 issues에 명시했다. 다산SR 자료와의 교차 확인은 이번 배치에서 이루어지지 않았으므로, 일반 브라우저 접근이 가능한 담당자의 후속 확인이 필요하다.

## 데이터 완성도

17개 전부 powersoft.com 공식 제품 페이지 + 계열 공용 데이터시트(PDF)로 사양을 확인했다. 채널/구성, 출력(정격, 다양한 부하·전압별), 오디오(게인·SNR·THD·주파수응답 등), DSP(AD/DA 컨버터, 레이턴시, EQ/크로스오버/리미터), 네트워킹(Dante/AES67 유무), 전원(유니버설 스위칭, 대기전력), 냉각, 구조/환경(크기·무게·동작온도), 인증(CE/FCC/CCC/CSA/CB/RoHS/REACH/EPA/UK DoC, DSP+D 모델은 CPR/EN54 추가) 순으로 그룹화했다.

- **모델 패밀리 구조**: Quattrocanali(4채널 1RU 랙), Duecanali(2채널 1RU 랙), Mezzo(2/4채널 하프랙)로 구분되며, 모델명의 "DSP"는 온보드 DSP 내장을, "+D"(Quattrocanali/Duecanali) 또는 "AD"(Mezzo)는 Dante/AES67 네트워킹 추가를 의미함을 확인했다.
- **동작 온도·냉각 팬 사양 미공개**: Mezzo 계열은 동작온도 범위 자체가 공식 자료에 없어 "정보 없음"으로 유지했다. Quattrocanali/Duecanali 랙형은 냉각 방식(팬 사양) 상세가 데이터시트에 없어 마찬가지로 정보 없음 처리했다(강제공랭 추정이 가능하나 임의 기재하지 않음).
- **대기전력 수치 불일치**: Mezzo 602/604 A·AD의 대기전력이 제품페이지 실측 스펙과 시리즈 공용 데이터시트 표 사이에서 서로 다르게 나타나(예: 602 AD 12W vs 17W), 두 수치를 모두 병기하고 이슈로 기록했다.
- **Duecanali 슬루 레이트 표기 이상**: 베이스 Duecanali 데이터시트의 Slew Rate 항목에 임피던스(mΩ) 단위값이 잘못 기재된 것으로 보이는 원본 오기가 발견되어, 임의로 바로잡지 않고 정상 스펙 표에서 제외한 뒤 원본 표기 이상으로 이슈에 남겼다.

## 이미지

Powersoft 공식 사이트 media API(`/api/media/file/...`)에서 각 제품의 "gallery-cardL" 원본(1024×500, 투명 배경 PNG cutout)을 확보했다. 더 큰 해상도 변형은 CDN에 존재하지 않음을 확인했다(리사이즈된 800x391/400x195 변형만 추가로 존재, 원본보다 작음). 투명 여백을 bbox+20px 패딩으로 크롭한 뒤 WebP(cwebp -q 90)로 변환해 최종 511~1007px 폭의 실사용 이미지를 만들었다(기존 Mezzo 322 AD 전례와 동일한 크롭 방식).

- **Mezzo 계열(8개)**: 전면+후면 2장 모두 확보. 단, 324 A/AD는 공식 사이트가 322 A 페이지의 전면 이미지를 그대로 재사용하고 있어 그 사실을 이미지 alt와 issues에 명시했다. 604 A/AD의 후면 이미지도 604 A 페이지의 대표컷을 AD 페이지가 공용으로 쓰는 등, 제조사 사이트 자체의 이미지 재사용/파일명 혼선을 있는 그대로 반영하고 임의로 정정하지 않았다.
- **Quattrocanali/Duecanali 랙형(9개)**: 공식 제품 페이지에 전용 후면 패널 사진이 없고(계열 스택 비교컷만 존재), 전면 1장만 확보했다. "앞뒤 사진 모두 필요"는 원칙을 유지하되, 제조사가 애초에 개별 후면 사진을 공개하지 않은 경우 강제로 대체 이미지를 넣지 않는 기존 방침(Never fabricate)을 그대로 적용했다.

## 코드 변경

- `beta/group1-images.mjs`: 17개 슬러그 신규 항목(group1Images, cardImages) 추가. publicationStatus는 최근 배치들과 동일하게 기본값("사용자 게시 승인 · 제조사 재사용 권리 미확인")을 사용했다(기존 Mezzo 322 AD는 더 이전 조사 시점의 "공식 대리점 구매·계약 기반 사용" 문구를 그대로 유지, 이번 신규 17개와는 문구가 다름 — 소급 통일하지 않음).
- `beta/site/catalog.json`: 17개 항목에 slug·card_image 필드 추가.
- `beta/site/detail/data/*.json`: 17개 신규 파일.
- `beta/manufacturer-hosts.mjs`: 변경 없음(Powersoft 항목에 이미 powersoft.com 등록됨).

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 187 details, 216 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다.
