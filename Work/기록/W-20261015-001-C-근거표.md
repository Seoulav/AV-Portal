# W-20261015-001 — HDF-CCF 근거표

| 항목 | 근거 | 반영 |
|---|---|---|
| 커넥터 방향 | 사용자 제공 HDF-CCF User Manual v1.1, 인쇄 4쪽(PDF 5쪽), Connection Instructions | SOURCE는 노트북, DISPLAY는 모니터 또는 허브 쪽. 방향을 바꿔 꽂지 않도록 안내 |
| 직결 | 같은 매뉴얼 인쇄 5쪽(PDF 6쪽), Application Scenarios 1 | 노트북 → AOC → 모니터, 4-lane DP 1.4 + USB 2.0. 모니터 쪽 PD가 노트북으로 역공급 |
| 허브 연동 | 같은 매뉴얼 인쇄 5쪽(PDF 6쪽), Application Scenarios 2 | 노트북 → AOC → 외부 Type-C 허브/프레젠테이션 스위치 → HDMI 출력 → TV/모니터, 허브의 USB 주변기기. 2-lane DP 1.4 + USB 3.2 10G. 허브 쪽 PD가 노트북으로 역공급 |
| 케이블 길이 | 같은 매뉴얼 사양표 및 기존 등록 데이터 | 5m / 10m / 15m 유지 |
| PD 수치 충돌 | 같은 매뉴얼 본문 최대 100W vs 사양표 5m 90W·10/15m 85W | 기존 CONFLICTED 상태 및 원 수치를 유지. 그림에는 수치 없이 ‘PD 역공급’만 표기, 하단에서 사양표 확인 안내 |
| 스타일 본보기 | RTCOM 구성기 XDM-CTR100 PSE Signal Flow 공개 화면·pseDiagram | 두 조합의 상하 배치, 양끝 기기, 케이블 위 라벨, 파랑 신호·주황 전원, 범례, 단계 설명, 크게 보기, 가벼운 흐름 애니메이션 |
| 연결 범위 | 사용자 요청 및 매뉴얼 Application Scenarios | 허브/스위치는 케이블 구성품이 아닌 외부 장비 예시. 그림은 동작 예시이며 고정 결선이 아님 |
