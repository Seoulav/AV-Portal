# W-20261003-008 AMX 자료·단자·사양 대조표

근거는 사용자가 제공한 `_harman/AMX/`·`_harman/AMX2/`의 PDF 사본이다. [SHA-256·변경 전 행·게시 파일별 적용 제품](W-20261003-008-evidence.json)을 기록하고 원본 비공개 폴더는 저장소에 넣지 않았다. PDF를 직접 렌더링하여 AMX NX 하드웨어 레퍼런스 10쪽, VARIA 공용 매뉴얼 표지·12·57쪽, VARIA-80 사양서 2쪽 및 NX 도면 3개를 판독했다.

## 파일 중복과 적용 모델

| 판정 | 결과 |
|---|---|
| 로컬 PDF 사본 | **31개**. Work의 30개 집계보다 1개 많다. `_harman/AMX/VARIA-100`과 `_harman/AMX2/VARIA-100`에 동일 매뉴얼·도면 사본이 있다 |
| SHA-256 고유 PDF | **16개**. Work의 고유 파일 수와 일치 |
| 게시 | **15개**, 각 SHA당 파일 1개. 2015년 `2015.Summer.Pocket.Guide.pdf` SHA `b146f10d9f7b…` 제외 |
| 업로드 연결 | 기존 **36 + 새 28 = 64건**. 15개는 물리 PDF 파일 수이고 `uploads`는 **제품별 연결 수**이므로 Work의 “51건”은 산식 오류다. 공용 5개×NX 3종=15, NX 개별 6, VARIA 공용×4종=4, VARIA 개별 3 |

NX 하드웨어 레퍼런스 표지는 NX-1200·NX-2200·NX-3200·NX-4200을 명시하고, **10쪽 기능표는 대상 3종의 모델과 FG2106-01·02·03을 각각 확인**한다. VARIA 공용 매뉴얼은 표지와 **12쪽 적용 목록에서 VARIA-SL50(AMX-UTP0501), VARIA-SL80(AMX-UTP0801), VARIA-80(AMX-UTP0811), VARIA-100(AMX-UTP1011)**을 각각 명시한다. 대상 네 제품 모두에 연결해도 된다. 161쪽 문서의 57쪽은 USB 저장소 설정과 일반적 “USB ports”를 설명하지만 네 모델별 물리 형상·수량을 확인하지 않는다. 따라서 개별 사양서가 없는 VARIA-100·SL50·SL80에는 USB 행을 만들지 않았다.

NX 개별 빠른 시작 안내와 95-2106-01·02·03 도면은 각각 해당 모델에만 연결했다. VARIA-80 데이터시트는 표지에 **VARIA-80 / AMX-UTP0811**을 명시한다. VARIA-100·SL50 도면은 각 모델 전용이며 SL80 개별 PDF는 없다. PPTX·HWP·DXF·DWG와 2015년 종합 카탈로그는 게시하지 않았다.

## VARIA-80 2쪽과 모델별 제한

| 근거 항목 | 반영 |
|---|---|
| CONNECTIONS `USB Type C OTG, USB Type 2.0` | `varia-80`에 `USB Type-C` 1행, `signal: USB OTG`, `protocol: USB 2.0`. **개수 원문이 없어 `quantity` 공란** |
| Display Type, Brightness, Contrast Ratio, Viewing Angle | 패널 종류 `TFT-LCD, IPS`, 밝기 `350 nits`, 명암비 `>800:1`, 시야각 `>80°/80°/80°/80°` |
| Touch Overlay, Illumination | 정전식, 동시 터치점 `>5`, 팜 리젝션·젖은 손가락·지문 방지·항균 코팅, LED 백라이트 |
| MEMORY, POWER | RAM `4 GB LPDDR4`, 저장 `16 GB eMMC`, DC 입력 `N/A` |

VARIA-80은 개별 사양서 근거 신규 **11행**과 기존 `해상도.condition`에서 분리한 `화면비` 1행으로 사양 **12→24행**, I/O **1→2행**이다. `Color Depth`·오디오 코덱 등 원문이 비어 있는 칸은 추가하지 않았다. VARIA-100·SL50은 `화면비` 1행으로 각 12→13행이다. VARIA-SL80은 `화면비` 1행과 기존 조건에서 분리한 인치 치수 1행으로 12→14행이다. 세 제품의 I/O는 각 1행 유지다. `varia-80`의 밝기·패널·메모리·USB 값을 이 3종에 복사하지 않았다.

수치가 있는 본래 사양 행은 삭제하지 않았다. 인치·파운드·화씨 표기는 표시 조건에서 빼고 **공개 `value` 안에 원문 그대로 병기**했다. 7종 `keyFacts`는 데이터에서 **모두 0개**로 유지된다. 화면 01은 렌더러가 기존 사양으로 만든 자동 요약 4칸을 보여 주지만 명시적 `keyFacts` 작성은 W-20261003-009 범위다.

**충돌 보존:** 기존 VARIA-SL80의 크기는 `127.64 × 213.22 × 26.65 mm`인데 인치 표기는 `5 1/16″ × 8 7/16″ × 11/16″`로 적혀 있어 마지막 깊이가 일치하지 않는다. 독립 리뷰가 원문 소실을 지적했다. mm 행의 값은 그대로 두고 기존 `condition` 전문을 `크기(H×W×D) · 인치 표기` 별도 행으로 옮겼으며 **양쪽을 `CONFLICTED`**로 표시했다. 어느 값도 임의 정정하지 않았다. 두 표기의 원문 재대조는 별도 검토가 필요하다.

## NX 도면과 Port Map 후속 가능성

도면 `95-2106-01/02/03` 각 1쪽은 **각 제품의 Rear View와 단자 배치·라벨을 포함**한다. 단자 근거 확보에는 쓸 수 있다. 다만 현행 상세 사진은 7종 모두 `Main` 1장뿐이고 NX도 `Rear` 사진이 없어서 사진 좌표 기반 Port Map은 이번에 만들지 않았다. 후면 게시 이미지가 확보되면 도면과 사진의 모델·단자 대응을 별도 게이트로 검증할 수 있다.
