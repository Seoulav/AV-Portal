QHC/QMC·QHF에는 HDMI 입력 3개, DP 입력 1개, USB 2개, 오디오 출력 1개, RJ45·RS232C IN/OUT·IR IN 각 1개가 있다. 제품 JSON은 같은 역할의 단자를 하나의 행으로 묶는 기존 형식을 유지한다. 매뉴얼에 없는 오디오 입력은 기존 `미지원(사양표 "No")` 행으로 남기고 수량은 비웠다. USB 2/1의 허용 전류 1.0/0.5 A, HDMI 3의 ARC, RJ45 10/100 Mbps 및 CAT 7(STP) 권장을 `availability`에 기록했다.

비디오월 HDMI는 매뉴얼의 `HDMI IN 1/2` 두 개이므로 `direction: IN`, `quantity: 2`, 신호 `비디오 입력`으로 바로잡고 행의 데이지 체인 표기를 지웠다. `DP IN`은 입력 1개, `DP OUT (LOOPOUT)`은 별도 출력 1개다. 후자에 같은 모델 간 연결 권장과 UHD/FHD 루프아웃 세트 비호환 주의를 남겼다. USB-A 형상 행은 매뉴얼 라벨대로 `SERVICE(서비스 전용)`으로 바꾸고 사용자 USB 저장장치용이 아님을 표시했다. 방향은 매뉴얼이 정하지 않아 빈 값으로 두었다. `IR 출력`은 제품별 1행을 추가했다. 전원 출력은 매뉴얼 도면에 없으므로 기존 미지원 행을 유지하고 수량에 0을 넣지 않았다. 오래된 웹 소개 출처 `P`의 HDMI 데이지 체인 메모는 독립 리뷰 지적에 따라 **HDMI는 입력 피드, 물리 루프아웃은 DP OUT만**이라는 구분을 적었다. `overview`·사양·기능 본문은 이번 승인 범위 밖이라 유지했으며 표현 정합성은 후속 검토 대상으로 넘긴다.
