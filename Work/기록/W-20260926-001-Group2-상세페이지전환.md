# W-20260926-001 — Group 2 8개 제품 상세페이지 전환 기록

작성: 2026-09-26, Claude Code 세션(Work/Codex 역할 동일 세션 대행)

## 배경

이사님이 "BRC-Am7처럼 모든 제품 하려면 여기서는 불가능하니?"라고 물어, 254개 전체를 한 번에 하는 건 원본 대장(로컬 전용, 이 세션에 없음)이 없어 어렵다고 답했다. 이어서 "codex가 조사한 자료가 깃허브에 있지 않니?"라는 지적을 받고 실제로 확인해보니:

- `docs/research/major-equipment-official-links-2026-09-23.json`: 271개 행·695개 공식 출처 URL 레지스트리(어디를 찾아야 하는지는 이미 조사됨, 값 자체는 아님)
- `Work/기획/BRC-AM7_PRODUCT_DETAIL_CONTENT.md`·`DM7_PRODUCT_DETAIL_CONTENT.md`: 기존 2개 제품의 원본 콘텐츠 문서
- `Work/기록/W-20260925-012-사진조사.md` + `beta/group2-images.mjs`: **Group 2 8개 제품의 사진은 이미 검증·게시승인까지 완료**돼 있고 상세페이지 없이 카드 미리보기로만 쓰이는 중

사진이 이미 끝난 이 8개가 상세페이지 전환에 가장 적은 추가 조사로 진행할 수 있는 대상이라 제안했고, 이사님이 "8개만 해보자"로 승인했다.

## 대상 8개 제품

Powersoft Mezzo 322 AD, Roland V-02HD MK II, Roland UVC-01, Epson EB-L530U, Audinate AVIO USB C(Dante AVIO USB-C, ADP-USBC-AU-2X2), Shure MXCW640, NETGEAR GSM4248PX, Analog Way Aquilon RS1.

## 조사 방법

브랜드별 공식 홈페이지(WebFetch)와 실제 PDF 원문(curl+pdftotext, poppler-utils 설치)을 병행했다. WebFetch는 바이너리 PDF를 직접 읽지 못해, PDF는 항상 curl로 받아 pdftotext로 텍스트를 뽑았다.

- **Powersoft Mezzo 322 AD**: 공식 제품 페이지 + Mezzo 시리즈 공용 User Guide(`PS_MEZZO_UG.pdf`) + 공용 기술자료(`powersoft_TDCD_MEZZO.pdf`, 322AD 포함 확인). 크기·무게는 어디에도 없어 MISSING.
- **Roland V-02HD MK II / UVC-01**: 공식 제품 페이지(사양 대부분 이 페이지에 있음) + 모델별 매뉴얼 다운로드 허브 페이지(개별 PDF는 못 골라 허브 URL을 User Manual로 채택).
- **Epson EB-L530U**: 공식 제품 페이지 + 모델 전용 한글 카탈로그(`my.epson.co.kr/upfiles/Catalog/thumb/EB-L530U.pdf`, 사양표 포함, VERIFIED)로 상세 스펙 확보. **발견**: 제조사 고객지원 다운로드 페이지(`epson.co.kr/.../EB-L530U/s/SPT_V11HA27040`)의 매뉴얼 PDF 파일명이 `EBL735U`로 표기되어 있어(다른 모델) User Manual은 채택하지 않고 MISSING으로 남김.
- **Audinate AVIO USB C**: 기존 manual_link로 이미 연결돼 있던 공식 데이터시트(`dante_avio-usb-c_0224-en.pdf`)에서 USB-C 모델(ADP-USBC-AU-2X2)의 전체 스펙표(채널·전원·지연시간·네트워크)를 확인. 물리 크기·무게는 데이터시트에 없어 MISSING.
- **Shure MXCW640**: 공식 제품 페이지 + 시스템 데이터시트(`MXCW_Datasheet_Systempage_EN_letter_1809.pdf`)에서 RF 대역(2.4/5GHz)·작동범위·크기·무게 확인. 마이크로폰 지향성 패턴은 미확인으로 남김.
- **NETGEAR GSM4248PX**: 공식 제품 페이지에서 대부분 확인(포트 구성·PoE·크기·전력). GSM4248PX가 "M4250 시리즈" 소속임을 페이지 본문(`M4250 Series GSM4248PX offers...`)으로 확인한 뒤, M4250 시리즈 공용 문서(사용설명서·데이터시트·제품 브리프)를 문서로 채택.
- **Analog Way Aquilon RS1**: 모델 전용 기술 데이터시트(`Aquilon-RS1-datasheet-en-20260703.pdf`)에서 I/O·처리 성능·크기·무게·전원까지 상세히 확인(가장 자료가 풍부했음). 시리즈 공용 브로슈어도 Technical Document로 추가.

## 반영 방식

- 각 제품의 상세 JSON(`beta/site/detail/data/<slug>.json`)을 기존 5개 제품과 동일한 스키마로 직접 작성했다(레거시 빌드 스크립트 `beta/build-group1-pages.mjs`는 별도의 로컬 마크다운 패키지 폴더를 요구해 이 세션 구조와 맞지 않아 사용하지 않음 — 대신 `beta/site/detail/app.js`가 `./data/<slug>.json`을 직접 fetch하는 구조를 확인하고 최종 JSON을 스키마에 맞춰 직접 생성).
- `beta/group1-images.mjs`: 8개 슬러그를 추가하되, Group 2 사진 조사 당시 확정된 게시권한 문구("사용자 게시 승인 · 공식 대리점 구매·계약 기반 사용")를 상세페이지 공용 문구로 덮어쓰지 않도록 `group2Image` 헬퍼를 별도로 두어 원문 그대로 보존했다.
- `beta/group2-images.mjs`: 8개 항목을 전부 제거(빈 배열). 파일 자체의 안내 주석대로 "상세페이지가 생기면 이 목록에서 빼고 group1-images.mjs의 cardImages로 옮긴다"를 그대로 따랐다.
- `beta/site/catalog.json`: 8개 항목에 `slug`·`card_image`를 추가하고 `preview_image`·`preview_image_alt`·`preview_image_scope`를 제거했다.
- `tests/group2-preview-images.test.mjs`: group2Previews가 전부 비워지면서 "기준 25개 안에 미리보기 사진이 있어야 한다"는 자체 전제 검사가 깨져, group2Previews가 비어 있을 때는 그 전제 검사를 건너뛰도록 조건을 추가했다(다른 검증 로직은 그대로 유지).
