# W-20261013-005·006 DS-8S 근거와 대조

## 후면 자료

- 대상: VS ENT `DS-8S`. 공식 [제품 쪽](http://www.vsent.co.kr/bbs/board.php?bo_table=c4&wr_id=14)은 전면 사진·리플렛만 제공한다. 다른 모델의 후면 사진은 사용하지 않았다.
- 사용자 제공 제조사 `DS-8S Operating Manual` 4쪽 문서: 게시된 `manuals/vs-ent-ds-8s-amx-manual-ko.pdf`. 표지의 `DS-8S`와 **3쪽 후면 패널 도면**의 단자 라벨을 확인했다. 3쪽 벡터 도면을 `ds-8s-diagram.webp`(1362×280, SHA-256 `e494096a0dda996fb104c2798557131204b73968e220aaf04ad7bf483fe79e03`)로 렌더·재단했다.
- 지도 6묶음: CH1–8 순차 AC 출력, DC 24V 출력, RS-485 링크, REMOTE SWITCH, REMOTE LED, AC 전원 입력 L/N/E. 도면에서 확인되지 않는 **비연동 AC 아울렛**과 기존 모니터 행에는 번호를 달지 않았다. 마커 좌표는 게시 WebP에서 측정했다.
- **자료 충돌:** 리플렛은 DC 24V/500mA, 같은 모델 Operating Manual 3쪽은 DC 24V/800mA. 이번 작업은 `io`에 두 값을 병기하고 `CONFLICTED`로 표시했다. 기존 `specifications`의 500mA 행은 범위 밖이라 그대로이며, 어느 전류가 현행인지 제조사 확인이 필요하다. REMOTE LED 잭과 리플렛의 모니터 5V 행도 동일 단자라고 가정하지 않았다.

## 설정 가이드

- 사용자 제공 `순차 전원 공급 설정 가이드_220529.pdf`, **4쪽**, 383,617바이트, SHA-256 `62b99aa1f94060e4579e60c6344aa6804b44d4b495a8a4785863819a14c45ca5`. 문서 자체에는 DS-8S 모델명이 없어 **사용자의 DS-8S 적용 지시**에 따라 연결했다. PDF는 비잠금 uploads로 게시했고 기존 잠금 12건은 유지한다.
- 1쪽: 전면 버튼·FND 조작부. TIME SET, BYPASS, D/OUT CH1, 채널 1–8의 위치 안내 SVG와 공통 5단계를 만들었다. 설정 전후 FND 값은 원문에 없어 `—`로 표시한다.
- 2~3쪽: `o1`~`o6`, `F00`~`F99`, `Fo2`, `F0o`/`F0F`, `F01`/`F02`/`F03`, 온 타임 적색 LED·오프 타임/상시 전원 녹색 LED를 원문 그대로 정리했다.
- 4쪽: RS-485 RJ-45 1~8번 핀 그림·표, PC↔장비 5·6·7번과 장비↔장비 3~8번, 1:1 케이블, POWER OFF 주의. 프로토콜 수치는 만들지 않고 원문의 `본사 문의 요망`을 유지했다.
