## 데이터 작성 전 G1~G5 판정 (2026-10-02)

기준 `dd2efbfe694fe8a4b71a3798aa83b3fab68b23ae`. 저장소 공개 PDF를 텍스트 추출하고 관련 쪽을 PNG로 렌더링하여 게시 Rear WebP와 직접 대조했다. 새 웹 조사·다운로드 없음. 아래 판정과 좌표 근거를 작성한 뒤 전용 RED 검사를 실행하고 제품 데이터를 작성한다.

Shure 매뉴얼의 쪽 번호는 인쇄 `N/전체`와 PDF 물리 페이지가 동일하다. MXCW 사양·브로셔에는 인쇄 쪽 번호가 없어 위 번호는 PDF 물리 페이지다. UA864A의 모델 변형별 내부 구조가 다를 수 있다는 1쪽 주석을 보존하며, 외부 BNC와 표기된 게인 스위치만 대상으로 한다.

## 판정 한계와 후속 입력

- MXCW640: 기존 이미지 alt의 ‘충전 접점’ 표현을 새 PDF 근거로 재사용하지 않았다. 사양서 3쪽의 battery connector와 사진 금색 접점의 기능 대응도 추정하지 않는다. 해당 접점을 명시한 매뉴얼 쪽이 필요하다.
- MXCWAPT-W: 정확 -W 적용 모델 표기와 후면 근거가 필요하다. 기존 이미지의 공통 모델 주석·빈 I/O 수량을 수정하지 않았다.
- SLXD4D+: 전용 후면 그림 또는 모델 전용 단자 표가 필요하다. 단채널 사진의 위치를 복제하지 않는다.
- SLXD4+의 사진/5쪽 그림 전원 표기는 15V 600mA이나 34쪽 모델 사양과 기존 I/O는 15V 360mA다. 새 지도는 전압·전류를 추가하지 않고 공급된 DC 전원 연결만 설명한다. 원문과 기존 값은 보존한다.
- UA864A를 기획서에서 ‘안테나 분배기’라고 부른 부분은 제조사 PDF 1쪽의 ‘Wall-Mounted Active Directional Antenna’와 다르다. 기획 명세는 수정하지 않으며 지도에는 실제 RF 출력·게인 선택만 표시한다.
- 원래 제외 5종: SLXD1+, ULXD1(해상도 부족), MXA925W-R, UA844+SWB, UA845UWB(근거 PDF 없음). 지도 부재와 기존 JSON 바이트를 검사한다.
- ULXD4D의 기존 캐스케이드 수량2·Signal Flow·11개 지도는 바꾸지 않는다. 기존 항목별 근거는 [시범 근거](W-20261001-001-Port-Map-근거.md), 이번 정확 모델 위치 근거는 DQ PDF 4쪽이다.

## 파일·좌표·검증

파일 SHA-256, 실측 크기, 기존 coreSha256, 항목별 PDF 쪽과 좌표는 [기계 검사 근거](W-20261002-001-shure-port-map-evidence.json)에 기록한다. 좌표는 게시 WebP의 실제 픽셀 기준이며 원본 이미지나 originalSize 메타데이터를 수정하지 않는다. 번호는 입력→출력→네트워크/제어→전원, 형제 모델의 역할 명칭은 동일하게 사용한다.

검증 결과와 캡처는 구현 후 이 문서 및 [Work 인계](W-20261002-001-Work-인계.md)에 기록한다.
