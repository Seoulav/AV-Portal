# W-20261013-007 세션 C — BEHX-H 연결 범례 지도

사용자가 사용을 지시한 삼성전자 설치가이드 `BN68-26620A-01_IG_BEHX-H_Basic_feet_43-85inch_WW_L10_260521.0.pdf`의 SHA-256은 `83e0ea88db6e5a212ee971d8f96362c93b47cff58292e7e19e7eda2367bbd479`이다. 이미 게시된 `beta/site/manuals/samsung-behx-h-installation-guide-ko.pdf`와 **바이트 단위로 동일**하므로 PDF와 uploads를 중복 추가하지 않았다. 1쪽 연결 안내 범례를 1120×624px Diagram으로 잘랐다. **이 그림은 실제 후면 전체 배치도가 아니다.** 번호는 범례의 다섯 커넥터 그림만 가리킨다.

2쪽의 모델 표는 BE43HX-**, BE50HX-**, BE55HX-**, BE65HX-**, BE75HX-**, BE85HX-**를 함께 열거한다. 1쪽에 크기별 별도 연결 범례가 없어 같은 픽셀의 이미지를 여섯 모델별 파일에 사용했다. 여섯 WebP의 SHA-256이 같은지 검사한다. 국내 제품 페이지와 기존 제품 JSON은 LH43/50/55/65/75/85BEHHLBFXKR을 BEHX-H 계열로 연결한다. 크기별 실제 후면 위치가 같다고 주장하지 않는다.

| 번호 | 1쪽의 보이는 표기 | 지도 범위 |
|---|---|---|
| 1 | USB | 왼쪽 첫째 행 USB 커넥터 |
| 2 | LAN | 오른쪽 첫째 행 LAN 커넥터 |
| 3 | HDMI (eARC) | 왼쪽 둘째 행 HDMI 커넥터 |
| 4 | ANT | 오른쪽 둘째 행 안테나 커넥터. RF 물리 단자 수는 미확정 |
| 5 | HDMI | 왼쪽 셋째 행 일반 HDMI 커넥터 |

1·3·5는 왼쪽, 2·4는 오른쪽 여백에 번호를 두고 각 행의 그림으로 선을 연결했다. 좌표는 발췌 이미지에서만 의미가 있다.

[1280px 로컬 점검](W-20261013-007-C-BEHHL-local-1280.png)에서 다섯 지시선을 각 범례 행에 대조했다. [390px 왼쪽](W-20261013-007-C-BEHHL-local-390.png)과 [오른쪽으로 스크롤한 화면](W-20261013-007-C-BEHHL-local-390-right.png)에서 1·3·5 및 2·4를 각각 눈으로 확인했다. 화면 전체 가로 넘침과 브라우저 오류는 없었다. 65형은 정면 사진이 없는 상태라 새 Diagram을 카드 대표로 연결했고, 제품 설명에 정면 사진 미확보를 유지했다.

| 자료 | 적용 시리즈 | HDMI 표기와 판단 |

| 삼성 국내 [LH55BEHHLBFXKR 제품 페이지](https://www.samsung.com/sec/business/smart-signage/behx-h-series/LH55BEHHLBFXKR/) 및 기존 제품별 사양 | BEHX-H 국내 모델 | HDMI 입력 **3개**. 사양 유지. 세 번째 위치는 그림에 없음 |
| 사용자 제공 BN68-23476A-01, 1–2쪽 | BEFX-H, BE43FX-** 등 | HDMI 표시 2개이나 **다른 시리즈**이므로 BEHX-H 지도 근거에서 배제 |

이번 BN68-26620A-01은 앞서 조사한 BEHX-H 문서와 **같은 파일**이다. BEFX-H BN68-23476A-01은 문서 번호·모델 표가 달라 같은 모델의 개정판이라고 단정하지 않는다. 이번 지도는 새로운 근거 자료가 생겨서가 아니라 사용자의 “보이는 단자만 표시” 결정에 따라 범례의 범위를 밝히고 만들었다. HDMI 3개 사양과 범례 2개 표시 사이의 충돌은 해소되지 않았다. 각 Diagram 설명과 HDMI 번호 설명에 “세 번째 위치 미표기”를 넣었고 기존 `io`는 그대로 두었다.

이력 되감기는 제품별 `images`, `imageStatuses`, `portMap`과 65형의 Diagram 전용 `presentation`, `card_image`만 과거 값으로 되돌리고 다른 필드의 변경은 남긴다. 43형의 손편집 형식은 원문 바이트 형식으로 복원한다. 잠긴 PDF 12건·다른 제품·렌더러·검증기는 변경하지 않았다. 세 번째 HDMI의 실제 위치와 RF 물리 단자 수를 확인하려면 모델명이 보이는 실물 후면 사진이 필요하다.
