# W-20261014-009 Work 인계

Carbonite Ultra의 Port Map 16개 설명을 단자의 용도와 연결 신호·대상 장비가 드러나도록 다시 썼다. 번호·라벨·좌표, `io`·사양·사진·문서 및 기존 출력 수 `CONFLICTED`는 변경하지 않았다. UPGD·SD는 매뉴얼 후면 도면에도 용도 설명이 없어 미확인으로 남겼다. 근거는 [설명 근거표](W-20261014-009-Carbonite-Port-설명근거.md)에 번호별로 정리했다.

전용 검사는 16개 설명과 나머지 제품 데이터의 불변을 확인한다. 선택적 역사 검사는 현재 JSON에서 설명만 과거 문구로 되돌리고, 승인 문구의 SHA가 다르면 실패하며, `io` 변이가 과거 검사에 그대로 드러남을 검증한다. 전체 순차 검사 697건 중 696 pass·0 fail·기존 skip 1, `verify-pages` 281장비·278상세·497 WebP·142 uploads, 검색 인덱스·문구 `--check` 통과. `feature-wording --diff origin/main`은 단순 말투 변경을 위한 엄격 검사라 새 용도·수치·모델 토큰 추가 20건을 보고했다. 추가 내용은 매뉴얼·기존 I/O·공식 사양표에 근거하며 기존 출력을 덮지 않았다. 로컬 1280px·390px에서 Port Map 설명·마커 각각 16개, 가로 넘침·JavaScript 오류 0을 확인했다. 캡처는 로컬 `outputs/coordination/w20261014-009/`에 있다.

후속 검토: 현재 `io[2]` AES와 `io[5]` LTC의 커넥터 `HD-BNC`는 게시된 Ultra 9.2 매뉴얼 177–178쪽 및 후면 사진의 3핀 소켓과 다르다. 이번 사용자는 Port Map **설명만** 요청했으므로 데이터 행을 고치지 않았다. 출력 수 충돌과 UPGD·SD 용도도 새 근거 없이 확정하지 않는다.

PR·CI·병합 SHA·Pages와 공개 화면 결과는 실제 완료 후 종료 기록에 추가한다.
