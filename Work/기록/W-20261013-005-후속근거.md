# DS-8S 공개 화면 후속: 지도 좌표와 설정 가이드 배치

사용자 공개 화면 지적을 받은 뒤 `ds-8s-diagram.webp` **게시 최종본 1362×280 픽셀**에서 단자 하우징을 다시 읽었다. 원본 PDF 페이지·크롭 전 캔버스 좌표는 쓰지 않았다. 사진·번호·라벨·설명은 변경하지 않았다. 기존 검토에서 괄호가 단자 아래쪽과 이웃 영역에 걸친 점을 놓쳤고, 이번에 각 단자의 몸체 중앙 또는 외곽으로 옮겼다.

| 번호 | 단자 몸체(게시 WebP 기준) | 이전 | 수정 |
|---|---|---|---|
| ① | 순차 출력 8개 하우징 약 x27–1148, y112–242 | x24–1150, y208 | **x27–1148, y176** |
| ② | DC 24V 블록 약 x845–906, y28–70 | x850–905, y67 | **x845–906, y48** |
| ③ | RS-485 RJ-45 약 x958–1053, y23–70 | x955–1053, y69 | **x958–1053, y47** |
| ④ | REMOTE SWITCH 원형 잭 약 x1070–1107, y20–65 | x1066–1108, y65 | **x1070–1107, y43** |
| ⑤ | REMOTE LED 원형 잭 약 x1109–1148, y20–65 | x1113–1155, y65 | **x1109–1148, y43** |
| ⑥ | AC 입력 단자대 약 x1238–1331, y14–265 | x1310, y50–252 | **x1331, y14–265** |

렌더 확인: [후면 1280px](W-20261013-005-후속-캡처/후면-1280.png), [후면 390px 왼쪽](W-20261013-005-후속-캡처/후면-390-왼쪽.png), [후면 390px 오른쪽](W-20261013-005-후속-캡처/후면-390-오른쪽.png). Python 명령이 없는 실행 환경이라 `scripts/portmap-audit.py`는 실행하지 못했다. 제품 상세의 실제 Port Map 렌더러를 Chromium으로 1280·1024·390px에서 재생성하고 overview를 눈으로 확인했다.

설정 가이드는 AC 라벨의 크기·위치를 표시창 왼쪽으로 조정하고, ④를 포함한 단계 카드의 코드 표시를 설명 아래로 내려 행 높이가 내용에 맞게 늘어나게 했다. RJ-45 핀 SVG와 표는 각각 카드 내부의 제한된 그리드 열에 두고 최소 너비·가로 스크롤 경계를 지정했다. 1280·1024·390px에서 핀 그림 카드 이탈·표 겹침·④ 텍스트 잘림·AC/표시창 겹침·페이지 가로 넘침이 모두 없고 JS 오류 0이었다. [전체 1280px](W-20261013-005-후속-캡처/전체-1280.png), [가이드 390px](W-20261013-005-후속-캡처/가이드-390.png).

문서 목록에는 리플렛, DS-8S AMX 통신 설명서, **순차 전원 공급 설정 가이드(2022-05)** 세 카드가 실제로 있다. 사용자 캡처는 첫 카드까지만 담았고 게시 누락은 아니다. PDF 경로는 공개 HTTP 200·383,617바이트로 확인했다. 새 파일을 중복 게시하지 않았다.
