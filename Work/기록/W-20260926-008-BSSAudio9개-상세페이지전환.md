# W-20260926-008 — BSS Audio 9개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-007 완료 후 다음 최소 브랜드인 BSS Audio(9개, HARMAN Professional Group 소속)를 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다.

AGENTS.md의 Harman 계열 브랜드 링크 우선순위 규칙(1순위 techdata-ps.com, 2순위 제조사)을 확인했으나, techdata-ps.com은 이 브랜드에 대해 매뉴얼 PDF/ZIP 다운로드만 제공하고 사양표·제품 사진은 없어, AMX 배치 때와 동일하게 사양·이미지는 제조사 공식 사이트(bssaudio.com)와 그 CDN(adn.harmanpro.com)에서 직접 확보했다.

## 제품별 조사 결과

- **EC-4BV, BLU-101, BLU-100, BLU-160, BLU-50**: 공식 제품 페이지 + Cut Sheet/데이터시트 PDF로 커넥터 타입, 임피던스, 레이턴시, 크기, 무게 등 정밀 사양까지 확인했다.
  - **BLU-50**: 공식 페이지에 "Discontinued"(단종) 표기와 후속 모델 "BLU-50v2" 안내가 있어 이슈로 기록(카탈로그 항목은 유지).
  - **BLU-160**: 카드 슬롯 4개와 지원 카드 6종(Analog Input/Output, Digital Input/Output, AEC, Telephone Hybrid PSTN)을 명시적으로 문서화하고 있어, 이번 배치의 I/O 카드 3종과의 연관성을 이슈로 남겼다.
- **I/O 카드 3종(BLU AEC-IN, BLUCARD-IN, BLUCARD-OUT)**: 카탈로그 표기와 공식 사이트의 실제 제품명이 다름을 발견했다.
  - BLU AEC-IN → 공식 명칭 "AEC Card"(`bssaudio.com/en-US/products/aec-card`)
  - BLUCARD-IN → 공식 명칭 "Analog Input Card"(`bssaudio.com/en-US/products/analog-input-card`)
  - BLUCARD-OUT → 공식 명칭 "Analog Output Card"(`bssaudio.com/en-US/products/analog-output-card`)
  - 제조사의 Input/Output Cards 제품군 페이지가 정확히 이 세 가지 유형(및 Digital I/O, Telephone Hybrid)을 나열하고 있어 합리적으로 식별했으나, 임의로 동일시하지 않고 각 제품의 issues에 REVIEW REQUIRED로 명시했다.
  - 세 제품의 공식 이미지가 바이트 단위로 동일한 범용 PCB 카드 사진임을 확인했다(제조사가 하나의 사진을 세 페이지에 재사용). 각 제품 고유의 sourceUrl(URL 자체는 서로 다름)을 그대로 사용하고, 사진만으로는 세 카드를 시각적으로 구분할 수 없다는 사실을 이슈로 명시했다 — 이미지를 억지로 차별화하거나 조작하지 않았다.
- **BLU-DAN**: 카탈로그의 official_links가 가리키는 지원 페이지는 다운로드 전용이고, 실제 현재 제품 페이지는 `bssaudio.com/en-US/products/blu-da`이며 공식 모델명이 "BLU-DA"(구 BLU-DAN, "Formerly known as BLU-DAN"으로 명시)로 변경되었음을 발견했다. 카탈로그 표기(BLU-DAN)는 유지하되 이슈로 기록했다.

## 검증한 스키마 정합성

에이전트 산출물은 이번에는 처음부터 `issues`/`features`/`specifications`/`io` 필드가 전부 올바른 딕셔너리 스키마로 작성되어 있어(문자열 형식 오류 없음), 별도 정규화 패치가 필요하지 않았다. 9개 전 제품에 이미지가 최소 1장 이상 포함되어 있어 `verify-pages.mjs`의 "게시 이미지가 비어 있음" 요구조건을 만족했다.

## 코드 변경

- `beta/manufacturer-hosts.mjs`: BSS Audio 항목에 `harmanpro.com` 추가(제품 이미지가 adn.harmanpro.com에서 호스팅됨).
- `beta/group1-images.mjs`: 9개 슬러그 신규 항목(group1Images, cardImages) 추가.
- `beta/site/catalog.json`: 9개 항목에 slug·card_image 필드 추가.
- `beta/site/detail/data/*.json`: 9개 신규 파일.

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 96 details, 114 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다.
