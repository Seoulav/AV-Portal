# W-20261003-010 JBL 사양대조표

대상 10종의 각 **모델명 인쇄된 사양서 2쪽 SYSTEM 표**를 별도로 읽었다. 기존 사양 행과 값은 모두 보존하고, 빠져 있던 `Frequency Response (±3 dB)`와 `Continuous Program (2 hrs)`만 각 1행씩 추가했다. 전자는 기존 `Frequency Range (-10 dB)`와 측정 기준이 달라 **별도 행**이며, 후자는 기존 Continuous Pink Noise 전력과 다른 정격이다. 다른 모델의 수치를 복사하지 않았다. 사용자 제공 사양서가 있는 416C/T·447C/T는 그것을 1순위로 사용했고, 나머지 8종은 각 모델의 JBL Pro 사양서를 사용했다.

**변경 전후:** 위 20행은 변경 전 “행 없음” → 표의 원문 값, `D1 / VERIFIED`다. 기존 모든 사양 행은 순서·값·검증 등급까지 불변이다. 10종마다 `sources`에 사양서 이름·게시 파일·SHA·2쪽을 한 번 추가했다. 기존 조건 문구, 단자, `keyFacts`, 본문은 변경하지 않았다.

**Control 416C/T 문서 내 불일치:** 제공 사양서 **3쪽** 치수 표는 `143 × 203 mm`라고 인쇄됐지만 같은 문서 **5쪽** 모델별 치수 도면은 `233 × 261 mm`(천장 타일 아래부터 222 mm)이고 기존 제품 값도 후자다. 3쪽은 223 mm 컷아웃과도 모순된다. 도면과 기존 값을 대조해 기존 치수를 유지했다. 이 충돌을 숨기거나 412C/T 수치로 덮어쓰지 않았다. **사양서 없는 6종:** `control-426ct`·`control-23-1`·`control-25-1`·`control-28-1`·`ac18-26`·`ac18-95`는 JSON 전체 바이트가 착수 main과 동일하다. 자료만 manifest를 통해 연결했다. [근거 JSON](W-20261003-010-evidence.json)에 변경 전 SHA를 남겼다.

## Port Map 후보 조사(작성하지 않음)

Control 440CS/T와 447C/T의 큰 Rear 사진을 우선 확인하고 Standard·Enhanced 대표 모델도 대조했다. 사진에는 밀폐된 백캔, 단자 커버 및 케이블 녹아웃이 주로 보이며 **확정 가능한 4개 이상의 독립 사용 단자·조작부가 없다. 후보는 0종**이다. 실제 전기 접속은 기존 I/O 1행이며 커버 속 단자 역할을 사진 표면에서 추정하지 않았다. 이번 배치의 `portMap`은 0건이다.
