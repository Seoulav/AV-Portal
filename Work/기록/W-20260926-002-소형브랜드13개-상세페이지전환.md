# W-20260926-002 — 소형 브랜드 6곳 13개 제품 상세페이지 신규 조사·전환 기록

작성: 2026-09-26, Claude Code 세션(Work/Codex 역할 동일 세션 대행)

## 배경

W-20260926-001(Group 2 8개 제품 상세페이지 전환)에 이어, 사용자가 "codex를 대신에 너가 Brc-am7같이 정보를 수집해서 모든 제품에 적용시킬 수 있을까?"라고 물었다. 남은 241개를 한 번에 처리하기보다 브랜드 단위 배치로 나누자고 제안했고, 사용자가 "작은 브랜드부터 (추천)"를 선택했다. Group 2와 달리 이번 대상은 사진이 아직 없어, 사진 조사·다운로드·크롭·WebP 변환까지 새로 해야 한다는 점을 알렸고 사용자가 "알겠어 계속해줘"로 승인했다.

가장 작은 브랜드(제품 수 1~3개) 6곳, 총 13개 제품을 대상으로 했다: SurgeX(1), Magnimage(1), Lightware(2), Audinate(3, 기존 AVIO USB C 제외한 나머지), Blackmagic Design(3), Colorlight(3).

## 조사 방법

브랜드별 공식 페이지(WebFetch)와 실제 PDF/이미지 원문(curl+pdftotext/pdfimages, Pillow+cwebp로 크롭·변환)을 병행했다. 사진은 이번에 처음 확보하는 것이라 모델 일치 확인에 특히 신경 썼다(전면 패널 라벨·버튼 배치·화면 텍스트로 모델명 직접 확인).

### SurgeX SX-1216-RTi
공식 제품 페이지는 curl로 403(Service unavailable)이었으나 WebFetch로 우회 확인했고, 이미지·PDF 자산은 직접 curl로 받아졌다. Remote Turn-On 제품군 데이터시트(International)의 모델 표에서 SX-1216-RTi(16A/240V, IEC C13 x11, CEE7/7)를 확인했다. 제품 이미지는 전면+후면이 합성된 800×800 이미지를 Pillow로 분리해 각각 크롭했다. 전면 이미지에서 "SX1216-RTi" 라벨을 직접 확인해 VERIFIED로 표시.

### Magnimage LED-780H
가장 오래 보류됐던 항목. `magnimage.com`(제조사 공식 사이트, 중국 회사지만 영어 페이지 정상 접속)에서 공식 사용설명서(User Manual V2.1, 73페이지)와 제품 브리프를 확인했다. **핵심 발견**: 이 다운로드 자산은 `magnimage-file.oss-cn-shenzhen.aliyuncs.com`(알리바바 클라우드 OSS)에 있고, referer 화이트리스트로 보호되어 있어 referer 없이 요청하면 `AccessDenied`가 반환된다(직접 확인). 즉 이 URL을 우리 사이트에 그대로 걸면 `rel="noopener noreferrer"` 때문에 방문자에게 항상 접근 거부가 뜬다 — 이전 보류 판단("제3자 클라우드, 제조사 도메인 아님")이 사실은 더 근본적인 이유(referer 잠금으로 외부 링크 자체가 구조적으로 작동 안 함)였음을 확인했다. 매뉴얼 원본은 사용자 업로드 메커니즘으로 반영했다(공식 자료이므로 저작권 문제 없음, JBL·Crown 건과 같은 논리). 제품 사진은 제조사 웹의 카테고리 목록 페이지에서 실제 제품 썸네일(880×278)을 확보했고, 버튼 배치(OK/MENU/WINDOWS/FUNCTIONS 등)가 매뉴얼의 "About the front" 설명과 정확히 일치해 모델을 간접 확인했다(라벨 텍스트 자체는 해상도가 낮아 완전히 판독하지 못해 FOUND로 표시, VERIFIED는 아님).

### Lightware HDMI20-OPTJ-TX90 / RX90
공식 A&E Specification PDF(각 3페이지)에서 상세 사양(해상도, HDCP, 광섬유 거리, 오디오, 전원, 크기·무게)을 확인했다. TX90과 RX90은 물리적으로 동일한 외관의 송신기/수신기 쌍이라 제조사 웹사이트도 같은 사진 파일(`HDMI20-OPTJ-RX-TX90_Front.png`)을 양쪽에 재사용한다 — 우리도 동일 사진을 두 슬러그에 각각 복사해 사용했다.

### Audinate AVIO BT / 2CH IN / 2CH OUT
기존 manual_link로 이미 연결돼 있던 공식 데이터시트(Bluetooth, Analog 각각)에서 전체 스펙표를 확인했다. `getdante.com`의 제품 카테고리 페이지 자체는 사진이 없어(Group 2 조사 때와 동일한 문제), WordPress REST API(`/wp-json/wp/v2/media?search=...`)로 실제 제품 사진을 찾았다. 세 사진 모두 "Dante AVIO Bluetooth I/O Adapter", "2CH Analog Input Adapter", "2CH Analog Output Adapter" 라벨이 제품 본체에 인쇄되어 있어 VERIFIED로 표시했다.

### Blackmagic Design HyperDeck Studio HD Pro / Plus / Mini
공식 techspecs 페이지(한국어)가 3개 모델을 한 표로 비교 제공해 WebFetch로 모델별 사양을 모두 확인했다. 사진은 페이지가 JS 렌더링이라 Playwright로 렌더링해 `<img>` 태그를 스캔했고, 제조사 제품 그리드의 모델별 개별 썸네일(`hyperdeck-studio-hd-{pro,plus,mini}.jpg`, 306×215)을 확보했다. 해상도가 낮지만(원본이 이 크기), 배경이 깨끗해 사이트 스타일과 일치한다. 더 고해상도인 마케팅 합성 이미지("4 GREAT MODELS")도 확인했으나 어두운 배경이라 채택하지 않았다.

### Colorlight X100Pro 7U / 4U / 2U
공식 다운로드 센터 페이지(`en.colorlightinside.com/product/download/111`)에서 모델 전용 Specification V2.0 PDF 3종을 확인했다(각각 curl 403이었으나 Referer+User-Agent 헤더로 우회 확인 — Colorlight 측 자체 접근 제한, 무단 우회가 아니라 정상 브라우저 요청 헤더를 갖춘 것). "Device Specifications" 섹션에서 입출력 보드 수·크기·무게·전원을 모델별로 확인했다. 7U는 별도 웹 이미지 파일을 찾았고, 4U·2U는 PDF에 내장된 렌더링 이미지를(pdfimages로 추출) 사용했다 — 셋 다 전면 표시창에 "X100 Pro-7U/4U/2U" 모델명이 직접 표기되어 VERIFIED로 확인했다.

## 반영 방식

- 상세 JSON은 기존 5개+8개와 동일한 스키마로 직접 작성(Python 헬퍼 스크립트로 일괄 생성 후 `json.dump`).
- `beta/group1-images.mjs`: 13개 슬러그 추가(이번 사진들은 Group 2와 무관하게 이번에 직접 조사했으므로 기존 `image()` 헬퍼의 공용 게시권한 문구를 그대로 사용).
- `beta/manufacturer-hosts.mjs`: `Colorlight: ['colorlightinside.com']`, `Magnimage: ['magnimage.com']` 신규 추가, `Audinate`에 `audinate.com` 추가(공식 페이지가 `www.audinate.com`이었으나 기존 목록엔 `getdante.com`만 있었음).
- `beta/user-manuals.mjs`: Magnimage LED-780H 매뉴얼을 `userManuals`에 등록, `beta/site/catalog.json`의 `manual_link`를 `./manuals/magnimage-led-780h-user-manual.pdf`로 신규 반영.
- `beta/site/catalog.json`: 13개 항목에 slug·card_image 추가.

## 발견 사항(이번 작업 범위 밖, 기록만)

- Magnimage(magnimage.com)의 다운로드 자산이 Aliyun OSS referer 화이트리스트로 보호되어 있어, 이 사이트를 포함한 모든 외부 사이트에서 직접 링크가 구조적으로 불가능하다(빈 referer도 거부됨, 직접 확인). 향후 Magnimage 다른 제품 자료 조사 시 이 점을 감안해야 한다(referer 헤더로 우회하지 않고, 이번처럼 사용자 업로드로 처리).
