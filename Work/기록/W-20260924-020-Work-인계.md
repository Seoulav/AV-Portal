- 로컬 주소: `http://127.0.0.1:4211/` (실행 중인 해당 PC에서 확인). 재실행: `node prototype/brc-am7/fetch-images.mjs` 후 `node prototype/brc-am7/serve.mjs --port 4211`.

## 경계와 다음 판단

- 제조사 사진 재게시·핫링크 권한은 **REVIEW REQUIRED**. 공개 사이트에서 사진이 보이도록 바꾸는 작업은 하지 않았다.
- 공개 생성물 동기화는 자동 승인 검토에서 공개 사이트 변경 위험으로 거절됐다. 현재 시안은 프로토타입 서버에서 주입하는 `local-visual.css`로 격리했다. 이 거절을 우회해 동기화하지 않는다.
- 사용자의 디자인 시안 평가를 받고, 공개 사진의 사용 허가 또는 제조사 공식 페이지로 보내는 대안 중 선택한다. 이후 공통 Product Detail 5개로 확대할지 별도 범위를 정한다. 공개 적용 전에는 사진 바이너리·업체 내부 자료가 PR/Pages에 없음을 다시 검증한다.
- 사용자는 2026-09-24 사진을 공개 사이트에서 볼 수 있게 배포하도록 요청했다. [Sony 한국어 약관 §8](https://pro.sony/ko_KR/terms-and-conditions)에 사진 재게시의 사전 서면 동의 조건이 있어, 현재 권한 미확인 사진의 공개 업로드는 보류했다. 필요한 입력은 Sony 서면 허가 또는 귀사가 직접 촬영해 공개 권리를 가진 BRC-AM7 사진이다.

## 후속 로컬 시안: 자체 제작 픽토그램

- 사용자가 직접 촬영한 사진을 나중에 제공하기로 하여, BRC-AM7 **한 제품에만** 범용 PTZ 도형을 표시하는 로컬 보기를 추가했다. `node prototype/brc-am7/serve.mjs --port 4212 --pictogram` 실행 후 회사 PC의 `http://127.0.0.1:4212/`에서 확인한다. 사진 다운로드는 필요 없다.
- SVG는 특정 제조사 사진·제품 외형을 복제하지 않은 직접 제작 도형이며 CC0 1.0으로 제공한다. SVG 외 상표·사진·콘텐츠 권리는 포함하지 않는다. 화면에는 “실물 사진 아님”과 사진 준비 중 상태를 표시한다.
- 원래 `content.json`, 사진 4장의 로컬 보기, 공개 데이터·Pages 파일은 바꾸지 않았다. 자동 검증 `npm test` 47 pass·1 skip·0 fail, `node beta/verify-pages.mjs` 통과; Chromium 1440px·390px에서 그림 표시·가로 넘침 없음을 확인했다.
- 다음 단계는 사용자 시안 평가다. 승인 전 다른 4개 상세나 전체 제품에 픽토그램을 일괄 적용하거나 main 병합·Pages 배포를 진행하지 않는다. 직접 촬영 사진은 모델·사용 권리를 확인하고 이후 교체한다.

## 후속 승인 범위: BRC-AM7 공개 픽토그램 시안

- 사용자의 “로컬 대신 사이트에 올려줘” 요청으로 **앞서 보여 준 BRC-AM7 한 제품**의 공개 게시가 승인됐다. 다른 제품은 일괄 변경하지 않고 사진 바이너리도 게시하지 않는다.
- 공개 데이터 `beta/site/detail/data/brc-am7.json`에 자체 제작 SVG 한 개만 추가했다. `imageStatuses`의 제조사 이미지 확인·권한 검토 상태는 유지한다. 화면에는 실물 사진이 아니라는 문구와 CC0 표시가 함께 나온다.
- 공통 상세 CSS 변경은 `body.brc-pictogram`에만 적용된다. 로컬 공개 아티팩트에서 BRC는 1440/390px 가로 넘침이 없고 8/27/14 콘텐츠·문서 4칸·확대·Esc를 확인했다. 나머지 4개 제품은 이미지 0개와 기존 테마를 유지한다. `npm test` 47 pass·1 skip·0 fail, `node beta/verify-pages.mjs` 통과.
- 본 기록 시점에는 main 병합·Pages 실제 배포 및 공개 URL 재검증이 남아 있다. 완료 여부는 GitHub PR·Pages run·실제 URL 결과로 별도 확인한다.
- Work의 다음 판단: 사용자 시각 피드백에 따라 제품군별 픽토그램 확대 범위와 직접 촬영 사진의 모델·권리 확인 절차를 정한다. 이번 배포가 다른 제품 일괄 적용 승인을 뜻하지 않는다.
