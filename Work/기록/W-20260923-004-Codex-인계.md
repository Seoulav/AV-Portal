## 구현 범위와 제외 범위

- 제품 ID로 수집대장의 제품–자료 관계를 읽는 별도 읽기 전용 어댑터, 선택 설정 `AV_PORTAL_RESOURCE_REGISTER_PATH`, `GET /api/products/:productId/resources`, 기존 제품 펼침 화면 안의 자료대장 영역을 구현한다.
- 자료 종류·공식/직접 제공/보조 출처·언어·개정·확인일·검증 수준·제품 적용 범위를 분리하고 명시적 `ko` 자료를 우선 표시한다. 공유 자료 관계를 보존하고 기존 목록 출처를 덮어쓰지 않는다.
- 로컬 `folder`·`local_reference`·경로형 제목과 원본 JSON 전체를 API·DOM·오류에 노출하지 않는다. 안전한 HTTPS URL만 링크로 표시한다. 미설정·자료 없음·파일/구조 오류·미등록 상태를 구분한다.
- 제품 목록 ID·원본 행·복수 카테고리·기존 검색/필터와 Builder·LED 외부 링크를 유지한다. RTCOM 웹 조사는 금지한다.
- 업로드·편집·파일 서비스·자동 수집/웹 재검증·원본 변경·공개 배포·DB/최종 Schema·Configurator·Compare·사양/I/O·이미지 구현은 범위 밖이다. 자료의 열람 또는 모델명 출현을 정확 사양·호환성·공개 준비 완료로 승격하지 않는다.
