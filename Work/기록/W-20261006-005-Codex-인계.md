## ★ 걱정했던 설계 변경이 필요 없습니다

사용자가 가리킨 알티컴 `qms-44ux`의 원본을 제가 열어 봤습니다.

```json
{ "n": 1, "label": "INPUT 1–4",  "x1": 640,  "x2": 1200 },
{ "n": 2, "label": "OUTPUT 1–4", "x1": 1285, "x2": 1805 }
```

**번호는 그대로 1·2·3 순차이고, 같은 종류 단자를 범위 마커 하나로 묶어 라벨에 `INPUT 1–4`로 적는 것뿐입니다.** `validMarker`가 이미 받는 형태라 **렌더러·검증기 변경이 없습니다.** NETGEAR가 이미 같은 방식입니다(`'PoE+ RJ-45 1–24'`).

## 라벨 규약

- 입력 묶음 **`INPUT <범위>`**, 출력 묶음 **`OUTPUT <범위>`**, 종류가 중요하면 `OMNI OUT 1–8`처럼 병기
- 범위 구분자는 **`–`(en dash)**
- 단독 단자는 지금처럼 단자 이름
- 번호 순서는 **입력 → 출력 → 제어·네트워크 → 전원.** 사진 배치가 크게 다르면 사진 흐름을 따르고 보고

> **`io`에 없는 단자에 번호를 달지 마세요.** 사진에 보이는데 `io`에 없으면 **보고만**, `io`에 있는데 자리를 못 찾으면 **비우고 보고.**
