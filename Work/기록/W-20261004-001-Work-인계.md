## 다음 기획 입력

1. RTCOM 대비 **번호의 세로 위치**만 의도적으로 다르다. RTCOM은 내부 `y`가 크면 번호가 사진을 덮지만, 사용자 지시에 따라 AV Portal은 항상 밖에 둔다. 47종의 내부 `y` 마커 454개에 적용됐다.
2. 렌더러는 `side:"left"|"right"` 세로 괄호를 그릴 수 있으나 **검증기 `validMarker`가 막고 있다**. `ez-umd-plus`의 측면 사진으로 지도를 만들려면 적용 이미지·검증기·근거·데이터를 별도 READY 작업으로 다뤄야 한다. 이번에는 사진과 데이터에 손대지 않았다.
3. `displayWidth` 경로는 구현·합성 단위 검사만 했다. 실제 사용 제품은 **0종**이라 공개 화면 검증은 불가능하다. RTCOM과 마찬가지로 CSS SVG 최소 너비 560px가 있어 그보다 작은 지정 폭의 동작은 별도 검토 대상이다.
4. RTCOM은 높이 2U 이상일 때만 정면/후면 버튼을 두지만 AV Portal은 기존 버튼을 유지한다. 이 차이는 이번 범위 밖이다.
