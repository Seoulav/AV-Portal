## 검증과 남은 단계

선택적 역사 되감기는 `images`·`imageStatuses`·`portMap`의 승인된 현재 해시를 먼저 검사한 뒤 세 필드만 과거 값으로 복원한다. 나머지 현재 필드는 그대로 과거 해시 검사에 통과한다. 원본 도면 SHA·새 이미지 SHA, 11개 번호·이름·설명 불변, 비승인 필드 해시와 I/O 변이 통과·Port Map 변이 실패를 전용 검사로 확인했다.

전체 순차 검사 **746건 중 745 pass·0 fail·기존 skip 1**, `verify-pages` **284항목·281상세·509 제품 이미지·156 uploads**, 검색 인덱스 `--check` 통과. 잠긴 PDF 12건의 기존 검사가 통과했다. 제품 JSON 외 기존 제품·문서·`builder/`·`cpq/`는 변경하지 않았다.

PR·CI·Work 병합 순서 확인·병합·Pages·공개 화면 확인은 아직 수행 전이며 미래 완료로 적지 않는다. 현재 환경의 브라우저 제어 목록은 비어 있어 로컬 미리보기와 공개 이미지 HTTP/SHA 대조를 우선 사용한다. 공개 1280px·390px 브라우저 캡처가 가능해지면 그 결과를 별도로 보강한다.
