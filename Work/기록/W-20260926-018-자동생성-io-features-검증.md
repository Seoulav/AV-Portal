# W-20260926-018 — 자동 생성 io·features 검증 기록

## 대상 및 방법

W-20260926-015(Powersoft 17)·016(Crown 26)·017(Shure 23)의 상세 JSON 66개를 대상으로, 통합 스크립트가 자동 생성한 `io[]`·`features[]`·`english`를 배경 에이전트 원본 사양과 제품별로 대조했다. 상위 모델로 전환한 뒤 수행했다.

## 발견한 오류

### 심각 — 원본과 반대되는 사실 표기

부정어가 들어간 값("미지원", "아님", "없음")을 키워드 존재만으로 "지원"으로 판정한 버그였다.

| 제품 | 잘못된 표기 | 원본 | 조치 |
|---|---|---|---|
| Crown DCi 2/300N·2/600N·4/300N·4/600N | Dante/AES67 지원(english·features) | "HARMAN BLU-Link (Dante 아님)" | Dante 삭제, BLU link 표기·단자 추가 |
| Crown CDi 2/300 | BLU link 지원(english·features·io) | "BLU link = 미지원 (BL 모델에서 지원)" | BLU link 삭제 |
| Shure ULXD4 | Dante 지원(features) | "없음(내장 Dante 미지원)" | 삭제 |
| Shure QLXD4 | 네트워크 단자를 "Dante audio"로 표기 | "Dante 미지원 — 제어/펌웨어 업데이트 용도" | "Network (control only)"로 정정 |
| Shure MXCWAPT-W | AES-256 암호화 | "AES-128 암호화"(무선 회의 유닛 RF 통신) | 원본 방식(AES-128)과 적용 범위로 정정 |

암호화 문구는 "암호화" 키워드만 보고 AES-256 고정 문장을 붙이던 방식이라, 원본 값에서 방식(AES-xxx)을 직접 읽도록 바꿨다.

### 근거 없는 기능 주장

- Crown: "DriveCore"(증폭 기술 명칭)를 DSP 근거로 오인해 DCi 아날로그 계열(2/300·4/300)과 I-Tech에 "온보드 DSP"를 붙였고, english는 26개 전부 "onboard DriveCore DSP"였다. 원본 사양·개요에 DSP가 명시된 계열(CDi, DCi N, DCi DA, ComTech D)에만 표기하도록 바꿨다. 같은 계열 문서를 공유하는 모델은 계열 단위로 판정했다. DCi 아날로그 4개와 I-Tech는 원본에 DSP 근거가 없어 표기하지 않는다.
- Crown I-Tech 4X3500HD는 투어링 앰프인데 "installation amplifier"로 표기되던 것을 "touring amplifier"로, ComTech D는 "commercial installation amplifier"로 구분했다.
