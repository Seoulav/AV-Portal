## 구현 결과

Analog Way 비디오 프로세서 11종(Aquilon RS alpha·RS1~RS6, Zenith 100·200, Pulse 4K·Eikos 4K) 상세의 보조 카드에 "화면·레이어 설계 가이드"를 추가했다. 화면 행(1·2·3·4 출력, 믹싱/분할, 레이어 수)·AUX 수·4K 입력 수를 넣으면 모델 11종의 가능 여부와 이유, 자원 사용, 첫 번째 가능한 모델 추천을 확인한다. 예시 3개, 현재 제품 강조, 결과별 사용 자원 펼치기, 계산 기준·가정·미확인 사항 접기, 제조사 시뮬레이터 링크가 포함된다.

계산은 `calculateRecommendations` 순수 함수로 두고 9개 시험으로 고정했다.

- Aquilon: Aquilon User Manual v6.2 66쪽: “Each VPU contains 8 source links and 8 outputs links.”, “Capacity 1 uses one link and capacity 2 uses two links, etc.”, “4 mixer layers (or 4 pairs of split layers) spread over 4 outputs, in capacity 2.” 출력 링크는 4K60 출력 수×2, 소스 링크는 믹싱×2+분할×1로 계산한다. 화면을 VPU에 first-fit 배분한다. 매뉴얼 68쪽 “A Screen using more than 8 outputs uses another VPU.”, 69쪽 “An Optimized mode is enabled for the whole VPU when one Screen uses at least 5 outputs links and at least one layer of capacity 2.”; 4K 전용 구성에서는 해당 모드가 4링크 경계 비용을 없앤다.
- Alta 4K: Alta 4K User Manual 42쪽: “One Layer resource = one Mixing layer or one pair of Split layers allocated to a Screen.” 화면 자원은 믹싱+ceil(분할÷2). 자원·PGM·AUX·커넥터 한도를 확인한다.
- Zenith 100·200 입력: 각 공식 데이터시트 6쪽의 “11x 4K60 inputs” 및 “14x 4K60 inputs”. 포털 `videoLayerPlan` 값과도 일치한다.
- Midra: Midra 4K User Manual 42쪽에서 Mixer의 단일 출력 화면, Matrix의 두 단일 출력 화면, Eikos만의 2출력 Blend 규칙을 읽어 모드별 고정 한도를 적용한다. Pulse/Eikos 데이터시트의 Mixer/Matrix별 레이어 수와 대조했다.

## 확인 필요 / 미확인
