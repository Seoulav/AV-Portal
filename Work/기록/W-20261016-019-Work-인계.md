## 구현 결과

Analog Way 비디오 프로세서 11종(Aquilon RS alpha·RS1~RS6, Zenith 100·200, Pulse 4K·Eikos 4K) 상세의 레이어 해설 카드 아래에 "화면·레이어 설계 가이드" 카드를 두었다. 화면 행(구성 1·2·3·4출력, 믹싱/분할, 레이어 수)·AUX 수·4K 입력 수를 넣으면 모델 11종의 가능/불가와 이유, 자원 사용, 가장 작은 추천 모델을 표로 보여 준다. 예시 3개 버튼, 현재 제품 강조, 다른 모델 이름은 그 상세로 이동, 계산 규칙·가정·근거는 접힘 영역, 제조사 시뮬레이터(AW LivePremier Simulator) 링크.

계산은 `evaluateModel`·`evaluateAll`(순수 함수)로 두고 시험 7건으로 고정했다. 규칙은 명세 "설계 2"와 같다.

- Aquilon: 4K60 출력 1 = 출력 링크 2, 믹싱 1 = 소스 링크 2, 분할 1 = 소스 링크 1. 화면을 VPU(8×8)에 첫 적합으로 담아 필요한 VPU 수를 구하고 VPU·PGM 출력·출력 커넥터·입력·4K 믹싱 환산 상한과 비교.
- Alta 4K: 레이어 자원 = 믹싱 + ceil(분할/2). 자원 3/4, PGM 출력 3/4, AUX 2/4, 출력 4/6.
- Midra 4K: 화면 수·출력 수로 Mixer·Matrix·Blend 모드 판정. 라이브 레이어 4(믹싱 2 = 분할 4), Blend는 Eikos만.

## 확인 필요 / 미확인

- 한 화면을 VPU 두 개에 나누는 규칙, 용량 1·2 레이어 혼용 비용, Alta 출력 경계 넘는 레이어 비용은 매뉴얼에 없어 가이드에 "미확인·가정"으로 표시했다(W-010·W-011과 같은 항목).
