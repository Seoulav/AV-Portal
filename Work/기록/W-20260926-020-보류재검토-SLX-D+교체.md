## 단종 SLX-D 삭제와 SLX-D+ 교체

- 사용자 지시로 단종 SLX-D(비Plus) 6개를 공개 카탈로그에서 삭제했다(이 6개는 상세페이지·이미지가 없는 보류 항목이었다).
- 이어서 사용자 지시로 후속 모델을 조사해 등재했다. 공식 모델명과 1:1 대응:

| 삭제 | 등재 | 이미지 |
|---|---|---|
| SLXD4D | SLXD4D+ | 전면·후면·각도 |
| SLXD4 | SLXD4+ | 전면·후면·각도 |
| SLXD2/SM58 | SLXD2+/58 | 전면(공식 1장뿐) |
| SLXD2/BETA58 | SLXD2+/B58 | 전면(공식 1장뿐) |
| SLXD2/BETA87 | SLXD2+/B87A | 전면(공식 1장뿐) |
| SLXD1 | SLXD1+ | 전면·후면·상단 |

- 출처: shure.com(en-US, 한국어 페이지 없음), SLX-D+ 스펙시트(shure.widen.net), SLXD4+ 사용자 가이드(pubs.shure.com). 이미지는 각 모델 페이지 갤러리의 3000px 원본이고, 전면 모델명 인쇄("SLXD4D+" 등)를 직접 확인했다.
- 확인된 사실: SLXD4+/4D+는 Dante 미지원(Dante는 SLXD4QDAN+만), AES-256 암호화 전 모델 지원, 수신기 전원 15 VDC @ 360 mA(후면 인쇄는 15V 600mA — 불일치 이슈 기록).
- 정정: 생성 스크립트가 송신기의 "Ethernet/Dante: 해당 없음"을 지원으로 읽는 버그를 조기에 발견해 부정어 규칙에 "해당 없음"을 추가했다(기존 23개 Shure 페이지 출력 불변 확인).
- 결정표: 공개 목록 모든 항목이 결정표에 있어야 한다는 테스트가 있어, SLX-D+ 6행을 `row: null`, `user_added` 출처로 추가했다. 워크북 행 번호는 지어내지 않았다. 테스트의 모델명 정규화가 "SLXD4D+"와 "SLXD4D"를 같은 키로 보므로 새 행을 뒤에 붙여 적용되게 했다.
