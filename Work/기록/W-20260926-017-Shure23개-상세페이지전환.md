# W-20260926-017 — Shure 23개 제품 상세페이지 전환 기록(6개 보류)

## 대상 및 방법

W-20260926-016(Crown) 완료 후, 마지막 남은 브랜드인 Shure(29개)를 대상으로 진행했다. 카탈로그 목록이 커서(무선 수신기/송신기 18개, 안테나·마이크·액세서리 11개) 배경 에이전트 2개에 나누어 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다. Shure는 HARMAN 계열이 아니므로 techdata-ps.com 우선순위 규칙이 적용되지 않아, 처음부터 shure.com 공식 사이트를 직접 조사했다.

## 카탈로그 SKU 설명 정정

작업 지시에 포함됐던 여러 SKU에 대한 추정이 실제와 달랐음을 조사 과정에서 발견하고 정정했다(모든 해당 제품의 issues에 명시):

- **ULXD8**: "바운더리 마이크 송신기"가 아니라 Microflex 구스넥 마이크(MX405/410/415 등)용 베이스 송신기다. 실제 바운더리 송신기는 ULXD6이다. 공식 매뉴얼로 확인했고, ULXD8 자체의 상세 치수/무게는 매뉴얼에 액세서리로만 언급되어 있어 추측하지 않고 정보 없음으로 유지했다.
- **A900W-R-GM**: 마이크로폰이 아니라 MXA920/MXA925 "라운드(원형)" 천장 어레이 마이크로폰을 천장에 매다는 Gripple 방식 서스펜션 마운트 액세서리 키트(흰색 커버)다.
- **UA844+SWB**: "안테나 콤바이너"가 아니라 능동형 5-way 안테나 분배·전원공급 시스템(470–960 MHz)이다. "SWB" 접미사의 정확한 의미(대역/모델 코드)는 제조사가 명시하지 않아 미확인으로 표기했다.
- **UA845UWB**: 마찬가지로 5-way, VHF+UHF 겸용 안테나 분배 시스템이다(UA844+와 달리 내장 AC 전원 사용). "UWB"는 "Ultra Wide Band" 무선 기술이 아니라 제조사가 "wideband"(174–1805MHz 중 5개 선택 대역 커버) 의미로 쓴 것으로 추정되며, 제조사가 약어를 직접 풀어쓰지 않아 추정임을 명시했다.
- **MXCWAPT-W**: "-W"는 흰색 색상 변형이 아니라 지역/주파수 코드("Worldwide", -A/-B/-JP/-IL 등과 병렬)다. 또한 "무선 충전 스테이션"이 아니라 Microflex Complete Wireless 회의 시스템의 Wi-Fi/Dante 액세스포인트 허브다(무선 충전 스테이션은 별도 제품 MXCWNCS).
- **MXC420/C**: "Microflex Advance"가 아니라 Microflex Complete/Complete Wireless(MXC/MXCW) 회의용 구스넥 계열이다(MXA는 천장 어레이 브랜드로 별도 제품군).
- **MX418D/C**: 조명 LED 링이 없다(로직 LED IN/OUT 제어 핀만 존재, 가시 상태 LED 없음) — 과제 설명의 "LED 표시 링" 가정을 정정했다.

## 데이터 완성도

- **ULX-D/QLX-D 12개(ULXD4Q, ULXD4D, ULXD4, ULXD1, ULXD8, ULXD2/BETA58, ULXD2/BETA87, ULXD2/KSM9, QLXD4, QLXD1, QLXD2/BETA87A, QLXD2/BETA58)**: shure.com 공식 제품 페이지 + 공식 PDF 사용자 안내서(pubs.shure.com)로 RF 감도/레이턴시/치수/무게/Dante 네트워킹/AES-256 암호화 등 상세 사양을 확인했다. ULX-D는 Dante가 듀얼 채널/쿼드 채널 수신기(ULXD4D/ULXD4Q)에 내장(별도 카드 불필요)임을, QLX-D는 Dante 미지원(제어 전용 단일 이더넷)임을 확인했다.
- **SLX-D 6개**: shure.com의 모든 원본 SLX-D(비Plus) URL이 후속 모델 "SLX-D+" 페이지로 전량 리다이렉트되고 있어 제품 사진을 확보할 수 없었다(2026-09-26 기준). 대신 공식 SLX-D 스펙시트 PDF(content-files.shure.com)와 사용자 안내서(pubs.shure.com)로 사양 자체는 확보했으나, 사진이 없어 이번 배치에서는 제외했다(후속 모델 사진으로 대체하지 않음).
- **안테나/마이크/액세서리 11개(UA874XA, A900W-R-GM, MX395, UA844+SWB, MX418D/C, MXCWAPT-W, MXC420/C, MXA925W-R, UA864A, MX392/C, UA845UWB)**: shure.com 공식 제품 페이지 + PDF 스펙시트/매뉴얼로 확인. MXA925W-R의 데이터시트 PDF는 제조사 공식 호스팅이 아니라 영국 대리점(audiologic.co.uk)의 S3 사본만 확인되어, 제조사 공식 출처 기준에 맞지 않는다고 판단해 배제하고 Specification 문서를 MISSING으로 유지했다(이슈로 명시, verify-pages.mjs의 공식 호스트 검증에서도 이 판단이 맞음을 확인했다 — 최초 통합 시 이 URL을 포함했다가 verify-pages.mjs가 "non-manufacturer URL"로 정확히 걸러냄).

## 이미지

products.shureweb.eu(Shure 자체 제품 이미지 CDN)에서 각 제품의 최고 해상도 정사각형 원본(1500~3300px)을 확보했다. ULX-D/QLX-D 계열은 1500px 원본이 이미 존재했고, 안테나/마이크 계열은 2397~3300px 원본을 1500px로 리사이즈해 다른 배치들과 이미지 크기를 통일했다(JPEG→WebP 변환, cwebp -q 85).

- SLX-D 6개를 제외한 23개 전부 최소 1장(전면) 이상을 확보했고, UA844+SWB/UA864A/UA845UWB는 후면도 확보했다. MXCWAPT-W는 전면 + 상세컷(Detail, "Other" 역할로 매핑)을 확보했다.
- MXA925W-R의 대표 이미지는 4가지 색상/형태(화이트·블랙 × 사각·원형)를 함께 보여주는 패밀리샷이며, 화이트/원형 단독 사진은 공식 페이지에 별도로 없어 이슈에 명시했다.

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 236 details, 292 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다. 처음 통합 시 MXA925W-R의 비공식 데이터시트 URL이 verify-pages.mjs의 공식 호스트 검증에서 정확히 차단되어, 해당 URL을 제거하고 이슈로 명시한 뒤 재검증했다.
