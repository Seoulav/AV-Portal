# W-20261013-005 DS-8S 실물 후면 후속 인계

- 범위: 제조사 제공 사용자 업로드 후면 사진을 Rear로 등록하고 게시 WebP 기준 8개 Port Map을 재측정. 기존 설명서 Diagram과 설정 가이드 RJ-45 핀표는 보존하며 판본 차이를 표시.
- 근거: [실물 후면 근거표](W-20261013-005-실물후면-근거표.md). 원본 PNG는 로컬 `tmp/ds8s/`에만 있으며 공개 저장소에는 게시용 WebP만 포함한다.
- 데이터: 사진에 보이는 SERIAL 4핀·LINK IN/OUT·SPRC LED·REMOTE SWITCH·AC 입력을 I/O에 반영. DC는 현재 사진 인쇄 24V/1.5A를 우선 노출하되 리플렛 500mA·설명서 800mA와 충돌 상태 유지. 기존 비연동 아울렛과 모니터 단자는 실물 사진에서 별도 식별되지 않음을 기록.
- 검증: 전체 순차 테스트 651건 중 650 pass·0 fail·기존 skip 1; `verify-pages` 276장비·273상세·480 WebP·134 uploads; 검색 인덱스 검사; 잠긴 PDF 12건. 8마커 audit lint 0, 로컬 1280px·390px 화면에서 사진·01 카드·설정 가이드 판본 안내와 가로 넘침 0을 확인.
- 남은 판단: Builder는 사진에 없는 구판 RJ-45 단자를 제거하면서 생성 단자 2886→2884, 확인 필요 83→87이다. 새 실물의 SERIAL/LINK/RCA 신호 규격은 사진만으로 확정할 수 없어서 Builder override를 만들지 않았다. 제조사의 현재 판본 핀 배치·신호 프로토콜 자료가 오면 Builder 작업 흐름에서 검토한다.
- 배포 확인: PR 병합과 Pages 공개 검증 후 실제 SHA·run 및 공개 캡처 결과를 후속 종료 기록에 기입한다. 이 파일의 로컬 검증 결과를 미래 병합 완료로 취급하지 않는다.
