# W-20260926-013 — Samsung 16개 제품 상세페이지 전환 기록

## 대상 및 방법

W-20260926-012 완료 후 다음 최소 브랜드인 Samsung(16개: 호텔 TV 3, 사이니지 8, 비디오월 2, KQ75LSF03WFXKR 1, Flip Pro 2)을 대상으로 진행했다. 조사는 배경 에이전트 1개에 위임했고(레포 파일 직접 수정 금지, 스크래치패드에만 출력), 결과를 이 세션에서 검증·통합했다.

## 핵심 발견: AJAX 게이트 사양표

samsung.com/sec 비즈니스 제품 페이지 대부분은 상세 사양표를 `/sec/business/xhr/goods/goodsSpec` 엔드포인트를 통한 AJAX 호출로 로드한다. 에이전트가 페이지 JS에서 정확한 엔드포인트·파라미터(goodsId, goodsTpCd)·쿠키를 추적해 GET/POST 여러 조합으로 직접 호출을 시도했으나 전부 HTTP 500을 반환했다(인증/세션 요구로 추정). samsungsvc.co.kr(카탈로그의 기존 manual_link)도 모든 제품에서 "다운로드 컨텐츠가 없습니다"로 비어 있음을 확인했다.

이 때문에 15개 제품(KQ75LSF03WFXKR 제외)은 페이지에 서버 렌더링되어 노출된 마케팅 사양 텍스트(밝기 nit, 두께 mm, 무게 kg, 베젤폭, HDMI/USB 포트 수 등)만 반영했고, 해상도·명암비 등 AJAX 사양표에만 있는 값은 임의로 채우지 않고 이슈로 남겼다.

**예외**: KQ75LSF03WFXKR은 B2B 페이지가 아니라 `samsung.com/sec/support/model/` 소비자 지원 페이지에서 서버 렌더링된 완전한 사양표(해상도, HDR, 치수, 무게, 전력, HDMI/USB/LAN/RS-232 포트 등 28개 사양·6개 I/O)를 확보했다 — 이번 배치에서 가장 상세한 항목이다.

## 카탈로그 링크 불일치·모델 정체성 발견

- **LH85QMCEBGCXKR, LH98QECEDGCXKR, LH43QHCEBGCXKR**: 카탈로그의 official_links가 samsungsvc.co.kr만 가리키고 있어 samsung.com 공식 제품 페이지가 없는 줄 알았으나, 에이전트가 각각 `.../qmc-series/`, `.../qec-series-d/`, `.../qhc-series/` 경로로 실제 제품 페이지를 찾아냈다.
- **KQ75LSF03WFXKR**: 카탈로그가 홍콩 사이트(hk_en) 링크만 갖고 있었고 실제로 접근하면 403이었다. 조사 결과 이 모델은 2025년형 **"The Frame Pro"**(소비자용 Neo QLED TV)임을 확인했다 — 카탈로그 카테고리("Display")와 실제 제품 성격(사이니지가 아닌 소비자 TV)이 다를 수 있어 이슈로 기록하고, 카탈로그 필드 자체는 임의로 고치지 않았다.

## 호텔 TV 3종의 데이터 한계

HG43/50/65U800FNFXKR(HU8000F 시리즈)은 호스피탈리티 기능(Link Cloud, SmartThings Pro, 멀티코드 IR 리모컨, Knox, TEP) 설명은 충실했으나, 해상도·명암비·무게 등 일반적인 디스플레이 정량 사양이 페이지 어디에도 노출되어 있지 않았다. 추정하지 않고 정보 없음으로 유지했다.

## 이미지

16개 전부 Samsung 공식 이미지 CDN(`images.samsung.com/kdp/goods/...`)에서 `$Q90_1920_1280_F_PNG$`(최고 해상도 옵션) 사이즈로 1920×1280 이미지를 확보했다. 각 페이지의 og:image/갤러리 "정면" 이미지와 정확히 일치함을 확인했다.

## 코드 변경

- `beta/group1-images.mjs`: 16개 슬러그 신규 항목(group1Images, cardImages) 추가.
- `beta/site/catalog.json`: 16개 항목에 slug·card_image 필드 추가.
- `beta/site/detail/data/*.json`: 16개 신규 파일.
- `beta/manufacturer-hosts.mjs`: 변경 없음(기존 `samsung.com` 허용 규칙이 `images.samsung.com`을 커버).

## 검증

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test` 전부 통과. verify-pages.mjs는 254 items, 154 details, 176 검증된 공식 WebP 이미지로 통과했고, npm test는 100개 중 99 pass·1 skip·0 fail로 기존과 동일한 결과를 유지했다.

## 남은 일

- LH85QMCEBGCXKR/LH98QECEDGCXKR/LH43QHCEBGCXKR의 official_links 필드 갱신 여부 확인.
- 다음 최소 브랜드로 계속 진행 예정(JBL 16개, Powersoft 17개 등).
