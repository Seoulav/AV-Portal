## 규칙과 해석

### Midra 4K — Pulse 4K / Eikos 4K

- User Manual 인쇄 42쪽: “One single output Program Screen with a format up to 4096 x 2160 @60Hz.” 모델별 레이어 상한은 각 제품 데이터시트가 구체화하므로 모델별 시트의 숫자를 사용했다.
- Pulse 4K 데이터시트 5쪽: Mixer는 1개 4K60 PGM과 화면당 믹싱 2개 또는 분할 4개, Matrix는 독립 PGM 2개와 각각 믹싱 1개 또는 분할 2개다. 모델 전체 합계는 두 모드 모두 믹싱 2개 또는 분할 4개다. Mixer 모드 Aux는 최대 1080p60 1개다.
- Eikos 4K 데이터시트 6쪽은 Mixer·Matrix 수치가 Pulse와 같다. 추가 Hard/Soft Edge 모드는 “One Program Screen using two outputs with a total resolution up to 2x 4096 x 2160 @60Hz.”이며 한 화면을 두 출력으로 블렌딩한다. 이 모드도 믹싱 2개 또는 분할 4개다. 두 출력이 독립 화면 2개라는 뜻으로 해석하지 않았다.
- Midra User Manual 인쇄 44쪽: “This layer mode consumes half the processing resources compared to mixing layers and doubles the number of layers available on Screen.” 따라서 분할은 해당 모델·모드의 믹싱 수를 두 배로 표현했다. 배경·전경 이미지는 라이브 레이어 수에 더하지 않았다.
- 공용 매뉴얼의 “up to four Live layers”와 모델별 데이터시트의 mixing/split 구분은 충돌로 보지 않았다. 모델별 데이터시트가 각 운영 모드의 믹싱/분할 레이어 수를 특정하므로 화면에는 모드별 값을 표시한다.

### Alta 4K — Zenith 100 / Zenith 200

- Alta 4K User Manual 인쇄 25쪽 표는 “4K layers in total”을 Zenith 100은 3 ML 또는 6 SL, Zenith 200은 4 ML 또는 8 SL로 제시한다(ML=Mixing Layer, SL=Split Layer).
- 인쇄 42쪽: “Three Layer resources can be allocated to four different outputs.” / “Four Layer resources can be allocated to six different outputs.” 그리고 “One Layer resource = one Mixing layer or one pair of Split layers allocated to a Screen.” 이 값은 화면별 고정 수가 아니라 장비 전체 레이어 자원 풀이다.
- 인쇄 43쪽은 “all possible examples using Mixing layers”라며 출력들 사이에 레이어 자원을 분배하는 구성을 보여 준다. 전체 자원을 한 화면에 배정하면 Zenith 100은 최대 3 믹싱(분할 6), Zenith 200은 최대 4 믹싱(분할 8)이다. 여러 화면에 배분할 때 화면별 레이어 수는 할당에 따라 달라지므로 “각 화면마다 3/4개”라고 쓰지 않았다.
- 모델 데이터시트 6쪽과 매뉴얼 25쪽의 Max Program Screen outputs는 Zenith 100 최대 3, Zenith 200 최대 4다. 이 값은 독립 화면뿐 아니라 다중 출력 와이드스크린 구성도 포함할 수 있으므로 카드에서 “PGM 출력 구성 최대”라고 표현했다. 남는 출력은 Zenith 100 최대 Aux 2개, Zenith 200 최대 Aux 4개(최대 1080p60).
- 매뉴얼 46쪽은 배경·라이브·전경·Aux 레이어를 구분하고, 분할 모드가 믹싱보다 자원을 절반 쓰고 화면 레이어 수를 두 배로 한다고 설명한다.

## 확인되지 않은 점

- 다중 출력 와이드스크린에서 하나의 레이어가 추가로 소비하는 자원 배수: 두 계열 자료에 계산식이 없어 미확인.
- 1080p Aux의 라이브 레이어 최대 수 및 4K/HD 혼합 시 레이어 자원 비용: 공식 자료에 명시되지 않아 미확인.
- 별도 PiP 자원 풀 또는 화면 전체 레이어 수를 넘어서는 추가 PiP 수: 문서가 별도 수치를 제시하지 않는다. 해설은 라이브 레이어 수로 한정하고 PiP 수를 더하지 않는다.

## 비교 자료

- `beta/site/rtcom/raw/products/xdm.json`, `lineup.XDM-WOS100.io[0]`가 기록한 출력 4개 및 원문 조건을 그대로 인용했다. 원본은 해당 제품의 최대 레이어 개수를 말하지 않으므로 레이어 숫자를 만들지 않았다.
- Aquilon 비교는 W-010의 매뉴얼 v6.2 해석(2×2 4K60 화면당 믹싱 4개·분할 8개)을 재인용했다. 이는 Midra·Alta와 별도 계열 근거다.
