## 규칙과 해석

### Midra 4K — Pulse 4K / Eikos 4K

- User Manual 인쇄 42쪽: “One single output Program Screen with a format up to 4096 x 2160 @60Hz.” 모델별 레이어 상한은 각 제품 데이터시트가 구체화하므로 모델별 시트의 숫자를 사용했다.
- Pulse 4K 데이터시트 5쪽: Mixer는 1개 4K60 PGM과 화면당 믹싱 2개 또는 분할 4개, Matrix는 독립 PGM 2개와 각각 믹싱 1개 또는 분할 2개다. 모델 전체 합계는 두 모드 모두 믹싱 2개 또는 분할 4개다. Mixer 모드 Aux는 최대 1080p60 1개다.
- Eikos 4K 데이터시트 6쪽은 Mixer·Matrix 수치가 Pulse와 같고, Hard/Soft Edge는 두 출력으로 한 블렌딩 화면을 구성한다. 화면 용어와 출력 해상도 경계는 **Midra User Manual 인쇄 42쪽**의 “One single output Program Screen with a format up to 4096 x 2160 @60Hz.”와 함께 해석한다. 두 출력을 독립 화면 2개로 계산하지 않는다.
- Midra User Manual 인쇄 44쪽: “This layer mode consumes half the processing resources compared to mixing layers and doubles the number of layers available on Screen.” 따라서 분할은 믹싱의 절반 자원으로 레이어 수를 두 배 구성한다. 같은 쪽은 “An Aux. Screen has only one unscalable layer…”라고 설명하므로 1080p Aux에는 크기를 바꿀 수 없는 레이어 1개가 있다.
- 배경은 라이브 입력 또는 이미지로 구성할 수 있다(Midra User Manual 인쇄 25쪽: “The Pulse 4K and the Eikos 4K can use Images or Live Inputs as Background content.”). 라이브 화면마다 배경 레이어 1개와 전경 레이어 1개가 따로 있다(Alta 4K User Manual 인쇄 46쪽: “A live Screen always has one background layer and one foreground layer”). Zenith 데이터시트 1쪽도 “Background layer live or still image”로 적는다. 따라서 표의 믹싱/분할 수는 배경·전경과 별도로 표시한다.
- 공용 매뉴얼의 “up to four Live layers”와 모델별 데이터시트의 mixing/split 구분은 충돌로 보지 않았다. 모델별 데이터시트가 각 운영 모드의 믹싱/분할 레이어 수를 특정하므로 화면에는 모드별 값을 표시한다.

### Alta 4K — Zenith 100 / Zenith 200

- Alta 4K User Manual 인쇄 25쪽 표는 “4K layers in total”을 Zenith 100은 3 ML 또는 6 SL, Zenith 200은 4 ML 또는 8 SL로 제시한다(ML=Mixing Layer, SL=Split Layer).
- 인쇄 42쪽: “Three Layer resources can be allocated to four different outputs.” / “Four Layer resources can be allocated to six different outputs.” 그리고 “One Layer resource = one Mixing layer or one pair of Split layers allocated to a Screen.” 이 값은 화면별 고정 수가 아니라 장비 전체 레이어 자원 풀이다.
- 인쇄 42쪽은 “One Layer resource = one Mixing layer or one pair of Split layers allocated to a Screen.”이라고 정의한다. 43쪽의 출력별 배분 표에 따라 최대 화면 수일 때 화면당 1 믹싱(분할 2), 한 화면으로 쓸 때 Zenith 100은 3(6), Zenith 200은 4(8)로 나눠 표기한다. 가능한 배분 예도 표에 맞춰 표시한다. 여러 출력을 한 화면으로 묶어도 화면에 배정된 자원 수를 사용한다. 다만 레이어가 출력 경계를 넘을 때 별도 자원이 추가되는 산식은 매뉴얼에 없어 미확인이다.
- 화면 최대 수는 Alta 4K 매뉴얼 50쪽 표에 따르고, 2×2 격자 출력은 52쪽에 명시된 지원 구성을 따른다. Zenith 200은 출력 4개를 한 화면에 묶어 2×2를 만들 수 있고, Zenith 100은 PGM 출력 최대 3개라 2×2 출력 4개를 만들 수 없다.
- 최대 화면 수로 구성할 때 보조 출력(Aux)은 Zenith 100 1개, Zenith 200 2개다(Alta 4K 매뉴얼 43쪽 배분 표). Alta의 보조 출력은 레이어 자원을 쓰지 않는 구성이다(인쇄 42·46쪽: “Up to two outputs without layer resources can be used as Aux.”). 모델의 가능한 전체 Aux 최대와 최대 화면 동시 구성의 Aux 수를 혼동하지 않는다.
- Alta User Manual 인쇄 46쪽은 라이브 화면의 배경·전경 레이어와 Aux 출력을 구분한다. 화면 안 작은 창(PiP)은 별도 레이어 수를 더하지 않는다.

## 확인되지 않은 점

- 하나의 라이브 레이어가 출력 경계를 넘을 때 추가 자원이 필요한지: 공식 자료에 산식이 없어 미확인.
- 4K와 HD 레이어를 섞을 때 추가 레이어 자원 비용: 공식 자료에 산식이 없어 미확인.
- 별도 PiP 자원 풀 또는 화면 전체 레이어 수를 넘어서는 추가 PiP 수: 문서가 별도 수치를 제시하지 않는다. 해설은 라이브 레이어 수로 한정하고 PiP 수를 더하지 않는다.
