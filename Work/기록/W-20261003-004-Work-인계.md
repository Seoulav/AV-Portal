## 완료 범위

호텔 TV `HG43U800FNFXKR`·`HG50U800FNFXKR`·`HG65U800FNFXKR`의 03 연결 단자에 HDMI 입력 3개(3번 eARC), DATA, VOL-CTRL, VARIABLE을 추가했다. 각 제품은 **9→13행**이며 `io` 내용이 동일하다. RF 입력은 방식별 `1/1/0` 표기에서 물리 단자 수 `2`로 정정하고 위성 미지원 사실을 보존했다. LAN-Out 수량 1, USB 전류 정보, 한글 매뉴얼 출처를 반영했다. HDMI 누락 이슈도 수량 확인으로 갱신하되 버전은 미확인으로 남겼다.

13쪽은 U800F/U700F 공통 범례다. 12쪽 U800F 도면에 없는 HP-ID·HEADPHONE JACK·SERVICE 세 단자는 사용자 재확인에 따라 **추가하지 않았다**. Work 명세의 “7행 추가”는 “4행 추가”가 맞다. 매뉴얼 11쪽은 RJ12를 DATA 케이블 규격으로 언급한다. 별도 RJ12 TV 포트는 확인되지 않아 기존 행을 유지하고 `REVIEW REQUIRED`로 낮췄다.

## 검증과 후속

전용 검사 RED(1 pass / 1 fail) → GREEN(2 pass / 0 fail). 착수 기준 전체 검사 **217 tests / 216 pass / 0 fail / 기존 skip 1**, Pages **249·242·370·업로드 22**였다. 최종 **219 tests / 218 pass / 0 fail / 기존 skip 1**, Pages **249·242·370·업로드 22**, 검색 인덱스 `--check` 통과, 읽기용 카탈로그 생성 완료. [로컬 6화면](W-20261003-004-screens/local-check.json)은 3종 × 1280px·390px에서 HDMI 첫 카드·총 13개, 오류·가로 넘침·깨진 이미지 0건이다. `specifications`와 보호 필드는 SHA-256으로, 호텔 TV 외 상세 JSON은 전체 집계 SHA-256으로 불변을 확인했다. 검색 인덱스는 `sourceSha256` 및 대상 3종 검색 항목만 달라졌다.

Work의 다음 자료 과제: RJ12가 DATA와 동일 물리 단자인지 제조사 단자 사양이나 실물로 확인하고, HDMI 버전도 별도 자료에서 확인한다. U700F 5종을 나중에 등록한다면 U700F 전용 도면을 사용해야 한다. 확인되지 않은 호텔 TV 사양 7행, 한글 매뉴얼 뷰어 게시, 다른 제품의 영상 입력 누락 점검은 별도 범위다. 원본 PDF는 로컬 사용자 제공 자료로 이 PR에 포함하지 않았다.
