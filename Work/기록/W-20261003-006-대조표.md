## 후면 단자 13·14쪽

| 기존/신규 행 | 처리 | 주의 |
|---|---|---|
| `HDMI 출력`·`HDMI` 입력·`오디오 출력` | 후면 각 1개, VERIFIED | 75인치 `HDMI` 기존 2→1은 **후면 수량** 정정 |
| `RJ45(LAN)` | 1개, `10/100 Mbps · CAT 7(STP) 케이블 권장`, VERIFIED | 매뉴얼의 LAN 표·각주 |
| `USB` | 기존 전체/옵션 트레이 수량 표기 보존, `후면 USB 허용 전류 최대 1.0 A` 추가 | 후면 1개 확정이 기존 전면·옵션 트레이 수량 부정은 아님 |
| `SERVICE` | 신규 1개, Control/IN, 서비스 전용·연결 주의, VERIFIED | 별도 기능이 없다는 매뉴얼 설명 그대로 |
| `TOUCH` | 신규 1개, Data/OUT, PC 터치 제어·USB 케이블 연결, VERIFIED | HDMI·DP 입력 PC 화면의 터치 전달 경로 |
| `USB-C 허브`·`RS-232C 입력` | **삭제하지 않음**. REVIEW REQUIRED와 `매뉴얼 후면 단자표에 없음 · 전면/옵션 트레이 여부 미확인` | 14쪽 표 제목이 「후면 단자」이므로 제품 전체 부재는 확정할 수 없음 |

두 제품의 I/O는 **7→9행**이다. 55인치는 확인 필요 **4→2행**, 75인치는 **0→2행**이다. HDMI 입력 카드의 `signal`은 `후면 비디오/오디오 입력`으로 범위를 드러낸다. 55인치 기존 `HDMI 2.0`·`HDCP 2.2` 표기와 오디오 출력의 `스테레오 미니 잭` 형상은 매뉴얼 13쪽이 확인하지 않으므로 VERIFIED 행의 `availability`에서 빼고 `WMFX-IO-DETAILS` REVIEW REQUIRED 이슈에 원문을 보존했다. 수량 1은 후면 수량이며 제품 전체 수량을 뜻하지 않는다.

75인치 제품 페이지 `P`의 HDMI 입력 **2개**와 매뉴얼 `M1` 14쪽의 후면 HDMI 입력 **1개**를 `HDMI-REAR-COUNT` 이슈에 양쪽 보존했다. 데이터의 수량은 매뉴얼의 후면 1개로 정정했고, 나머지 1개가 전면인지 여부는 확인되지 않아 이슈는 REVIEW REQUIRED다. 이를 제품 전체에 HDMI가 1개뿐이라는 단정으로 읽지 않는다.

독립 리뷰에서 후면 수량이 카드에서 제품 전체 수량처럼 읽힐 위험과 55인치의 미확인 세부 규격이 VERIFIED 행에 남은 점을 Important 1건으로 지적했다. 위 범위 표기와 이슈 분리로 처리했고, 전용 검사에 두 조건을 고정했다.
