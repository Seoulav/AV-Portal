# W-20261012-011 — VS ENT DS-8S 근거표

## 모델·분류

사용자 제공 리플렛 한 장에 `DS-8S` 모델명과 VS ENT 로고가 함께 인쇄돼 있다. 제조사 [공식 DS-8S 제품 페이지](http://www.vsent.co.kr/bbs/board.php?bo_table=c4&wr_id=14)도 같은 모델명과 공개 리플렛을 싣는다. 제조사 사이트는 2026-10-12 현재 HTTPS로 열리지 않아, 사용자 확인을 받은 해당 제품 주소 한 개만 HTTP 공식 링크 예외로 등록했다. 다른 제조사 URL의 HTTPS 제한은 유지한다. 분류는 기존 SurgeX 전원 제어 제품을 따라 `제어 / Control / Power Conditioner`로 두었다.

## AC 출력 충돌과 입력 근거

리플렛 본문은 연동 8개·비연동 1개를 각각 `2200W`라 쓴다. 같은 리플렛 사양표는 `채널당 2500W (AC 220V 10A)`라 쓴다. 별도 동일 모델 사양서는 `CH 2200W (AC220V 10A) MAX. 2500W`를 함께 적어 정격/최대 해석의 단서를 주지만, 리플렛 표의 표기를 대신 고치지 않는다. 제품 사양의 AC 출력 행에 `2200 / 2500 W/채널`, `CONFLICTED`와 두 원문을 함께 남겼다. 계산으로 단일 값을 만들지 않았다.

`io`는 리플렛의 연동 AC 아울렛 8, 비연동 AC 아울렛 1, 비연동 DC 24V/500mA 출력, RJ-45 RS-485 링크, REMOTE 무접점, DC 5V 모니터 단자만 등록했다. 리플렛이 수량을 명시하지 않은 뒤의 세 단자는 `quantity`를 비웠고, 커넥터 형상을 추측하지 않았다. 제품의 후면 사진·Port Map은 등록하지 않았다.

## 화면·검증 기준

제품 상세는 `CONFLICTED` 배지를 AC 출력 칸에 표시하고, 전면 사진은 리플렛의 실제 DS-8S다. `2026-10-12` 로컬 1280px 및 CSS 390px 화면을 렌더해 사진·사양·문서 카드가 표시되는 것을 확인했다. PDF.js 뷰어를 실제 브라우저에서 열어 리플렛 `/ 1`(첫 캔버스 1000×1444), AMX 설명서 `/ 4`(첫 캔버스 1000×1413)의 본문 렌더와 내려받기 링크 활성화를 확인했다. 업로드 URL을 다시 받아 원본과 SHA-256이 같은 것도 확인했다. 역사 검사 입력에서는 이 작업으로 새로 생긴 제품 1건·업로드 2건만 제외해 이전 해시 기대값을 유지한다. DS-8S 전용 검사는 현재의 제조사·모델·충돌 행·입출력·비잠금 자료와 잠금 12건을 직접 검사한다.
