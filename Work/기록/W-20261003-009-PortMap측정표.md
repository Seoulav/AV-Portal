# W-20261003-009 Crown DCi N Port Map 측정표

기준: `origin/main` `e0b0297e3f91878140e8e6417e19b8a472499be7`. 네 제품의 `Rear` 이미지와 테크데이타 제공 DCi Network Series 한글 사용설명서(SHA-256 `7795eb2db600…`, 65쪽)를 직접 대조했다. 매뉴얼 표지 1쪽에 `DCi 2|300N`, `2|600N`, `4|300N`, `4|600N`이 모두 나온다. 6쪽 후면 그림은 **8채널 예시**이므로 단자 역할의 근거로만 썼고, 2·4채널 단자 위치는 각각 해당 모델의 공개 Rear 사진에서 측정했다. 7쪽은 입출력 배선, 8쪽은 HiQnet/BLU link 역할, 52쪽은 모델별 출력 W, 53쪽은 성능·전원 사양 근거다. 마커별 쪽 번호와 좌표는 [근거 JSON](W-20261003-009-evidence.json)의 `products[].markers`에 기록했다.

| 모델 | Rear SHA-256 앞 12자 | 게시 크기 | 마커 | 출력 설명 근거 |
|---|---|---:|---:|---|
| `dci-2-300n` | `5d994d5b347c` | 2000×546 | 10 | 기존 4Ω 행 300 W/채널, 매뉴얼 52쪽 |
| `dci-2-600n` | `5d994d5b347c` | 2000×546 | 10 | 기존 4Ω 행 600 W/채널, 매뉴얼 52쪽 |
| `dci-4-300n` | `29ce707c6626` | 2000×544 | 12 | 기존 4Ω 행 300 W/채널, 매뉴얼 52쪽 |
| `dci-4-600n` | `29ce707c6626` | 2000×544 | 12 | 기존 4Ω 행 600 W/채널, 매뉴얼 52쪽 |

동일 채널 수의 두 Rear 사진은 SHA-256까지 같다. 2채널 좌표군은 아날로그 입력 1·2, 스피커 출력 1·2, GPIO, Ethernet, BLU link IN/OUT, 입력 감쇠 1·2, AUX, 퓨즈, AC 전원으로 구성했다. 4채널은 입력·출력을 물리적으로 분리된 3·4 및 1·2 블록별로 번호를 붙이고 입력 감쇠 노브 네 개를 하나로 묶었다. 모두 채널별 번호를 과하게 늘리지 않았다. 출력 W만 제품별로 다르고 연결 역할과 좌표는 채널 수별로 동일하다. 새 이미지 파일은 없다.

`validMap` 허용 키, 연속 번호, 좌표 범위, `measuredImage`의 파일명·폭·높이와 `images[].resolution` 일치를 전용 검사와 `prepareEnhancements()`로 확인했다. [로컬 캡처](W-20261003-009-screens/)는 4종 × 1280px·390px이며 390px 오른쪽 스크롤 캡처도 별도로 있다. [자동 화면 결과](W-20261003-009-screens/local-check.json): HTTP 200 8/8, 마커와 목록 10/12개 표시 8/8, 번호 박스 교차 0, 본문 가로 넘침 0, JS 오류 0. 모바일에서는 사진 내부를 좌우로 스크롤하며 전 영역의 번호를 볼 수 있다.
