# W-20261004-022 삼성 제품군 정렬 근거

기준 `origin/main` `d422accc64e53774dbac37a81c03cf7195276019`. 공개 카탈로그 249종 중 삼성 17종, 그 외 232종이다. 명세의 “다른 225종”은 상세 JSON 242종을 기준으로 한 숫자이며, 목록 정렬 회귀는 비삼성 카탈로그 **232종 전체**를 대조했다.

카탈로그의 선택 필드 `brandSort: { group, order, size }`로 제품군 이름, 그룹 순위, 그룹 안의 크기를 기록했다. 브랜드 이름을 정렬 코드에 넣지 않아 다음 브랜드에도 같은 필드를 쓸 수 있다. 필드가 없는 제품은 기존 제품명 정렬을 사용한다. LED는 사용자가 지정한 일곱 그룹에 없지만 포털의 기존 제품이므로 명세대로 끝에 놓았다. 사용자가 다른 위치를 정하면 `order`만 바꾸면 된다.

수정 전 전용 검사: **3 tests / 2 pass / 1 fail**(삼성 순서). 수정 후 **3/3 pass**. `git show origin/main:beta/site/catalog.json`과 현재 파일을 항목별로 대조한 결과 249종 중 삼성 17종에 `brandSort`만 추가됐고 비삼성 232종은 기존 필드 전체가 같다. 기존 정렬 함수와 새 정렬 함수의 비삼성 232개 slug 배열도 완전히 같았다. `sort=product`·`sort=relevance`·QMC 검색·Digital Signage 분류 결과가 정렬 필드 없는 목록과 같았다. 검색 인덱스의 `items` SHA-256은 `c8d1fbd238ad891276c5c326eaf2662476963fcfcacb4ca4ceacfed664f356f1`로 전후 동일하며 `catalogSha256`·`catalogSetSha256`·`sourceSha256`만 갱신됐다.
