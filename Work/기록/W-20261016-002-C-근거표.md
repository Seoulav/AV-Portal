# W-20261016-002 · U-BRIDGE 3 차폐 케이블 근거

## 승인과 출처

- 사용자 확인(2026-10-16): “U-BRIDGE 3는 반드시 U/FTP CAT6A 이상 S/FTP 케이블을 사용해야 해”. 제품 사양의 신규 출처 코드는 `U`이며, 검증 상태는 `FOUND`다.
- [INOGENI 공식 U-BRIDGE 3 제품 페이지](https://inogeni.com/product/u-bridge-3-0/)는 한 가닥의 CAT6A U/FTP 링크와 INO-CAT6A 케이블 **권장**을 안내한다. 제조사가 모든 차폐 케이블을 의무화했다고 표현하지 않는다.
- 사용자 확인 조건은 공식 페이지의 권장 제품명과 충돌하지 않는 **강화된 설치 조건**이다. 따라서 케이블 브랜드를 필수 조건으로 쓰지 않고 CAT6A U/FTP 이상 차폐형(U/FTP·S/FTP) 필수, 비차폐 UTP 사용 불가로 표시한다.

## 반영 위치와 불변 사항

| 위치 | 반영 |

| 제품 전용 시그널 플로우 렌더 | 기존 고정 문구였던 U-BRIDGE 케이블 알약을 해당 시나리오 데이터의 caption으로 표시 |

기존 CAT6A U/FTP 한 가닥, 최대 100m, USB 3.0, 24V·PoC 경로, 각 모듈 단자와 다른 제품의 데이터는 유지했다. 케이블 알약을 데이터와 일치시키는 변경은 이 제품 전용 그림 경로에 한정했다. 제품 JSON과 렌더러의 선택적 되감기 함수는 직전 커밋의 SHA-256을 각각 재현한다.
