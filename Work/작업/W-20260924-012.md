## 목표

현재 공개된 Group 1 제품 상세 5개를 사용자가 제공한 TechDataPS 모바일 화면의 **정보 순서와 밀도**에 맞춘다. 제품명과 제조사를 즉시 읽고, 확인된 사진이 공개 가능한 경우에만 큰 갤러리를 제품 앞에 둔다. 설명 다음에는 매뉴얼·시방서·사양서·기술문서 4칸을 2×2로 표시한다. 그 아래 특징과 사양을 간결하게 탐색한다. AV Portal의 I/O·문서·출처·검증 상태는 계속 접근 가능해야 한다.

## 구현 범위

- 공통 상세 렌더러의 HTML/CSS와 필요한 최소 JS만 변경한다. 5개 제품 모두 동일 UI를 사용한다.
- 모바일 390px에서 제품 이미지 0장일 때 큰 빈 갤러리 공간 대신 제품명 → 제조사 → 영문·한글 설명 → 문서 2×2를 먼저 보여준다. 이미지 미게시와 권한 미확인 상태는 짧은 안내·공식 출처 링크로 남긴다.
- 이미지가 실제 사용 가능한 로컬 프로토타입에서는 큰 이미지·역할 전환·확대 동작을 유지하고 제품명 앞에 배치한다. 다른 모델 사진이나 가짜 URL은 쓰지 않는다.
- 밝은 카드의 장식과 과한 간격을 줄이고, 참고 화면의 다크 톤·단순 구분선·밑줄형 섹션 탐색·단일 특징 목록을 참고한다. TechDataPS 로고·배너·사진·문구·푸터를 복제하지 않는다.
- Overview/Features/Specifications/I/O/Documents/Sources 데이터와 상태는 유지한다. 본문은 특징·사양을 주로 읽되 다른 엔지니어링 정보를 명확한 링크로 찾을 수 있게 한다. 기존 `#io`·`#source-*` 직접 진입과 활성 섹션 표시는 유지한다.
- `prototype/brc-am7/` 원본과 `beta/site/detail/` 공개 파일을 함께 갱신한다. 공개 상세 5개 JSON, Library catalog와 검색·필터, `verify-pages.mjs`의 공개 경계 규칙은 변경하지 않는다.
