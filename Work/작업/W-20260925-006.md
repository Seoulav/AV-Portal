## 목표

JavaScript를 실행하지 않는 GPT·검색 도구도 AV Portal의 공개 범위를 읽을 수 있도록 정적 HTML 카탈로그와 LLM용 텍스트 파일을 제공한다. 기존 화면, 검색, 공개 제품 범위와 상세 데이터는 변경하지 않는다.

## 범위

- `beta/site/catalog.html`: 공개 `catalog.json`의 27개 제품을 제조사·제품명·분류·종류·공식 링크로 정적 렌더링한다.
- `beta/site/llms.txt`: 사이트 설명, 공개 범위, 카탈로그와 Group 1 상세 URL을 UTF-8 평문으로 제공한다.
- 홈 `<head>`에 canonical, robots, `llms.txt` discovery 링크를 추가하고 본문에 텍스트 카탈로그 다운로드 링크를 표시한다.
- Pages 아티팩트 고정 목록·누출 검사와 자동 테스트를 갱신한다.
- main 병합 후 기존 Pages workflow로 배포하고 두 공개 URL의 HTTP 200, MIME, 다운로드·내용을 검증한다.

## 제한

- 공개 `catalog.json` 27개와 상세 JSON 5개의 값·수량을 변경하지 않는다.
- 비공개 Excel, 업체 정보, 내부 메모, 로컬 경로, Work 문서 내용을 공개 파일에 넣지 않는다.
- 새 제품·새 공식 링크·기술 사양을 추가하지 않는다.
- 최종 Schema·DB·Storage를 정하지 않는다.
