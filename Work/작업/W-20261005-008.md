## ★ Work가 사진 존재를 7종 전부 확인했다 — 있나 없나는 다시 묻지 마라

[W-20261004-004](W-20261004-004.md) 미결 사항에 **"AMX 7종도 후면이 없다. 같은 방법이 통하는지 확인하지 않았다"**고 적어 뒀다. **오늘 확인했고 통한다.**

AMX는 하만 계열이라 **BSS와 같은 공식 이미지 서버**를 쓴다. 지금 7종의 `Main` 사진도 거기서 받은 것이다.

**새 절차가 아니다. 같은 절차를 7종에 더 적용하는 것이다.**

## NX 3종 — Port Map까지 간다

### 단자 이름·자리의 근거가 이미 저장소에 있다

[W-20261003-008 대조표](../기록/W-20261003-008-대조표.md) 73행에 Codex 본인이 적어 뒀다.

> 도면 `95-2106-01/02/03` 각 1쪽은 **각 제품의 Rear View와 단자 배치·라벨을 포함**한다.

이 세 파일은 **이미 게시돼 있다.**

```
manuals/amx-nx-1200-pictorial-drawing.pdf   (95-2106-01)
manuals/amx-nx-2200-pictorial-drawing.pdf   (95-2106-02)
manuals/amx-nx-3200-pictorial-drawing.pdf   (95-2106-03)
```

**도면으로 「무엇이 어디」를 정하고, 사진 위에 번호를 찍는다.**

### 번호는 `io` 행과 대응해야 한다

| 제품 | 현재 `io` |
|---|---:|
| NX-3200 | **9행** |
| NX-2200 | **9행** |
| NX-1200 | **8행** |

> **`io`에 없는 단자를 지어내지 마라.** 도면에 보이는데 `io`에 없으면 **번호를 달지 말고 보고**하라.
>
> **`io`에 있는데 사진에서 자리를 못 찾으면 그 행은 번호를 비운다.** 억지로 끼우지 마라.

`io`를 이번에 고치지 않는다. **대응표만 보고**하라.

### 모양은 BSS를 그대로 따른다

`blu-101`이 본보기다. **기존 `Main`을 지우지 않고 `Rear`를 더하는** 방식이다.

```json
"images": [ { "role": "Main", … }, { "role": "Rear", … } ],
"portMap": { "image": "Rear", "measuredImage": { "file": …, "width": …, "height": … }, "items": [ … ] }
```

| | |
|---|---|
| `portMap.image` | **`"Rear"`** — `validMap`은 `Front`·`Rear`·`Diagram`만 받는다 |
| `measuredImage` | **게시 해상도와 정확히 일치**해야 한다 |
| 각 항목 | `n`은 **1부터 빠짐없이** · `label`·`desc`·좌표·`side` |

### ★ 사진을 열어 모델명을 읽고 시작하라

[W-20261004-004](W-20261004-004.md)와 같은 게이트다.

> **후면 패널이 맞는지 눈으로 보고, 인쇄된 모델명을 읽어 제품과 일치함을 확인한다. 불일치하면 등록하지 않고 보고한다.**

NX는 후면에 모델명이 인쇄돼 있을 수도, 없을 수도 있다. **없으면 없다고 보고**하고, 도면의 Rear View와 **단자 구성이 일치**하는지로 대신 확인하라.

## VARIA 4종 — 사진만 여러 장

> 2026-10-05 사용자: **"VARIA시리즈는 측면 후면 사진 여러가지 추가해줘"**

### 몇 장을 넣나

**모델마다 확보되는 만큼 넣되, 역할이 겹치지 않게 하라.**

| 역할 | 쓸 것 |
|---|---|
| `Main` | **기존 것 그대로.** 바꾸지 마라 |
| `Rear` | 후면 1장 |
| 그 외 측면·각도 | **`validMap`이 쓰는 역할(`Front`·`Rear`·`Diagram`)과 충돌하지 않게** 하라 |

> **★ 여기서 멈추고 물어라.** 측면 사진에 **어떤 `role` 이름을 쓸지**는 Work가 정해 주지 않았다. 기존 저장소에 측면 사진을 가진 제품이 있으면 **그 이름을 그대로 따르고**, 없으면 **이름 후보를 들고 와서 물어라.** 역할 이름을 혼자 새로 만들지 마라. 상세 렌더러가 모르는 역할은 화면에 안 나온다.

### ★ 거치대에 올린 사진을 조심하라

VARIA-80·VARIA-100 쪽에는 **`ACS810A`·`ACS100F` 거치대에 장착한 사진**이 섞여 있고 이름에 **`Disclaimer`**가 붙어 있다.

| | |
|---|---|
| 쓸 것 | **제품 단독** 사진 (예: `08._AMX_VARIA80_Rear`) |
| 쓰지 말 것 | **거치대가 함께 찍힌 사진** |

거치대는 **우리가 팔지 않는 별도 제품**이다. 단독 사진이 없으면 **그 역할을 비우고 보고**하라.

## 보고에 포함할 것

1. **제품별 받은 사진 목록** — 역할·파일명·원본 해상도·게시 해상도·SHA-256·받은 주소

4. **도면에는 있는데 `io`에 없는 단자**가 있으면 그 목록 — **고치지 말고 보고만**
5. **거치대 사진을 걸러낸 내역**
6. **측면 사진에 쓴 역할 이름**과 그렇게 정한 근거
7. 현재 기준 수치 (장비·상세·WebP·uploads·잠금)
8. 7종 × 1280px·390px 화면. **번호가 사진을 가리지 않는지**
