## 목적과 승인 범위

사용자가 브랜드와 제품을 찾고 확보된 자료의 종류·검증 수준·원본 행을 볼 수 있는 첫 로컬 실행 앱을 만든다. 다음을 구현한다.

- 브랜드·제품명·별칭 통합 검색, 브랜드 필터, 복수 카테고리 필터. 한 제품의 여러 카테고리를 유지한다.
- 338개 고유 제품을 각 1회 표시하고 네 중복 묶음의 원본 행 8개를 포함한 342개 행 연결을 유지한다.
- 제품별 제조사 공식 URL과 지정 보조 출처 URL을 구분해 원본 사이트로 연결한다. URL의 존재를 자료 검증 완료나 정식 공개 준비 완료로 해석하지 않는다.
- 제조사 직접 제공 자료는 공개 파일 링크를 생성하지 않고 목록에 있는 참조 정보만 표시한다.
- 브랜드 미식별 4개와 자료 링크 미확보 상태를 명확히 표시한다. 세부 SKU·색상·주파수 대역·호환성 판단은 착수·탐색 조건이 아니다.
- Builder와 LED는 기존 외부 서비스 링크만 제공한다.

## 기존 명세와의 관계

W-20260922-002는 공식 추가 자료 및 구현 착수 조건 정리용 DRAFT로 유지한다. 이 작업은 사용자의 새로운 직접 승인에 따라 독립적인 최소 탐색 앱을 착수한다. 기존 인계의 제품 구현 보류는 **이번 화면과 로컬 목록 읽기 범위에서만** 해제된다. 최종 제품 Schema, DB, 영구 저장소, Migration, 기존 RTCOM Logic 변경, 제품 공개 판정, 자료 원본 재배포, 신규 제품 웹 조사는 승인되지 않았다. RTCOM 웹 검색은 하지 않는다. 한국 공식 자료 우선 및 공식·보조 출처 구분을 유지하고, 목록에 없는 언어·검증 사실은 추정하지 않는다. 네 제외 모델은 목록에 없으며 이후에도 활성 목록에 추가하지 않는다.

## 구현 방식과 이유

의존성 없는 Node.js 로컬 HTTP 서버가 실행 때 경로를 지정받아 JSON을 읽고 브라우저에 제공한다. 로컬 목록을 코드나 Git에 복제하지 않고, 현재 자료를 교체하여 확인할 수 있다. 브라우저는 검색·필터·상세 표시를 담당한다. 이는 첫 화면의 실행 방식이며 최종 Architecture/Schema/DB 결정이 아니다. 공개 HTTPS URL만 클릭 가능한 링크로 만들고, 원본 행·직접 제공 참조는 문자로만 표시한다. 자료 검증 상태 문자열을 그대로 보존한다. 실행 경로를 지정하지 않거나 목록이 없으면 명확한 오류를 보인다.
