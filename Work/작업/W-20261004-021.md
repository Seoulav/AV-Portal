## ★ 먼저 — 암호는 제대로 걸려 있다

Work가 **공개 배포본 3건을 직접 받아** 확인했다.

| 파일 | 크기 | 암호화 |
|---|---:|:--:|
| `samsung-lcd-signage-product-guide-ko.pdf` | 5,849,449 | **O** |
| `samsung-115qhf-spec-ko.pdf` | 350,860 | **O** |
| `samsung-videowall-product-guide-ko.pdf` | 2,618,281 | **O** |

**받아 간 파일은 비밀번호 없이 못 연다.** [W-20261004-012](W-20261004-012.md)의 AES-256이 작동한다. **내용은 새지 않았다.**

## 무엇이 문제인가 — 버튼이 안 묻는다

`pdf-viewer.mjs:224`

```js
download.href = file;
download.download = file.split('/').at(-1);
```

**창이 열리는 순간 내려받기 링크가 살아 있다.** 비밀번호를 묻기 **전**이다. `task.onPassword`는 **그 뒤**(`:243`)에 걸린다.

`app.js:152`에도 하나 더 있다.

```js
const download = element('a', 'pg-btn', labels.download);
download.href = action.file;
```

**상세 카드의 `↓ 내려받기`는 창을 열지도 않고 파일로 바로 간다.**

**두 곳 다 비밀번호를 안 묻는다.**

## ★★ 솔직히 — 이것은 UI 잠금이다

**파일은 공개 주소에 그대로 있다.**

```
https://seoulav.github.io/AV-Portal/manuals/samsung-lcd-signage-product-guide-ko.pdf
```

Work가 방금 `curl`로 받았다. **버튼을 잠가도 주소를 아는 사람은 그냥 받는다.** 정적 사이트라 서버에서 막을 방법이 없다.

**그래도 할 가치가 있다.**

| | |
|---|---|
| 막히는 것 | **사이트를 둘러보다 무심코 받아 쌓아 두는 것** |
| **안 막히는 것** | **주소를 직접 치는 것** |
| **진짜 보호** | **파일 자체의 AES-256.** 받아도 못 연다 |

**사용자에게 이 한계를 분명히 전한다.** 버튼을 잠갔다고 파일이 안전해지는 것이 아니다. 안전한 이유는 **암호가 걸려 있어서**다.

## 어떻게 묻게 하나 — 비밀번호를 저장소에 안 적고

**PDF.js가 이미 판정기다.** `onPassword` 콜백이 맞는지 틀린지 알려 준다. **우리가 비밀번호를 알 필요가 없다.**

```
보기 → 비밀번호 입력 → 열림 → 그제야 내려받기가 살아난다
```

1. 창이 열릴 때 **내려받기를 꺼 둔다**
2. `task.promise`가 **풀린 뒤에만** `download.href`를 건다
3. 상세 카드의 `↓`는 **잠긴 자료면 창을 연다.** 파일로 바로 가지 않는다

**비밀번호 문자열은 어디에도 안 적는다.** [W-20261004-012](W-20261004-012.md)와 같은 규칙이다. **저장소는 공개다.**

## 무엇이 잠긴 자료인지 어떻게 아나

`manifest.json`의 `uploads` 항목에 **`locked: true`**를 적는다.

```json
{ "slug": "lh115qhfebgxkr", "file": "manuals/samsung-lcd-signage-product-guide-ko.pdf",
  "kind": "reference", "title": "…", "locked": true }
```

**비밀이 아니다.** "이 파일은 암호가 걸려 있다"는 사실일 뿐이고, 받아 보면 바로 알 수 있다.

### 검사가 이것을 지킨다

`verify-pages.mjs`가 **PDF 파일을 열어** 대조한다.

| 적힘 | 실제 | |
|---|---|---|
| `locked: true` | 암호 있음 | **통과** |
| `locked` 없음 | 암호 없음 | **통과** |
| `locked: true` | **암호 없음** | **실패** |
| `locked` 없음 | **암호 있음** | **실패** |

**[W-20261004-012](W-20261004-012.md)에 이 검사가 없었다.** 평문으로 되돌려 놓아도 아무도 모른다. **이번에 넣는다.**

## 미결 사항

- **정적 사이트라 주소를 직접 치는 것은 못 막는다.** 진짜 막으려면 서버가 필요하고, GitHub Pages로는 안 된다. **진짜 보호는 파일의 암호다.**
- 비밀번호가 **작업 지시 대화에 적혔다.** [W-20261004-012](W-20261004-012.md)가 **한 번 바꾸기**를 권했고 아직 안 바꿨다.
- **Git 이력에 평문 원본이 남아 있다.** 사용자가 **"현재 상태로 둡니다"**로 정했다. [AGENTS.md](../../AGENTS.md) 자료 규칙이 재발을 막는다.
