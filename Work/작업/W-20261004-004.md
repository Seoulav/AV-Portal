## 사용자가 지목한 차이의 원인

`blu-101`과 `qms-88ux`를 대조했다.

| | AV Portal `blu-101` | 알티컴 `qms-88ux` |
|---|---|---|
| 사진 | **`Main` 1장** (4096×410) | `Front` · `Rear` · `Diagram` |
| `portMap` | **없음** | 있음 |
| `io` | **6행** | 3행 |
| `specifications` | **18행** | 10행 |
| `documents` | **5건** | 3건 |

**자료의 양은 `blu-101`이 오히려 많다.** 차이는 전부 **후면 사진 한 장**에서 온다.

Work가 `blu-101-main.webp`를 직접 열어 확인했다. **전면 패널이 맞다.** Soundweb London 로고와 입력 A·B·C, 출력 D·E의 LED만 있고 **단자가 하나도 없다.** `io` 6행의 Phoenix 단자는 후면에 있는데 그 사진이 없었다.

## 자료를 확보했다

`bssaudio.com` 제품 페이지에서 후면 사진 주소를 찾아 **제조사 공식 이미지 서버**에서 받았다.

```
bssaudio.com/en-US/products/<model>  →  adn.harmanpro.com/product_attachments/…_x_large_2x.webp
```

원본 주소는 인계서에 적는다.

### 이 방법은 이미 쓰던 방법이다

`blu-50v2`의 기존 `Rear`가 **같은 경로에서 왔다.**

```json
"sourceUrl": "https://adn.harmanpro.com/…/11573_1728954901/BSS_BLU-50_V2_Rear_%281%29_x_large_2x.webp",
"originalSize": "4096x1354", "resolution": "2000x394"
```

**새 절차가 아니라 같은 절차를 4종에 더 적용하는 것이다.**

## ★ `blu-50v2`는 제외한다

`blu-50v2`는 **이미 `Rear` 2000×394와 `portMap` 8개를 갖고 있다.** 후면 사진을 받아 두긴 했으나 **등록하지 않는다.**

중복 구현 금지다. 기존 `portMap`을 건드리지 않는다.

## ★ `blu-aec-in`·`blucard-in`·`blucard-out`·`ec-4bv`는 자료가 없다

- 앞 3종: `bssaudio.com`이 **HTTP 202**를 반환했다. 제품 페이지가 없거나 접근이 제한된다
- `ec-4bv`: 페이지는 열리나 **후면 이미지가 없다**

**억지로 붙이지 마라.** 4종은 이번 범위 밖이다.

### `Main` 역할은 이번에 고치지 않는다

4종의 `Main`은 `alt`가 이미 **"전면부"**라고 적고 있어 역할이 어긋나 있다. **고치고 싶겠지만 이번에는 하지 마라.** `Main`을 `Front`로 바꾸면 갤러리 기본 선택과 `imageStatuses`가 함께 움직여 범위가 커진다. **별도 작업으로 보고만 한다.**
