## 목표와 현재 상태

현재 연결 단자 섹션은 각 단자마다 SIGNAL·QUANTITY·PROTOCOL / STANDARD·FIXED / OPTIONAL 라벨을 큰 카드 안에서 반복해 정보가 길고 흩어져 보인다. 그룹을 유지하면서 단자명과 신호·규격을 먼저 읽는 간결한 행으로 바꾼다. 방향·수량·고정/옵션·조건·출처·검증 상태는 가까운 보조 정보로 유지한다. 단자를 누르지 않아도 값이 보여야 한다.

## 범위

- 공통 Product Detail의 I/O 렌더러와 해당 CSS만 변경한다. `prototype/brc-am7/` 원본과 `beta/site/detail/` 공개본을 함께 갱신한다.
- 모든 실제 I/O 그룹과 모든 항목의 connector, signal, direction, quantity, protocol/standard, fixed/optional, condition, verification, source를 보존한다. 상태 미확인은 확정처럼 표시하지 않는다.
- 데스크톱은 단자명과 핵심 신호·규격을 나란히, 모바일은 한 열로 표시한다. 그룹명·그룹별 참고 문구는 유지하고, 행을 간결한 구분선으로 나눈다.
- 제품 JSON 5개·Library·Specs·Features·Gallery·Documents·Sources·해시 진입·공개 권한 정책은 변경하지 않는다. TechDataPS 로고·사진·문구·푸터를 복사하지 않는다.
