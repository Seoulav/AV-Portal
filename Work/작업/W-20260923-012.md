## 목표와 설계

현재 개인 PC의 338개 입력에서 **검토 가능한 일부 항목만** 뽑아, 원본 없이도 실행할 수 있는 정적 공개 베타 묶음을 로컬에 만든다. 공개 데이터는 `brand`, `product`, `categories`, `official_links`, 장비/서비스 보기용 `kind`만 포함한다. 제품 ID·별칭·원본 행·내부 메모·업체·로컬 경로·비공개 직접 제공 자료·보조 출처·사진/PDF 파일은 배포본에서 제외한다. 공식 링크는 제조사 HTTPS 웹페이지 중 모델 본문 확인 기록과 URL의 모델 대응을 검토한 것만 사용한다. 현재 기록만으로 자동 승인하지 않으며, **Git 제외 로컬 채택 결정표**에서 항목과 링크를 명시적으로 고른다. 새 옵션은 넣지 않는다.

독립 정적 화면은 생성된 `catalog.json`만 읽으며 브랜드·제품명 검색, 브랜드와 복수 분류 필터, 장비/서비스 탭, 공식 웹페이지 링크를 제공한다. 서비스가 채택되지 않으면 0건과 설명을 표시한다. 자산 경로는 상대 경로로 두어 어느 정적 호스팅 경로에서도 동작하게 한다. 기존 내부 탐색 앱과 자료 API는 수정하지 않는다. 빌드 스크립트와 화면 코드·합성 테스트만 Git에 올리고, 실제 채택 결정표·선별 데이터·배포 묶음·상세 검토표는 로컬 `outputs/`에 둔다. `.gitignore`로 hkkim/·outputs/·로컬 운영 파일의 실수 업로드를 막는다.

호스팅 권장안은 **Cloudflare Pages Direct Upload**의 수동 정적 파일 업로드다. 개인 PC 원본 없이 생성된 묶음만 업로드할 수 있고 Git 연동·자동 배포를 켜지 않는다. 요금·용량·예상 URL 형식은 공식 문서로 확인해 결과에 기록한다. 이번에는 계정 연결, 프로젝트 생성, 업로드, 외부 미리보기, 결제를 하지 않는다.
