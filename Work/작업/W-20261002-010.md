## 처리 규칙

국내 자료로 대체할 수 없는 행을 어떻게 둘 것인가가 핵심이다.

| 상황 | 처리 |
|---|---|
| 국내 자료에 같은 항목이 있다 | `source`를 국내로 바꾸고 값은 그대로 둔다 |
| 국내 자료에 같은 항목이 **없다** | **값을 지우지 않는다.** `verification`을 `REVIEW REQUIRED`로 바꾸고, 해당 `sources` 항목의 `name`·`scope`에 **"국내 자료 미확보 · 해외 지역 페이지 기록"**을 명시한다 |
| 국내 자료와 값이 다르다 | **국내 값을 쓴다.** 변경 전/후를 대조표에 기록 |
| 해외 출처를 쓰는 행이 0이 된 제품 | 해당 `sources` 항목을 제거한다 |

**값을 삭제하지 않는 이유**: 수치가 사라지면 사용자에게 더 나쁜 상태가 된다. 출처 등급을 낮추고 "국내 미확보"로 드러내는 편이 정직하다. 국내 자료가 생기면 그때 승격한다.

**새 입력에는 해외 페이지를 쓰지 않는다.** 이 작업은 기존 데이터 정리이며, 앞으로의 조사는 AGENTS.md 규칙이 막는다.

## 미결 사항

- **W-20261002-008 병합이 선행**이다. 같은 파일을 건드린다.
- **전자칠판 2종·호텔 TV 3종 국내 자료를 사용자가 나중에 제공한다.** 받으면 `REVIEW REQUIRED`를 해제하는 별도 배치로 이어간다.
- **LED 사이니지는 예외**다. 참조할 수 있으나 **입력 전 사용자 검토**를 받는다. 현재 Library에 삼성 LED 제품이 없으므로 이번 범위가 아니다. 사용자가 제공한 `MPF 시리즈 제품가이드`(MP008F·MP012F·MP016F)는 보관만 한다.
- `REVIEW REQUIRED`로 바뀌는 행이 많으면 공개 화면에 확인 필요 배지가 늘어난다. 이는 **실제 상태를 드러내는 것**이며 숨기지 않는다. 다만 한 제품에서 20행을 넘으면 보고하고 표시 방식을 상의한다.

## 추가 요구사항 — 삼성 LED 사이니지 제품 등록 (2026-10-02)

사용자가 **"AV 포탈에 삼성 LED 사이니지 관련 정보 중에서 MMF하고 MPF IFR IEA는 있어야 해. 근데 IFR 같은 경우는 IFRM으로 바뀌었어"**라고 지시했다. **이 작업의 범위가 아니며 별도 작업으로 다룬다.** 요구사항을 잃지 않도록 여기 기록한다.

| 시리즈 | 상태 | 자료 |
|---|---|---|
| **MPF** | 자료 있음 | 사용자 제공 `MPF 시리즈 제품가이드.pptx` — MP008F·MP012F·MP016F 3종 전체 사양표 수록 |
| **MMF** | **자료 없음** | 필요 |
| **IFRM** (구 IFR) | **자료 없음** | 필요. **IFR → IFRM 명칭 변경**을 반영해야 한다 |
| **IEA** | **자료 없음** | 필요 |

현재 Library에 삼성 LED 제품은 **0종**이고 LED 카테고리 자체가 없다. 제품 등록은 제품 수·ID·카테고리를 바꾸는 일이므로 지금까지의 "변경 안 함" 범위를 벗어난다. 착수 전에 정할 것:

- 제품 ID·slug 규칙(캐비닛 단위인지 시리즈 단위인지)
- 새 카테고리 체계(`LED Signage` 등)와 [제품 분류](../기획/PRODUCT_TAXONOMY.md)와의 관계
- 이미지 확보 방안. 현재 LED 제품 이미지가 없다
- LED는 AGENTS.md 규칙상 **입력 전 사용자 검토 필수**다

**저작권 주의.** 제공된 MPF 가이드 1쪽에 *"삼성전자의 동의 없이 본 자료를 무단으로 제3자에게 복제 배포하는 경우 저작권 침해 행위에 해당"*이라는 문구가 인쇄돼 있다. [자료 게시 운영 정책](../기획/자료게시운영정책-2026-09-29.md)은 허락 확인을 게시의 필수 조건으로 두지 않지만, **이 자료에는 제한이 명시돼 있다.** 내용을 사양 근거로 쓰는 것과 파일 자체를 공개 배포하는 것은 다르다. **파일을 `beta/site/`에 게시하기 전에 사용자 확인을 받는다.**
