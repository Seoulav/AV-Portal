## 문제

W-20261002-015에서 비디오월 2종의 **단자 데이터**는 고쳤다. HDMI는 `direction: IN`이 됐고 루프아웃은 `DP 출력(LOOPOUT)` 하나만 남았다.

**그런데 같은 페이지의 본문 4곳은 아직 "DisplayPort 1.2/HDMI 데이지 체인"이라고 적고 있다.**

| 위치 | 화면에서 보이는 자리 | 현재 문구 |
|---|---|---|
| `lead` | **01 한눈에 보기** (가장 위) | "균일 베젤과 **데이지 체인**으로 다중 화면을 구성한다." |
| `features[3]` | **05 주요 기능** | "**DisplayPort 1.2/HDMI 데이지 체인** 기술로 외장 그래픽카드나 UHD 분배기 없이 최대 5x5 구성의 UHD 콘텐츠를 송출한다." |
| `overview` | 전체 설명 보기 | "**DisplayPort 1.2 또는 HDMI**를 사용하는 데이지 체인 기술로 … 최대 5x5 …" |
| `korean` | 요약 | "**DisplayPort/HDMI 데이지 체인**(최대 5x5)을 지원한다." |

**단자표는 고쳤는데 본문은 반대로 말하는 상태다.** 한 화면 안에서 모순된다. 설계자가 본문을 보고 HDMI로 다대수 연결을 잡으면 현장에서 연결되지 않는다. 본문이 단자표보다 위에 있고 글자도 크다.

### 제품 페이지 문구를 어떻게 볼 것인가

"DisplayPort 1.2 또는 HDMI를 사용하는"은 **들어오는 신호원**을 가리키는 말로 읽을 여지가 있다. 첫 대에 HDMI로 신호를 넣고, 다음 대부터는 DP 루프아웃으로 잇는 구성이다. 그러나 **이것은 추론이며 삼성 자료 어디에도 그렇게 쓰여 있지 않다.**

**추론을 사실로 적지 않는다.** 본문은 매뉴얼이 확인해 주는 범위까지만 쓰고, 제품 페이지의 원문은 충돌 기록으로 남긴다.

## 고칠 것

### 1. 본문 4곳

HDMI가 **데이지 체인·루프아웃을 한다는 표현을 지운다.** 루프아웃은 DP로만 적는다.

| 위치 | 바꿀 방향 |
|---|---|
| `lead` | "데이지 체인" → **"DisplayPort 루프아웃"**. 두 문장·`**` 한 쌍 유지 |
| `features[3]` | "DisplayPort 1.2/HDMI 데이지 체인" → **"DisplayPort 1.2 루프아웃(데이지 체인)"**. 나머지 문장(외장 그래픽카드·UHD 분배기 불필요, 최대 5x5)은 유지 |
| `overview` | 해당 문장만 같은 방향으로 수정. **다른 문장은 건드리지 않는다** |
| `korean` | "DisplayPort/HDMI 데이지 체인" → **"DisplayPort 데이지 체인"** |

**"최대 5x5"는 그대로 둔다.** 삼성 한국 제품 페이지 근거이고 매뉴얼과 충돌하지 않는다.

**새 사실을 추가하지 않는다.** "HDMI로 신호를 받아 DP로 내보낸다" 같은 추론 문장을 만들지 않는다.

### 2. 충돌 기록

`데이지 체인 최대 구성` 사양 행(현재 `value: 최대 5x5`, `verification: FOUND`, `source: P`)은 **값과 검증 상태를 유지**한다. 5x5 자체는 충돌이 아니다.

대신 **`issues`에 충돌을 1건 기록**한다. 두 자료의 원문을 양쪽 다 적고, 매뉴얼을 따른 근거(AGENTS.md 규칙·2026-10-03 사용자 판정)를 적는다. **제품 페이지 문구를 지우지 않는다.** 나중에 삼성이 정정하거나 추가 자료가 나오면 다시 본다.
