## 목표와 현재 상태

카탈로그에서 항목 수가 가장 적은 브랜드부터 상세페이지가 없는 제품을 전환하는 작업을 이어간다. 이번 배치 선정 시 남은 브랜드 중 Sony(4개)와 Yamaha(4개)가 공동 최소였다. Sony의 공식 페이지(`pro.sony`)는 curl과 WebFetch 모두 403으로 이번에도 접근 불가를 재확인해 이번 배치에서 제외했고, Yamaha(`kr.yamaha.com`)는 정상 접속을 확인해 Yamaha 4개 제품을 대상으로 진행했다.

대상: Tio1608-D2, DM3, Rio1608-D3, Rio3224-D3 (Yamaha, 4개 전부).

## 범위

- 신규 상세 JSON: `beta/site/detail/data/{tio1608-d2,dm3,rio1608-d3,rio3224-d3}.json`
- 신규 이미지 8개(WebP, Front·Rear 각 1): `beta/site/detail/images/`
- `beta/group1-images.mjs`: 4개 슬러그의 이미지 매니페스트·cardImages 추가
- `beta/site/catalog.json`: 4개 항목에 slug·card_image 추가(기존 manual_link는 이미 반영되어 있어 변경 없음)
- `beta/manufacturer-hosts.mjs`: 변경 없음(`kr.yamaha.com`/`data.yamaha.com`/`manual.yamaha.com` 모두 기존 `yamaha.com` 서브도메인 규칙으로 이미 허용됨)

## 검증 방법

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test`. 로컬 정적 서버로 4개 상세 JSON의 실제 서빙(200 OK)과 필드 값을 확인했다.

## 미결 사항·의존성

- Sony 4개 제품(SRG-X40UH, SRG-A40, RM-IP10, RM-IP500)은 `pro.sony`가 curl·WebFetch 모두 403으로 이번에도 접근 불가 확인. 사용자 제공 자료 또는 접근 가능한 우회 경로가 필요해 보류.
- DM3는 제조사 사양 탭이 Dante 지원 "DM3"와 Dante 미지원 "DM3 Standard"를 나란히 제공한다. 카탈로그 항목명이 "DM3"이고 확보한 공식 이미지 라벨도 "DM3"이므로 Dante 지원 모델 값을 채택했다(이슈로 기록).
- 나머지 브랜드(AVer·Lumantek·Logitech 5개, Panasonic·Analog Way 6개 등)는 다음 배치로 진행.
