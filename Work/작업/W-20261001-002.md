## 구성
밝은 AV Portal 스타일. 카드당 2K 레이어 최대16과 장치 최대48을 구분한다. 기본은 두 출력 카드 영역을 걸치는 영상1개 예시. 카드 A 안 / A·B 경계 / 카드 B 안 선택으로 그림과 각 카드 자원 사용량을 바꾼다. 2K 영상1개의 위치 예시이며 임의 카드 구성·실시간 장비 상태·전체 자원 계산기가 아니다.

## 근거와 불확실성
H5 저장 사양서 V1.17.0 물리 PDF4쪽: 카드당2K16/DL8/4K4, cross-connector output. 8쪽: 전환·입력 커넥터 용량 조건. 10쪽: 장치 최대48. 서로 다른 카드 영역에 걸치면 양쪽 자원을 소모한다는 설명은 사용자가 이번 대화에서 제공한 운용 설명으로 구분한다. PDF의 cross-connector 문구만으로 같은 카드 포트와 서로 다른 카드 경계를 동일시하지 않는다. 펌웨어/카드별 세부 조건은 미확인 상태를 남긴다. 사진·단자 번호나 실제 화면 치수는 추측하지 않는다.
