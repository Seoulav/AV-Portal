## 방법

Sonnet 에이전트가 단자 규격이 비어 있는 63곳을 조사했다. 대상은 BSS 5곳, Crown 46곳, Shure 12곳이다. 제조사 공식 매뉴얼·데이터시트에서 단자 형식을 원문 인용과 함께 찾았다. 문서가 단자 형식을 명시하지 않은 경우는 사진이나 다른 모델을 근거로 추정하지 않고 미해결로 남겼다. 제안은 모두 검토한 뒤 반영했다.

## 반영 (43곳, 27개 페이지)

| 대상 | 반영 값 | 근거 |
|---|---|---|
| Crown CDi·DCi 스피커 출력 | Barrier strip(4극 터치 방지 단자대, 채널 쌍당 1개) | 각 매뉴얼 후면 패널 설명 |
| Crown CDi BL BLU link, HiQnet | RJ-45 | CDi 매뉴얼 "These two RJ45 connectors…" |
| Crown CDi GPIO/AUX | 8핀 블록 커넥터 | CDi 매뉴얼 |
| Crown DCi N GPIO | RJ-11(6포지션) | DCi Network 매뉴얼 p.25 |
| Crown DCi DA Dante | RJ-45 | DCi DA 매뉴얼 "two Dante (RJ-45) ports" |
| Crown I-Tech 4x3500HD 입력 | XLR-3F(아날로그·AES3), etherCON/RJ-45(CobraNet·VDrive) | I-Tech 매뉴얼 p.14–15 |
| Shure MX392/C 출력 | 커넥터 없음(3.7 m 무단말 케이블 직결) | MX391/392/393 스펙시트 |
| Shure MXA925W-R | RJ-45(듀얼) | MXA925 스펙시트 "Dual RJ45 connectors" |
| Shure ULXD4D·ULXD4Q 네트워크, 전원 | RJ-45 / IEC 전원 인렛 | ULX-D Dual/Quad 가이드 |

- 각 행의 출처에 해당 문서 코드를 연결했다. 페이지에 없던 문서는 출처 `CN`(제조사 공식 문서, 단자 규격 확인)으로 추가했다.
- 에이전트는 ULXD 전원에 "IEC C14"라는 표기를 제안했지만, 원문에는 "IEC Connector"만 있어 C14는 넣지 않았다.

## 추가로 발견한 결함

- A900W-R-GM은 오디오 단자가 없는 기계식 마운트 키트다. 그런데 I/O 표에 'Microphone audio output 8개' 행이 잘못 생성돼 있었다. 이 행을 삭제하고 이슈 R3(RESOLVED)로 기록했다.
