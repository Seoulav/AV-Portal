## W-20260925-008 범위와의 관계

W-20260925-008의 범위는 "새 웹 조사, 이미지 다운로드, PDF 재배포를 하지 않는다"였다. 이 작업은 **사용자의 명시적 최신 지시로 그 제외 항목 중 사진 조사·다운로드만 별도로 승인받아 수행**한다([AGENTS.md](../../AGENTS.md)의 "사용자의 명시적 최신 지시를 우선한다"). W-008의 나머지 제외 항목(제품 JSON 변경, renderer 변경, Library 링크 변경, Pages 배포)은 그대로 유지한다.

## 선행 조사의 차단 사유와 이번 환경의 차이

[PHOTO_CANDIDATES.md](../기획/group2/PHOTO_CANDIDATES.md)는 "이 작업 환경은 제조사 사이트로의 파일 다운로드(`WebFetch`/`curl`)가 egress 정책으로 막혀 있어 실제 이미지 바이트를 받아오지 못했다"고 기록하고, 다운로드·변환·모델 일치 확인을 네트워크 제한이 없는 환경으로 넘겼다.

이번 세션의 컨테이너는 같은 URL에 대해 다운로드가 된다. 착수 전 Analog Way 이미지 URL로 직접 확인했다(HTTP 200, `image/jpeg`, 3175×1772). 따라서 이 작업이 그 인계 대상을 수행한다.

## 범위

- 대상 8개 제품: Mezzo 322 AD · V-02HD MK II · UVC-01 · EB-L530U · AVIO USB C · MXCW640 · GSM4248PX · Aquilon RS1
- 각 제품의 **제조사 공식 출처**에서 제품 사진을 조사하고 원본을 내려받는다.
- 내려받은 원본을 `beta/group1-images.mjs`와 같은 형식(role·file·alt·provider·model·sourceUrl·verificationStatus·originalSize·resolution·publicationStatus)의 WebP로 변환하고 manifest에 기록한다.
- 긴 변 1800px 상한은 Group 1과 같게 적용한다.
- 산출 위치는 `docs/research/group2-images/`다. **공개 대상인 `beta/site/`에 넣지 않는다.**

## 제외

- `beta/site/` 아래 어떤 변경도 하지 않는다. 공개 JSON·renderer·Library 링크·Pages 배포는 후속 승인 작업이다.
- `beta/group1-images.mjs`, `beta/verify-pages.mjs`, 기존 Group 1 이미지 13개는 건드리지 않는다.
- 제조사 재사용·재배포 권리를 판단하지 않는다. 미확인 상태로 보존한다.
- 사양값을 사진이나 마케팅 그래픽에서 읽어 제품 데이터로 확정하지 않는다.

## 모델 구분 유지 조건

[W-20260925-008](W-20260925-008.md)의 제품별 유지 조건을 사진에도 그대로 적용한다. 공개 카탈로그에 형제 모델이 함께 등재되어 있어 특히 중요하다.

| 대상 | 카탈로그에 함께 있는 형제 모델 | 사진에서 지켜야 할 것 |
|---|---|---|
| Mezzo 322 AD | Mezzo 322 A | `A`와 `AD`를 구분한다. 다른 Mezzo(324 AD·604 A·602 A)의 후면 사진을 322 AD 후면으로 쓰지 않는다 |
| V-02HD MK II | V-02HD | MK II 전용 자료만 쓴다 |
| GSM4248PX | GSM4248P | M4250 계열 공용·연출 이미지를 모델 사진으로 쓰지 않는다 |
| AVIO USB C | 다른 AVIO Adapter | USB-A 및 다른 AVIO와 합치지 않는다 |
| Aquilon RS1 | Aquilon RS2 | RS2 사진을 쓰지 않고 이미지 재사용 상태를 검토 상태로 유지한다 |

## 검증 방법

1. `docs/research/group2-images/manifest.json`의 8개 슬러그와 승인된 제품명을 대조한다.
2. 각 WebP의 매직 바이트(`RIFF`/`WEBP`)와 크기를 확인한다.
3. `git status --porcelain beta/`가 비어 있는지 확인한다.
4. `node beta/update-snapshot.mjs` → `node beta/verify-pages.mjs` → `npm test`를 실행하고 결과를 기록한다.
5. `git diff --check origin/main...HEAD`로 커밋된 전체 변경을 검사한다.
