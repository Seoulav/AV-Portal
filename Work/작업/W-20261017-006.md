## 목표

종합 페이지에서 "4K 패널 몇 판 구성이면 어떤 제품이 되는가"를 한눈에 보여 준다.

## 할 일

1. **조견표 절 추가(종합 페이지)**: 4K60 패널 수(구성 예 포함) → 가능한 제품을 표로 보여 준다.
   - 행: 1판, 2판(2×1), 3판(3×1), 4판(2×2), 6판(3×2), 8판(4×2), 9판(3×3), 12판(3×4·4×3), 16판(4×4)
   - 열: 구성 예(해상도), 필요한 4K60 출력 수·출력 링크, 가능한 모델(시리즈별)
   - **판정은 기존 `analogway-layer-guide.mjs`의 평가 함수를 호출해 계산한다. 가능/불가를 하드코딩하지 않는다.** 레이어 가정은 "믹싱 2개"와 "레이어 0개" 두 줄 표기(또는 전환)로 하여, 레이어를 쓰면 경계가 올라가는 것을 보여 준다.
   - 근거 문구: 패널 1판=출력 링크 2, VPU 1개=출력 링크 8(매뉴얼 66쪽), 레이어 자원 실측(시뮬레이터 2026-10-17). Midra 2판은 Eikos 블렌딩만 가능(Pulse 제외), Zenith 100은 출력 3까지 — 기존 공개 데이터·기준 문서의 수치만 사용.
2. **설계 가이드에 타일 입력 방식 추가**: 입력 방식 선택에 "4K 패널 가로×세로"를 추가한다. 가로 수×세로 수를 고르면 4K60 출력 (가로×세로)개로 환산해 기존 판정을 호출한다. 해상도 환산 표(documentedFormats)를 거치지 않으므로 "문서에 없는 해상도" 미확인 처리와 충돌하지 않는다. 타일 가정(겹침 없는 동일 4K60 타일)을 화면에 명시한다.
3. 시험: 조견표의 대표 셀(4판=Zenith 200·전 Aquilon 가능, 6판=VPU 2 이상만, 16판=RS6·Cmax만)과 타일 입력 환산을 검증하는 시험 추가.

## 하면 안 되는 것

- 가능/불가 결과 하드코딩, 제품 JSON 수치 변경, Alta·Midra 평가 로직 변경, 새 제조사 주장 창작(모든 수치는 기존 평가 함수·공개 데이터·기준 문서에서만).
