## 바꿀 것

### 1 · 두 행의 `condition`과 `verification`

| | |
|---|---|
| `condition` | **「예정·미확인」 문구를 지운다.** 더 이상 사실이 아니다 |
| `verification` | `REVIEW REQUIRED` → **`FOUND`** |

**`value`는 건드리지 않는다.** `CS4B / CS4F`와 `Optical (CS4B) / Copper (CS4F)`가 그대로 맞다.

`FOUND`를 쓰는 이유는 **같은 제품의 다른 엑셀 출처 행들이 `FOUND`**이기 때문이다. `VERIFIED`로 올리지 않는다.

### 2 · ★ 출처를 새로 단다 — 가장 중요한 부분이다

**`S1`(엑셀)을 그대로 두고 조건만 지우면 안 된다.** 엑셀에는 **"예정"**이라고 적혀 있다. **엑셀이 말하지 않은 것을 엑셀이 말한 것처럼 만드는 셈**이다.

**확정은 사용자에게서 왔다.** 그러니 **사용자 확인을 출처로 적는다.**

`sources`에 항목을 더한다. **이미 쓰던 방식이 있다.**

```
"사용자 제공(2026-09-27, 서울영상테크 SI사업본부 정리): pro.sony·공식 유통사 스펙 기준, 제조사 원문 아님"
```

**이 문장 형식을 따른다.** 담아야 할 것은 셋이다.

| | |
|---|---|
| **날짜** | 2026-10-05 |
| **누가** | 사용자(서울영상) 확인 |
| **제조사 원문이 아니라는 것** | 반드시 적는다 |

두 행의 `source`가 **새 출처를 가리키게** 한다. 엑셀에서 온 `value`까지 지우지는 않으니, **두 출처를 함께 적는 것이 맞다고 판단되면 그렇게 해도 된다.** 판단은 맡긴다.

> **지켜야 할 것 하나 — 「제조사 문서가 그렇게 말했다」로 읽히지 않을 것.**
