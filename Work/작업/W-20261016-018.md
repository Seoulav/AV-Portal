## 할 일

1. **카탈로그·상세 등록**: 기존 Aquilon RS 등록 형식(분류·문서 4칸·사양 표)을 따른다. 빠른 문서 4번째 칸은 W-010의 데이터 기반 "브로슈어" 칸을 쓴다.
2. **사진**: 공식 사진을 쓴다. 사진을 열어 어느 면인지 보고 인쇄된 모델명을 읽어 일치를 확인한다(AGENTS.md 사진 모델 일치 규칙).
3. **Port Map**: 후면 사진이 있으면 만든다.
   - W-015·016·017 기준을 따른다. 가장자리 괄호, 관통 0, 오인 0, 번호는 사진 바깥, 사진 안 수평 구간은 사진 폭의 1/4 이하, 다른 선과 6px 이상 띄운다.
   - 같은 종류 카드의 번호 규칙은 세션 C의 W-20261016-014 결과를 따른다. W-014가 아직 병합 전이면 지금 규칙(번호 중복 없음)으로 만들고 기록한다.
4. **시그널 플로우**: 기존 형식(`signalFlow`, `validFlow`)으로 만든다.
5. **레이어 해설**: W-010 `layerPlan` 렌더러를 재사용한다.
   - C 시리즈 4종의 모델별 표와 맨 위 결론 한 문장("2×2 4K60 화면 n개, 화면마다 레이어 m개")을 둔다.
   - 값은 브로슈어 7쪽 Quick Overview와 C 시리즈에 적용되는 공식 문서로만 정한다.
   - RS 시리즈의 VPU 규칙(W-010)이 C 시리즈에도 적용되는지는 문서로 확인한다. 확인되지 않으면 "공식 자료 미확인"으로 둔다.
   - RS 시리즈 JSON의 `layerPlan`은 고치지 않는다. 표에 C 시리즈를 함께 보여 주려면 C 시리즈 쪽 데이터에만 둔다.
6. 파생 산출물 재생성, 되감기 함수, 검색 인덱스 확인
