## 목표와 현재 상태

후면 Port Map 2단계는 제조사 단위의 작은 배치로 진행한다. 1차 Crown 22종이 PR #153으로 병합·배포됐고, 2차 대상으로 Shure를 준비한다.

[자료현황](../기록/W-20261001-001-Port-Map-자료현황.md) 기준 Shure의 Rear 사진 보유 제품은 14종이고 그 가운데 판정이 **가능**인 제품은 9종이다. 이 9종 중 ULXD4D는 시범 단계에서 이미 Port Map 11개 항목을 보유하고 공개 검증까지 마쳤다. 따라서 이번 배치는 **신규 8종 + 기존 ULXD4D 1종 재검증**으로 설계한다.

현재 저장소에서 2026-10-02에 직접 확인한 상태는 다음과 같다.

- 9종 모두 `beta/site/detail/data/<slug>.json`과 `Rear` 역할 이미지가 존재한다.
- 9종의 게시 Rear WebP 실제 디코딩 크기를 측정했고 자료현황 표의 값과 모두 일치한다.
- 자료현황이 지목한 PDF 사본 8개가 `beta/site/docs/` 아래에 모두 존재한다.
- ULXD4D를 제외한 8종의 JSON에는 `portMap`이 없다.

**다만 '가능'은 사본 보유 판정이며 모델별 PDF 적용·단자 페이지 검증 완료를 뜻하지 않는다.** 특히 이 배치의 PDF 사본 다수가 대상 모델과 다른 파일명을 쓴다(`qlxd1-…`, `slxd1-plus-…`, `ulxd1-…`, `mxcw640-…`). Crown 1차에서 `cdi-2-1200` 파일명 사양서가 실제로는 12개 모델을 포함함을 PDF 본문에서 확인하고 사용한 선례가 있으므로, 이번에도 **파일명이 아니라 PDF 본문의 적용 모델 표기와 후면 패널 쪽**을 사람이 대조하는 것을 선행 검증으로 둔다.

### 유지해야 할 결정

- 제조사 사양을 추측하지 않는다. 정보 없음 / 0 / 미지원 / 해당 없음을 구분한다(AGENTS.md, MODEL_ROUTING.md §8).
- 사진만으로 단자 수량을 확정하지 않는다. 매뉴얼 쪽 근거가 있는 **빈** quantity만 채울 수 있고, 비어 있지 않은 값과 기존 검증 상태는 바꾸지 않는다(W-20261001-001 보완 규칙).
- Shure 공식 자료 + 삼아프로사운드 출처 정책을 유지한다. 이번 배치는 저장소에 이미 있는 자료만 사용하고 새 웹 조사·다운로드를 하지 않는다.
- 유효한 Rear 지도가 있으면 03에서 같은 사진을 반복하지 않고, 기존 단자 카드·전체 단자 표·사진 전환·확대는 유지한다.
- 번호 순서는 입력 → 출력 → 네트워크/제어 → 전원이며 분리된 A/B는 별도 번호를 받는다.

## 미결 사항·의존성

- **D1 — 사용자 결정 필요(차단).** Shure 배치의 제품 데이터 작성·병합·배포 승인. Crown 인계서와 지시서가 "Shure 9종은 시작하지 않는다"로 남아 있어 현재는 **Codex 착수 불가**다. 이 명세와 인계서는 승인 시 바로 쓸 수 있는 준비물이며, 승인 전에는 READY로 바꾸지 않고 구현 프롬프트도 만들지 않는다. 담당: 사용자.
- **D2 — 범위 축소 가능성.** 선행 검증 게이트에서 공통 PDF의 적용 모델 또는 후면 단자 쪽을 확인하지 못하면 해당 모델이 빠진다. 최대 9종이며 최소 보장 수량은 약속하지 않는다. 게이트 결과는 근거표 머리말에 적는다.
- **D3 — ULXD4D 처리.** 재검증에서 기존 값과 PDF 근거가 어긋나면 수정 전에 사용자 확인을 받는다. 기존 공개본이 이미 사용자 승인을 받았기 때문이다.
- **D4 — UA864A 사진 비율.** 1500×1500 정사각 사진이어서 가로로 긴 랙 제품과 번호 배치 특성이 다르다. 번호 겹침·잘림 검사를 이 제품에서 특히 주의한다. 실패 시 이 제품만 제외하고 사유를 남긴다.
