## Work가 확인한 가이드 내용 (요약의 뼈대)

| 모드 FND | 설정 내용 | 값 표시 | 적용 방법 |
|---|---|---|---|
| o1 | 채널별 온 타임(0~99초) | F00~F99 | 시간 표시 중 채널 스위치(1~8) 클릭 → 적색 LED |
| o2 | 채널별 오프 타임(0~99초) | F00~F99 | 시간 표시 중 채널 스위치 클릭 → 녹색 LED |
| o3 | 상시 전원 채널 | Fo2 | 채널 버튼 클릭 → 녹색 LED |
| o4 | 전면 스위치 잠금 | F0o(잠금)/F0F(해제) | 채널 버튼 클릭마다 전환 |
| o5 | 제어 모드 | F01(마스터)/F02(슬레이브)/F03(채널) | 채널 버튼 클릭마다 순환 |
| o6 | 유니트 번호(0~99) | F00~F99 | F00이면 일반 모드(이전 버전 호환) |

공통 절차: TIME SET으로 설정 모드 시작 → BYPASS 반복 클릭으로 모드
선택 → D/OUT 클릭으로 진입 → 값 설정·채널 적용 → TIME SET으로 저장.
통신: RS-485S INPUT RJ-45 핀 배치(5:A TX+/RX+ · 6:B TX-/RX- · 7,8:GND ·
3:IN1 · 4:OUT2), PC↔장비는 핀 5·6·7, 장비↔장비는 핀 3~8, 1대1 케이블.
외부 통신 프로토콜 규격은 "본사 문의". **주의: 통신 제어 시 POWER
스위치 OFF 상태 필요.**

## 할 일

1. DS-8S 상세 **하단**(문서·출처 섹션 앞)에 "설정 가이드" 섹션을 추가한다.
   - 스타일 참고: 사용자가 지정한 **HD-13U 구성기 제품 페이지의 설정
     섹션**(https://seoulav.github.io/rtcom-configurator/#products/hd-13u) —
     모드 표+단계 카드 식 구성을 참고하되, 포털 상세의 기존 섹션 규약
     (번호 헤딩·카드 스타일)과 어울리게 만든다. 구성기 코드를 복사할
     필요는 없고 시각 개념(표 + 절차 카드)을 따른다.
   - 내용은 위 요약 표 + 공통 절차 + 통신 핀 배치 + 주의 문구.
     **수치·코드(FND 표시값)는 가이드 원문 그대로**, 요약 문구는 포털
     말투 규약대로.
2. 가이드 원문 PDF를 uploads 방식으로 문서 섹션에 게시한다(제목
   "순차 전원 공급 설정 가이드(2022-05)", 사용자 제공 명기).
3. 근거표에 출처(쪽 번호)와 SHA를 기록한다.
4. 모바일 390px에서 표 내부 스크롤(기존 선례) 확인.
