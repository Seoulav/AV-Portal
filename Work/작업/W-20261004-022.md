## 지금 무슨 순서인가

`beta/site/app.js:37`

```js
if (sort === 'brand') return a.brand.localeCompare(b.brand, 'ko') || a.product.localeCompare(b.product, 'ko');
```

**모델명 가나다순**이다. 그래서 이렇게 나온다.

```
HG43U800F · HG50U800F · HG65U800F    ← 호텔TV가 맨 위
LH115QHF
LH32QMC · LH43QMC · LH43QHC · LH75QHC · LH85QMC · LH98QMC   ← QMC와 QHC가 섞인다
LH55VHCR · LH55VMCR
LH55WMFW · LH75WMFW
MP008F · MP012F · MP016F
```

**QMC와 QHC가 모델 번호 때문에 섞인다.** 사람이 찾는 순서가 아니다.

### ★ LED는 사용자가 말하지 않았다

7개만 적었고 **LED 3종이 빠져 있다.** 지우라는 말이 아니라 **순서에서 언급이 안 된 것**이다.

**맨 뒤에 둔다.** 사용자가 다른 자리를 원하면 그때 옮긴다. **빠뜨려서 안 보이게 하는 일은 없어야 한다.**

### 제품군 안에서는 크기순

| 제품군 | 순서 |
|---|---|
| QHC | 43 → 75 |
| QMC | 32 → 43 → 85 → 98 |
| 호텔TV | 43 → 50 → 65 |
| 전자칠판 | 55 → 75 |
| LED | 008 → 012 → 016 |

**지금 가나다순과 결과가 같다.** 모델 번호가 다 두 자리라 우연히 맞는다. **115인치가 들어오면 깨진다** — `LH115`는 `LH32`보다 앞이다. QHF가 혼자라 지금은 드러나지 않는다.

## ★ 어떻게 만드나 — 코드에 "Samsung"을 박지 마라

`app.js`에 `if (brand === 'Samsung')`를 넣으면 **다음 브랜드마다 또 넣게 된다.**

**데이터에 순서를 적는다.**

- 카탈로그 항목에 **제품군과 그 순서**를 적는다
- 정렬은 **그 값이 있으면 그걸 먼저 보고, 없으면 지금처럼** 모델명으로
- **값이 없는 브랜드는 하나도 안 바뀐다**

구체적인 방식(필드 이름·모양)은 **Codex가 정해 보고**한다. 지켜야 할 것은 하나다.

> **삼성 17종 말고 다른 225종의 보이는 순서가 하나도 바뀌면 안 된다.**

### 새 분류를 만들지 마라

지금 `categories`가 `사이니지 · Display · Digital Signage`다. **QHF·QHC·QMC가 전부 `Digital Signage`로 같다.**

여기를 쪼개면 **화면의 분류 거르개와 검색 인덱스가 같이 바뀐다.** 이번 일은 **순서**다. **`categories`를 건드리지 마라.**
