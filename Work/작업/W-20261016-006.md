## 사용자 캡처에서 보이는 문제 (Work 확인)

캡처: 세션 A 폴더 `tmp/ubridge/user-mobile-20261016-1231.jpg`.

- 모바일에서 Port Map 사진이 확대되어 좌우로 밀어 보는 상태다("사진을 좌우로 이동해 번호를 확인하세요").
- `u-bridge-3-panels.png`(784×580)에서 **PC HOST 열과 DEVICE 열 사이 간격이 약 30px**밖에 안 된다. 그래서 확대 화면에서 PC HOST 아래 단자판의 오른쪽 끝과 DEVICE 아래 단자판의 왼쪽 끝이 맞붙어 보인다. 8번(PC HOST RS-232)과 9번(DEVICE DC 24V)도 바로 옆에 붙는다. 사용자는 이 부분 두 곳을 빨간 원으로 표시했다.
- "PC HOST"·"DEVICE" 제목이 위·아래 단자판 사이에 있어서, 위쪽 단자판이 어느 모듈인지 바로 읽히지 않는다.

## 할 일

1. **단자판 이미지 다시 배치** (같은 원본 도면에서 자르기·배치만, 단자판 픽셀 변경 금지):
   - 두 열 사이 간격을 **단자판 폭의 절반 이상**으로 넓혀, 확대된 모바일 화면에서도 두 모듈이 확실히 떨어져 보이게 한다. 두 열 사이에 옅은 세로 구분선을 넣어도 된다.
   - "PC HOST"·"DEVICE" 제목은 **각 열의 맨 위**로 옮긴다. 위 단자판 번호(1~5)와 제목이 겹치지 않도록, 제목과 위 여백 번호의 순서를 정하고 간격을 둔다.
   - 같은 열의 위·아래 단자판 사이 간격은 지금처럼 넉넉히 유지한다.
2. **Port Map 좌표를 새 이미지에 맞춰 다시 잰다.** 번호·label·desc는 바꾸지 않는다.
3. **모바일 확인이 핵심이다.** 390px 화면에서 확대·좌우 이동 상태로 PC HOST 열과 DEVICE 열이 떨어져 보이는지, 8번과 9번이 떨어져 보이는지 확인한다. 브라우저를 쓸 수 없으면 실제 렌더 코드와 같은 배율로 그린 390px 미리보기를 만들어 확인한다.
4. 렌더러가 이미지 폭에 따라 확대 배율을 정한다면, 새 이미지가 넓어져 확대가 더 커지는지 확인하고 결과를 보고한다(렌더러는 고치지 않는다. 필요하면 보고만 한다).
