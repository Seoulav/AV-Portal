## 범위

### 1. 원본 자산 동기화 (선행, 긴급)

`beta/site/detail/`은 `beta/build-group1-pages.mjs:77-100`이 `prototype/brc-am7/`를 복사·치환해 만드는 **생성물**이다. 현재 `prototype/brc-am7/app.js`에는 **W-20260924-009의 수정이 하나도 없다** — `content.json` fallback이 그대로 있고, 해시 재보정과 Library 복귀 링크가 없다. `styles.css`와 `product-detail-model.mjs`는 일치한다.

**누구든 빌드를 한 번 실행하면 W-009 수정 전체가 사라진다.** 동기화를 검사하는 테스트도 없다.

- `prototype/brc-am7/app.js`를 공개본과 동기화한다. 단 프로토타입에서는 `content.json` 진입이 계속 동작해야 하므로, 치환 규칙으로 흡수하거나 빌드가 그 차이를 만들어내도록 한다.
- 원본과 생성물의 일치를 검사하는 테스트를 `tests/`에 추가하고 `npm test`에 포함한다. 빌드가 쓰는 치환 규칙을 재사용하거나 같은 값을 공유한다.

### 2. 본문을 2탭으로 축소

- 6개 섹션(`overview`·`features`·`specifications`·`io`·`documents`·`sources`)과 sticky 내비 6개를 **`특징` · `스펙` 2탭**으로 재편한다.
- **`특징` 탭** — 현재 Features 전체. 접기 없이 한 번에 보인다. Overview의 요약 문장은 탭 위 공통 영역에 한 문단으로 둔다.
- **`스펙` 탭** — Specifications → I/O → 근거·검토 항목 순서로 한 탭 안에 둔다. AV 장비에서 커넥터는 사양의 일부이므로 별도 탭으로 나누지 않는다.
- 탭은 `role="tablist"`/`role="tab"`/`aria-selected`/`role="tabpanel"`을 갖추고 좌우 화살표 키로 이동한다.
- Documents의 보조 문서 목록은 `스펙` 탭 하단 또는 자료 2×2 아래 접힌 영역으로 옮긴다. Quick Documents 4칸은 탭 위에 그대로 둔다.

### 3. 빈 갤러리 제거

- 이미지가 0장일 때 89px 갤러리 패널을 만들지 않는다.
- 다만 **"사진 없음"과 "사진은 확인했으나 재게시 권한 미확인"을 구분하는 표시는 유지한다.** `PORTAL_MVP_SPEC`의 "정보 없음 / 해당 없음 / 미지원 / 0개를 다르게 표시한다" 규정 때문이다. 자료 영역 근처에 한 줄로 요약한다(예: `제품 이미지 · 공식 출처 4건 확인 · 재게시 권한 미확인`). 이미지별 상태는 접힌 영역에 보존한다.
- 이미지가 있는 제품이 생기면 갤러리를 제품명 위에 두는 것은 후속 작업으로 남긴다. 현재 공개 5개는 모두 0장이다.

### 4. 기존 해시 링크 보존

W-009가 고친 해시 동작이 회귀하면 안 된다.

- `#specifications`·`#io`·`#documents`·`#sources`로 직접 진입하면 **해당 탭을 연 뒤** 그 위치로 이동한다.
- 스펙 값의 `근거` 링크(`#source-XX`)를 누르면 `스펙` 탭 안에서 이동한다. 탭이 닫혀 있으면 열고 이동한다.
- 활성 탭이 주소에 반영돼 새로고침·공유에서 유지된다.

- `beta/verify-pages.mjs`의 고정 해시·파일 목록 assert

- 다크 테마 전환 — 이번 범위 아님. 시각 방향 변경은 별도 승인 필요
