# AV Portal 개편 기획서 — RTCOM 제품정보 방식으로 통일

- 작성일: 2026-09-29
- 요청자: 서울영상테크 SI사업본부
- 대상 저장소: `Seoulav/AV-Portal` (공개 주소 https://seoulav.github.io/AV-Portal/)
- 기준 사이트: `Seoulav/rtcom-configurator`의 알티컴 제품정보 화면 (https://seoulav.github.io/rtcom-configurator/#products/hd-210u)
- 이 묶음을 받은 작업자(GPT·Codex)는 이 문서를 가장 먼저 읽고, 단계 문서(01~06)를 순서대로 진행합니다.

## 1. 목표

AV Portal의 화면을 RTCOM 제품정보 화면과 같은 디자인·배치로 바꾸고, 알티컴 제품을 AV Portal 라이브러리에 함께 보여 줍니다.

| 지금 | 목표 |
|---|---|
| 상세 화면이 탭 7개로 나뉘어 한 번에 한 탭만 보임 | 번호 붙은 카드(01~07)를 한 화면에 모두 보여 줌 |
| 흰 평면 패널, 초대형 제목, 글꼴 파일 없음 | 글래스 카드, 27px 제목, Pretendard 글꼴 파일 포함 |
| 검수용 배지·"자료 없음" 칸이 곳곳에 노출 | 맨 아래 접힌 "자료 출처·검증 기록" 하나에 모음 |
| 홈 화면을 열 때 상세 JSON 240개를 모두 받음(요청 245번, 3.8MB) | 검색용 목록 파일 하나만 받음 |
| 알티컴 제품 0개 | 알티컴 공개 제품정보 31종을 읽기 전용으로 표시 |

## 2. 현재 상태 요약

자세한 수치는 `REF_ANALYSIS_2026-09-29.md`에 있습니다.

- 정적 HTML + JavaScript 모듈, 제품마다 JSON 하나(`detail/data/<slug>.json`). 프레임워크 없음
- 공개 장비 247개, 상세 페이지 240개, 제조사 28곳
- 240개 모두 `packageStatus: REVIEW REQUIRED`, 관련 제품 데이터 0개, 문서 칸 51%가 "없음"
- 휴대폰 가로 스크롤 없음, 콘솔 오류 없음(유지해야 할 장점)

| 단계 | 문서 | 내용 | 바꾸는 것 | 사용자 확인 |

| 2 | `02_DETAIL_PAGE.md` | 제품 상세 화면 개편(탭 → 카드) | `detail/` 화면 코드 | 대표 4종 캡처 |

| 4 | `04_SEARCH_INDEX.md` | 홈 검색 속도 개선 | 빌드 스크립트, 루트 `app.js` | 요청 수·시간 비교 |
| 5 | `05_DATA_CLEANUP.md` | 카테고리·그룹 이름 정리 | 데이터 JSON(이름만) | 변경 대응표 |

- 순서를 지킵니다. 앞 단계의 사용자 확인이 끝나기 전에 다음 단계를 시작하지 않습니다.
- 한 단계는 한 작업(PR)입니다. 두 단계를 한 PR에 섞지 않습니다.
- 1~3단계는 **화면만** 바꾸고 데이터를 건드리지 않습니다. 데이터 변경은 5단계에서만 합니다.
- 내부 자료(단가·노하우 등) 연결은 이 기획에 포함하지 않습니다. AV Portal 비공개 전환이 끝난 뒤 별도 작업으로 합니다.

## 4. 모든 단계에 적용하는 규칙

1. 데이터에 없는 사양·기능·설명·그림을 새로 만들지 않습니다.
2. 제품 id별 예외 코드(`if (slug === '...')`)를 만들지 않습니다. 템플릿 하나가 모든 제품을 그립니다.
3. 기존 주소와 해시는 계속 동작해야 합니다: `/detail/?product=<slug>`, `?q=`, `#overview` `#features` `#specifications` `#io` `#related-products` `#documents` `#sources`.
4. 검색, 이미지 확대(돋보기), 뒤로 가기 스크롤 복원, `catalog.html`·`llms.txt`는 기능을 유지합니다.
5. 새 외부 라이브러리·CDN을 추가하지 않습니다. 글꼴은 파일을 직접 넣습니다.
6. 알티컴 제품정보의 원본은 `Seoulav/rtcom-configurator`입니다. AV Portal에서 그 값을 고치지 않고, 그쪽으로 보내는 기능을 만들지 않습니다.
7. AV Portal은 현재 **공개 사이트**입니다. 단가·원가·거래처·노하우 같은 내부 정보를 어떤 파일에도 넣지 않습니다.
8. 라이트 모드만 만듭니다.
9. AV Portal 저장소의 기존 절차(AGENTS.md, `Work/작업/` 명세, 작업 ID `wNNN`)를 따릅니다. 이 묶음의 문서는 `Work/작업/`에 옮겨 두고, 작업 ID는 저장소의 다음 빈 번호를 씁니다.
