    - `EB-PU1008B`는 기준 main에서 이미 후보 URL과 일치하므로 무변경 확인 대상으로 둔다. 구현 기준 main에서 404 단축 URL이면 후보 URL로 교체한다.
  - `docs/research/equipment-listing-decisions-2026-09-25.json`
    - 두 항목의 `official_urls`를 확인된 정확 URL과 일치시킨다.
    - 두 항목에 `url_corrected`를 추가한다. 기존 GSM4212P 형식(`corrected_at`, `previous_urls`, `reason`, `work_id`)을 그대로 따른다.

    - 공개 카탈로그가 실제로 변경되면 `node beta/update-snapshot.mjs`로 카탈로그 SHA를 갱신한다. 두 대상은 카탈로그 인덱스 148·221로 기준 25개 밖이므로 `baselineSha256`은 바뀌지 않아야 한다.

1. 두 URL을 열어 제조사 도메인, HTTPS, 페이지 제목과 본문 모델 표기를 확인한다.
2. JSON을 파싱해 두 제품의 카탈로그·결정표 URL과 `url_corrected` 구조를 비교한다.

4. 공개 카탈로그가 변경되면 `node beta/update-snapshot.mjs`를 실행하고 `baselineSha256` 불변을 확인한다.
