## ★ Work가 틀렸던 것을 먼저 적는다

[W-20261004-033](W-20261004-033.md)에서 **"설치가이드에는 스탠드 조립·치수표·VESA뿐"**이라고 적었다. **틀렸다.**

**2쪽만 보고 1쪽을 안 봤다.** 사용자가 다시 보내 주며 **"첫페이지에 있어"**라고 알려 줘서 확인했다.

**1쪽 상단에 단자 안내 상자가 있다.** 뒷면 그림에서 점선으로 단자 자리를 표시하고, 지시선으로 상자를 연결한다.

```
USB          HDMI (eARC)      HDMI
LAN          ANT
```

> **교훈: 2쪽짜리 문서라도 전 쪽을 본다.** 쪽 수가 적다고 건너뛰지 않는다.

## ★ 제품 데이터와 대조했다

| 설치가이드 1쪽 | `io` 행 | |
|---|---|---|
| USB | `[1]` USB-A ×1 | 일치 |
| HDMI (eARC) | `[0]` HDMI ×3 · `availability: "HDMI ARC: eARC"` | 일치 |
| HDMI | `[0]` 같은 행 | 일치 |
| LAN | `[2]` Ethernet ×1 | 일치 |
| **ANT** | **`[3]` RF 입력 — `"물리 단자 수는 미확인"`** | **← 이 자리가 풀린다** |

`[4]`·`[5]`는 Wi-Fi·Bluetooth로 **물리 단자가 없다.** 안내 상자에 없는 것이 맞다.

**다섯 종류가 모두 맞는다.** 이 문서가 이 제품 것이라는 뒷받침이기도 하다. 설치가이드 치수표에 **`BE43HX-*`**가 있어 모델 계열도 맞는다.

## ★ 하지 않는 것 — 번호 지도는 아직이다

**단자 「종류」는 알아냈지만 「자리」는 모른다.**

안내 상자는 **어떤 단자가 있는지 알려주는 범례**다. 뒷면 그림의 점선 상자는 **단자 뭉치가 어디쯤 모여 있는지**만 보여주고, 그 안의 작은 도형은 **2~3개로 그려져 실제 개수와도 맞지 않는다.**

| | |
|---|---|
| 아는 것 | **어떤 단자가 있나** · 뒷면 오목부 **왼쪽 가장자리에 모여 있다** · 전원은 **아래쪽에 따로** |
| 모르는 것 | **위에서 몇 번째가 무엇인가** |

> **번호 지도는 자리를 알아야 만든다.** 지금 자료로는 못 만든다.

**추측해서 번호를 달지 않는다.** [W-20261005-003](../기록/W-20261005-003-자료대기.md)에 **실물 뒷면 사진**을 기다리는 것으로 남겨 둔다.
