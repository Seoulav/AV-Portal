### RTCOM 직접 제공 자료 요청

현재 미발견 판정은 확인표·안내의 제공 폴더 대조 기록에 근거한다. 이번 기획에서 제조사 파일 본문 전체를 재검증한 것은 아니다. 제조사 자료가 없다는 판정으로 확대하지 않는다.

- Excel 영상 123 FT101-U, 124 FR101-U, 145 MR-4S: 전면·후면 원본 사진과 매뉴얼 미발견. MR-4S의 사양서는 기존 제공 후보를 먼저 적용 검토한다.
- Excel 영상 125 OBHD-2C-TX, 126 OBHD-2C-RX: 전면·후면 미발견. 매뉴얼 등 '유형별 미조사'는 별도로 확인하며 미발견으로 바꾸지 않는다.
- 부록 12항목 중 미발견 10항목: AHOC, CT101-U/CR101-U, CT102-U/CR102-U, CT103-U-H/CR103-U, FT102-U/FR102-U, FT103-U-H/FR103-U, HD-D102U, HOC-UX, LHOC, UMC Locking Cable. 전·후면 사진 및 매뉴얼 요청. 케이블에 해당 유형이 적용되지 않으면 제조사의 사유 있는 '해당 없음' 회신을 기록한다.
- 위 10항목 중 CT102-U/CR102-U, FT102-U/FR102-U는 사양 근거도 미발견이므로 1차에 먼저 요청한다. 부록의 미발견 자료 열만 보지 말고 사양 근거 열도 대조한다.
- CT103-U-H/CT103-U, HOC UX/HOC-UX 표기는 동일성을 추정하지 않는다. UMC는 UMC-001/002/003/005/010별 구성·길이·자료 적용을 확인한다.
- 나머지 부록 OBUX-1C는 기존 TX/RX 사진 4장·문서의 모델·개정·권한을 검토한다. SPX Series는 일부 사진과 SPX-M810 파일명 대비 SPX-M24 본문 충돌을 구분하고 프레임별 자료를 요청한다.
- HS-88UX를 제외 모델과 동일시하지 않는다. CT-104-U/CR-104-U 표기를 자동 수정하지 않는다. HS-88M-U, HS-88MX, HD-D104U, HD-D108U 제외 정책과 원본 증빙 보존을 유지한다.
- RTCOM은 제조사 직접 제공만 사용한다. 검색 엔진·웹사이트로 빈칸을 채우지 않는다.

## 업체 회신 기록과 완료 기준

이 절차는 임시 검토대장의 기록 요구사항이며 최종 Schema 또는 Database/Storage 설계가 아니다. 별도 로컬 회신 기록에 원본 파일 해시·시트·원본 행(부록은 대상명+부록 행)을 연결한다. 제조사/모델 원문과 검토 후보, 회신 확정값을 별도 보존하고 원본 Excel을 덮어쓰지 않는다. 한 회신이 여러 중복 행에 적용되면 모든 행 키를 연결하고 적용 이유를 남긴다.

자료별로 아래 세 상태를 **독립적으로** 관리한다.

1. 자료 확보: 미수령 / 링크만 확보 / 원본 수령·열람 확인 / 미발행·해당 없음(근거 있음).
2. 사양·적용 검증: 미검토 / 부분 검증 / 근거로 확인 / 충돌·미확인. 원본 수령만으로 자동 확인하지 않는다.
3. 공개 허가: 미확인 / 조건부 / 허용 / 불허. 기술적으로 맞는 자료라도 허가 미확인이면 게시 가능으로 표시하지 않는다.

회신 처리 완료는 해당 요청의 모든 항목에 결과·근거·남은 조치가 기록된 상태다. 자료 완비나 게시 승인과 다르다. 미회신은 처리 완료로 세지 않고 대기 건수로 보고한다. 게시 가능은 해당 파일의 모델 적용·사용 품질 확인과 명시적 사용 허가 조건 충족을 모두 확인했을 때만 별도 판정하며, 실제 게시 작업은 범위 밖이다.
