## 목표와 범위

기존 정적 베타의 화면과 **동일한 25개 공개 후보**를 GitHub Pages 프로젝트 경로 `/AV-Portal/`에 게시한다. 허용된 공개 JSON 필드는 `brand`, `product`, `categories`, `kind`, `official_links`뿐이다. 공개 데이터의 GitHub 저장 및 Pages 배포는 이번 사용자 지시의 명시적 외부 공개 승인 범위다. 앞선 W-012의 게시 보류 기록은 당시 범위의 이력으로 유지한다.

GitHub Actions는 `main`의 정적 사이트 폴더 **만** Pages 아티팩트로 업로드한다. 호스팅에 필요한 공개 JSON과 워크플로, 짧은 실행·진행 기록만 추가한다. 기존 `./` 상대 asset·데이터 경로가 프로젝트 경로와 새로고침에서 동작하는지 실제 주소에서 확인한다. 원본 Excel·업체/공급처·내부 메모·private provenance·개인 경로·직접 제공 자료·내부 결정표·비밀키는 GitHub 및 Pages 아티팩트에서 제외한다. 제품 조사·Schema·DB·대규모 UI 수정은 하지 않는다.
