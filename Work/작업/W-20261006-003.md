## ★ Work가 Sony 5종을 전수 확인했다 — 다시 조사하지 마라

**등급은 전부 이미 `specifications`에 있다. 새로 받을 자료가 없다.**

| 제품 | 공식 등급 | 지금 어디에 적혀 있나 |
|---|---|---|
| **BRC-AM7** | **PoE++** `IEEE 802.3bt Type 4 Class 8` | 사양 행 `PoE++` |
| **SRG-A40** | **PoE++** `IEEE 802.3bt Type 4 Class 8` | 사양 행 `PoE` |
| **SRG-X40UH** | **PoE+** `IEEE802.3at` | 사양 행 `PoE` |
| RM-IP10 | **없음** — AC 전원 어댑터 | — |
| RM-IP500 | **없음** | — |

> **대상은 카메라 3종이다.** RM-IP10·RM-IP500은 **PoE 제품이 아니다. 건드리지 마라.**

## 문제는 「없다」가 아니라 「안 보인다」다

**등급이 사양표 깊숙이 묻혀 있다.** 단자 표에서는 셋이 **똑같아 보인다.**

```json
"connector": "LAN RJ-45",  "signal": "Network/PoE"     ← 3종 전부 같다
```

**세 제품의 전원 요구가 완전히 다른데 단자 표만 봐서는 구분이 안 된다.** PoE+ 스위치에 PoE++ 카메라를 물리면 켜지지 않는다. **현장에서 바로 문제가 되는 정보다.**

## ★★ 같은 방식의 선례가 이미 있다

NETGEAR 번호 지도가 **등급을 라벨에 직접 박아 두었다.**

```js
// tests/netgear-port-maps.test.mjs:23
gs108pp: ['RJ-45 1–4 · PoE+', 'RJ-45 5–8 · PoE+'],
```

**새 표기법을 만들지 마라. 이 방식을 Sony에 그대로 적용한다.**

## 바꿀 것 — `io`의 LAN 행 하나씩이다

### `signal`에 등급을 쓴다

| 제품 | 지금 | **바꿀 값** |
|---|---|---|
| `brc-am7` | `Network/PoE` | **`Network/PoE++`** |
| `srg-a40` | `Network/PoE` | **`Network/PoE++`** |
| `srg-x40uh` | `Network/PoE` | **`Network/PoE+`** |

### `condition`에 규격 번호를 남긴다

**기존 문구를 지우지 말고 규격을 덧붙인다.**

| 제품 | 지금 `condition` | 덧붙일 것 |
|---|---|---|
| `brc-am7` | `적합 PoE++ 스위치 필요` | `IEEE 802.3bt Type 4 Class 8` |
| `srg-a40` | `IP 스트리밍·VISCA over IP·HTTP 제어` | `PoE++ (IEEE 802.3bt Type 4 Class 8)` |
| `srg-x40uh` | `LAN 속도 규격은 공식 사양에 명시 없음(정보 없음)` | `PoE+ (IEEE802.3at)` |

> **`srg-x40uh`의 「LAN 속도 미명시」는 그대로 둔다.** 아직 모르는 것이 맞다. **PoE 등급과 LAN 속도는 다른 값이다.**

### 출처

세 제품 다 **이미 가진 출처로 충분하다.** `specifications`의 PoE 행이 쓰는 코드를 그대로 쓴다. **새 출처를 만들지 마라.**

## 번호 지도 — `srg-x40uh` 한 곳만 본다

`srg-x40uh`만 `portMap` 6개를 갖고 있다. 5번 항목이 **이미 등급을 적고 있다.**

```
5: LAN | RJ-45 · 네트워크 제어 및 PoE+ 전원을 연결합니다.
```

**이미 맞다. 고치지 마라.** 규격 번호를 더할지는 **선택**이고, 더한다면 `desc`에만 넣는다.

> `brc-am7`·`srg-a40`은 `portMap`이 없다. **이번에 만들지 마라.**

## 사양 행 이름은 건드리지 마라

지금 행 이름이 제품마다 다르다 — `PoE++`(BRC-AM7) · `PoE`(나머지 둘). **보기엔 어긋나지만 값은 셋 다 정확하다.**

> **이름 통일은 이번 범위가 아니다.** 과거 해시 검사를 건드리는 비용이 얻는 것보다 크다. **대기열 3번(말투 조정)에서 함께 다룬다.** 그 사실만 보고하라.
