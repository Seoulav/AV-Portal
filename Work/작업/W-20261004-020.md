## 0 — ★★ QMC·QHC 5종의 번호가 **4번부터 어긋나 있다**

사용자가 **"미묘하게 안맞아"**라고 했다. Work가 **도면 WebP의 픽셀을 직접 재서** 확인했다. 눈으로 본 것이 아니다.

### 재는 방법 (Codex도 이 방법을 쓴다)

도면의 **왼쪽 아이콘 칸**(`x 35~115`)만 훑어 **어두운 픽셀이 있는 세로 구간**을 뽑는다. 단자 그림 하나가 구간 하나다. 바깥 테두리의 위·아래 모서리 두 개를 빼면 **남는 수가 단자 수와 같아야 한다.**

```python
from PIL import Image
im = Image.open(path).convert('L'); w, h = im.size; px = im.load()
rows = [sum(1 for x in range(35, 115) if px[x, y] < 140) for y in range(h)]
# rows 가 0이 아닌 연속 구간 = 단자 하나
```

`lh43qmcebgcxkr-diagram.webp`에서 **구간 11개**, `lh32qmcebgcxkr-diagram.webp`에서 **구간 10개**가 나왔다. 단자 수와 정확히 맞는다. **방법이 맞다는 증거다.**

### 왜 이렇게 됐나

[W-20261004-017](W-20261004-017.md)에서 **QM32C는 자기 도면을 보고 쟀고**, 5종 공통 좌표는 **그만큼 꼼꼼히 다시 재지 않은 것**으로 보인다. 1~3번이 맞는 것이 그 흔적이다.

**Work의 명세가 "좌표가 5종에서 같은가"만 완료 조건으로 걸고, "좌표가 그림과 맞는가"는 안 걸었다.** 5종이 똑같이 틀려도 통과한다. **이번에 그 조건을 넣는다.**

사용자가 **"QMC, QHC 공통이니까 알아서 잘 바꿔줘"**라고 했다. **한 벌을 고쳐 5종에 그대로 넣는다.**

## 3 — 돋보기

`app.js:319`가 Port Map에, `app.js:314`가 이미지 대화상자에 돋보기를 붙인다. **제품별 설정이 아니라 전체 기능**이다.
