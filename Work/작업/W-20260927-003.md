## 배경

samsung.com/sec 비즈니스 페이지의 스펙 탭은 로그인 세션에서만 불러와져서, Samsung 페이지 16개의 정량 사양(해상도·밝기·명암비·무게·단자 수 등)이 비어 있었다. Opus 조사 에이전트는 사용자 중단으로 도중에 멈췄지만, 모델별 추가안 파일 16개는 이미 만들어 둔 상태였다. 이번 작업에서 그 파일을 검토하고 반영했다.

## 출처

- 삼성전자 공식 해외 지역 비즈니스 페이지의 사양표만 사용했다. 모두 samsung.com 도메인이다(영국·캐나다·중남미·스웨덴·뉴질랜드·홍콩).
- 국내 모델과 기본 모델 코드가 같고 지역 접미사만 다르다(예: LH55VHCRBGBXKR ↔ LH55VHCRBGBXEN).
- 각 사양 행의 조건에 사용한 지역 모델 코드를 적었다.
- 페이지마다 SPEC-REGION 이슈(REVIEW REQUIRED)를 두어, 전원·소비전력·인증처럼 지역에 따라 다를 수 있는 항목은 국내 사양서로 확인해야 한다고 기록했다.
- KQ75LSF03WFXKR(The Frame Pro)은 국내 지원 페이지에 사양표가 이미 있어 추가하지 않았다.

## 검토

- 추가안 파일에 저장된 원문 페이지 28개와 숫자 값을 자동 대조했다.
  - 숫자가 있는 값 395개는 모두 원문에서 확인됐다.
  - 숫자가 없는 값 169개(예: "미지원", 패널 종류)와 기존 출처를 인용한 값 38개는 자동 대조 대상이 아니다.
- 출처 코드 연결, 기존 사양 이름과의 중복 여부, 수정 대상 행의 원래 값 일치를 스크립트로 확인했다.
- 수정 2건은 원문을 직접 확인했다.
  - LH55WMF 밝기: "450 (w/o glass), 300 (w/ glass)"
  - LH75WMF 밝기: "450 (w/o glass)"
  - 처음 반영할 때 LH75WMF 값이 잘못 들어가 바로 고쳤다.
