## A — SIGNAL FLOW **2종만**

사용자가 **"나머지는 그리지말고"**라고 못 박았다. **`brc-am7`과 `srg-a40` 둘뿐이다.**

### ★ 필요한 값이 `io`에 이미 있다

Work가 꺼내 봤다. **새로 찾을 것이 없다.**

#### `brc-am7` — 14행

```
SDI OUT1 BNC    protocol "12G/6G/3G/HD-SDI"      ← 사용자가 말한 12G
SDI OUT2 BNC    protocol "3G-SDI Level A/HD-SDI" ← 등급이 다르다
HDMI Type A     protocol "HDMI"
OPTICAL SFP+    출력
GENLOCK IN BNC  protocol "1.0Vp-p, 75Ω"          ← 사용자가 말한 Genlock
TC IN BNC       Timecode
VISCA IN/OUT · LAN(PoE) · XLR 3핀 ×2 · 3.5mm · DC IN XLR 4핀 · OPTION(Tally) · CFexpress/SD
```

**두 SDI 출력의 등급이 다르다.** `OUT1`은 12G까지, `OUT2`는 3G까지다. **이 차이가 그림에 드러나야 한다.** 사용자가 **"12G, 3G"**를 콕 집은 이유다.

#### `srg-a40` — 8행

```
SDI OUT BNC     protocol "3G-SDI(Level A/B), HD-SDI"   condition "4K 출력 미지원"
HDMI Type A     protocol "HDMI, 최대 3840×2160/29.97p"  condition "SDI와 동시 출력"
LAN RJ-45 (PoE) · VISCA RS-422 IN/OUT · MIC 3.5mm · DC IN 19.5V
GENLOCK / TC    수량 0  ·  availability "Not available"
```

### ★★ `srg-a40`에는 젠록이 **없다**

사용자가 **"srg-a40도 마찬가지로"**라고 했지만, **이 제품에는 젠록이 없다.**

```json
{ "connector": "GENLOCK / TC", "quantity": "0", "availability": "Not available",
  "condition": "공식 사양 '젠록 입력 아니요', 'TC 입력/출력 아니요'" }
```

**`isAbsentConnector()`가 걸러 내는 값**이다. **젠록을 그리면 없는 단자를 그리는 것이 된다.**

**두 제품은 구조가 다르다.** `brc-am7`을 베껴서 `srg-a40`을 만들지 마라.

### HDMI·SDI 동시 출력 — **한쪽만 확인됐다**

사용자가 **"확인되면 그 부분을 텍스트로 표기"**라고 조건을 달았다.

| 제품 | `io`에 적힌 것 | |
|---|---|---|
| **`srg-a40`** | HDMI `condition: "SDI와 동시 출력"` | **확인됨 → 적는다** |
| **`brc-am7`** | SDI1 `"출력 설정별"` · HDMI `"형식·프레임 설정별"` | **기록 없음 → 안 적는다** |

**`brc-am7`에 동시 출력을 적지 마라.** 4K/프레임 설정에 따라 달라진다는 말만 있고 **동시에 되는지는 적혀 있지 않다.**

공식 쪽이나 설명서에서 **확인되면 적어도 된다.** 확인 못 하면 **"기록 없음"으로 보고**하라.

### 그릴 때

- **수는 `io`에서 읽는다.** 지어내지 마라
- 제어(VISCA·LAN)·전원·기록매체는 **신호 경로가 아니다.** 보조선으로 두거나 뺀다
- `flowTypes`에 **`camera`**가 있다. `processKinds`에 **`capture`**가 있다
- `auxiliary` 선마다 **`label`**을 붙여라. [W-20261004-019](W-20261004-019.md)가 병합되면 범례에 쓰인다
- **검증기를 고칠 일이 없다.** 고쳐야 한다고 판단되면 **먼저 물어라**
