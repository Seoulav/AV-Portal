## ★★ Work가 먼저 찾아봤다 — **재료가 없다**

사용자가 **"QMC처럼 매뉴얼 기반"**으로 해 달라고 했다. QMC는 설명서 20쪽에 **단자 선 도면 + 2열 설명표**가 있어서 가능했다.

**비즈니스TV는 그 쪽이 없다.** Work가 세 군데를 직접 확인했다.

### 1. 가진 PDF 두 건 — 도면 없음

| 파일 | 쪽 수 | 내용 |
|---|---:|---|
| `BN68-26617B-00_SUG_BEHX-H_KR_KOR_260526.0.pdf` | **2쪽** | 안전·구성품·초기 설정·리모컨·문제해결·제품 규격 |
| `BN68-26620A-01_IG_BEHX-H_Basic_feet_43-85inch.pdf` | **2쪽** | 스탠드 조립·치수표·VESA |

**두 쪽씩뿐이고 단자 설명 쪽이 없다.** TV라 **전체 설명서가 TV 안의 e-매뉴얼**이다. 간단 설명서에 이렇게 적혀 있다.

> *"TV 사용 설명서 보기 > 일반 설정 > …"*

#### 덤으로 확인된 것

설치 안내의 치수표가 **`BE43HX-*` ~ `BE85HX-*` 6종**을 싣고 있고, **`BE43HX`가 `957.8 × 558.8 × 76.3 mm`**다. [W-20261004-023](W-20261004-023.md)이 공식 쪽에서 읽은 값과 **일치한다.** 시리즈가 6종이라는 것도 다시 확인됐다.

### 2. 공식 제품 쪽 사진 — 뒷면 없음

갤러리 **5장을 받아 직접 봤다.**

```
정면(스탠드) · 측면 · 화면 확대 · 정면(크게) · 정면(비스듬)
```

**전부 앞·옆 홍보 사진이다. 뒷면도 단자도 없다.**

[W-20261004-010](W-20261004-010.md)에서 115인치를 할 때는 공식 갤러리에 **단자 근접 사진(`g5`)**이 있었다. **이 제품에는 그런 장이 없다.**

### 3. 전체 설명서 276쪽 — ★ 설명서가 직접 "안 싣는다"고 적어 놓았다

사용자가 **`BN81-28760B-500_EUG_ROPATSCH_KR_KOR_260703.0.pdf`**를 올려 줬다. **276쪽짜리 한글 전체 설명서**다.

Work가 **전 쪽을 훑어** 단자 관련 쪽을 뽑았다. 배치 도면이 **없다.** 대신 **21쪽에 이렇게 적혀 있다.**

> **"단자의 명칭, 위치, 개수는 제품에 따라 다를 수 있습니다."**

**이 설명서는 여러 TV 모델을 한꺼번에 덮는 공용 문서**라 **모델별 단자 그림을 일부러 싣지 않는다.**

QMC 설명서가 `QH43C / QM43C / …` **15개 모델에 도면 하나**를 준 것과 정반대다.

| | 사이니지 (QMC·QHC) | **TV (BEHX-H)** |
|---|---|---|
| 설명서 | 모델별 **단자 도면 + 2열 표** | **"제품에 따라 다름"으로 생략** |

#### Work가 이 파일을 놓쳤다

**`_samsung-pdf/`에 이미 있었다.** 파일명이 `ROPATSCH`라는 **내부 코드명**이라 BEHX-H 것인 줄 몰랐다. 사용자가 올려 줘서 연결됐다.

**앞으로 `_samsung-pdf/`의 파일을 코드명만 보고 넘기지 않는다.** 열어서 적용 모델을 확인한다.

| 하지 말 것 | |

| **다른 모델 도면 가져다 쓰기** | QMC 도면은 사이니지 것이다. **비즈니스TV는 TV다** |

| **홍보 사진에 번호 달기** | 단자가 안 보인다 |
| **다운로드센터를 더 뒤지기** | **설명서가 이미 답했다.** 시간을 쓰지 마라 |

[W-20261004-023](W-20261004-023.md)에서 **"단자가 보이는 사진이 없어 Port Map을 추측해 만들지 않았다"**고 한 판단이 **옳았다.** 그대로 둔다.

## ★★ 대신 할 일 — 설명서를 등록한다

**276쪽짜리 한글 전체 설명서는 제조사 공개 배포물**이라 그대로 올릴 수 있다. **그림은 못 만들어도 설명서는 붙일 수 있다.**

| | |
|---|---|
| 파일 | `BN81-28760B-500_EUG_ROPATSCH_KR_KOR_260703.0.pdf` · **5,471,890B** · **276쪽** |
| 있는 곳 | `_samsung-pdf/` (사용자가 올린 것과 **SHA-256 동일**: `245d8208…`) |
| 성격 | **제조사 공개 배포 설명서.** 영업 자료가 아니다 → **암호 불필요** |
| 적용 | BEHX-H **공용**. 제목에 그 사실이 드러나야 한다 |

**설치 안내 `BN68-26620A-01`도 같이 올릴지 판단하라.** 스탠드 조립·치수표·VESA가 들어 있어 쓸모가 있다. **이것도 공개 배포물이다.**
