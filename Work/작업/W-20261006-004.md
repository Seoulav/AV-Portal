| **나) 우리가 잘못 잘랐다** | Lightware 2종 · LED-780H = **3장** | **우리 처리 실수다** |

### UA874XA는 정상이다 — 건드리지 마라

사용자가 **"UA844+SWB외 안테나 전부"**라고 했지만, Work가 열어 보니 **`UA874XA`는 문제가 없다.** 지향성 안테나라 **정사각 틀을 가득 채운다.**

> **손대지 마라.** 고칠 것이 없다.

## 가) Shure 랙 3종 — 정사각 여백을 잘라낸다

### 무엇이 문제인가

`UA844+SWB` 전면을 열어 봤다. **1500×1500 정사각인데 제품은 1RU다.**

```
┌──────────────────────┐
│                      │  ← 검은 여백
│ ▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭  │  ← 제품 (세로 10% 남짓)
│                      │  ← 검은 여백
└──────────────────────┘
```

**목록과 상세에서 제품이 아주 작게 보인다.** 옆 제품과 나란히 놓으면 혼자 비어 보인다.

### 대상 6장

| 제품 | 파일 | 원본 |
|---|---|---|
| `ua844-swb` | `ua844swb-front.webp` · `ua844swb-rear.webp` | 3000×3000 |
| `ua864a` | `ua864a-front.webp` · `ua864a-rear.webp` | 3000×3000 |
| `ua845uwb` | `ua845uwb-front.webp` · `ua845uwb-rear.webp` | 3300×3300 |

출처는 셋 다 `products.shureweb.eu`이고 **각 제품 JSON의 `sourceUrl`에 그대로 적혀 있다.**

### 어떻게 자르나

| | |
|---|---|
| **원본에서 다시 받아** 자른다 | 게시본 1500×1500을 다시 늘리지 마라 |
| **빈 여백만** 잘라낸다 | 제품 가장자리를 자르지 마라 |
| **가로세로 비율을 바꾸지 마라** | 늘리거나 눌러서 맞추지 마라 |
| 위아래 **약간의 여유는 남긴다** | 제품이 틀에 딱 붙으면 답답하다 |

> **앞뒤 두 장의 최종 크기를 서로 맞춰라.** 같은 제품인데 앞뒤가 다른 비율이면 갤러리에서 튄다.

## 나) Lightware 2종 · LED-780H — 우리가 자른 것을 되돌린다

### 숫자가 말해 준다

| 제품 | 원본 | **지금 게시본** | 잘려 나간 세로 |
|---|---|---|---|
| `hdmi20-optj-rx90` | **1200×780** | `905×177` | **약 77%** |
| `hdmi20-optj-tx90` | **1200×780** | `905×177` | **약 77%** |
| `led-780h` | **880×278** | `880×159` | **약 43%** |

**원본에는 기기 전체가 들어 있는데 게시본에서 위아래가 잘려 나갔다.** Work가 열어 보니 **기기 윗면과 아랫면이 실제로 프레임에 잘려 있다.**

### 어떻게 고치나

**원본을 다시 받아 기기 전체가 들어가게 다시 만든다.** 자르지 않아도 된다면 자르지 마라.

| 제품 | 출처 |
|---|---|
| Lightware 2종 | `assets.prod.pim.lightware.com/.../HDMI20-OPTJ-RX-TX90_Front.png` |
| `led-780h` | `magnimage.com` 제품 쪽 — **`880×278` 원본을 다시 확보하라** |

> **★ Lightware 두 모델은 제조사가 같은 파일을 쓴다** (`HDMI20-OPTJ-RX-TX90_Front.png`). **그래도 우리 파일은 제품별로 따로 둔다.** `verify-pages`가 1:1로 대조한다. **파일을 공유하지 마라.**
>
> 바이트가 같아지면 [W-20261005-006](W-20261005-006.md)처럼 **제품군 공통 이미지임을 표시**하고 보고하라.

### `led-780h`는 각도도 비스듬하다

정면이 아니라 **비스듬한 각도**로 찍혀 있다. **정면 이미지를 새로 찾을 수 있으면 바꿔라.** 못 찾으면 **지금 것을 잘리지 않게만 고치고** 그 사실을 보고하라.

> **다른 제품 사진을 가져다 쓰지 마라.** `Magnimage LED-780H`가 맞는지 확인하고 쓴다.

## 메타데이터를 함께 고친다

크기가 바뀌면 **기록도 바뀌어야 한다.**

| | |
|---|---|
| `originalSize` | **실제로 받은 원본 해상도** |
| `resolution` | **새 게시 해상도** |
