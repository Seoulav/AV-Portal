## 목표와 현재 상태

현재 공개 홈은 진입 즉시 27개 장비를 나열하며, 검색과 카테고리가 탐색의 시작점으로 충분히 강조되지 않는다. Product Detail은 W-20260925-001에서 기본 노출량을 줄였으나, 화면 순서와 연결 단자 전체 목록은 사용자가 제시한 제품 중심 정보 구조에 맞춰 더 정리할 필요가 있다.

홈은 검색·상위 카테고리·제조사·두 외부 도구를 먼저 제시하고 사용자 입력 전에는 제품 목록을 숨긴다. 검색/카테고리/제조사 선택 뒤 같은 페이지의 결과 영역을 표시하며 URL 상태로 복원 가능하게 한다. Product Detail은 밝은 AV Portal 디자인을 유지하면서 이미지/제품 요약/문서/공식 페이지를 상단에 두고, 연결 단자는 Desktop 표와 Mobile 압축 목록으로 바꾼다.

## 범위

- `beta/site/index.html`, `beta/site/styles.css`, `beta/site/app.js`
  - 공통 헤더 검색, 홈 탐색 카드, 상위 카테고리 6개, 제조사 선택, 외부 도구 링크를 구성한다.
  - 초기 진입에는 제품 결과를 숨기고 검색·카테고리·제조사 선택 뒤 결과를 표시한다.
  - 검색은 공개 데이터에 있는 제조사·제품명·모델/별칭·카테고리와 공개 Product Detail의 확인된 Feature/I/O 규격 검색어를 안전하게 보강한다. 공개되지 않은 조사 데이터는 사용하지 않는다.
  - 검색 제안은 제품·제조사·카테고리로 구분하고, 제품 선택은 기존 상세 URL로 이동한다.
  - 결과에는 검색/카테고리 문맥, 결과 수, 하위 카테고리, 제조사, 자료·검증 상태, 정렬, 초기화를 제공한다. 현재 데이터에서 의미 없는 필터는 숨긴다.
  - 검색어·필터·스크롤 위치를 URL/session history로 복원한다.
- `prototype/brc-am7/` 정본과 `beta/site/detail/` 생성물을 함께 변경한다.
  - 상단 정보 순서를 이미지 Gallery와 제품 요약/Quick Documents/공식 페이지 중심으로 유지한다.
  - 상세 내비게이션은 개요·특징·스펙·연결 단자·관련 제품·문서·출처·검증을 제공하되, 데이터가 없는 관련 제품은 완성 기능처럼 꾸미지 않고 비어 있음을 명확히 표시하거나 비활성 처리한다.
  - 연결 단자는 Desktop 연속형 표 `구분 | 연결 단자 | 방향 | 수량 | 규격 및 용도`, Mobile 신호 그룹별 압축 목록/아코디언으로 표시한다.
  - 입력/출력/양방향은 한글 텍스트로 표시하고, 옵션·조건·검토 필요만 강조한다. 출처·검증·상세 조건은 근거/검증 펼침에 보존한다.
- 테스트는 원본/생성물 동기화, 초기 목록 비노출, 탐색 후 결과 표시, 검색 범위, URL 상태 복원, 5개 상세 데이터 보존, Desktop 표/Mobile 압축 목록을 검증한다.
- 작업 기록과 `Work/기록/W-20260925-002-Work-인계.md`를 구현 PR에 포함한다.
