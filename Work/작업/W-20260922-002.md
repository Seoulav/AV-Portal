## 목표

Work가 기존 보류 사항과 자료 수령 결과를 정리해 실제 구현 가능한 다음 작업을 준비한다. 이 문서는 구현 허가가 아니며, Codex는 이 DRAFT로 제품 코딩을 시작하지 않는다.

## Work가 먼저 준비할 항목

- 공식 자료의 실제 제공 위치·수령일·공개 가능 범위 확인
- 기존 자료 대비 신규·동일·개정·누락과 충돌 정리
- 제품 상태 및 Series / Model / Module / TX-RX 관계의 미확정 항목 구분
- 현재 저장소에 없는 원본 RTCOM 코드와 자료의 제공 여부 확인
- 사용자에게 필요한 결정과 구현 가능한 최소 작업 범위 제안

## READY 전환 조건

구현 대상, 변경 경로, 확인 가능한 완료 조건, 검증 방법, 실제 승인 근거를 구체화한다. 미확정 제품 사실은 추측하지 않는다. 공식 자료가 없어도 독립적으로 진행 가능한 작업은 별도 ID로 분리하고 그 범위의 승인 여부를 기록한다.

## Codex 인계

현재 인계 가능한 제품 구현 작업은 없다. Work가 준비를 마치면 새 명세 또는 이 명세의 확정판을 PR로 병합하고, Codex는 그 커밋 SHA를 지시서에 기록한 뒤 착수한다.
