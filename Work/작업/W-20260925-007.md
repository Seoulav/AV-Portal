## 목표와 현재 상태

7탭 구조와 나머지 화면은 승인됐다. **출처 표시만 걷어내고 검증 상태 탭을 정리한다.**

### 왜 걷어내는가 — 5개 제품 전수 점검

**가. 선언했으나 아무 값도 뒷받침하지 않는 출처가 8건이다.**

| 제품 | 인용 실적 | 인용 0건 |
|---|---|---|
| BRC-AM7 | HS 사양22+IO12 · HC 사양2+IO14 · PP 사양7 | **P · H · SP** |
| DM7 | TD 사양16+IO14 · RM 사양1+IO10 | **P · IMG** |
| Ki Pro GO2 | P 사양16+IO11 | **M** |
| PT-MZ17K | F 사양5 · M 사양3+IO1 | **P · R** |
| Rally Bar | P 사양10+IO9 · S 사양6+IO9 · F 사양2 | 없음 |

`P`(제조사 공식 제품 페이지)는 두 제품에서만 인용되고 세 제품에서 0건이다. 제품마다 기준이 다르다.

**나. 특징 39개 전부 `source`가 빈 문자열이다** (8/8, 8/8, 8/8, 7/7, 8/8). 그런데 `특징별 근거 보기` 펼침이 있고 열면 아무것도 없다.

**다. PT-MZ17K는 사양 5/13, 연결 단자 3/4에도 `source`가 없다.**

**라. 코드 문자가 독자에게 의미가 없다.** `P`·`HS`·`TD`·`PP`를 보고 어떤 자료인지 알 수 없다. 이름도 `제조사 자료 목록`·`제조사 사용 안내`처럼 일반명이라 구분이 안 된다.

정확하지 않은 출처를 고쳐서 보여주려면 제조사 원본을 다시 읽어야 한다. **어느 자료를 봤는지는 `문서` 탭이, 믿을 만한지는 검증 배지가 이미 담당한다.** 출처 표시는 화면에서 걷어낸다.

**데이터는 지우지 않는다.** JSON의 `source`·`sources` 값을 그대로 두어 나중에 다시 켤 수 있게 한다.

## 할 일

### 1. 출처 표시 제거

- **사양·연결 단자 행의 `근거 HS · TD` 링크를 없앤다.** 5개 제품 합계 170건이다.
- **`제조사 공식 출처`(Manufacturer Official) 목록 섹션을 없앤다.**
- **`특징별 근거 보기` 펼침을 없앤다.**
- `#source-XX` 앵커 대상이 사라지므로, 그 해시로 진입하면 **오류 없이 해당 탭만 열고** 페이지 최상단에 머문다. 콘솔 오류가 없어야 한다.

### 2. 검증 상태 요약을 탭 맨 위에

값은 **JSON에서 집계**한다. 개수를 지어내지 않는다.

```
사양 13개        ✓ 9 검증   △ 2 검토 중   ✗ 2 미확인
연결 단자 4개               △ 1 일부      ✗ 3 미확인
```

- 상태별 개수를 기존 배지 색으로 구분한다.
- **`VERIFIED`가 0개인 구간은 눈에 띄게 표시한다** — PT-MZ17K의 연결 단자가 그렇다.
- 항목이 없는 상태는 칸을 만들지 않는다.

### 3. 탭 이름과 구성

- 표시 이름을 **`출처·검증` → `검증 상태`** 로 바꾼다.
- **패널 `id`는 `sources`를 유지한다.** 공개된 `#sources` 링크가 이미 쓰이고 있다.
- 탭에 남는 것은 세 가지다.
  1. 검증 상태 요약 (위 2번)
  2. `검토 중인 항목` — 기존 내용 유지
  3. `검증 상태 설명` 범례 — **맨 아래 각주**로 내린다

### 4. 문서 목록 제거

`검증 정보 보기` 안의 매뉴얼·시방서·사양서·기술문서 목록을 없앤다. `문서` 탭이 담당한다.

### 5. 화면 정리

- 펼침 장치를 **한 가지 모양으로** 통일한다. 현재 `−` 아이콘·`▸` 삼각형·테두리 버튼 세 가지가 섞여 있다.
- `Supplemental / Domestic`은 내용이 없으면 섹션을 만들지 않는다.
- 영문 제목을 한글로 — `Manufacturer Official`·`4 SOURCES`·`Supplemental / Domestic`.
- **푸터의 빌드 문자열을 공개 화면에서 제거한다.** `beta/site/index.html:67`과 `beta/site/detail/index.html:137`의 `SYSTEM v0.1.0 · build local`이다. 배포본에서 `build 41 · 6a168fb`로 치환돼 고객 화면에 빌드 해시가 노출된다. 필요하면 주석이나 `<meta>`로 옮긴다.

## 미결 사항·의존성

- **데이터는 그대로 둔다.** JSON의 `source`·`sources` 값을 지우지 않으므로, 나중에 출처 코드를 제대로 채운 뒤 표시를 다시 켤 수 있다.
- 출처 코드 보완은 별도 작업이다. 특징 39건 전부, PT-MZ17K의 사양 5건·연결 단자 3건에 `source`가 없고, 인용 0건 출처가 8건이다. 제조사 원본과 로컬 Group 1 패키지가 필요하다.
- 배포는 별도 승인 후 진행한다.
