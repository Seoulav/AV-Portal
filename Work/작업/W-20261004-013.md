## 자료는 이미 있다. 안 보일 뿐이다

사용자가 115인치에 **"제품 가로세로깊이가 반드시 있어야 한다"**고 했는데, 확인해 보니 **이미 들어 있었다.**

```
크기(가로x높이x깊이)      = 2565.2 x 1467.6 x 34.1 mm
포장 크기(가로x높이x깊이) = 2765.0 x 1652.0 x 250.0 mm
중량                     = 83.7 kg
```

문제는 **보이지 않는다**는 것이다. `app.js:367`이 **처음 12행만** 보여 준다.

```js
$('#spec-toggle').hidden = specNumber <= 12;
$('#spec-toggle').textContent = `사양 ${specNumber - 12}개 더 보기`;
```

115인치는 사양이 **56행**이고 치수는 **33번째쯤**이라 `사양 44개 더 보기`를 눌러야 나온다.

행 순서는 `group` 값이 나온 순서다(`product-detail-model.mjs:240`). `Display` 그룹이 앞에 몰려 **12행 안이 전부 화면·화질 항목**이다.

## ② 중복 병합과 삭제

### 기준 — 사용자가 확정했다

> **근거가 있는 값은 지우지 않고, 근거가 없는 값은 남기지 않는다.**

사용자가 삼성 공식 스펙 표(13항목)를 제시하며 **"이정도 스펙만 명시하면 되"**라고 했으나, 대조해 보니 그 표에는 **`해상도`가 없다.** 홍보용 요약이기 때문이다. 그래서 **표를 그대로 따르지 않고 근거 기준으로 간다.**

| 삼성 표에 없으나 **매뉴얼로 검증**된 값 |
|---|
| `해상도` 3,840 x 2,160 · `최대 주사율` 120 Hz · `디스플레이 면적` · `전원 사양` · `동작 습도` |

**이 값들은 유지한다.**

### ②-1 밝기 병합

```
밝기(Typ)  = 1000 nit   REVIEW REQUIRED · 출처 없음
밝기(최대) = 1000 nit   FOUND · 공식 페이지
```

**값이 같고 하나는 근거가 없다.** `밝기(Typ)`는 **출처 없는 `REVIEW REQUIRED` 삭제(②-3)로 함께 지워지므로** 별도 병합 작업이 없다. 결과적으로 `밝기(최대)` 한 행만 남아 사용자 요청이 충족된다.

남는 행 이름이 `밝기(최대)`인데 값이 하나뿐이라 **다른 최댓값이 따로 있는 것처럼 읽힐 수 있다.** 이름을 `밝기`로 다듬을지는 **Codex 판단에 맡기고 보고하게 한다.** 값과 검증 상태는 건드리지 않는다.

다른 제품의 밝기 행은 **값이 다르거나 하나뿐**이라 병합 대상이 아니다.

| 제품 | 밝기 행 |
|---|---|
| `lh55wmfwbgcxkr` | `450 (유리 미장착) / 300 (유리 장착)` — **조건이 다르다. 합치지 않는다** |
| `mp008f` 외 2종 | `피크 1,800 / 최대 1,000` — **조건이 다르다. 합치지 않는다** |
| 나머지 | `밝기(Typ)` 하나뿐 |

### ②-2 사용자가 지목한 13행 삭제

| 행 | 적용 종수 |
|---|---:|
| `수평 주사 주파수` · `최대 픽셀 주파수` · `수직 주사 주파수` · `패널 헤이즈(Haze)` | 각 **11** |
| `옵션 벽걸이 마운트` · `안전 규격` | 각 **10** |
| `베젤 색상` · `옵션 스탠드` · `EMC 등급` | 각 **9** |
| `보관 온도` · `보관 습도` | 각 3 |
| `화면 보정` · `방수/방진` | 각 1 |

**총 99행.**

사용자는 **`보관 온도`·`보관 습도`가 매뉴얼 검증(`VERIFIED`) 값임을 알고도 "13행 전부 삭제"를 선택했다.** 그대로 지운다.

`Certification`·`Accessory` 그룹은 **통째로 사라진다.** 정상이다.

### ②-3 출처 없는 `REVIEW REQUIRED` 삭제

`verification`이 `REVIEW REQUIRED`이고 **`source`가 비어 있는** 행이다. 조건란에 `국내 자료 미확보`라고 적혀 있다.

| 제품 | 해당 행 |
|---|---:|
| `lh115qhfebgxkr` | **17** |
| `lh55wmfwbgcxkr` | **15** |
| 나머지 15종 | **0** |

**총 32행.** 두 제품에만 몰려 있다.

**`source`가 있으면 `REVIEW REQUIRED`라도 지우지 않는다.** 근거는 있고 확인이 덜 된 상태일 뿐이다.

**숫자를 맞추려고 근거 있는 행을 더 지우지 않는다.** 숫자는 Work 계산의 산물이고 기준은 **"근거가 있으면 남기고 없으면 지운다"**다. 둘이 어긋나면 **기준을 따른다.**

## ★ 삭제는 되돌리기 어렵다
