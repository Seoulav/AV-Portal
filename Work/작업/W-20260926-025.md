- [ ] SLX-D 6개: 로컬 결정표 `approved`에서 제외
- [ ] SLX-D+ 6개: 원본 목록에 제품 추가(공식 제품 페이지 URL은 위 결정표 `official_urls`)하고 `approved`에 추가
- [ ] GS728TPP: `approved`에 포함되어 있는지 확인
- [ ] GSM4212P: 원본 목록의 공식 링크를 `https://www.netgear.com/kr/business/wired/switches/fully-managed/gsm4212p/`로 교체하고, `approved`의 `urls`도 교체
- [ ] 원본 목록이 바뀌면 파일 해시도 바뀐다. 로컬 결정표의 `source_sha256`을 새 해시로 갱신(`beta/build.mjs`가 해시가 다르면 빌드를 중단한다)
