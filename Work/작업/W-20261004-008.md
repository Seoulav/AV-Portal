## 지금 무엇이 다른가

사용자가 두 화면의 버전 표기를 나란히 표시해 보여 주었다. 양쪽 소스를 대조했다.

알티컴 `index.html:4`

```html
<div class="rt-meta"><b>AV 시스템 설계 도구</b><br>CATALOG BASED · 0.195</div>
```

```css
.rt-meta{padding:8px 14px;border-radius:999px;background:#f0f4fa;text-align:center;line-height:1.35;font-size:12px;color:var(--rt-muted)}
.rt-meta b{font-weight:700;color:#376cd0}
```

| 항목 | 알티컴 | AV Portal |
|---|---|---|
| **배치** | 헤더 안(`.rt-top-links`) **문서 흐름** | **`position:fixed`** 떠 있음 |
| **줄 수** | **2줄** (`<b>` + `<br>` + 본문) | 1줄 `white-space:nowrap` |
| **정렬** | `text-align:center` | — |
| **배경** | `#f0f4fa` | `#fffffff0` + `backdrop-filter:blur(8px)` |
| **테두리** | **없음** | `1px solid #cbd8e8` |
| **그림자** | **없음** | `0 4px 14px #17375f1f` |
| **글꼴** | 본문체 **12px** | **monospace 10px / 700** |
| **1행** | `AV 시스템 설계 도구` — **700 · `#376cd0`** | 없음 |
| **2행** | `CATALOG BASED · 0.195` | `SYSTEM v0.1.0 · build 200 · f0dd51b` |

**떠 있는 알약을 헤더 안의 2줄 표기로 바꾸는 작업이다.**

## 넣을 문구 — 사용자가 정했다

```
AV 장비 자료실                         ← 700 · #376cd0
DOCUMENT BASED · v0.1.0 · 200          ← 본문체 · muted
```

| 자리 | 알티컴 | AV Portal | 근거 |
|---|---|---|---|
| 1행 | `AV 시스템 설계 도구` | **`AV 장비 자료실`** | 사이트 설명문 "AV 장비를 제조사, 제품명, 카테고리와 연결 규격으로 탐색하는"에서 왔다 |
| 2행 앞 | `CATALOG BASED` | **`DOCUMENT BASED`** | 알티컴은 카탈로그, 우리는 제조사 공식 문서가 근거다 |
| 2행 뒤 | `0.195` | **`v{version} · {build}`** | 빌드 번호로 배포 갱신을 확인한다 |

**커밋 SHA(`revision`)는 2행에서 빼고 `title` 설명으로 옮긴다.** 마우스를 올리면 나온다. 배포 시각도 지금처럼 `title`에 남긴다.

**1행은 고정 문구다.** `version.json`에 넣지 않는다.

## `#376cd0`은 알티컴 값을 그대로 쓴다

AV Portal 토큰에 없는 색이다. `--pg-accent-2`(`#0057D8`)가 가깝지만 다르다.

**사용자 지시가 "이 사이트처럼"이므로 `#376cd0`을 쓴다.** [W-20261004-001](W-20261004-001.md)에서 `#2459b0`을 걷어낸 것과 모순되지 않는다. 그때는 **알티컴에 없는 색**이라 지웠고, 이번은 **알티컴에 있는 색**이라 가져온다. 근거표에 그 판단을 적는다.

## 배치를 헤더 안으로 옮긴다

`position:fixed`를 **버린다.** 세 페이지 헤더의 오른쪽 끝, 기존 요소들과 같은 흐름에 둔다.

- `beta/site/index.html` — `.site-header` 오른쪽
- `beta/site/catalog.html` — 같음
- `beta/site/detail/index.html` — 같음

**[W-20261004-002](W-20261004-002.md)에서 넣은 `top` 분기 4개가 전부 불필요해진다. 지운다.**

```css
.pg-page .system-version{top:112px}
@media(min-width:721px) and (max-width:1000px){.pg-page:has(.home-wrap) .system-version{top:155px}}
@media(max-width:720px){.pg-page .system-version{top:120px}.pg-page:has(.home-wrap) .system-version{top:185px}}
@media(max-width:460px){.system-version{right:8px;top:8px;…}}
```

떠 있지 않으므로 **헤더와 겹칠 일이 없다.** `pointer-events:none`도 더 이상 필요 없다.

**세 페이지의 헤더 구조가 서로 다르다.** 각각 확인하고, 좁은 화면에서 헤더가 무너지지 않는지 본다. 알티컴은 좁은 화면에서 `.rt-top-links{flex-direction:column;align-items:stretch}`로 세로로 쌓고 `.rt-meta{width:100%}`를 준다. **같은 방식을 쓴다.**

## 두 줄을 안전하게 만든다

지금은 `badge.textContent = …` 한 줄이다. 굵은 1행이 필요하므로 요소를 만들어 붙인다.

**`innerHTML`을 쓰지 않는다.** `document.createElement('b')`와 `document.createElement('br')`로 조립한다. 값이 우리 `version.json`에서 오더라도 마찬가지다.

실패 경로(`version.json`을 못 읽을 때)도 **2줄 형태를 유지**한다. 지금은 `SYSTEM VERSION · 확인 필요` 한 줄이다. 1행은 고정 문구이므로 그대로 두고 **2행만** `DOCUMENT BASED · 확인 필요`로 둔다.

## 범위

- `beta/site/system-version.css` — 알티컴 형태로 교체, `position:fixed`와 `top` 분기 제거
- `beta/site/system-version.js` — 2줄 조립, `title`에 SHA·배포 시각
- `beta/site/index.html`·`catalog.html`·`detail/index.html` — 배지를 헤더 흐름 안으로 이동
- 전용 검사, 캡처, `Work/지시서.md`, Work 인계

## 미결 사항

- 알티컴 로컬 사본은 `0.195`, 공개 사이트는 `0.199`다. **로컬 사본이 뒤처져 있을 뿐**이며 형태는 같다.
