## ★★★ 가장 중요한 것 — Port Map을 만들지 마라

## `io`는 9행으로 맞춘다

기존 QMC 6종이 모두 **`io` 9행**이다. 75인치도 같은 모양으로 맞춘다. 근거는 위 슬라이드 10의 **연결성 칸**이다.

```
HDMI 입력 3 · DP 입력 1 · USB 2 · IR 입력 있음 · WiFi 있음 · Bluetooth 있음
```

| | |
|---|---|
| 수량이 적힌 단자 | `quantity`에 그 수를 적고 `source`를 **`S3`** |
| `있음`만 적힌 단자 | **수량을 지어내지 마라.** `quantity`를 비우고 `availability`에 근거를 적는다 |

**9행을 채우려고 없는 단자를 만들지 마라.** 근거로 채워지는 만큼만 만들고, **9행이 안 되면 그 사실을 보고**하라.
