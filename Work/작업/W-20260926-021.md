## 목표와 현재 상태

W-20260926-020에서 새로 만들거나 사진을 바꾼 페이지를 실제 브라우저로 열어, 극단 비율 사진의 갤러리·확대 보기·돋보기 동작과 새 사양 행 표시를 확인한다.

## 확인 방법과 결과

- 로컬 정적 서버(`python3 -m http.server`, `beta/site`) + Playwright(Chromium), 데스크톱 1280px·모바일 390px
- 대상 8개: slxd4d-plus, slxd2-plus-b87a, slxd1-plus, gs728tpp, ulxd4q, comtech-d-8125, qlxd4, i-tech-4x3500hd
- 결과
  - 이미지 20여 장 전부 로드됨. HTTP 오류·콘솔 오류 0건
  - 극단 비율 사진(893×96, 2000×264, 473×2000 등)도 갤러리에서 비율을 유지한 채 표시
  - 확대 보기와 돋보기가 전 이미지에서 동작
  - 모바일 레이아웃 깨짐 없음
  - '국내 인증' 사양 행은 스펙 탭 '인증' 그룹에 정상 표시
- 발견한 기존 결함(모든 상세페이지 공통):
  - `body.summary-detail main :where(p,span,…){color:#294867}` 규칙이 갤러리의 역할 표시(`#image-role`, span)와 확대 버튼 아이콘(span)의 글자색을 남색으로 덮어썼다.
  - 두 요소는 어두운 배경(#303030) 위에 있어 거의 보이지 않았다.

## 범위
