[원본 전체 기획서](av-portal-redesign-20260929/00_MASTER_PLAN.md), [6단계 원문](av-portal-redesign-20260929/06_RTCOM_INTEGRATION.md), [보정 명세](W-20260929-001-보정명세.md) 6·7장을 적용한다. 원문과 보정 명세가 다르면 보정 명세를 우선하며, 아래 2026-09-29 사용자 결정이 최종 기준이다.

RTCOM 공개 제품정보를 AV Portal이 읽고 AV Portal의 목록·검색·상세 화면 틀로 보여 준다. RTCOM 원본 저장소와 공개 데이터가 단일 원본이며 AV Portal은 값을 고치거나 원본으로 되돌려 보내지 않는다.

## 원본과 사용자 결정

- 원본 목록: `https://seoulav.github.io/rtcom-configurator/data/products/index.json`
- 스키마: `rtcom.products.v1`
- 2026-09-29 확인 기준 제품 수는 32종이나, 구현·검증에서 이 수를 고정 상수로 사용하지 않는다.
- 상세 주소: `/detail/?product=rtcom-<id>`
- 기존 AV Portal slug와 충돌하면 동기화를 실패 처리한다.
- 제외 모델 `HS-88M-U`, `HS-88MX`, `HD-D104U`, `HD-D108U`가 원본에 나타나면 공개 세트에 넣지 않고 차단 사실을 기록한다.
- RTCOM 매트릭스 구성기는 다시 만들지 않는다. 홈 `03 설계 도구`에 기존 카드와 같은 모양의 `RTCOM Matrix Configurator` 링크를 추가한다.
  - `https://seoulav.github.io/rtcom-configurator/#matrix-configurator`
- RTCOM 상세 머리에 `알티컴 제품정보에서 자세히 보기 ↗` 링크를 둔다.
  - `https://seoulav.github.io/rtcom-configurator/#products/<id>`
- RTCOM의 Port Map·Signal Flow·EDID·딥 스위치 카드는 AV Portal에서 재구현하지 않는다.
- `catalog.html`과 `llms.txt`, `search-index.json`에 RTCOM 제품을 포함한다.
- RTCOM `documents[].file` PDF는 복사하지 않고 원래 공개 주소를 W-20260929-007 PDF.js 뷰어로 연다.
- 하루 한 번 예약 실행과 `workflow_dispatch` 수동 실행을 제공한다. 변경이 있을 때만 PR을 만들고, 검증된 PR 상시 병합 규칙에 따라 병합·배포한다. 변경이 없으면 PR을 만들지 않는다.

## 구현 범위

1. 원본 목록·상세 JSON과 이미지 세트를 받아 검증하는 동기화 스크립트
2. 받은 원본 JSON의 바이트와 SHA를 보존하는 마지막 정상본 저장 영역
3. 원본을 수정하지 않고 AV Portal 표시 구조로 읽는 별도 어댑터
4. 홈 목록·검색 인덱스·읽기용 `catalog.html`·`llms.txt`의 RTCOM 항목
5. `/detail/?product=rtcom-<id>` 상세 화면, 공식 RTCOM 상세 링크, 기존 PDF 뷰어 연결
6. 홈 `03 설계 도구`의 RTCOM Matrix Configurator 링크 카드
7. 예약·수동 동기화 GitHub Actions와 변경 있을 때만 PR을 만드는 흐름
8. 목록·상세·이미지가 같은 시점인지, 기존 240개가 바뀌지 않았는지, 실패 시 마지막 정상본이 유지되는지 검증하는 테스트와 기록

## 원자적 교체와 실패 정책

- 목록·모든 상세·모든 필요한 이미지가 하나의 임시 세트에서 검증된 뒤에만 새 정상본으로 교체한다.
- 목록·상세·이미지 중 하나라도 다운로드 또는 검증에 실패하면 기존 마지막 정상본을 그대로 유지한다.
- 서로 다른 실행 시점의 목록·상세·이미지를 섞지 않는다.
- 원본 JSON은 바이트 그대로 저장하고 SHA-256을 기록한다. 화면용 기본값·URL·slug·그룹 변환은 별도 어댑터에 둔다.
- 같은 원본 SHA로 다시 실행했을 때 공개 파일을 다시 쓰지 않고 변경 없음으로 끝낸다.
- 문서는 복사 대상에서 제외하되, 공개 주소와 PDF 여부는 표시·뷰어 연결 전에 검증한다.
