Aquilon(RS·C)·Alta 4K(Zenith)·Midra 4K(Pulse·Eikos)의 **레이어 연출 규칙을 한 문서·한 화면으로** 정리합니다. 지금은 규칙이 제품 페이지 해설(W-010·011·018)과 가이드(W-019)에 흩어져 있습니다.

1. 기준 문서 `Work/기획/AnalogWay-레이어연출기준.md`를 씁니다. 시리즈마다 아래 항목을 같은 순서로 적습니다.
   - 화면(Screen)·출력·AUX의 관계
   - 레이어 종류: 믹싱·분할·배경·전경·AUX 레이어
   - 화면당·장비 전체 레이어 수와 나눠 쓰는 방식
   - 화면 크기·해상도(용량)에 따른 차이
   - 여러 출력에 걸친 화면의 계산
   - 레이어 없는 화면, PiP, 확인되지 않은 점
   - 각 항목에 원문 영어 문장과 쪽을 답니다. 이미 독립 검증한 결과(W-010·011·018·019 PR 기록)를 기준으로 하고, 다르면 고치지 말고 표시합니다.

   - 시리즈별 요약 표와 예시 3~4개를 넣습니다. 예: "4K 화면 1개에 PiP 몇 개", "8K LED월 1면", "화면 2개 동시 운영".

## 2부 — 설계 가이드 보완 (1부 병합 뒤)

1. **화면 크기로 입력**: LED월·디스플레이 해상도(예: 3840×2160, 7680×2160, 5760×1080, 7680×4320)를 넣으면 필요한 출력 수와 용량을 자동으로 정합니다.
   - 근거는 Aquilon 매뉴얼 61쪽 용량 표(1080p60·2560×1600@60 = 1, 3840×2160@60 = 2, 5120×2880@60·7680×4320@30 = 4)와 Alta·Midra 매뉴얼의 출력 형식입니다.
   - 표에 없는 해상도는 "공식 자료 미확인"으로 둡니다.
2. **HD(용량 1) 레이어 선택**: Aquilon 매뉴얼 66쪽 "VPU당 HD 8개"와 69쪽 권고("Optimized mode에서는 용량 2만")를 근거로 합니다.
   - 용량 1 레이어를 섞을 때의 비용이 문서에 없으면, 그 조합은 "미확인 · 제조사 시뮬레이터로 확인" 판정으로 따로 표시합니다. 계산을 지어내지 마십시오.
3. **시뮬레이터 연결**: 결과 아래에 "이 구성을 제조사 시뮬레이터로 확인" 안내와 공식 링크를 둡니다.
4. **결과 내보내기**: 입력한 구성과 결과를 복사하거나 인쇄용으로 볼 수 있게 합니다(링크 공유 또는 텍스트 복사).
5. W-019의 계산 함수·시험·전수 탐색은 유지합니다. 새 입력은 기존 계산에 들어가는 값(출력 수·용량)으로 변환하는 층으로 추가합니다.
