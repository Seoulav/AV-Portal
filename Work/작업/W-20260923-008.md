## 옵션 19행의 판단 기준

원본 영상 44–54행은 NovaStar 후보 11행, 59–66행은 Colorlight 후보 8행이다. 17행의 모델/규격 텍스트는 정확한 SKU 확정 근거가 아니다.

- 44–50·52: 모델 형태의 표기를 가진 카드 후보. 브랜드·입출력 방향·독립 옵션 식별 근거를 검토하여 편입 후보 또는 보류로 기록한다. 일괄 승인하지 않는다.
- 51·53: 기존 조사에서 표기/채널 설명 충돌이 보고됐다. 원문을 그대로 보존하고 오인되지 않는 식별 근거가 확보되기 전 보류한다.
- 54: 전원 후보의 주문명/부품번호 식별을 확인한다. 전력 설명만으로 독립 제품을 확정하지 않는다.
- 59–64: 포트 규격 설명만으로 SKU를 만들지 않는다. 59/64, 60/63의 동일 규격 텍스트는 입력/출력 방향이 다르므로 자동 중복 병합 금지.
- 65–66: 모델 공백 2행은 기본적으로 식별 보류. 원본 행 기반 추적용 키를 쓰되 확정 제품 ID로 취급하지 않는다.

행별 결과는 편입 후보 / 기존 항목 연결 후보 / 묶음 근거 검토 / 식별 보류 중 하나와 이유로 기록한다. 실제 고유 옵션임을 식별할 수 있으면 세부 호환성 전체 확정을 무조건 기다리지 않고 호환성 미확인 상태로 분리할 수 있다. 단, H2/H5·X100 Pro 등 본체 호환을 미확인 상태에서 지원한다고 표시하지 않는다. 묶음은 제조사 구성 근거가 있을 때만 제안한다.

자료 확보·정확 모델 적용 검증·게시 허가는 각각 독립 판정한다. 외부 공개용 자료 연결은 별도의 권한 검토를 필요로 한다.
