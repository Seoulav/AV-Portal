## 매뉴얼이 사용자 판단을 뒷받침한다

`BN81-24537G-14` **20쪽 「단자 설명」 하나가 15개 모델**을 함께 다룬다.

```
QH43C / QM43C / QH50C / QM50C / QH55C / QM55C / QH65C / QM65C
/ QH75C / QM75C / QM85C / QB98C / QB98C-N / QH98C / QM98C
```

**제조사가 직접 "이 모델들은 단자가 같다"고 밝힌 것**이므로, 같은 도면을 여러 제품에 붙여도 되는 근거가 된다.

## ★ 세 묶음이다 — 32인치가 다르다

| 묶음 | 우리 제품 | 매뉴얼 | 단자 |
|---|---|---|---:|
| **A — QMC·QHC 공통** | `lh43qmcebgcxkr` · `lh85qmcebgcxkr` · `lh98qmcebgcxkr` · `lh43qhcebgcxkr` · `lh75qhcebgcxkr` **5종** | **20쪽** | **11** |
| **B — QM32C** | `lh32qmcebgcxkr` **1종** | **24쪽 전용** | **10** |
| C — 115QHF | 완료 ([W-20261004-010](W-20261004-010.md)) | 15쪽 | 11 |

### 세 묶음의 단자 순서가 서로 다르다

```
A (QMC·QHC)  USB2 → USB1 → 🔊 → DP → HDMI3(ARC) → 2 → 1 → RJ45 → RS232C↵ → RS232C↱ → IR
B (QM32C)    USB2 → USB1 → 🔊 → RS232C↵ → RS232C↱ → HDMI3(ARC) → 2 → 1 → RJ45 → IR
C (115QHF)   USB2 → USB1 → 🔊 → HDMI3(ARC) → 2 → 1 → DP → RJ45 → RS232C↵ → RS232C↱ → IR
```

**B에는 DP가 없고**, A와 C는 **DP 위치가 다르다.**

→ **115인치 것을 복사하면 틀린다.** A용을 새로 만들어 5종이 공유하고, B는 따로 만든다.

## ★★ QM32C의 `io`에 DisplayPort가 있는데 도면에는 없다

| | |
|---|---|
| 우리 `io` | `IN · DisplayPort` **있음** |
| 매뉴얼 24쪽 도면 | **없음** |

사용자가 **"기준은 매뉴얼이야 최우선이야"**라고 했고, 이번 처리도 **"좋아 그렇게해"**로 승인했다.

→ **도면을 따라 단자 10개로 만든다. DP 번호를 붙이지 않는다.**

→ **`io`의 DP 행은 지우지 않는다.** 범위 밖이다. **불일치를 근거표에 기록**하고 후속 판단에 넘긴다.

### 왜 실사진이 아니라 도면인가

115인치는 **공식 갤러리 실사진**을 썼는데, [W-20261004-010](W-20261004-010.md) 판정이 이렇다.

> **"돋보기 없는 390px 화면에서는 어두운 제품 각인을 독립적으로 읽기 어렵다."**

삼성 사이니지 뒷면은 **검은 제품에 검은 각인**이라 색 대비가 없다. **도면은 흰 바탕에 검은 선**이라 작은 화면에서도 읽힌다.

**도면 하나로 A 묶음 5종을 전부 덮는 이점**도 있다. 실사진이면 5종을 각각 받아야 한다.

## 코드 — `Diagram` 역할을 더한다

`validMap`의 `image`가 지금 **`['Front','Rear']`**만 받는다. 도면은 사진이 아니므로 **`'Diagram'`을 더한다.**

알티컴도 `Diagram` 역할을 쓴다(`qms-44ux`가 `Front`·`Rear`·`Diagram` 보유).

**[W-20261004-010](W-20261004-010.md)에서는 "`Diagram`을 더하지 말라"고 했다.** 그때는 실사진을 `Rear`로 쓸 수 있어 필요가 없었다. **이번에는 필요하다.**

### 좌·우 마커는 이미 열려 있다

[W-20261004-010](W-20261004-010.md)에서 `validMarker`에 `left`/`right` 분기가 들어갔다. 세로 패널이므로 그대로 쓴다.

### 높이 상한도 이미 있다

[W-20261004-014](W-20261004-014.md)의 900px 상한이 적용된다. 290×1420은 세로비 4.9라 **자동으로 줄어든다.** 별도 조치가 필요 없다.

## ★ 같은 파일을 5종이 공유한다

A 묶음 5종이 **같은 이미지 파일·같은 `portMap` 좌표**를 쓴다. 사용자가 말한 **"똑같은 거를 계속 붙여 넣게"**가 이것이다.

- 이미지 파일은 `beta/site/detail/images/`에 **한 번만** 둔다
- 5종의 `images[]`가 **같은 파일명**을 가리킨다
- `portMap.items` **11개의 좌표가 5종 모두 동일**하다

**5종을 각각 손으로 재지 마라.** 한 번 재고 복사한다. 다만 **`alt`와 `sourceUrl`은 제품마다 맞춘다.**
