- 선행 조건: PR #619(W-006) 병합 완료(02f4a7e, 확인됨).

## 목표

타일 모드(4K 패널 가로×세로)에서 벽 구성을 고르면, **가능한 모델 카드마다 그 벽에서 동시에 쓸 수 있는 4K60 믹싱 레이어 최대 수(분할이면 2배)를 바로 보여 준다.** 사용자가 레이어 수를 미리 입력하지 않아도 모델별 한도를 한눈에 비교할 수 있게 한다.

## 할 일

1. 타일 모드 결과의 모델 카드에 "4K60 믹싱 최대 N개 · 분할 최대 2N개" 표시를 추가한다.
   - **N은 기존 평가 함수(`calculateRecommendations`)를 레이어 수를 늘려 가며 호출해 통과하는 최대값으로 구한다(이분 탐색 또는 상한까지 증가). 산식을 따로 하드코딩하지 않는다.** 입력 상한(화면당 8 등)이 걸리면 평가 가능한 범위까지만 표시하고 그 사실을 밝힌다.
   - 레이어 수 입력 칸은 그대로 두되, 입력값과 무관하게 모델별 최대치가 보이게 한다(입력값은 가능/불가 판정용).
2. 불가 모델 카드에는 기존 불가 사유를 유지한다(최대치 표시 없음 또는 "0개").
3. 표시 문구에 전제 두 가지를 짧게 밝힌다: 레이어 수는 출력 그룹당이 아니라 **벽 전체 기준의 동시 믹싱 수**로 환산해 보여 준다는 것(그룹 배분은 계산이 처리), 배경 1장은 별도(자원 미사용)라는 것.
4. 시험 추가: 4×2에서 RS2=믹싱 8·RS4=12·RS6=16(분할 2배), 2×2에서 RSα=4, 16판(4×4)에서 Cmax의 값 — 평가 함수 호출 결과와 일치하는지 확인.

## 하면 안 되는 것

- 최대치 산식·모델별 수치 하드코딩, 제품 JSON·layerPlan 변경, Alta·Midra 평가 로직 변경, 새 제조사 주장 창작. Alta·Midra 모델 카드는 기존 layerPlan 기반 표시를 유지한다(이번 최대치 계산은 Aquilon 타일 판정에 한함. Alta·Midra에 같은 표시가 가능하면 기존 평가 함수 범위 안에서만 한다).
