## 목표와 현재 상태

W-20260926-004(AVer·Lumantek·Logitech) 완료 후, 사용자가 Sony는 직접 이미지를 제공하겠다고 하여 보류하고 나머지 작업을 계속하도록 지시했다. 다음 최소 브랜드는 Panasonic·Analog Way(각 6개)였다.

대상: Panasonic 6개(PT-VMZ71, PT-VMZ61, PT-VMZ51, PT-MZ14K, PT-MZ11K, PT-MZ882), Analog Way 6개(Pulse 4K, Eikos 4K, Aquilon RS2, Zenith 100, Zenith 200, RC400T) = 12개.

## 범위

- 신규 상세 JSON 12개: `beta/site/detail/data/{pt-vmz71,pt-vmz61,pt-vmz51,pt-mz14k,pt-mz11k,pt-mz882,pulse-4k,eikos-4k,aquilon-rs2,zenith-100,zenith-200,rc400t}.json`
- 신규 이미지 9개(WebP, 그중 3개는 시리즈 공용 이미지를 다른 파일명으로 복제해 총 12개 파일): `beta/site/detail/images/`
- `beta/group1-images.mjs`: 12개 슬러그의 이미지 매니페스트·cardImages 추가
- `beta/site/catalog.json`: 12개 항목에 slug·card_image 추가
- `beta/manufacturer-hosts.mjs`: Analog Way에 `website-files.com`(공식 웹사이트 자체 Webflow CDN) 추가

## 완료 조건

- [x] 12개 제품 모두 제조사 공식 자료(공식 제품 페이지·사양 페이지·Technical Datasheet)로 features·specifications·io·documents·images 작성
- [x] Panasonic PT-MZ14K/PT-MZ11K의 카탈로그 표기(L 접미사 없음)가 제조사 공식 모델명(PT-MZ14KL/PT-MZ11KL)과 다름을 발견해 이슈로 기록(임의 수정하지 않음)
- [x] Analog Way 6개 제품 전부 모델 전용 Technical Datasheet(dwn01.analogway.com)로 상세 사양 확인, 이미지도 전면 패널에 모델명이 직접 인쇄되어 있어 전부 VERIFIED로 확인
- [x] RC400T 이미지가 다른 5개와 달리 dwn01이 아닌 analogway.com 자체 Webflow CDN에서 제공됨을 확인, manufacturer-hosts.mjs에 반영
- [x] `node beta/update-snapshot.mjs`·`node beta/verify-pages.mjs`·`npm test` 통과

## 검증 방법

`node beta/build-readable-catalog.mjs && node beta/update-snapshot.mjs && node beta/verify-pages.mjs && npm test`. 로컬 정적 서버로 10개 상세 JSON의 실제 서빙(200 OK)과 필드 값을 확인했다.

## 미결 사항·의존성

- PT-MZ14K/PT-MZ11K의 카탈로그 표기와 공식 모델명(PT-MZ14KL/PT-MZ11KL) 차이는 Work 확인이 필요하다(제조사 표기 오류 추정 또는 국내 유통 관례 차이일 수 있음).
- Panasonic 6개 제품은 모두 시리즈 공용 흑백 투톤 이미지를 사용했고(개별 모델 전용 사진 없음), 모델명 텍스트가 이미지에 없어 FOUND(VERIFIED 아님)로 표시.
- Sony 4개 제품은 사용자가 직접 이미지를 제공하기로 해 이번 범위에서 제외.
