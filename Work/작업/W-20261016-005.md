## 원인 (Work 확인)

`u-bridge-3`의 Port Map 바탕은 `u-bridge-3-diagram.png`(1024×924, 투명 배경)다. 이 제조사 도면에는 **영어 설명선과 글자가 이미 그려져 있다**("USB 3.2 host port", "USB 3.2 device ports" 괄호, "MGMT port", "Power port", "Link port", "RS-232 port"와 각 지시선). 포털 번호 지시선(11개)이 이 설명선·글자를 가로지르거나 나란히 지나가서 두 겹으로 보인다. 예: 1번 선이 "USB 3.2 host port" 꺾은선 옆을 지나고, 4번 선이 "USB 3.2 device ports" 괄호를 관통하며, 7·10번 선이 "Link port" 글자와 세로선에 겹친다.

Work가 그린 현재 상태 미리보기: 세션 A 폴더 `tmp/ubridge/current-portmap-overlay.png`(도면 원본 `tmp/ubridge/diag.png`).

## 할 일

1. **깨끗한 단자판 이미지 만들기**: 같은 제조사 도면에서 **네 개의 단자판(PC HOST 위·아래, DEVICE 위·아래)만** 잘라 새 이미지로 배치한다. 영어 설명선·글자는 넣지 않는다. 모듈 구분이 보이도록 "PC HOST"·"DEVICE" 제목은 남겨도 된다(도면의 제목 글자를 그대로 잘라 쓰거나, 두 열 배치로 구분). 단자판 픽셀은 늘이거나 고치지 않는다(자르기·배치만). 투명 배경을 유지하거나 흰 배경으로 하되 포털의 다른 도면과 어울리게 한다.
   - 파일명 예: `u-bridge-3-panels.webp`(역할은 기존 규약에 맞춰 Diagram 또는 Rear 계열 중 검사가 허용하는 것). 기존 `u-bridge-3-diagram.png`는 **지우지 않고** 갤러리 이미지로 남긴다(제조사 원본 도면 보존).
   - 이미지 note에 "제조사 도면에서 단자판만 잘라 배치, 설명선 제거"를 적는다.
2. **Port Map 다시 붙이기**: 새 이미지를 바탕으로 11개 번호의 좌표를 다시 잰다. 번호·label·desc는 지금 값을 그대로 쓴다(내용 변경 없음).
   - 위쪽 단자판 단자는 위 여백으로, 아래쪽 단자판 단자는 아래 여백으로 번호를 낸다. 지시선이 다른 단자판·제목을 가로지르지 않게 배치한다. 필요하면 위·아래 단자판 사이 간격을 넉넉히 두고 배치한다.
   - 번호는 사진 바깥 여백(AGENTS.md 규약, 원·글자·선 수치 동일), 연속 단자는 범위 라벨(4번 `DEVICE USB-A 1–2`) 유지.
3. `signalFlow`·`io`·문서·사양은 바꾸지 않는다.
