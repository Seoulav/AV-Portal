## ① 01 한눈에 보기 — 사양표를 그대로 퍼온다

사용자가 VS10 화면을 보내며 **"너무 어지럽다"**고 했다. 원인은 `beta/site/detail/app.js:179`다.

```js
for (const specification of data.keySpecifications.slice(0, 4)) {
```

**`keyFacts`가 없으면 사양표 맨 위 4줄을 길이 확인 없이 그대로 넣는다.** 카드 안에 문단이 들어간다.

VS10이 받은 값이다.

| 넣은 값 | 글자 수 |
|---|---:|
| `480i59/576i50(입력 전용), 1080p23~30, 1080i50~60, 720p50~60, 1080p50~60` | **95** |
| `Mix&Effect 1, PIP 2, KEY(LUMA/CHROMA) 1, DSK(FILL/KEY) 1, 패턴제너레이터 2, 미디어 2, 멀티뷰(10/13/16view) 1` | **95** |

### 166종이 이 경로를 탄다

`keyFacts`가 2개 이상인 제품은 **76종**뿐이다. 나머지 **166종**이 전부 폴백이다. 실측 분포다.

| 네 칸 중 가장 긴 값 | 제품 수 |
|---|---:|
| 24자 초과 | **94** |
| 40자 초과 | 37 |
| 60자 초과 | 18 |
| 80자 초과 | **8** |

최악은 NETGEAR `gs728tppv3` **177자**다. 들어간 것이 사양이 아니다.

```
모델 설명 = 선택적 원격/클라우드 관리 및 4개의 SFP 포트가 있는 24포트 기가비트 PoE+ 스마트 스위치
주문 코드 = GS728TPP-300AUS / GS728TPP-300EUS / GS728TPP-300INS / GS728TPP-300JPS / ...
```

**홍보 문구와 주문코드 목록**이다. 한눈에 보는 칸에 들어갈 성질이 아니다.

### 고치는 규칙

`selectKeySpecifications()`(`product-detail-model.mjs:123`)가 길이를 보지 않는다. 폴백 선택에 **표시 길이 기준**을 넣는다.

1. 표시값 = `[value, unit].filter(Boolean).join(' ')`
2. **24자 이하**를 먼저 채운다 (390px 2×2 격자에서 한 줄에 들어가는 길이)
3. 모자라면 **48자 이하**로 채운다
4. **48자를 넘는 행은 쓰지 않는다**
5. 그래도 **2개 미만이면 격자를 숨긴다**

5번은 새 규칙이 아니다. 작성된 `keyFacts`에 이미 같은 규칙이 있다(`detail-enhancements.mjs:100` `length >= 2`). **폴백만 예외였던 것을 없앤다.**

안전망으로 `.long-key-value`에 `-webkit-line-clamp: 2`를 둔다.

### 이것은 응급처치다

근본 해결은 166종에 `keyFacts`를 직접 쓰는 것이다. [W-20261004-003](W-20261004-003.md)에서 Shure 30종부터 시작한다. **이번 변경은 작성된 76종을 건드리지 않는다.**

## ② 버전 표기 — 지금은 어디에도 안 나온다

`beta/site/system-version.js`와 `system-version.css`는 있지만 **어느 페이지에도 붙어 있지 않다.** 오히려 검사가 막고 있다.

```js
// beta/verify-pages.mjs:94
assert.doesNotMatch(homeHtml, /data-system-version|SYSTEM v\d|build local|system-version\.(?:css|js)/);
// tests/system-version.test.mjs:35
assert.doesNotMatch(html, /data-system-version|SYSTEM v0\.1\.0|build local/);
```

그리고 CSS는 **우측 하단**이다.

```css
.system-version{position:fixed;right:14px;bottom:12px; …}
```

### 규칙을 뒤집는 작업이다

사용자가 **"우측 상단에 있게해줘"**라고 지시했다. 이는 **"배포 메타데이터는 내부용"**이라는 기존 결정을 뒤집는다. 명시적 최신 지시가 우선한다([AGENTS.md](../../AGENTS.md) "사용자의 명시적 최신 지시를 우선한다").

- `.system-version`을 **`top:12px; right:14px`**로 바꾼다. `bottom` 선언을 지운다
- 좁은 화면 분기도 `top:8px`로 바꾼다
- `beta/site/index.html`·`catalog.html`·`detail/index.html`에 배지와 `system-version.css`·`system-version.js`를 넣는다
- **막고 있는 검사 3곳을 반대로 뒤집는다.** 지우지 말고 **"있어야 한다"**로 바꾼다
- `beta/verify-pages.mjs:21`의 파일 목록은 이미 두 파일을 포함한다. 그대로 둔다

### 겹침을 확인한다

`.site-header`가 `position:sticky; top:12px`이고 `z-index:20`이다. 배지는 `z-index:100`이라 위에 뜬다. **헤더 오른쪽 끝 요소(검색창·제품 참여 버튼)와 겹치는지 1280px·390px에서 확인**하고, 겹치면 `top` 값을 헤더 아래로 내린다. `pointer-events:none`이라 클릭은 막지 않는다.
