## 규칙 (D4 확인 대상)

| 지금 끝맺음 | 바꾼 뒤 | 예 |
|---|---|---|
| `~을 지원한다.` | `~ 지원` | `Dante 64x64 채널 오디오 네트워킹을 지원한다.` → `Dante 64x64 채널 오디오 네트워킹 지원` |
| `~을 제공한다.` | `~ 제공` | `… 2개의 전용 멀티뷰어 출력을 제공한다.` → `… 2개의 전용 멀티뷰어 출력 제공` |
| `~할 수 있다.` | `~ 가능` | `실시간 소스 축소판을 보며 제어할 수 있다.` → `실시간 소스 축소판을 보며 제어 가능` |
| `~로 구성되는 ~ 설계다.` / `~이다.` | 명사로 끝냄 | `… 모듈형 설계다.` → `… 모듈형 설계` |
| `~을 갖췄다.` / `~이 있다.` | `~ 탑재`·`~ 구비` 중 원뜻에 맞는 것 | `이중화 이더넷 포트를 갖췄다.` → `이중화 이더넷 포트 탑재` |
| `~이 포함되지 않는다.` / `~ 없다.` | `~ 미포함`·`~ 없음` | `이더넷 케이블은 포함되지 않는다.` → `이더넷 케이블 미포함` |
| `~합니다.`·`~입니다.` | 위와 같음 | |
| 명사형인데 끝 마침표만 | 마침표 삭제 | |

지킬 것:

- **사실·수치·모델명·단서를 지우거나 바꾸지 않는다.** 바꾸는 것은 끝맺음과, 끝맺음을 위해 필요한 조사(`을/를`)뿐이다.
- 한 문장 안에 `~하며, ~한다.`처럼 서술이 이어지면 앞 서술도 명사형으로 맞추고 `,`·` · `로 잇는다. 문장을 둘로 쪼개거나 합치지 않는다(항목 수 유지).
- 「~은 마이크로폰이 아니라 …이다」처럼 **부정·구별 설명**은 뜻이 약해지지 않게 `… 마운트 키트(마이크로폰 아님)` 식으로 남긴다. 애매하면 대조표에 「검토」로 올린다.
- `source` 필드, 항목 순서·개수는 그대로.
- 명백한 오타가 보여도 이번에는 고치지 않고 대조표 「오타 후보」 칸에만 적는다(계획서 §7).
