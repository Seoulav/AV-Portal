# W-20261017-011 — Aquilon 뒷면 포트맵을 슬롯 중심으로 재구성

- 명세 상태: **READY**
- 작성 담당: Work
- 작성일: 2026-10-17
- 담당 세션: C (Analog Way 포트맵 담당 경력)
- **승인 근거** (2026-10-17): 사용자 지시 "아날로그웨이 뒷모양 사진들이 조금 수정이 필요할 것 같아. 전반적으로 슬롯 부분은 그냥 슬롯, 특정 슬롯을 표현해 주고. 뭔가 좀 아쉬워." (휴대폰 캡처로 Aquilon 뒷면 포트맵을 지적)
- 대상: 슬롯식 섀시인 Aquilon RS alpha·RS1~RS6·Cmini·C·C+·Cmax (11종)의 Rear 포트맵. Alta·Midra(고정 단자)는 제외.

## 현재 문제 (사용자 캡처 기준, 예: RS 계열 Rear)

1. 번호가 "HDMI 입력 카드(2장)"처럼 카드 종류를 묶어 가리켜서, 어느 슬롯에 무엇이 꽂힌 구성인지 읽히지 않는다.
2. 번호 순서가 화면 배치와 어긋난다(왼쪽에서 4번이 3번 위에 있고, 아랫줄이 8·10·9 순으로 보임).
3. 사진이 "장착 예시"라는 사실이 설명 꼬리말에만 있어 약하다.

## 새 기준

1. **슬롯 번호 우선**: 입·출력 카드 슬롯을 왼쪽→오른쪽, 위→아래 순서로 "슬롯 1, 2, 3…"으로 매긴다. 포트맵 번호 = 슬롯 번호가 되게 하고, 설명은 "슬롯 N — 사진 예시: HDMI 입력 카드 · IN 1~4"처럼 **슬롯(고정) + 장착 카드(예시)**를 구분해 적는다. 빈 슬롯도 "슬롯 N — 빈 슬롯(덮개)"으로 표기한다.
2. **고정부는 이어지는 번호**: 슬롯 번호 다음에 USB·SYNC·LOCK·LAN·MULTIVIEWER·Dante·GPO·전원 등 섀시 고정 단자를 왼→오 순서로 붙인다.
3. **번호 표시 순서 정렬**: 화면에서 번호가 좌→우, 상→하로 자연스럽게 읽히게 좌표를 정리한다(현행 4↔3, 9↔10 역전 해소).
4. 사진 위 요약 또는 설명 첫 줄에 "슬롯식 섀시 — 사진은 카드 장착 예시이며 실제 구성은 주문에 따라 다릅니다"를 명시한다.
5. 기존 포트맵 규칙(W-20261016-015)은 그대로: 번호는 사진 바깥 여백, 괄호는 가장자리, 관통·오인 0, 390px 확대 확인, 원 r=10·글자 11px·#007AFF. 사진 파일 수정·창작 금지.
6. 단자 이름·io 값이 바뀌는 경우(카드→슬롯 재구성에 따른 설명 문구 변경)는 근거(제조사 자료의 슬롯 구성)와 함께 기록한다. 수치·사양은 바꾸지 않는다.
