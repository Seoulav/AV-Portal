## 착수 판정과 다음 조치

READY, 사용자 승인, 선행 조건, 실제 main 병합이 모두 충족되고 미완료 작업일 때만 착수 가능하다. 병합 전 이 파일은 **Codex 착수 불가 — main 병합 전**으로 기록한다. 미충족 조건별 담당자와 조치를 적는다. 문서 병합만으로 제품 기능을 승인하지 않는다.

## 사용자에게 전달할 결과

Work는 실제 PR 상태를 재조회하고 명세·이 인계서 경로, 확인 시점, PR·병합 SHA, 착수 판정, 필요한 다음 조치를 결과 보고에 적는다. 인계서가 병합 전 스냅샷이면 그 사실과 실제 병합 증거를 함께 보고한다.

착수 가능할 때만 [Work 안내](../README.md)의 작성 규칙에 따라 실제 ID·경로·PR·SHA·승인·선행 조건이 모두 채워진 **Codex 구현 프롬프트 하나**를 결과 보고에 포함한다. 사용자가 값을 찾아 넣게 하지 않는다. 착수 불가 또는 이미 완료된 작업이면 구현 프롬프트를 제공하지 않는다.
