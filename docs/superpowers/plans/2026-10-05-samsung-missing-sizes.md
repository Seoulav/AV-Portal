# W-20261005-006 구현 계획

기준: `origin/main` `be86caa59f6077feb4c23e61e1baf251f910cb8c`. 범위는 HU8000F 3종과 BEHX-H 5종의 신규 등록뿐이다.

1. 삼성 국내 제품 페이지의 각 모델 스펙 탭과 해당 모델 갤러리 URL을 기록한다. HU8000F 매뉴얼 적용 모델과 BEHX-H 설치가이드의 모델별 치수표를 대조한다. 근거가 없는 값과 사진은 만들지 않는다.
2. 기존 제품의 필드 구조를 따라 8개 상세 JSON과 카탈로그 항목을 추가한다. 스펙 값은 각 모델 페이지에서 개별 대응하고, 설명서의 공용 단자 정보만 적용한다. 기존 제품 파일은 변경하지 않는다.
3. 제품별 문서 연결 및 사진의 모델 대응을 확인한다. 사진은 제품별 파일로 저장하고 해시·원본 URL을 기록한다. Port Map은 만들지 않는다.
4. 8종 전용 검사와 기존 삼성 묶음·자료·I/O 검사를 보완한다. 과거 해시 검사는 승인된 추가 항목만 선택적으로 되감고 다른 현재 필드는 그대로 검사한다.
5. 검색 인덱스와 읽기용 카탈로그를 생성하고 명세의 전체 검증을 실행한다. 1280px·390px 화면과 잠긴 PDF 12건을 확인한 뒤 독립 검토·PR·병합·Pages 공개 화면을 확인한다.
