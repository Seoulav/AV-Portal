# 점검표 양식

`Work/기록/<작업ID>-점검표.md`에 쓴다. 제품 하나 = 절 하나. 표식은 번호순으로 **빠짐없이**.

```markdown
## <slug> — <제조사> <모델> · <image> 사진 <width>×<height> · 표식 <N>개

- 사진: `beta/site/detail/images/<file>` · crop: 없음 | top <t> / bottom <b>
- 숫자 검사: 없음 | SAME_COORD 1·3 / STACKED 5·7 …
- 형제 공유: 없음 | <slug>, <slug> (사진 동일 확인함 / 사진 다름 → 따로 판정)
- 요약: OK <a> · 좌표 수정 <b> · 확인 요청 <c> · 판정 불가 <d>

| n | label | 정체 | 개수 | 범위 | 높이 | 이웃 | 판정 | 전 → 후 / 메모 |
|---|---|---|---|---|---|---|---|---|
| 1 | 아날로그 입력 A · 1–4 | ✓ 인쇄 `A` | ✓ 4 | ✓ | ✓ | ✓ | OK | |
| 2 | HDMI IN 2 | ✓ 형상(글자 미확인) | ✓ 1 | ✗ 왼쪽 38px 모자람 | ✓ | ✓ | 좌표 수정 | x1 1210→1172 |
| 3 | RS-232 | ✗ 구간 안은 USB-A | — | — | — | — | 확인 요청 | 인쇄 `SERVICE`. RS-232는 오른쪽 옆 D-sub로 보임 |
```

칸 쓰는 법:

- **정체**: `✓ 인쇄 <읽은 글자>` · `✓ 형상(글자 미확인)` · `✗ <실제로 보인 것>`
- **개수**: `✓ <수>` · `✗ 라벨 <a> / 사진 <b>`
- **범위·높이·이웃**: `✓` 또는 `✗ <어느 쪽으로 몇 px>`
- **전 → 후**: 바꾼 필드만. `x1 1210→1172, y 295→301`

맨 위에는 전체 요약을 둔다.

```markdown
# W-20261012-001 Port Map 점검표

- 기준: origin/main <SHA> · 도구: scripts/portmap-audit.py · 스킬: .claude/skills/portmap-audit
- 대상 <P>종 <M>표식 · OK <a> · 좌표 수정 <b>(<p>종) · 확인 요청 <c> · 판정 불가 <d>
- 보류(열린 PR과 겹침): <slug> — PR #<n>

## 확인 요청 모음
| slug | n | label | 본 것 | 질문 |
```
