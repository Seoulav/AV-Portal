## 2. 명사 서술(`~이다`·`~다`) — 제품 정체를 말하는 문장

| 실제 예 | 바꾼 뒤 |
|---|---|
| `1채널 수신기다.` | `1채널 수신기` |
| `… 모듈형 설계다.` | `… 모듈형 설계` |
| `MX418D/C는 18인치 길이의 카디오이드 구스넥 콘덴서 마이크로폰으로, … 빠르게 설치·철거할 수 있도록 설계되었다.` | `18인치 길이의 카디오이드 구스넥 콘덴서 마이크로폰, … 빠르게 설치·철거할 수 있도록 설계` |

주어로 제품명을 다시 쓴 경우(`MX418D/C는 …`): **지우지 않는다**가 기본이다(영문 토큰 보존 검사). 지우는 편이 자연스러우면 「검토」로 올린다.

## 9. 판단이 갈리면 — 「검토」로

- 부정·구별(`~이 아니라`)
- 조건·한정(`~일 때만`, `~ 기준`)이 끝 동사에 붙어 있어 떼면 뜻이 넓어지는 경우
- 주어(제품명)를 지워야 자연스러운 경우
- 한 문장이 너무 길어(약 120자 초과) 명사형으로 끝내면 읽기 어려운 경우 — 쪼개지 말고 그대로 두고 올린다
